# Phase 2：GitHub Pagesで通常8イベントを操作できる試用画面（2026-10-23）

## 目的と入口

[ブラウザ用の開発プレビュー](https://nimrodx0.github.io/Umasupport/poc/phase2-eight-preview.html) を、新規の `poc/phase2-eight-preview.html` として用意する。リポジトリをクローンせずブラウザから、固定GT未収録SSR30318〜30321の通常イベント **8件・16選択肢・4件のスキルヒント**を試せる。4枚のカードを切り替え、各イベントについて「未選択／上／下」を操作。GameWith採用値の能力・体力・絆などの数値と、選択時に本番集計エンジン `UmaCore.directRoutes` が返すヒント候補を区別して表示。

**これは誰でもURLから閲覧可能な開発用試用ページ**であり、非公開ローカル審査画面と異なる。通常版の正式承認済みイベント収録や、第三者由来素材の包括的な公開許諾を意味しない。

## データ境界

- `poc/src/phase2_eight_pages_preview_artifact.cjs` は既存の限定編集台帳の `phase2_eight_event_review_view` を再検証し、公開試用専用の**最小構造化数値データ**を生成する。
- `poc/preview/phase2-eight-events.v1.json` は上記生成結果とNode CIで**深い一致**を検証し、4サポカ／通常8イベント／16選択／4ヒントから外れる変化を拒否。イベント短見出し・出典URL・上／下の位置・数値効果・ヒントID/Lv/名称のみを含む。
- イベント本文、選択肢のゲーム・攻略サイト原文セリフ、画像、連続12段階、未裁定の結果・打ち切りは含めない。発生確率やゲーム内での実取得は再現しない。
- `poc/data/reviewed_events.v1.json`、`poc/config/event-release-approvals.v1.json` は引き続き**0件**。 `poc/live.html` のデータ読込、設定やキャッシュ機構に変更なし。プレビュー用スクリプトは独立して起動し、通常アプリへの承認なし混入はできない。

## 確認項目（A/B/C）

- A：Nodeで公開プレビューJSONを元の非公開編集資料と比較。GitHub Pagesの静的相対パスで読み込み、不正な `formallyApproved:true` データを拒否。実コアで未選択はヒント0、4件の各位置の選択は1件、別位置は0件をChromiumで確認。
- B：出典は既にGameWithを用いて個別裁定したGT欠損4SSRの限定8件のみ。GameTora固定全2,488件の正式公開承認ではない。
- C：Playwright Chromiumの390pxと1280pxで4枚切り替え、全4件のスキルヒント、スクロールの横溢れ、改変拒否を試験。**公開Pagesへの反映後**はHTTP経由でアクセス可否を確認する。Windows/Android物理端末での試用はユーザー側に確認を依頼する。

## 今後の正式収録

公開用の独自イベントDBへ正式採用するには、イベント見出しと選択肢の識別しやすさ、採用した数値の例外、出典および公開利用範囲、各イベントSHAと6項目の承認を従来のゲートで確定する。**オンラインで試せること**と**本番に採用したイベントであること**は独立した扱いとする。
