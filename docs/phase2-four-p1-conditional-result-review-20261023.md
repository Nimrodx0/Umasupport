# Phase 2：Checker P1・成功／失敗の4位置とスキル経路への影響（2026-10-23）

## 出典と判断

[残存16位置のスキル影響全件監査](phase2-remaining-checker-skill-impact-20261023.md)では、SSR30180のP0欠損を非公開2,512候補へ補完済み。次の優先候補はCheckerの条件付き効果を含む**4位置**。固定Checker `checker_event_hints.v1.json` の数値ID・ダイジェストを、既存のP1監査結果と正確に照合した。

| カード | Checkerイベント位置 | 条件付き選択・結果行 | Checkerの数値スキルヒント |
| --- | ---: | ---: | ---: |
| SSR30067 玉座に集いし者たち | 10 | 3 | 0 |
| 30081 | 12 | 3 | 0 |
| 30137 | 10 | 3 | 0 |
| 30160 | 10 | 1 | 0 |
| **計** | **4位置** | **10行** | **0件** |

**30067を個別調査**：固定GT側の[玉座に集いし者たち](https://gametora.com/ja/umamusume/supports/30067-the-thrones-assemblage)を確認した。GameWith[イベント個別記事](https://gamewith.jp/uma-musume/article/show/352660)「鍛えよ共に(温かなメッセージ)」では、**3つのプレイヤー選択それぞれに成功・失敗**が記載される。効果の差は主にステータス／スキルPtであり、**どの結果にもスキルヒント報酬は掲載されない**。「友人2回目以降イベント」であり、連続イベントの打ち切り分岐として表示されていない。

ただし、元Checkerのイベント位置10を、固定GTのあるイベントIDに**完全同定できたわけではない**。公開イベントを足したり、GTの別イベントと自動対応付けたりせず、GameWithの当該**条件分岐に新規スキル報酬が無いという具体的事実だけ**を編集採用する。ユーザーの規則「明示的な打ち切りなしなら次段階フラグON」は維持し、発生確率はモデル外。

## 実装

`poc/src/phase2_four_p1_outcome_review.cjs` が、Checker全2,109イベントの候補DB検証と、4カードの元イベントordinal・sourceKey・sourceDigest・選択肢の条件付きフラグ・**数値スキルヒント0件**を改変拒否で検査する。30067だけ出典記事に限定した編集上の非スキル報酬結論を記録し、残3件はカード／イベント記事の追加調査を保留する。

データの出力はカードID・位置・条件フラグ・個別採否だけ。記事本文・選択肢文言・原ゲーム画像は含めない。**2,512件の非公開候補・正式公開0件は変えない**。SSR30240の連続3段階とChecker側の未対イベント同定はこの監査では解消していない。

### A/B/C

A：Nodeで全4位置の厳密な照合と、sourceKey・digest・hint件数・公開区分を改変した負のテスト。B：固定GT/Checker全件ワークフロー内で実2,109元Checker候補と全2,511件の数値優先監査を同時に通し、30067と残3位置の母数を実測。C：新しい公開イベントやUIを作成しないためPages操作は対象外。実ゲームの発生抽選・掲載権利を新たな採否条件に加えない。

**次の作業**：30081/12、30137/10、30160/10の3位置をGT対象カードで確認し、GameWithイベント記事と比較してスキル取得・連続打ち切り・結果報酬への実質的影響を順に裁定する。

## 追加の3カードのGT/GameWith照合（2026-10-23）

最優先P0修正後のP1条件結果の残り3カードについて、固定GTの対象カードイベントJSONを**元カードID指定**で読み、各カードのGameToraページを確認したうえで、当該GameWith記事の条件付き結果と突き合わせた。Checker側の `ordinal` をGTイベントIDへ断定対応させる根拠はまだない。従って**カード単位の出典確認と、Checker元位置の同一性確定は別**。

`phase2_four_p1_outcome_review.cjs` は、元Checkerの4件・条件行10・数値ヒント0・元位置SHAの既存確認に加え、3カードの参照イベントと条件分岐の種類を**公開不能な全文ではなく出典URLと独自の短い分類語**で記録する。3位置は `checkerOrdinalIdentityProven:false` のまま、`eventIdentityPaired:false` を維持し、`skillGrantAdded:false`／`chainFlagChanged:false` とする。30160はカード全体に別のスキル・お出かけ終了がある注意だけ添付する。

**進捗の厳密な区分**：4位置のうち30067は既にイベント個別の非スキル事実を採用、その他3カードは対象カードのGameToraとGameWith記事の関連分岐を調査した。しかし、Checker元イベントからGT／GameWithに向けた**固有イベントID・位置の一対一対応は依然4件とも未確定**。Checkerの0ヒントは「実ゲームの全ての関連選択が無ヒント」を意味しない。

A：新しい3カードの参照記録・30160の別イベント警告、元出典digest改変・未承認昇格拒否の合成テストを既存P1監査に追加。B：固定全件監査はPR専用ワークフローで実行し、通過した結果だけ合格とする。C：通常Webアプリ・公開イベントJSONは不変なのでUI操作ゲートは対象外。

次工程はChecker元側のイベント見出し（権利に配慮したローカル照合・SHA等）とGameToraのイベントID／原位置との一対一対応を固定し、結果／スキル経路が実際に変化する位置だけを追加裁定する。公開イベント0件・非公開2,512件を維持。


## 2026-10-23後続裁定による訂正

この文書の「GTの同名イベントがChecker元イベントに対応しそう」という初期推測は**イベントIDとしての同定ではない**。Checker元見出しの固定`sourceKey`を検証した[後続調査](phase2-p1-title-key-crosscheck-20261023.md)で、30067・30081・30137は共通見出し「温かなメッセージ」、30160は国内の「お疲れ様！！」とは別の海外イベント「労いのエール」であると確定。さらに[GameWithの共通イベント説明と2カードの海外結果の限定採用](phase2-p1-larc-replacement-and-mei-overseas-20261023.md)により、前3件は**L'Arc夏遠征中の表示置換で、GT元イベントと報酬効果は同一。加算・新イベント化しない**。最後の1件は**R10094とSSR30160双方で別の海外限定イベント**として、スキルヒントなしの数値結果を独立した編集メタデータに記録。元の未承認GT/Checkerイベント同一性台帳は変えない。
