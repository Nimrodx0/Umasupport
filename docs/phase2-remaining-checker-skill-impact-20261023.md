# Phase 2：残存Checker 16位置のスキル経路影響による優先順位（2026-10-23）

## 対象

[SSR30301の個別編集裁定](phase2-30301-gt-hint-vs-checker-event-20261023.md)の後に残る、GTカードあり・Checker個別イベント同定未了の**9枚／16位置**。両固定データにないSSR30240の連続3段階は別の問題なので別表示にする。

前の65位置監査や2,511件本番互換統合は**実収録イベントの全件性を証明していない**。CheckerはGameWith由来の候補であり、イベント報酬と通常ヒント、条件分岐、原文表現の取り違えがあり得るため、未対応Checker行を機械的に実イベントとして追加しない。

## 新しい監査

`poc/src/phase2_2511_remaining_checker_skill_impact.cjs`は既存のテキストを持たない`checker_event_hints.v1.json`（元Checker固定出典に由来する未承認スキル候補）と、[全2,511件の非公開統合モデル](phase2-private-2511-chain-loader-20261023.md)を、安定sourceKey・カードID・Checkerイベント位置・候補ファイルにあるdigestで結ぶ。**名前でスキルIDを同一化しない**。

- **P0**：Checkerには数値ヒントIDがあるが、そのIDがGT基準カードの**イベント報酬**には見当たらない。通常ヒントにあればイベント収録漏れとは限らず、必ずGameToraのカード記事を確認したうえでGameWithの該当イベント報酬を調べる。
- **P1**：候補の数値IDが未解決、効果のヒント表記が未解析、または成功／失敗などの結果条件を含む。報酬を無条件に加算しない。
- **P2**：未対イベント位置に、未収録数値ヒントも未解析条件も見つからない。Checkerにスキル記載がないことは、全報酬や打ち切りの正しさを保証しない。

元Checker候補の数値IDと現在のGTイベント報酬の一致を、**カード全体で比較**する。これは「同一イベントとペアになった」「ヒントLvや経路まで一致した」という意味ではない。未対16件は引き続き編集対象だが、スキル報酬が無い可能性の高い位置から処理する必要はない。

### 自動ゲート

- `checker_candidate_database.validate`で固定未承認候補の形式、digest、数値スキルID／ヒントLv、配列順と件数を検証。
- 固定GT/Checkerソースpin、残件監査のsourceKey／ordinal、元2,511イベントのSHA一致を確認。
- Checker側の報酬候補の数値IDがカード内イベントに既存か／非収録かを区分。名称だけでの一致やイベントIDの自動推定はしない。
- 取得した全16元位置にP0/P1/P2を付与し、元未承認候補から公開イベントを作らない。
- 固定GT全件CIで**第三者原文・元Checker文章をログに出さず**、カードID・Checkerイベント位置・数値ID・件数のみをメタデータとして出力する。人工fixtureと実固定出典Bを混同しない。

現段階で**正式公開イベント0件、2,511非公開技術候補**を維持。C（公開サイト全カード操作・Windows/Android実端末）はこの監査で行わない。

## 2026-10-30 後続整理：P0/P1裁定済み、P2の11位置だけがイベント同定未完

**この節は2026-10-23時点の16位置監査からの後続分類であり、旧P0=1、P1=4、P2=11という当時の測定値を改ざんしない。** 後続の[SSR30180非公開補完](phase2-30180-special-cornering-2512-20261023.md)でP0は対応済み。[P1の4位置の裁定](phase2-p1-larc-replacement-and-mei-overseas-20261023.md)により30067/10、30081/12、30137/10はL'Arc中の既存イベントの表示置換で**追加報酬0**、30160/10は海外限定の**別イベント（非スキル報酬の事実は編集採用、既存2,512候補には未統合）**と判明済み。元Checkerの16位置を一律に再照合しない。

## 固定全件実測結果（2026-10-23）

[GT/Checker全件Action](https://github.com/Nimrodx0/Umasupport/actions/runs/39942584498) **PASS**。未対16元位置の分類は**P0=1、P1=4、P2=11**。

- **P0：SSR30180「刻み続ける者たち」、Checkerイベント位置7**。数値ID`200332`（「コーナー巧者○」）がCheckerのイベントヒント候補に存在するが、固定GT2,511件の同カードの**イベント報酬**には存在しない。該当カードの[GameWith個別記事](https://gamewith.jp/uma-musume/article/show/431692)には「あなたを想って」（選択なし、クラシック級1月前半）で「コーナー巧者◯」ヒントLv1と明記される。固定GameToraの[カードページ](https://gametora.com/ja/umamusume/supports/30180-group)の対応カードも確認した。これは出典方針に従って、個別イベント位置・ヒントレベルを編集採用して補完する優先候補。
- **P1：30067/10、30081/12、30137/10、30160/10**。Checkerには成功／失敗等の条件を含む結果行があるが、この固定数値ヒント抽出では新規のスキルIDは検出しなかった。選択／結果・連続終了に関係する可能性を継続調査。
- **P2：残り11位置**。うち**30137/4・5・6および30207/1**の4位置では、Checkerに報告される数値ヒントIDが同じGTカードのイベント報酬中に存在した。ただし同一イベントID・同一分岐まで確認できた意味ではない。残り7位置はCheckerの元候補から新しい数値ヒントIDを検出しなかった。

**SSR30240の連続3段階は16位置とは別の欠損案件。** 本監査では出典に明記のない内部結果とLvを補完しない。正式公開0件のまま。次にSSR30180をGameWithの明示値から本番互換の**非公開**イベント型へ追加する。
