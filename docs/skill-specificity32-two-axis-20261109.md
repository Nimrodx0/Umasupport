# P2：元32順位条件の10m成立機会と4脚質特異性を分離した検証（2026-11-09）

**状態：固定GlobalSim v77の均衡編成1,440レースを再実行し、既存30シードの成果物SHA-256が完全一致することを確認。さらに前半15シードと後半15シードを独立に集計し、元77スキルの81 AND/OR経路から重複を除いた32条件×4脚質の2軸を評価。6脚質ペア×32条件＝192比較のうち146比較は全該当設定・両半群で厳密に同方向、46比較は保留。高／中／低閾値・本番ラベル・カード得点は未採用。**

仕様判断は[2軸評価のユーザー合意](decisions.md)、旧研究は[4脚質比較](skill-position-balanced-four-style-rule-20261106.md)、最新の成立機会と背景は[10mランダム窓・元77件の監査](skill-subphase10-77-audit-20261107.md)、[ダート17件](skill-dirt17-10m-audit-20261107.md)、[コース・頭数・能力の感度](skill-context-stability-77-audit-20261107.md)を参照。今回の再実測は**第2軸のみを現行10m窓へ合わせた研究用改訂**であり、古い占有率・一様順位基準を無言で上書きしない。

## 1. 第1軸と第2軸の定義

| 観点 | 使用する式／データ | 実際に説明できること |
| --- | --- | --- |
| **第1軸：成立機会** | `W_style = 10mランダム抽選窓の中に元順位条件を満たす地点が含まれる幾何学的な機会` | 固定無スキルモデル内の該当局面・順位ANDに対する、特定脚質の成立機会の大きさ（0～100%） |
| **第2軸：脚質特異性** | 同一発動条件・同一コース／9または12頭／能力モードで `S_style = W_style - (W_逃+W_先+W_差+W_追)/4`（**パーセントポイント**） | そのモデル設定において、脚質4種を等重みで扱った平均に対する有利・不利 |
| **第2軸：相対優劣の厳密な比較** | 元条件が同じ6脚質ペアごとの `W_A-W_B`。**全該当モデル設定で符号が同じで、前半15seed・後半15seedでも同符号**の比較だけ報告 | 確定したモデル比較の部分順序。片方の符号逆転・0差・半群の不一致は `held` |

第2軸は**第1軸の数値から作る比較量**であって、統計的に独立した新しい標本ではない。「2軸」は**回答したい問いとデータの見せ方を区別する設計**であり、数学的に無相関な2変数という意味ではない。両軸を一つの総合スコアへ加算しない。第2軸の正符号であっても第1軸が極めて低ければ、発動しやすいと評価しない。

今回、過去の1地点順位占有率に使用した `100 × (順位帯の整数順位数/出走頭数)` の「全順位一様」基準を、**10m窓の成立機会から直接減算しない**。1地点の無作為順位と10m区間に1度でも成立する事象ではサンプリングの機構が違うため、一方の理論基準を他方の期待値として採用すると見かけ上の脚質特異性が歪む。今回の `S` はその代わり、**同一条件で実際にモデル測定した4脚質の平均**を参照する。

## 2. 固定出典・モデルの範囲

- 2026-11-07の元77件・81元AND/OR経路監査から、厳密な元時期窓・順位帯・距離・芝／ダート条件を一致させた[32種類の派生マニフェスト](../poc/data/p2_position_condition32_research.v1.json)を採用。芝26種類・ダート6種類。複数ORを持つ元スキル4件は**元AND経路を別々に評価**し、合併成立確率へ勝手に格上げしない。例：元ID `204511` は同一スキルでも中距離用と長距離用で**別条件**。32条件は31の異なる元スキルIDを含み、77件全体の無作為標本ではない。
- 固定UmaSim技能辞書SHA-256：`4c036527bbe6b5aad34d7f12110a06094c9071514e37fdfc68ae195403333be5`。固定GlobalSim v77：`80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1`。**モデルの出力は日本版の真のスキル発動率ではない**。
- 芝6コース＋ダート6コース、均衡脚質9頭（逃2・先2・差3・追2）／12頭（各脚質3）、能力equal／人工jitter10%、各30seedで合計**1,440モデルレース**。元条件の明示距離・芝／ダートに合う実在モデルコースだけ選択する。
- 9頭／12頭の元整数順位条件（`order_rate`）を既存のソース対応変換器で解釈。全局面`phase_random`だけでなく、先行研究で検証した`phase_firsthalf_random`／`phase_laterhalf_random`の厳密な抽選時間窓も含む。
- [再測定器](../poc/tools/globalsim_specificity32_split_replay.cjs)は全30seedを元の観測順に再集計し、**PR #370の均衡編成レポートSHA-256 `63a6e44656684bf94cebe4dba7c2118a1c9668e8d4623c02321876949ec2a6b2` に完全一致**することをチェック。同じ1440レースを15seed×2群にも別集計し、各コース／頭数／能力／元条件／脚質の平均値と走者分母が全30seedに一致することを確認。両半群は30seedとは別の実験レースではなく、**同じレースの相互排他的な分割**。
- 平均は元条件に合うコース数（1・2・6）×頭数2×能力2の**4／8／24文脈**に等しい重み。**現実の対戦で各文脈や各脚質の出走確率が等しいとは証明していない**。旧1地点モデルとの比較や、人工的な前方偏重／後方偏重／逃げ不在の出力は今回の標準2軸へ混ぜない。

## 3. 実測の4脚質ペアの判定状況

| 調べた192脚質ペア | 件数 |
| --- | ---: |
| **全対象設定で30seedの大小が厳密に同方向** | **156** |
| そのうち両15seed半群でも**全設定で同方向** | **146** |
| 30seedでは全設定同方向だが、半群で同方向を再現できず保留 | 10 |
| 30seedの時点で同値や設定依存の逆転などがあり保留 | 36 |
| **総保留** | **46** |

芝156比較中は**119厳密方向・37保留**、ダート36比較中は**27厳密方向・9保留**。方向が定まった146件については、全対象文脈と両15seed群の双方で符号が揃っている。ただし半群同士が数値的にどれだけ離れたかも集計可能である。**「厳密に符号が揃う」は日本版ゲームでの再現性や統計的な信頼区間、実際の発動率差の有意性を保証しない**。絶対差の大きさやモデルの構造に注意する。

### 全員を1～4位に並べない理由

厳格な6ペア関係を適用すると、**128条件×脚質ケースすべてに少なくとも1つ「比較保留」の相手がある**。したがって「1位・2位・3位・4位」という完全な脚質順や「相対的最高・最低」をどのケースにも自動割当しなかった。

これは情報がないという意味ではない。たとえば「逃げ＞差し」「先行＞差し」が厳密に確かな一方、「逃げ vs 先行」では同点が含まれ保留となるケースがある。**確かな部分順序の辺だけ保持し、未知の辺を同値または優劣なしとして補完しない**。

## 5. 評価表示に関する研究用ルールと未決事項

- **第1軸は実数値**（0～100%）で保持。頭数・明示距離・馬場・抽選窓の適用条件も保持し、実ゲームの発動確率と呼ばない。
- **第2軸は符号付きSと部分順序**を保持。符号だけで「高適合／低適合」へ変換しない。研究出力の小数6桁で差が0として観測された場合は、優劣を確定しない。大小方向が設定・半群で割れれば`held`にし、どこで符号が変わったかを記録する。
- 4脚質を対称な重みで比較したSは相対的な記述量。**その脚質が現実で何割出走するか**や、大逃げの出走分布の代用にはしない。実際の出走者数で重み付けする標準評価は未承認。
- 元スキルには追加ANDや`preConditions`が残るもの、4件の複数OR経路を含むものがある。**元順位条件の部分評価からスキル全体の発動率へ、スキル全体からサポカ評価へ自動変換しない**。
- 旧「前方群・後方群」モデルと順位占有率を新しい10m特異性と同一視しない。本研究は第2軸の測定条件を統一したもので、旧公開53スキルのラベルを変える承認ではない。
- 成立機会の高／中／低閾値、脚質特異性の表示区分・不確かさの表現方法、サポカP3集約、実ゲームの発動後効果の有用性、物理端末での表示・操作は引き続き未決／未検証。
