# Phase 2：ランダムイベントからのお出かけ解放と打ち切りの全件共通化（2026-10-26）

## 背景と根拠

固定GameTora由来元 `systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67` のイベント **2,488件**のうち、従来30件が元データの内部規則を確定的な非スキル結果へ投影できず保留だった。そのうち14件は全て次の構造を共有する。

- サポカのランダムイベント `section:'random'`、`event_type:'pd'` に複数のプレイヤー選択肢がある。
- 出典のある選択肢に `chain_end` があり、別の選択肢は終了しない。
- 同カードに `section:'dates'` のお出かけイベント列が存在し、`section:'arrows'` の通常連続イベント列は存在しない。
- 同カード内で終了を伴うランダムイベントはただ1件だけである。

固定元の [`event_engine.py`](https://github.com/systemless10/UmamusumePS/blob/6e38b54af4fad397ff4491e63007a90705a4fe67/server/app/event_engine.py) に、この `chain_end` はそのサポカの **お出かけ等の連続イベントを終了**させるが、当該サポカの他の**ランダムイベントを無効にする効果ではない**と明記。これは外部のイベント発生抽選を再現するという意味ではない。

既存の [`gametora_app_schema_dry_run.cjs`](../poc/src/gametora_app_schema_dry_run.cjs) は同じ出典構造のときだけ `candidateUnlock` を採用し、通常ランダム側の選択肢結果に `terminal:true` を保存していた。非スキル監査だけは、それまで `chain_end` を矢印チェーン以外では常に拒否しており、同じサポカのお出かけ解放規則を別々の判定として扱っていた。

## 実装と誤判定防止

[`phase2_gt_whole_nonskill_effect_inventory.cjs`](../poc/src/phase2_gt_whole_nonskill_effect_inventory.cjs) の各固定サポカの元イベント一覧に、既存スキルプロジェクタと同条件の `outingUnlock` 判定を追加した。**カード個別の専用関数は追加しない**。終了ランダムイベント1件、継続側選択、`dates` の有無、`arrows` の不存在、元イベント種別 `pd` を満たすときだけ、該当結果の引数のない `chain_end` を `terminal:true` として認める。その他の終了マーカーや不明な出典条件は引き続き保留する。

最終結合は [`phase2_2512_private_effect_join.cjs`](../poc/src/phase2_2512_private_effect_join.cjs) の既存の厳格なプロトコルを使用し、**非スキル結果の `terminal` と既存スキル結果の `terminal` が同一**、選択肢数・各結果順位・イベント種別が一致する場合に限る。報酬値、選択肢本文、イベントの発生確率、推定継続経路を創作しない。終了選択を選んだ場合も、**元結果が与える報酬**自体は保持する。

14イベントを含むサポカID：`10021`、`10022`、`10060`、`10074`、`10083`、`10094`、`10104`、`20021`、`30021`、`30036`、`30052`、`30080`、`30160`、`30188`。元に現れる打ち切りは18**結果経路**（一部選択に複数のランダム結果があるため14より多い）。通常の矢印チェーンで認めていた終了91件と合計して109の元 `chain_end` 記載が今回の元監査で受理される。**受理＝正式公開ではない。**

## A / B / C の検証

A：[`phase2_gt_random_outing_unlock_batch.test.cjs`](../poc/tests/phase2_gt_random_outing_unlock_batch.test.cjs) で同一元構造を14カード分にまとめた合成入力、終了側・継続側の報酬区別、通常ランダムを終了しないこと、source属性・`pd`不一致、矢印との競合、外部の分岐条件、二重ランダム終了の拒否を検証。

B：固定元GT559ソースカード、2,488イベント、4,376元結果経路を全件走査し、2,512非公開スキル候補へ本番用と同形式で一時 `preflight/attach`。元の全563カードのスキル経路を完全比較。唯一の独立ソースとの差異であるSSR30080 #6の結合例外は残す。

C：公開サイトの既存ブラウザChromium保護回帰は別ゲート。今回は未承認イベントをブラウザに展開した操作確認、Windows／Androidの物理端末、現行ゲーム内の動作再現は未実施。第三者のイベント本文、選択肢文章、元JSON、カード画像はPublicへ書き出していない。
