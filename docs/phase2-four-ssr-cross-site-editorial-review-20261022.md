# Phase 2：固定GTにない4SSRの20イベントを現在のカード別資料と照合（2026-10-22）

## 元の課題と重要な新情報

[Phase 2：4SSRの数値ヒント候補](phase2-four-missing-ssr-numeric-hint-intake-20261022.md)には、固定GameTora由来JSON`systemless10/UmamusumePS@6e38b54a`に収録されない**30318〜30321のSSR4枚**について、Checkerから20イベント・35件の効果行・12件の数値ヒントを抽出した。しかし掲載行数はゲームでの選択肢数を意味せず、20件の選択・結果・内部連続分岐は未審査だった。

2026-10-22時点の**現在のGameToraサイト**では、固定版にない4カードが掲載されている。[サイトの全カード一覧](https://gametora.com/ja/umamusume/supports)は563枚を掲示しており、[30318のページ](https://gametora.com/ja/umamusume/supports/30318-rice-shower)、[30319のページ](https://gametora.com/ja/umamusume/supports/30319-narita-brian)、[30321のページ](https://gametora.com/ja/umamusume/supports/30321-duramente)では**連続3段階／通常2イベントの見出し**を直接確認できる。**追加調査で[30320の個別ページ](https://gametora.com/ja/umamusume/supports/30320-admire-groove)の存在と、カードID・名称・実装日・イベント獲得スキルの概要を独立に確認した**。ただし今回取得できた表示範囲には30320のイベント欄の5件の見出し・個別選択肢・結果が含まれないため、詳細構造は依然未確認。**現在のWebサイトの収録と、固定版リポジトリに再現可能なJSONがあることを混同しない**。ライブサイトを新しい無条件の配信マスターとして扱わない。

参照した他のカード別記事：GameWithの [30318](https://gamewith.jp/uma-musume/article/show/578814)、[30319](https://gamewith.jp/uma-musume/article/show/578819)、[30320](https://gamewith.jp/uma-musume/article/show/578818)、[30321](https://gamewith.jp/uma-musume/article/show/578817)。別編集部のゲームエイトの [30318](https://game8.jp/umamusume/818871)、[30319](https://game8.jp/umamusume/818831)、[30320](https://game8.jp/umamusume/818830)、[30321](https://game8.jp/umamusume/818829)も参照した。Checkerの元はGameWith派生であるため、Checker＋GameWithを2つの独立な証拠とは数えない。ゲームエイト等を加えても公式実機確認ではない。

**掲載上の整合17件／表現が未解決3件**という数字は、資料の行の並びを確認する指標。**17件の実ゲーム選択肢が確証された意味ではない**。ゲーム内のイベントの外的な発生確率・タイミングは対象外だが、内部連続・打ち切り・結果条件は必須なので、3件について自動の選択肢や結果分岐を生成してはならない。

**12件のヒント報酬候補**について数値ID、元位置、Lvを両カード別記事と対比し、固定Checkerと2026年スキル名データの候補値に矛盾がないか調べた。これは記事上の**数値と掲載上の位置の裏付け**であり、実際のヒント取得条件・先行結果依存・確率が確認できたという意味ではない。特に30321の3/1ヒントについては、別のコミュニティー資料に成功/失敗があるため、無条件の獲得とはみなさない。

## 監査実装と意味論の境界

- `poc/src/phase2_four_ssr_editorial_review.cjs`：既存`missing_four_ssr_numeric_skill_candidates.v1.json`を受け取り、元出典の固定版、カードID、各イベント・掲載行、12件のスキルIDとLvの**一致を強制**。不一致・未承認状態の破壊を拒否。原イベント名／選択肢本文／ヒント名は出力しない。
- `poc/tools/audit_four_ssr_editorial_numeric_review.cjs`：GitHub Actions内の`whole-event-output/`に数値の個別レビュー情報と保留箇所のみを出力。`poc/data/`への保存を禁止。
- `poc/tests/phase2_four_ssr_editorial_review.test.cjs`：人工数値候補で20件・35行・12ヒントを固定し、Lv・ID・行番号・出典ピン・未確認フラグの変造を拒否する。
- [GitHub Actions全件監査](https://github.com/Nimrodx0/Umasupport/actions/workflows/whole-event-inventory.yml)に配置し、既存の固定ゲーム元・Checker・2026スキルID監査を**削除せず**追加する。

GameToraライブの証拠範囲は、イベント見出し3カード／カード個別ページ概要だけ1カード／一覧だけ0カード。**30320個別ページがあることは5イベントの独立照合、構造化JSON入手、現行ゲームの確認を意味しない**。

この段階で**固定GameToraのイベント分母2,488件**、未収録4SSR、Checker候補20件、正式公開イベント0件の全ては不変。現在のGTサイトは新しい参考情報として記録するだけで、固定バージョンのファイルを権利未確認のまま自動コピー・公開しない。

次に進むべき工程は、(1) 3つの内部選択／成功失敗差分を現行ゲームの記録または信頼できる数値出典で解決、(2) ライブGameToraの4カードを**版と取得条件を特定できる構造化の非公開元データ**と照合、(3) 20イベントの**実分岐と報酬**を独自の公開用台帳へ1件ずつレビューすること。データの正確性と再利用許可・表示権限は別審査とし、正式公開を推測で進めない。

A：人工機構の全件不変条件、B：固定Checkerの20イベント／35行／12ヒントと複数サイトの編集情報、C：実ゲームおよびWindows/Androidの物理端末試験**未実施**。
