# Phase 2：SSR30080の3択を固定GameTora全件候補の実行形式へ限定上書き（2026-10-23）

## 対象と出典

SSR30080・固定GTイベント位置6（ローカルID1392）は、元GTの `special` イベント1行／空ラベル／ヒント数値ID201591 Lv3。個別[GameWith裁定記事](https://gamewith.jp/uma-musume/article/show/315701)は **プレイヤーが操作できる3選択肢**で、いずれも同じスキルヒントLv3を持つ。GameTora固定出典を優先しながらその**特定の構造不足だけ**をGameWith掲載の具体的事実により補正する、前から記録済みの例外である。

既存[限定3択の数値編集採用](phase2-30080-three-choice-editorial-repair-20261022.md)と[65件の統合例外トリアージ](phase2-source-exception-overlay-20261023.md)を再利用する。新たな攻略記事の大量取得や、ゲーム内部story_idを全資料で照合する工程は要求しない。

## 今回の変更

`poc/src/phase2_30080_runtime_overlay.cjs` が、実データの非公開GT全2,488イベント投影のうち、カードID30080／元出典ordinal6／ローカルID1392／安定イベントID`gt-30080-event-006`のみを置換する。

1. **置換前**：元GTの `special`・操作なし `auto` の1行、数値スキルID201591ヒントLv3、元イベントSHA、出典の数値正規化、公開前の未署名審査票を厳密に確認。異なるID・スキルLv・イベント型・特殊条件・署名状態なら停止。
2. **置換後**：**元イベントIDと短い見出しを維持**したまま `type:'choice'`／`option1..3` とし、各位置へLv3ヒントを割り当てる。元 `availabilityKind:'special-trigger'` を保持して、特殊イベントの発生を保証するスキル経路と誤認しない。外的発生確率やGameWith掲載の範囲内非スキル報酬はアプリのスキル経路と混ぜない。
3. 実 `UmaCore.directRoutes` で **未選択0経路／各選択1経路**、いずれも「特殊イベントの発生時」という条件付きを確認。同一カードの2デッキ枠では提供カード数が1になることも独立に検証。
4. 対象以外のGTイベント2,487件は一切変更せず、正式イベント公開DBと人手承認台帳も変更しない。置換版は固定全件CIのプロセスメモリ内で破棄し、**変更前後のSHA、位置、4分岐の集計件数だけ**をログに出す。

## 合格と未完了

- A：合成のGT固定1行＋補正版3行を使い、元ソース構造改変、スキルID/Lv異常、SHA変更、特殊発生条件欠損、無承認からの昇格を拒否。実 `core.aggregate` の2スロット1提供者試験。
- B：固定GT全件CIの2,488イベント投影から実SSR30080/6を1件だけ補正し、他2,487イベントのID・件数を保つ。実データ検査結果に応じて追記。
- C：CIの既存Chromiumブラウザ試験とは別であり、**この非公開補正版をGitHub Pagesのユーザー向けイベントDBで公開配信したことではない**。実ゲーム内再現・物理Windows/Androidは未実施。

元GTの他の条件付き結果の不足と、個別GameWith記事の効果幅が全結果を網羅するかどうかは別の編集対象。未掲載分岐や確率は補わず、**この1件について「プレイヤーが3択できる」編集事実のみ解消**する。
