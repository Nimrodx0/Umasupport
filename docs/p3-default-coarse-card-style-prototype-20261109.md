# P3：入力なしのサポカ脚質適性・大まかな傾向の試作（2026-11-09）

**状態：固定版566カードを実データで試作・検証した研究用ルール。サポカ一覧・デッキ画面・保存データにはまだ接続していない。** 利用者の新方針は「頭数や対戦相手脚質配分などを事前入力せず、デフォルトでは多くの場合に役立つ大雑把な傾向を手軽に示すこと。詳細条件別のカスタム評価は任意拡張」とすること。[以前の厳密研究](skill-specificity32-two-axis-20261109.md)は規則の根拠・注意事項として維持するが、網羅的な追加レースシミュレーションをデフォルトUI完成の必須条件としない。

**重要な区別**：今回の試験は「サポカが取得候補として提供するスキルの発動条件から見た脚質傾向」であり、スキルを取得できる確率、発動確率、加速・速度効果の有用性、カード総合力、実際のチャンミの対戦分布を測定していない。候補件数はカード強さを表す採用済みスコアではない。

## 1. デフォルトにおける提案ルール

- 逃げ・先行・差し・追込を**常に4脚質独立**に表示し、頭数・脚質配分・コースを入力させない。内部比較基準は以前の合意どおり**均衡編成**。実レースでの最頻編成と主張しない。
- スキルについて**明示的な発動不可**を最優先。元IDと日本語名を照合したP1の構造化条件、複数Invoke、ORの各AND枝、preConditionsを確認する。対象脚質が発動可能だと分かるだけでは高適合とは扱わないが、他脚質が明示的に排除される専門スキルは**その対象脚質への提供候補**として数える。
- 4脚質間の比較は[固定均衡GlobalSimの11順位帯×4局面の分割試験に基づく研究器](../poc/src/skill_balanced_four_style_fit.cjs)で、**同じ順位帯・全局面の元条件が一致し、余分な未知AND/ORがない場合だけ**相対的な優勢・劣勢を採用。中団は「先行／差し」のような個別差を優先し、前後2群だけを最終判定にしない。
- 4脚質個別比較が未対応でも、[v1.3の前後群の旧固定研究](../poc/src/skill_activation_fit_v1.cjs)で**元の条件すべてが確認できる**場合だけ、確度が低い「前方／後方の参考傾向」として別に数える。この参考値と4脚質比較を**同じ証拠階層であると表示しない**。
- 追加AND、preConditions、ORの一部が未確認、元辞書と照合できない、モデルにないスキルは**不明**。情報不足を「脚質に向かない」や「発動可能性ゼロ」に読み替えない。
- サポカの提供スキルは**検証済み通常ヒント**と**公開承認済みイベント報酬**のみ。未選択イベントの選択肢報酬を採用しない。通常ヒントは指定凸段階（初回試作では便宜的に4凸）のものを使い、金と白を同名・上下関係で勝手に融合しない。同一スキルIDの複数経路は1候補として数える。イベントの結果条件等が未解決の場合は、その**条件付き候補を表示するが、デフォルトの主要脚質方向の根拠には数えない**。
- 各脚質で「向きの傾向／向きにくい傾向／傾向が割れる／材料不足」を**暫定的なスキル証拠一覧の見出し**として出力。ただしカードの単一の最適脚質ではない。主要な候補には、支持／反対する**無条件の獲得候補スキル数に対する非劣位（パレート）比較**を併記する。これにより「4脚質すべて良い」のような表示を抑制する一方、異なる根拠の質が衝突すると単一の候補を選ばない。
- **閾値20/80など、スキル成立率からカード点数への換算は未採用**。カードの強さ、効果の価値、レアリティ、イベント出現確率、能力値を足した総合評価を捏造しない。

## 3. 試作の不自然さ・残った設計論点

- **「向きにくい」の誤読**：実カード1枚に脚質限定スキルが1つあって他の脚質では使えないことは、その**スキルの明示適用外**であり、他の汎用スキルを含むカード全体が無価値・不適合だという事実ではない。初回は「向きにくい傾向」が特に追込で多数表示されるが、正式UIでは「その脚質の専門的な候補が少ない」と混同しない文言へ改訂が必要。
- **有力候補が決まらない混合カード**：ビコーペガサスのように前方向け・後方向けのスキルを両方提供し、スキル効果の価値・取得しやすさが未評価の場合、厳格な非劣位比較では方向を出せない。ユーザーが求める大雑把な使いやすい基準では、**単純な証拠件数優勢**など別の暫定方式も比較してもよいが、本PRでは採用・公開していない。
- **金／白の効果差、凸段階、育成上の価値**：スキル別の条件の方向だけでは、金スキル1つと白スキル多数をどう比較するか、スキルが汎用で有用かをまだ評価できない。モデルの推定発動率を重みやカード点数に直結させない。
- **通常ヒントとイベント報酬**：既存のアプリ実装と同じ選択設定を使い、明示的に到達できない分岐を採用しない。イベントに既知のルート条件が残る場合は確定入手扱いしない。完全イベントが公開されていないカードの未収録は0報酬と同一視しない。
- **現実の発動機会**：固定均衡GlobalSimの相対方向を研究上の手がかりに使うが、その編成が実対戦の多数を占めること、ゲームバージョンをまたいで全条件の方向が保存されることは証明していない。

## 4. 次の実装と受け入れのゴール

**本番に必要なのは「厳密なあらゆる編成でのスキル発動確率」ではなく、少数の脚質ラベルがサポカ比較時に有用かどうかの確認**。次の工程では**コンパクトな4脚質表示のレビュー画面**を用意し、今回のサンプルや脚質限定・混合・未知・イベント選択に応じた評価を目視で確認する。デフォルトは入力フォームを出さず、タップで根拠スキルを展開する案を基準とする。多数の例でカードの強みが自然に伝わるかをレビューし、曖昧・紛らわしいケースだけ評価の言い回し／方向合成方法を修正する。

**リリース判断を分離**：A機構（経路／条件／比較／重複のテスト）、B固定実データ（566枚の出典照合）、C公開UI・実機のレイアウト・操作評価は別の合否。今回A/Bの試作が成功してもCの完成ではない。正式な「◎○△」等の定義・提示順・フィルター、スキル効果有用性を自動で加える方式、現実の相手分布を組み込むかどうかはレビュー後に決める。

## 5. リサーチ用のカード一覧レビュー画面（別PRで試作）

- [研究専用画面](../poc/p3-coarse-review.html)：研究JSONをブラウザ内で選択して、固定版サンプル12枚の4脚質見出し、候補数、根拠スキル、通常ヒント／イベント取得経路の別、条件付き・未照合を調べる。**通常アプリへは未接続**。
- [純粋な入力検証・表示補助](../poc/src/p3_coarse_review_ui.js) と [回帰テスト](../poc/tests/p3_coarse_review_ui.test.cjs) は、研究専用ステータス・4脚質・個別スキル経路を検査する。JSONファイルの内容は外部へ送らず、ブラウザ保存もしない。
- 試すには、PR #375の `P3 default coarse style candidate card preview (fixed source)` の成功したActions実行から `p3-coarse-card-default-566-review-only` をダウンロード・展開し、その中の `p3-coarse-style-readonly.json` を選択する。ローカルではルートで `python -m http.server 8000` の後、`/poc/p3-coarse-review.html` を開く。**Actions成果物は14日保持**。
- 現状の12枚は4脚質比較の材料が多いカードを優先した**偏りのある診断サンプル**であり、566枚の代表抽出ではない。混合型・明示限定・材料不足・イベント未収録のカバレッジを確かめるには、次工程で抽出設計と対象数の拡張が必要。
- 「向きにくい傾向」は個別スキルの不利・明示対象外の材料を示すだけで、カード全体が弱いことではない。非劣位候補は単一スコアでもおすすめ順位でもない。レビューから正式な適性ラベルへの採用は別の判断にする。
