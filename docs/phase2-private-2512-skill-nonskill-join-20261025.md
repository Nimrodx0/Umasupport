# Phase 2：スキル2,512イベントとGT非スキル2,220形式の厳密な非公開統合（2026-10-25）

## 目的と条件

従来の[非公開スキル本番候補2,512件](phase2-30180-special-cornering-2512-20261023.md)と、[GT非スキル数値構造2,220件](phase2-all-stats-five-attributes-20261024.md)は**別のイベントカタログ**だった。これを同じGT基準イベントへ結合し、スキル獲得経路・結果の排他性・連続解放フラグを保持できるかを、公開データとは隔離して実測した。

- GTソース固定版：`systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`。Checker・UmaSim・2026スキル名の検証経路は前工程と同じ。
- 元のスキルランタイム：**563枚・2,512イベント**。旧GT2,488＋不足4SSR通常8＋5SSR連続15＋SSR30180の特殊1。**SSR30080の3択補正は元GT1イベントの内容変更であり件数増に含めない**。
- 非スキル側：固定GT2,488イベントのうち、**2,220イベント分**だけを、効果種類・符号・対象キャラID・結果を個別に認識済みの匿名プレビューとして保持する。残り268元イベントのうち不明コード・前段ガード・打ち切り等があるものは結合しない。
- 統合対象を**同じカード数値ID＋GT元イベント位置の一意な`gt-<cardId>-event-<ordinal>`**に限定。GameWithだけで追加した24件と、佐岳メイの別海外イベントは別枠。外部的な発生率を推測しない。

## 統合の安全条件

`poc/src/phase2_2512_private_effect_join.cjs`を追加した。

1. 2,512イベント元のカタログと技術出典`phase2-gt-whole-nonskill-effect-inventory`の元バージョン・非公開フラグを検証する。元カタログのSHAに差があれば失敗。
2. GTカードID＋元イベント順位を照合し、元のイベントID・名称・イベント型を保存。
3. 位置の一致だけで自動採用しない。**イベントがauto/choiceか、選択肢数とIDが一致するか、結果の元順位を特定できるか**を確認。スキル候補が同じ元結果から排他的に派生する場合、スキル側の`route-NN-or-M`を元の`route-NN`に戻して非スキル効果を各派生結果へ引き継ぐ。元結果が欠けた場合、OR番号に飛びや重複がある場合、元分岐順位が逆転した場合は全イベントを保留。効果を複数の候補結果へ保持するが、**複数結果を一度に獲得したと数えない**。
4. 全結果について、スキルの`rewards`、選択`terminal`、`requires`、利用条件と元名称をそのまま保持し、別欄`effects`だけをコピー。スキル収録数、前段フラグ、選択肢の結果分岐は変更しない。
5. 保存前に**統合後の全イベントから`effects`だけ取り除いたものと元スキルイベントをSHAで全件照合**し、構造やスキル報酬が1つでも異なる場合は失敗。さらに全563カードについて同じ任意選択状態で`UmaCore.directRoutes`を実行し、元と結果が完全一致することを検証。
6. 固定GT/Checker全件CIで生成済みの非スキル監査JSONをGit管理外から一時読込み、元スキル2,512件とマージ。実運用と同じ`public_event_catalog.preflight`・使い捨てカードモデルへの`attach`を通し、`UmaCore.directEffectRoutes`による数値効果の取得を確認。合体カタログ全文・第三者イベントの説明文・選択肢の原文は出力・公開しない。

## B：固定出典の全件実測

[最終確認前の固定全件監査 #40190025853](https://github.com/Nimrodx0/Umasupport/actions/runs/40190025853) PASS。初回の形状を1対1に限定した監査では11位置が保留だったが、GTの元結果順位を追跡する追加規則で全件解決した。

9,928はイベント内の全分岐に保持した**成分行数**であり、実際に一回の育成で全部を得るという意味ではない。5,920はテスト用に各選択肢の先頭・各イベントの結果を仮設定した状態での**条件付き候補を含む経路数**であり、獲得保証数ではない。

初回に統合を保留した11位置は固定GTのR10022（2位置）・SR20021（2）・SR20024（1）・SSR30011／30018／30025／30040／30101／30109（各1）の合計。**ゲーム上のデータ欠落ではなく、スキル候補を排他的に追加分割した際の内部表現差**であった。今回、元の`route-NN`と技術用の`route-NN-or-M`の親子関係および連続番号で整合を機械的に確認した場合だけ統合。残った元分岐差0件。

## A/B/Cと保留

A：`poc/tests/phase2_2512_private_effect_join.test.cjs`で合成元データによるauto、choice、outcomes、負数、受け手、前段`requires`、明示打ち切り維持、異なる結果ID・選択数の拒否、スキル集計不変をテスト。

B：元のGT全2,488イベント監査と同一CI上で**2,512件をすべてpreflight/attachし、2,220結合・0保留を含む完全な母数を確認**。公式GTサイト／GameWithを全件再取得する工程ではない。検証不能の元GT効果は保留のまま。

C：公開Pages／独自公開イベントDB／保存状態に変更なし。現行UIのChromium回帰は行うが、公開アプリ上で2,220イベントが見られるわけではない。ゲーム実機の直接再現は求めるイベント編集採用の必須条件ではなく、元ゲーム完全性と正式公開承認は別審査。

**未完了：** 別枠の非スキル268件（数値効果の条件や特殊状態を未変換）の特殊効果を段階的に扱う。さらにスキル収録側で未解消のSSR30240連続3段階、Checker未同定11位置、正式配信0件の独自表現・出典・公開承認を整理する。これらをすべて機能完了とは主張しない。
