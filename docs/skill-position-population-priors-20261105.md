# P2：実対戦脚質分布を使った順位条件シミュレーションの感度検証（2026-11-05）

**目的**：脚質の人数構成に応じて上位50%・後方50%順位条件の成立傾向がどう変わるかを調べる。「均衡型を基準にし、実際の対戦での平均的な構成を調べる」というユーザーの方針を受けた実験である。

**禁止する混同**：ここでの観測は「特定時点にレース内に出走した脚質の割合」で、得られるモデル結果は「速度・位置から計算する順位帯の成立頻度」。スキルの発動抽選率・効果の有用性・既存53スキルの厳格な適性ではない。

## 1. 既存の公開観測データ

原文で人数を確認できる観測は、脚質比率の**イベント固有**の実測値として保持する。独立したゲーム全体の抽出標本ではなく、複数プレイヤーやマッチが独立・等確率に標本抽出されたとの情報もない。

**3大会合算の参考値**：240人×3大会を機械的に合算すると、逃げ**82/720＝11.4%**、先行**296/720＝41.1%**、差し**265/720＝36.8%**、追込**77/720＝10.7%**。これは「同一調査者の3大会を均等に組み合わせた感度チェック用の重み」であり、全国／直近全イベントの代表的な平均を推定したものではない。

**結論**：「全国のウマ娘レースで逃げ何%、先行何%」という**全レース共通の平均**を、上記を平均しただけで導出できない。短距離／中距離／長距離、開催月、適用キャラ・サポカ、競技会の形式、集計対象の強さ等の影響が大きい。特に各攻略班の50戦と個人の対人マッチで、母集団選択に違いがある。**2026年6/7月の記事から4脚質の正確な数を補完・推測しない。直近のイベントでは先行＋差しの割合が今回の720人合算（77.9%）より高い例が報告されているため、**3大会合算型を「現在の平均」と呼ばない**。**

したがって、まず「均衡型」を**統制比較の基準**として保存し、「2026年1月型」「2025年12月型」「2025年10月型」および**3大会合算型（参考）**の出走者の構成比率を、独立したシナリオとして扱う。この2件を混ぜた平均を「実際の平均」とは呼ばない。12頭LoHには6頭のNPCが混じるため、9頭対人の観測値を移した12頭シナリオは**出走人数の技術的な感度実験**であり、現実のLoH編成の推定ではない。

## 2. 実験設定

固定版[GlobalSim v77コミット](https://github.com/daftuyda/GlobalSim/tree/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1)を一時作業領域に取得し、その[配布例](https://github.com/daftuyda/GlobalSim/blob/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1/examples/v77-race.jsonl)の入力と数値データを流用する。ランナーのステータス以外のランタイム設定は変更せず、サポカ・イベント情報や第三者データを当アプリに再配布しない。

| 軸 | 値 | 意味 |
| --- | --- | --- |
| 出走数 | 9、12頭 | チャンミと追加の人数感度確認。12頭のLoH NPC再現ではない |
| コース | 元コースID10501（1200m）、10504（2000m）、10506（2500m） | 短／中／長距離の比較。前処理で出典固定コースの距離を照合 |
| 脚質構成 | ①均衡型、②2026年1月実測型、③2025年12月実測型、④2025年10月実測型、⑤3大会参考合算、⑥逃げ不在 | 統制の基準と2つの実測分布・構成感度 |
| 均衡型の内訳 | 9頭：逃2・先2・差3・追2、12頭：各3頭 | 事実の平均ではなく構成を固定した比較基準 |
| 実測型の割付 | 元記事の4脚質**各240人の比率**を使って9人／12人を乱数抽選 | 月別に独立。プレイヤー3人チーム単位での共出走やマッチングの相関は未再現 |
| 能力 | v77配布例の同一能力、あるいは各能力を一頭ごと±10%変化させる人工条件 | 実際の対人ステータス分布ではない。能力差を導入した感度チェック |
| スキル | 全頭「なし」 | スキル自身の効果を持たない基準順位帯の観測 |
| 時点 | 全距離の1/6・1/3・1/2・2/3・70%・75%・80%・5/6・90% | 各馬が到達した時刻に、他馬も**同一時刻**の位置で比較 |
| 出力 | 逃／先／差／追ごとの上位半数・後方半数の成立件数、割合、平均順位、順位不明件数 | 推定が成り立った標本数・脚質不在・マッチ分布の実際の抽選数も保存 |

**脚質割合の推定は、発動スキルに直接使わない**。本実験ではスキルの発動機会全体（抽選位置、残り距離、追い抜き条件等）ではなく、単なる**順位帯条件**を扱っている。効果の有効性を扱わない点も変更しない。

## 3. シミュレーション実行と検証

- 解析器：`poc/tools/globalsim_position_expanded.cjs`。流れてきた出力を1レースごとに解析・解放する。膨大な元リプレイJSONLをリポジトリに格納しない。
- 単体テスト：`poc/tests/globalsim_position_expanded.test.cjs`。実測件数・合計・9/12頭・乱数再現性・ゲートの交替・ステータス変化・全馬の順位カウント・異常系を検査。
- 完全分離した[実エンジンのCI](../.github/workflows/globalsim-position-expanded.yml)：固定GlobalSimを`cargo build --release --locked`し、競走全員の位置が得られた場合だけ派生集計の`summary.json`を保存する。
- 独立性：Python/JSの実験で外部の公式レースログを作ったことにはならない。元のGlobalSimの検証値[公式グローバル版の約70万レース一致](https://github.com/daftuyda/GlobalSim/blob/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1/docs/ACCURACY.md)を試験内容の証拠として参照する一方、データの独立検証ではない。
- 公式日本版との違いの**優先度は下げる**というユーザー方針を反映。ただし、現行日本版との完全同一性を証明したと表示しない。研究用GlobalSim順位分布の**再現可能性**と**脚質構成への頑健性**を先に確認する。

## 4. 実験結果と判定方法

後続のActions実行で、各脚質・各コース・人数・ステータス条件における`pTopHalf`と`pBackHalf`を記録する。**一方の脚質が0件だった場合はゼロ確率ではなく標本が存在しないため未判定**とする。

現行P2ラベル（逃げ・先行寄り46、差し・追込寄り7）を機械的に置き換える前に、少なくとも次を点検する。

1. 均衡型の9頭で予備実験と定性的に整合するか。
2. 12頭・短長距離・実測型・能力差に変えても大きな逆転が起きない条件はどこか。
3. 逆転が起きるなら、コース・集計地点・脚質の人数比・スキルの条件式のどれに依存するか。
4. **発動地点の抽選**があるスキルは、その位置分布を使う加重集計に進む必要がある。離散9地点のうちたった1点の成立割合をそのままスキル発動率に読み替えない。

**出所の優劣に関する仕様**：均衡型は統制比較の基準であって、実測の平均ではない。実測分布の脚質構成が均衡型から離れる場合でも、予め均衡型を「正解」とせず、両者の結果を別々に示す。数値の順位条件成立率はGlobalSimモデル上の推計として明示する。
