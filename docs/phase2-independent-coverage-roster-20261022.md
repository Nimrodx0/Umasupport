# Phase 2：サポートカード563枚の独立収録範囲リスク監査（2026-10-22）

## 目的と母集団

固定GameToraとCheckerの差分65件をゼロにしても、**両方が同じイベントを収録し損ねた場合には検出できない**。対策として固定UmaSimのサポカ**563枚すべて**に対し、GameTora由来連続イベントの段階数、イベント区分、固定Checker収録数、固定GTスキル数値候補、独立編集記事による確認状態を組み合わせた**レビュー優先順位**を生成する。

使用版は `systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`、`Cilda/UmaUmaChecker@8cf9fcb3cc7239041161be75c84daf9f8f22d29f`、UmaSimカード母集団`cf9366f6a487bd8f197b53d8a11981207beb9f6c`。入力はCIが既に生成している全カード統合索引・GT連続トポロジー・GT数値候補・完全性例外台帳。固定GTのイベント**2,488件**とCheckerの**2,109件**を保持し、新たに第三者イベント原文を大量取得しない。

## 全563カードの構造別分類

| 区分 | カード枚数 | 判断と注意 |
| --- | ---: | --- |
| R（連続イベント期待の対象外） | **146** | Rの全イベント欠落を意味せず、連続イベント不足の自動検出から除外 |
| GT元カードのデータがない | **4** | SSR30318～30321。Checkerに各5イベント候補あり。最新ゲームとの照合は別工程 |
| 連続段階0・通常2イベントだけ | **2** | **SSR30221・30240**。独立攻略記事がそれぞれ連続3段階を掲載する特定疑義 |
| 連続段階0・他区分のイベントあり | **17** | 友人・シナリオ関連の `special` / `dates` 等。通常SSRの3段階ルールで一律に収録漏れと判定しない |
| 連続段階が少ないSR／SSR | **7** | SR 1カードで1段階、SSR 6カードで1段階。必ずしも欠損ではない |
| 通常のSR 2／SSR 3連続段階 | **387** | 固定ソースの段階数が一般的な形状。全ゲームでの完全性を保証するものではない |
| **合計** | **563** | 全カードID一意かつ固定元のイベント件数を保全 |

現在の検査では**最優先レビュー11カード**＝GTの連続段階0・通常2件だけの2枚、GT元カード欠損4枚、短い連続段階のうち独立記事で「1回完結」と確認していない5枚。未確認の4枚の短いSSRは30258・30270・30271・30300。固有の1段階という可能性を明記し、欠損確定にしない。残る2枚（30244、30286）は独立記事で短期完結を確認済みのため最優先から外す。スキル重要度は**既存のGT数値ヒント記録件数を同順位で比較する補助指標**にとどめ、GTが記録していない報酬を勝手に推測・加算しない。

## 独立した資料で特定できた違い

- **SR20075 タップダンスシチー**：固定GTに通常イベント2件と`arrows`の最終段階1件（GT位置3／局所ID416）だけ。固定Checkerには連続イベントが**2段階**あり、Checker位置1（`checker:20075:8fd4b0e1da2eeb063087`）はGTに存在しない。元Checker位置2→GT位置3で連続最終段階は対応済み。[ゲームエイトのカード別記事](https://game8.jp/umamusume/600213)も2段階と明記するため、**固定GTの連続初段階欠損を編集記事レベルで裏付けた**。ただし**初段階の数値効果はChecker「根性+15・絆+15」とゲームエイト「根性+5・絆+5」で衝突**しており、どちらも現行ゲーム直接記録ではない。欠落している段階の報酬数値を決め打ちしない。既存GT最終段階のスキルID202462 Lv1と不足する前段階は区別する。
- **SSR30221 サトノダイヤモンド**：独立記事の連続3段階は既に**Checker-only3件**として検出済み（[ゲームエイト](https://game8.jp/umamusume/636307)、[U-tools](https://xn--gck1f423k.xn--1bvt37a.tools/supports/30221/event)）。今回の「新たなイベント数」に足さない。
- **SSR30240 ジャングルポケット**：独立記事に連続3段階があるが、固定GT・固定Checker**双方にその3段階がない**（[GameTora現在の該当カード](https://gametora.com/ja/umamusume/supports/30240-jungle-pocket)）。元2資料の差分65件の外に位置する別枠の3候補として追跡。
- **SSR30244 メジロブライト**：GTで`arrows`1件／局所ID1143。[ゲームエイト](https://game8.jp/umamusume/675743)に「連続イベントは1つだけ」と明記。**短いことを理由に欠損としない**。
- **SSR30286 マチカネフクキタル**：GTで`arrows`1件／局所ID1255。[ゲームエイト](https://game8.jp/umamusume/758987)に「連続イベントは1つのみ」と明記。同様に正常な短期構造の候補として分類する。

編集サイト同士の情報源や実ゲームデータの更新時点が完全に独立であるとは限らない。以上は**編集記事と固定元の一致・不一致の記録**であり、発生条件や報酬の2026年実ゲーム裏付けとは別。

## 実装上の保証

`poc/src/phase2_independent_roster_coverage.cjs`とCLIで全563枚のカードID、GTイベント数、連続イベント数、元イベント区分、Checker件数・未対応行数を照合し、非公開の候補キューを生成する。元GTカード欠損・友人／シナリオ等・R・正規の1段階・真の不足を区別。SR20075はCheckerの元IDと未対位置・GT最終段階IDを固定し、30221/30240は前PRの監査証拠を照合する。30244／30286の単発も元GT IDで失効ゲートを設ける。新しいデータ出力はCI一時成果物とし、`poc/data/`への書き込み・未承認イベントのランタイム採用を明示的に禁止する。

**全件の固定元出典間差異は65件のまま**（Checker-only40、非R GT-only24、GT元の3択構造不足1）。SR20075は既存Checker-only40のうち1件。30240の両固定元外3候補も従来どおり別枠。独立資料での比較可能性が上がったことを正式配信や実ゲームの全件網羅達成とは呼ばない。

**A 機構**：カード区分・版固定・イベント区分・数字の変化拒否、数値と公開フラグの合成回帰。**B データ**：全563枚の固定GT＋Checkerインデックス＋独立掲載を限定引用した記事照合。**C 実環境**：CI上ChromiumとNode。Windows／Android物理端末・ゲーム内の発生条件と正しい報酬の実証・第三者素材の公開条件は未実施。正式公開イベント0件。
