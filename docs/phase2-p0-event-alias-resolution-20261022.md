# Phase 2：P0未照合2件の実イベント同定を解決（2026-10-22）

## 全体計画での意味

[Phase 2の全件欠落監査](phase2-cross-source-completeness-exceptions-20261022.md)で、Checker側に存在してGameTora側にペアがなく、しかもスキル報酬に影響する**最優先P0候補2件**が見つかっていた。これはゲームにイベントが追加されたという証拠ではない。原イベントの同定差なら、実データを二重登録せずに1対1へ対応付けることが正しい。

固定GameTora由来版`systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`、Checker`Cilda/UmaUmaChecker@8cf9fcb3cc7239041161be75c84daf9f8f22d29f`の2件を、**元位置・イベント名のSHA-256・候補sourceKey・選択肢構造・分岐スキル**まで確認した。

| カード／Checker位置 | GameTora位置／ローカルID | 同定を阻んでいた差 | 実イベントの構造 |
| --- | --- | --- | --- |
| **30139／3** | **5／857** | イベント名の`凜`と`凛`の字体差。一般的なNFKC／句読点除去では必ずしも一致しない | **最終連続段階、選択肢なし、成功結果2本**。同一スキル数値ID`202581`のヒントLv3／1。候補イベントを増やさず、既存GTへ対応付ける |
| **30198／1** | **3／1017** | Checkerでイベント名の末尾`（日帰り）`が省略。自動的な部分一致で勝手に結び付けてはいけない | **連続1段階目、実選択肢2つ**。上で継続し、下には`chain_end`がある。元の打ち切り経路を維持 |

両イベントの選択・結果・報酬構造は、個別資料でも照合した。30139：[GameWithの当該カード](https://gamewith.jp/uma-musume/article/show/393389)／[ゲームエイト](https://game8.jp/umamusume/520179)；30198：[GameWith当該イベント](https://gamewith.jp/uma-musume/article/show/444503)／[ゲームエイトの当該カード](https://game8.jp/umamusume/603618)。後者の資料では略称ではなく、GameToraと同じ括弧付きのイベント名称が採用されている。

**資料2サイト＋CheckerとGameToraが、ゲーム2026年10月22日の実機で独立した4回の観測を行ったことを意味しない**。ここで確認できたのは、固定イベントの同一性と元に記録された内部連続ルートへの対応付け。元タイトル・選択肢・効果本文を公開用データへ転記していない。Checkerの元由来がGameWithに依存する可能性があるため、別の独立一次証拠として二重カウントしない。

## 再現可能な実装と不正同定への防御

- `poc/src/phase2_reviewed_event_aliases.cjs`：**2つのカードIDにしか発動しない**出典ハッシュ、イベント位置、元ローカルID、Checker候補キー、選択肢個数、ヒントLv、終了経路まで厳格な一致を要求する。条件が変われば例外を投げ、近い名前を全カードへ自動マッピングしない。これは非公開の**イベント同定の裁定**であり、データ本文・イベント権利・2026年現行ゲームの全件検証ではない。
- `poc/tools/build_whole_event_index.cjs`：元の厳密一致とタイポグラフィ一致の**後**、対象2件の未対ペアにのみレビュー済み照合を適用。すでにペア済みのイベントは再利用せず、一つのGameToraイベントを2つのCheckerイベントへ結び付けない。P0の位置から追跡情報を失わない。
- `poc/tools/audit_whole_event_rewards.cjs`：数値ヒントや打ち切りの分析も、出典確認された同定法を受け入れ、単にタイトル一致だったと偽装しない。元カード・イベント数の母集団は変えない。
- `poc/tests/phase2_reviewed_event_aliases.test.cjs`：成功・失敗の2ヒントLv、連続終了の位置を人工条件で確認。ハッシュ・件数・報酬・打ち切り等の変更、既にペア済みで再利用しようとするケースを拒否。
- [全件GitHub Actions](https://github.com/Nimrodx0/Umasupport/actions/workflows/whole-event-inventory.yml)で、元ファイル変更時に監査停止、固定563カード／559GTカード／417Checkerカードの保存則を確認する。
