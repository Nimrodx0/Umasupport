# Phase 2：通常8イベントを手元のブラウザで選択検証する非公開ビュー（2026-10-23）

## 前提と用途

[通常8イベント／16選択の数値・仮表示](phase2-eight-standalone-event-display-review-20261022.md)を、**本番スキル計算エンジン `UmaCore.directRoutes` を流用したローカルWeb画面で操作**できるようにした。サーバーは必ず`127.0.0.1`だけで待ち受け、ネットワーク上の攻略サイトへGETせず、配信用 `reviewed_events.v1.json` や承認台帳を一切書き換えない。**GitHub Pages本番のイベント表示とは別機構のレビュー専用UI**である。

```sh
node poc/tools/preview_phase2_standalone_local.cjs --port=8765
```

ブラウザで`http://127.0.0.1:8765`を開く。4SSRの通常イベント2件ずつが現れ、選択肢16位置について、採用済みの能力／体力／絆などの数値、スキル数値IDから確認した短い名前、ヒントLvを表示する。「未選択」はヒント0件、「選択1／2」は**当該位置だけ**をプレビュー集計する。出現確率やスキル獲得の確定ではない。

### 題名と選択肢の特別な扱い

GameWithの該当カード個別記事に載る**通常8イベント見出し**を人手確認して2026-10-23時点のNFKC空白正規化SHA-256を保持した。記事原文のイベント名／選択肢セリフはサーバーのJSON・HTMLに同梱しない。代わりに**独立の短い日本語要約案**を載せる（例：花屋でのやり取り、走りと体調）。これは正式なゲームイベント名ではない。元記事のタイトルハッシュがあることは、固定Checker同名イベントと完全照合したこと、イベントゲーム内IDを特定したこと、ゲーム内操作選択を直接観察したことではない。

GameWith同カード記事：
- [SSR30318 ライスシャワー](https://gamewith.jp/uma-musume/article/show/578814)
- [SSR30319 ナリタブライアン](https://gamewith.jp/uma-musume/article/show/578819)
- [SSR30320 アドマイヤグルーヴ](https://gamewith.jp/uma-musume/article/show/578818)
- [SSR30321 ドゥラメンテ](https://gamewith.jp/uma-musume/article/show/578817)

**30319／通常第2イベント**：同カード記事の初段行に「選択肢なし」の表示があるため、ソース解釈は紛らわしい。先行レビューが採用した[個別イベント記事](https://gamewith.jp/uma-musume/article/show/289111)の2択解釈と、数値台帳の2択を維持する。これは明示した編集上の裁定でありゲーム実機確証ではない。

### 品質ゲートと残件

- A：Nodeで4カード／通常8件／16択／4ヒントを数値編集台帳に厳密照合。実集計コアをブラウザ上で使い、未選択0・相反選択0・各指定位置だけの獲得候補をLinux Chromiumの幅390px実描画で確認。localhost以外にサーバーを開く引数を禁止、`POST`と任意のファイルパスを拒否。
- B：この8件のGameWith本文に**イベント見出しがあること**を元記事ごとに照合したが、カード記事とCheckerが同じGameWithファミリー由来で独立のプレイ証拠とは言えない。全563枚のイベント・分岐を検証したわけではない。
- C：CIのChromiumはLinux実行であり、Windows／Android物理端末、実ゲーム内の選択や報酬の観察、GitHub Pages本番での実イベント表示は未実施。
- 公開：独自見出しも画面も**非公開レビュー用途**であり、出典の正しい同定、全結果網羅、出所・表現に関する判断、イベントSHAと6観点の人手承認は別工程。正式承認イベント数は0。

この作業の次は、**本人が実ゲーム操作時に見られる選択肢と、効果由来の短い表示で迷わず対応できるか**の検証、および通常イベントの報酬結果が単一か複数かの確認。それを満たしてから本番イベントUIに接続する。
