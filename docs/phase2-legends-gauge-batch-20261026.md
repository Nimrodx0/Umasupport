# Phase 2：レジェンズの全員／選択相手の指南ゲージ共通変換（2026-10-26）

## 対象と出典

固定GameTora元 `systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67` の [`support_30241.json`](https://github.com/systemless10/UmamusumePS/blob/6e38b54af4fad397ff4491e63007a90705a4fe67/server/data/events/gametora/support_30241.json) にある「伝説の体現者」の **9イベント**。固定元の元イベント順位は7・8・9・13・14・15・16・17・18。GameWithの[同カードのイベント情報](https://gamewith.jp/uma-musume/article/show/485772)に、全員の指南ゲージと選択相手1名の指南ゲージが明記されている。二種類の意味を混同しない。

- `ttl_gauge_all`：7元イベントに各1記載。+3が6イベント、+2が1イベント。3名（セントライト、スピードシンボリ、ハイセイコー）それぞれの指南ゲージに適用する元効果で、通常の5能力値や絆とは独立。**新型 `legends-all-guide-gauges`** を作る。
- `ttl_gauge`：2元イベントに各3選択肢＝6記載。+1と+8の二段階（それぞれ3記載）。選んだ相手 **1名** の指南ゲージに限る。**新型 `legends-choice-guide-gauge`** として各元選択肢を別々に保持する。固定元の効果オブジェクトには対象キャラクターIDが無いため、汎用変換では相手の名前を推定せず `chosen-legend-from-event-choice` を対象条件とする。GameWithの内容は個別カードの事実を裏付けるが、本文や選択肢の逐語表記は保持しない。

## 共通変換と安全な表現

既存の [`SCENARIO_RESOURCES`](../poc/src/phase2_gt_whole_nonskill_effect_inventory.cjs) に、上記2コードを追加する。各結果は `type` と符号付き整数 `value` のみを許容し、`possible:true`、`scenario:'legends'`、型ごとの `targetSelection` を持つ `dynamicEffects[]` へ正規化する。元結果での重複効果、未確認追加フィールド、数値幅、数値でない値は元イベント全体を保留する。元の結果・選択肢・継続フラグ・ヒントIDは変更せず、シナリオ特有のゲージを通常の能力値／スキル獲得に換算しない。

[イベントスキーマ](../poc/src/event_schema.js)・[`UmaCore.directDynamicEffectRoutes`](../poc/src/core.js) に両効果型を追加し、`conditional:true`、`unresolvedTargets:true` 付きで結果を列挙する。選択肢が未指定なら1名用ゲージは取得候補として出さず、全員への3重加算も行わない。実ゲームのシナリオ内報酬反映を直接再現する実装ではない。**技術変換結果であり、現行ゲームや正式公開を保証するものではない。**
