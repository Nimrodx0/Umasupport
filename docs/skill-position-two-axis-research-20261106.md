# P2：スキル発動条件の2軸評価（均衡編成、2026-11-06）

**方針はユーザー合意済み。評価尺度の数値区分とサポカ集約方法は未確定。** 実装はGlobalSimモデルの順位帯という**部分条件の研究専用**。公開アプリと既存53＋追加24スキルの高／低ラベルは変更しない。[有効要件](requirements.md)・[意思決定](decisions.md)・[固定4脚質研究](skill-position-balanced-four-style-rule-20261106.md)。

## 区別する3つの概念

1. **第1軸：成立機会（opportunity）**。指定した脚質で、元の順位帯にいるモデル上の走行距離割合。全24均衡編成設定（6コース×9/12頭×2能力条件）の均等重み平均・最小・最大、9頭／12頭別の平均を保持する。全レースの「スキルが発動する確率」ではない。
2. **第2軸：脚質特異性（specificity）**。順位帯の広さを考慮するため、各設定の `100 × (順位帯に含まれる整数順位数) / 出走頭数` を仮想的な無作為順位基準とし、モデル占有率平均との差（パーセントポイント）を保持。加えて4脚質間の6ペアについて、**全24設定＋前後15シードで同方向**と確認できた高低関係・保留関係を保持する。この基準は実際の対戦相手・順位が均一だとする仮定ではない。
3. **別の将来評価軸：発動後の効果の有用性（effect utility）**。加速や速度、回復等がその脚質・距離・局面でどれほど役立つか。①②の数値から算出せず、今回の評価対象には含めない。

①②を加重平均した単一のスコアや、根拠のない高／中／低の閾値は初期方式に採用しない。①のモデル占有率が高い場合でも、元の発動条件に別のAND／前提条件があれば、スキル全体の成立率が高いと認めない。

## 現在のモデルで測れる範囲

GlobalSim v77固定2,160レースから、**均衡編成だけ**（9頭：逃2、先2、差3、追2／12頭：各3）を抽出。4局面×11順位帯×4脚質＝**176脚質・帯域の研究データ**を生成する。

- [元データの固定ソース](https://github.com/Nimrodx0/Umasupport/actions/runs/42164735064) の `four-style-pairwise.json` SHA256 `62764af14894ed0ef5354f3136b8d9eaae0dc8426ca2d8a0f146ccd24ea25cc9` を照合する。順位帯の9/12頭への整数換算、元の4脚質ペア方向表、24均衡設定の母数を変えない。
- [2軸集計器](../poc/tools/globalsim_balanced_two_axis.cjs) は2軸を独立出力し、完全な固定出典に反するデータと、不明脚質の0%補完を拒否する。
- [研究用スキル適用器](../poc/src/skill_two_axis_research.cjs) は既存の[4脚質条件照合](../poc/src/skill_balanced_four_style_fit.cjs)のAND／OR・発動制限・前提条件の保留を引き継ぐ。スキルの高低適性そのものを確定しない。

単純なモデル占有率から見た均衡編成の順位は **差し＞先行＞追込＞逃げ**。この順位帯・局面についてのみ6ペアが全設定で一致。他の順位帯・局面には部分順序の保留があり、無理に1～4位の順位を付けない。平均は異なる大会・コースの出現頻度を推定したものではない。

**注意**：`phase_random` が必ず距離一様な地点で単発判定されると証明されたわけではない。モデル内の滞在距離割合を実ゲームの判定時の確率や発動率に変えるには、ゲーム側の抽選地点／条件再判定・他の契機／シミュレータの再現誤差を別に検証する必要がある。

## 実装の不変条件

- 均衡編成以外の脚質構成を標準評価へ混ぜない。均衡編成を実際の最頻編成とは呼ばない。
- 元の `order_rate` AND 組合せと `phase_random` の元窓に**厳密一致**したときにだけ、2軸の**順位帯部分条件**を返す。細分化された発動区間・`is_overtake`等の追加AND・OR・複数Invoke・前提条件は保留を保持し、順位帯の部分データだけを参照可能にする。
- 明示的な脚質による発動不可と距離・馬場の明示レース条件は別に保持する。未知は0点・無条件・脚質差なしとしない。
- サポカ単位へ勝手に加算・平均・ランキング化しない。金白・複数経路・排他的結果の重複対策は別途検証する。

## 次に決めること

1. **数値の意味と運用**：順位帯の距離占有率を成立機会の比較用モデル指標として採用できる条件を、実際の抽選仕様・代表スキルの条件と照合する。成立機会の分類閾値を決めるなら、順位帯の広さ・局面・時間抽選の違いを考慮し、実スキル53＋24件と反例を先にレビューする。
2. **脚質特異性の表示方法**：符号付き基準差、厳密な4脚質ペア関係、条件を満たしやすい脚質の範囲をどの粒度で表示するか。脚質間の同値・逆転は無理に決めない。
3. **P3集約への入力**：スキル獲得候補の確認済みIDと通常ヒント／承認イベント／実選択、OR・AND・未判定の境界を保持したサポカ単位の集計形式を試作する。根拠なく一つの適性スコアに集約しない。
4. **効果有用性**：別の将来研究として効果量・発動タイミング・脚質・コースの妥当性を調査する。今回の2軸からの自動算出はしない。

A（機構）：単体テスト、欠測・AND／OR保留、二軸独立性。B（モデル）：固定GlobalSim SHA照合・176件の再集計。C（実環境）：今回の研究専用PRでは本番画面に変更なし。**CI成功は日本版の実発動率測定・実機合格の証拠ではない**。
