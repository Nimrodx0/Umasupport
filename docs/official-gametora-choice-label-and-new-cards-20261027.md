# GameTora本体にない選択肢文言の補完と新SSR掲載監査（2026-10-27）

## 対象と根拠

前工程の[GameTora本体からのイベント経路取得検証](official-gametora-direct-feasibility-20261027.md)では、既存SSR30001の **5イベント／9経路**を効果・数値スキルID・ヒントLvで一意に照合できた。しかし **非空の選択肢ラベル6件は、本体のイベント表示・ページ全体には一致0件**。不足しているのは報酬の数値だけではなく、実際に画面で選ぶ選択肢の*文言*である。

個別の編集調査では、固定GT旧版にあるSSR30001の次の3イベントについて、**同じ6件の選択肢表記がGameWithの該当記事に掲載**されている。

| 固定参照内イベント位置 | 区分 | 候補選択肢数 | 補完先の根拠 |
| --- | --- | ---: | --- |
| 1 | 通常イベント | 2 | [曲がり角には、気をつけます！](https://gamewith.jp/uma-musume/article/show/261724) |
| 2 | 通常イベント | 2 | [あれもこれもで、悩んじゃいます！](https://gamewith.jp/uma-musume/article/show/261812) |
| 4 | 連続イベント第2段階 | 2 | [想いは、ジェットコースター！](https://gamewith.jp/uma-musume/article/show/261813) |

[SSR30001に限定したGameWithカード記事](https://gamewith.jp/uma-musume/article/show/257460)にも各選択肢が掲載される。通常イベント2件の個別ページは**男性／女性トレーナー向けのセリフ差**を列挙しているため、今回の6件一致はページ内の既定表記の照合に限定する。別表記・別カードの全対応を示さない。

**出典レイヤーの分離**：

- 数値効果、スキルID、ヒントLv、可視OR、連続打ち切りの取得基準を **GameTora本体**とし、旧派生GT JSONは歴史的整合チェックに使う。
- 元ページで選択肢の日本語セリフが特定できない場合、**そのカード・イベントに限定したGameWith記事の表示表記**を文言補完候補として扱う。記事と元ページでイベント・選択位置・報酬の対応を確かめる前に全カードへ類推しない。
- [非公開ラベル出典台帳](../poc/review/choice-label-provenance-30001.v1.json)には出典URL、カードID／イベント位置／選択位置、6件の正規化済みSHA-256、確認日、未承認状態だけを登録。**原文、本文のコピー、イベントJSONは保存・公開しない**。
- [ハッシュ検査](../poc/tools/verify_choice_label_provenance.cjs)は履歴固定Git blobと台帳の6個の指紋一致を検証する。**GameWithサイトの現在の文言を自動取得して再検証するものではない**。記事側の変更をこのCIが自動検知すると断定しない。
- 編集上の事実確認と、選択肢テキストをWebアプリのPublicデータとして再配布する権利・採用承認とは別。現状の正式配信イベントは **0件**。

## 新SSR 30322／30323を直接閲覧する少数カード追加検証

[Ubuntu 24.04の実Chrome検証](https://github.com/Nimrodx0/Umasupport/actions/runs/40488989364)では、2026-10-26実装の2枚のカードページだけを順次開いた。[実装](../poc/tools/probe_official_gametora_new_cards.cjs)は固定2カード以外を拒否し、robots.txtを先に確認、単一ブラウザ・6秒間隔、403／429停止、原HTML・文章・画像・レスポンス本文・JSONを出力しない。

| 検査 | SSR30322（マヤノトップガン） | SSR30323（吾妻） |
| --- | ---: | ---: |
| 元サイトのカードページHTTP 200 | Yes | Yes |
| Chromeで元ページが表示 | Yes | Yes |
| `section`内の開閉ボタン数 | **6** | **12** |
| 実際に開いたサンプルパネル | 2 | 2 |
| パネル内に符号付き数値効果を検出 | 1 / 2 | 1 / 2 |
| 全イベント報酬・分岐の完全照合 | 未実施 | 未実施 |
| スキルID・ヒントLvの独立照合 | 未実施 | 未実施 |
| 文言・先行依存・終了制御 | 未実施 | 未実施 |
| 元文書・画像の配布承認 | 未実施 | 未実施 |

**開閉ボタン数は、ゲームのイベント数の確定値ではない**。見出しはカテゴリごとに`h2/h3/h4`へ分かれていないため、カテゴリ別見出しの出現数0を「連続イベント0件」「お出かけ0件」と読んではいけない。また、サンプルパネル内の数値未検出はイベントに報酬がないことも意味しない。初期SSR2枚でも元サイトのブラウザ表示ができた、というのが今回のB実測の範囲である。

## ゲートの区別

**A（機構）**：ラベル指紋の変更・位置重複・無関係URL・公開フラグの誤昇格を拒否し、新カードページの固定対象のみ許容する合成試験。

**B（出典内容）**：既存SSR30001の6ラベルをGameWith記事の個別位置と編集照合。固定版の文字列とのハッシュ一致6/6。新SSR2ページの開閉UIと少数の報酬表示の存在。**新カードの経路・報酬完全性は未確認**。

**C（ブラウザ）**：GitHub Actions Ubuntu 24.04で元サイトの実Chromeを使用。これは現地物理端末やゲーム内操作を再現するものではない。

**D（公開）**：元文章の転載権利・直接サイトからの継続的取得条件を未承認。公開イベント0件、本番の固定GT由来監査ピンに変更なし。

## 次の実装境界

GameTora本体の新SSRで、イベントごとの表示と数値報酬を独立して構造化し、選択肢のセリフが必要な部分だけ個別GameWith記事へ照合する。実データを全カードに定期巡回する前にアクセス条件を検討し、各経路で不明な出典事実と完全に未収録の事実を区別する。SSR30323は友人タイプなので、連続イベントとお出かけ解放を別扱いにし、サンプル2パネルの成功で内部経路が完成したとみなさない。
