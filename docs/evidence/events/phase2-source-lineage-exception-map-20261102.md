### 固定コホートの検証

- GTの出典横断補正 **1件を例外除外**した2,487イベントの審査候補SHA-256（ID＋各イベントの正規化内容を集約）：`9cfb7f3241c1c94250605ef418260eef4080404debcfeea46738ba24bc756d2e`。
- 別出典の `usl:` 24イベントの技術的集合SHA-256：`0caf5ddf29c25aea9eb844571de67e278969748c977da26c59a0de9444123131`。
- 追加24、GT派生2,487＋例外1で**収録漏れ0**。いずれもv2で「承認」されたという意味ではない。
- `phase2_source_lineage_audit.cjs` は各工程の固定IDを追跡し、ID重複・途中欠落・未知の追加系列・最終SHAの齟齬・表示だけの工程での追加を拒否する。GT例外は `event_release_cohorts.inventory` に**除外イベントIDを明示**して一括審査候補から外す。**その除外イベント自体も後に別の個別／集合審査が必要**であり、黙って対象外としたまま公開してはならない。

## 公開利用条件の具体的な確認

法律上の**事実の非著作物性**は、数値事実が適法な方法・条件で取得され、他人のデータベースを単純複製してよいという包括的な許可ではない。確認した根拠：

1. [CRIC：著作物とは](https://www.cric.or.jp/qa/hajime/hajime1.html)：「事実」や「ありふれた表現」は著作物と認められない一方、創作的な編集・データベースは保護対象。題名も**通常は**保護されない。ただし個々の表現による例外、契約・不正競争等の別論点を残す。
2. [GameTora CLA](https://gametora.com/docs/cla)：寄稿者が権利を保持しGameToraに非独占の利用許諾を与える。GameTora自身が混合ライセンスと説明。**派生GitHubにAGPL表示があるだけで、元のゲーム表現やGT独自のDB構成を本アプリが再配布できるとは判断しない。**
3. [GameWith利用規約](https://gamewith.jp/terms)：第9条14号で通常利用を超えたサーバ負荷、第9条17号でサービス機能の複製・解析等、第10条1項で利用と知的財産権の許諾の違いを規定。**個別に事実を参照することと、文章の転載・大量機械取得は別**。第10条3項はユーザー投稿についての条項で、攻略記事・収録イベントデータ全体の許諾ではない。
4. [ウマ娘公式の二次創作ガイドライン](https://umamusume.jp/derivativework_guidelines)：他者の権利を侵害しないこと、商業・営利利用の制限等を記載。イベント名・選択肢・データベースを一括配布する包括許諾ではない。

**結論：今の根拠では、3集合とも公開承認はまだできない。** しかし短いイベント名を一律削除する根拠もない。機能を縮小する代わりに、イベント名を使用した独自形式について、固定出典・参照条件・DB構造と原文の違いを確認する。
