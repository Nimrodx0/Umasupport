# Phase 2：SSR30180の固定時期イベント「あなたを想って」を非公開候補に補完（2026-10-23）

## 個別裁定の根拠

GT/Checkerの非公開2,511イベントの数値差異監査では、残存Checker位置16のうち、**SSR30180「刻み続ける者たち」のChecker位置7**だけが、Checkerに数値スキルID`200332`があり、同カードの既存GT**イベント報酬**にはないP0候補だった。[固定全件のP0抽出](phase2-remaining-checker-skill-impact-20261023.md)による。

GameToraカード個別ページ：[30180 刻み続ける者たち](https://gametora.com/ja/umamusume/supports/30180-group)。GameWithカード個別ページ：[記事431692](https://gamewith.jp/uma-musume/article/show/431692)には、**「クラシック1月前半固定」**の「あなたを想って」に**選択肢なし**、**「コーナー巧者◯」ヒントLv1**と記載。掲載されるスタミナ／根性／スキルPtの値はボーナスにより変動するため、今回は数値スキルヒントのみ採用する。

## 実装・仕様

`poc/data/curation/adjudicated/30180_special_cornering.v1.json` はカード30180・Checker元位置7・スキルID200332・名称「コーナー巧者○」・ヒントLv1を元記事URLとともに記録。数値IDを利用者表示には使用しない。

`poc/src/phase2_30180_special_overlay.cjs` は、上記P0ソースキーと、全2,511候補の内容SHA・未承認状態を一致確認してから、元イベントを改変せず新規1件の `type:'auto'` + `availabilityKind:'special-trigger'` + `rewards:[{skillId:'skill:200332',level:1}]` を追加する。

「クラシック1月前半」の発生時期や抽選確率を**獲得経路のフラグ条件として扱わない**。ただし通常連続イベントの1段階と取り違えないよう、特殊イベント発生区分を保持する。別IDで既収録の同一イベントがないかは、カード固有の短い正式名と出典位置で監査し、重複が判明すれば独立イベントに追加し直さない。

本番イベント読込器の`preflight`・`attach`を一時モデルだけで行い、**563サポカ・2,512イベント**の数値・日本語スキル名・報酬経路の一致を検証する。元モデルと2,511イベントのSHAを変更しない。

## 境界

A：スキル候補と実`UmaCore.directRoutes`、元SHA・P0位置・正式公開台帳0件の回帰検査。B：GT全件・Checker全件数値監査と編集裁定済みGameWith記事の値に基づく固定実データ全件確認。C：今回の一般公開サイト内全2,512件操作・実端末は未実施。

正式公開用 `reviewed_events.v1.json` とイベント6項目の承認台帳は変更せず**0件**。この補完は技術的に動く非公開イベントデータの追加であり、掲載許諾・本文／選択肢文言の公開判断を自動確定するものではない。
