# Phase 2：SSR安心沢刺々美30080／位置6の3択を編集上補正（2026-10-22）

## 確認した出典と対象

基準は固定GameTora由来 `systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`。SSR安心沢刺々美 `30080`、GTイベント位置`6`・ローカルID`1392`（Checker位置`5`）は、元の固定データではラベル空の1行にスキルID **201591／ヒント+3** が記録されている。既存の[全件差異監査](phase2-cross-source-completeness-exceptions-20261022.md)では、このイベントにプレイヤーの実3択が存在するのに固定GTではまとめられていることを確認し、非公開数値候補だけ保持していた。

2026-10-22に[GameToraのSSR30080ページ](https://gametora.com/ja/umamusume/supports/30080-sasami-anshinzawa)をカード単位で参照。[GameWithのイベント個別記事](https://gamewith.jp/uma-musume/article/show/315701)では3つの操作選択肢がそれぞれ「ウマ好み」ヒントLv3を付与すると明記される。[ゲームエイト](https://game8.jp/umamusume/421771)も3択を掲載する。これは固定GTの1行をそのまま3択として解釈したのではなく、GameWithのイベント別事実を採用したもの。**GT現在ページの当該イベント詳細3択を個別取得したとの主張はしない。**

| 操作選択位置 | スキルID・ヒントLv | 同じ選択肢について掲載されたその他の数値事実 |
| --- | --- | --- |
| 1（上） | 201591、Lv3 | 体力+10～16／ランダムな能力値2種各+10～15／絆+5 |
| 2（中） | 201591、Lv3 | 同上 |
| 3（下） | 201591、Lv3 | 同上 |

選択肢の原文や画像は保存しない。能力値と体力の**変動幅**は編集台帳に残し、単一の確定値としてスキル集計へ混入させない。現行ゲームでの出現時期・確率は再現対象外。ゲームの現在の正しさと再配布許可は別途未確認。

## 変更内容

- `poc/data/curation/adjudicated/30080_choice_repair.v1.json`：独自の選択位置1/2/3、数値報酬、固定版・記事URL、ゲーム未検証・未公開の証跡。
- `poc/src/phase2_completeness_exception_queue.cjs`：既存の固定元GT・Checker差異とGameWith補正候補を読み出せる監査APIを追加。新しい編集台帳が従来の数値位置やIDから乖離すると拒否する。
- `poc/src/phase2_30080_three_choice_repair.cjs`：例外裁定契約を検証してから、既存のイベントスキーマに3選択肢として**非公開メモリ内でのみ**投影する。選択肢には転載文章でなく独自ラベルを用いる。
- `poc/tests/phase2_30080_three_choice_repair.test.cjs`：未選択ではイベント報酬0、どの選択肢を指定してもスキル201591ヒントLv3が**1経路**だけ発生し、同一カードを複数登録しても提供枚数が増えないことを実集計コアで検証。数値・位置の改変、イベント文章の混入、公開済みフラグの捏造を拒否。

```sh
node --test poc/tests/phase2_30080_three_choice_repair.test.cjs
node poc/tools/verify_event_release.cjs
```

**A 機構**：Nodeの実集計コアとイベントスキーマを利用した非公開テスト。**B 出典**：GT元の1行不足をGameWithの独立した操作3択記事で裁定。**C 実環境**：実ゲーム内での現行正確性・物理Android/Windows端末・第三者素材の再配布許可は今回未検証。

**正式公開イベント0件は不変**。固定GT自体の元ファイルも書き換えない。そのため全件固定GT監査の「構造不足1件」は引き続き差異として残す。編集上の3択再構成と、アプリの集計コアで扱えることのみが今回の成果である。
