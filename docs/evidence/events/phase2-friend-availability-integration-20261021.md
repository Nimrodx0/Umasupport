## 修正した実行時意味論

今回追加したイベントフィールド`availabilityKind`の値を、正しい入力カテゴリに限って使用する。

- `special-trigger`：特殊発生イベント。「特殊イベントの発生時」という未確定条件を付ける。
- `outing-sequence`：お出かけ実行によって進む各段階。「お出かけイベントの発生時」という未確定条件を付け、**同カード内の前のお出かけ段階が変換済みの場合だけ`requires`を付ける**。前段が未変換なら後段を独立イベントとして掲載しない。
- `outing-random`：お出かけ中に発生するランダムイベント。毎回の発生は保証されないため「お出かけ中のランダムイベント発生時」という条件を付ける。

`poc/src/event_schema.js`でこの3値だけを許可。`poc/src/core.js`の`reachability()`は**いずれも`conditional`を返す**。イベントの結果・選択肢をユーザーが選んでも、自動的に「発生条件を達成した」と解釈しない。前段お出かけが未選択の後続段階は到達不可、前段が成立しても特殊なお出かけ条件は残る。

これは**利用者が自分の編成で「どのようなスキル獲得機会があるか」を見るための条件付きモデル**であり、特別なイベントが通常の育成で必ず発生すると断定するものではない。GameToraの分類をアプリに直接採用する方針を維持し、これらすべてをGameWithに逐一問い合わせない。
