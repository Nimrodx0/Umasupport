# Phase 2：SSR30221連続3段階の手動到達プレビュー追加（2026-10-23）

## 対象と編集上の根拠

カードはSSR30221 サトノダイヤモンド **「今日もたのしく、おいしく。」**（KFC限定特典）。同一キャラクターの別SSRと混同しない。固定GameTora由来データは当該カードの通常イベント2件のみで、連続イベントを含まない。[カード別GameTora](https://gametora.com/ja/umamusume/supports/30221-satono-diamond)を確認済みの個別欠損として、[カード別GameWith](https://gamewith.jp/uma-musume/article/show/461418)に明示された**選択肢なし・連続3段階、体力・スタミナ・絆、最終段階の「食いしん坊」Lv1**を編集上採用する。記事は具体的な前後継続・打ち切りの選択や内部IDまでは確証しない。

既存の `poc/src/phase2_30221_missing_chain_intake.cjs` の出典改変拒否・カードID・スキル数値ID201351と「食いしん坊」の名称照合を必ず通してから、**非公開の手動到達表示**だけに転用する。内部story_idの他資料照合と実ゲームの再現試験は編集採用の必要条件としない。

## 今回のユーザー向け差分

既存 [GitHub Pagesの連続イベント試用](https://nimrodx0.github.io/Umasupport/poc/phase2-chain-preview.html) に5枚目として「サトノダイヤモンド」を追加。3つのカード固有の正式見出しを GameWith に照合して表示する。

- 第1段階「ふたりでひとつは、とってもおいしい！」：体力+5、スタミナ+5、絆+5。スキルヒントは掲載なし
- 第2段階「それはまるで“スーパーノヴァ”」：体力+10、スタミナ+5、絆+5。ヒント掲載なし
- 第3段階「打ち解ければ、きっと伝わるから！」：体力+10、スタミナ+5、絆+5、「食いしん坊」ヒントLv1

これらは、各段階で「この段階に到達した」を**ユーザーが明示的に選んだときだけ**スキル候補へ反映。第1・第2を押しても後続が自動的にオンにならないし、第3だけ到達を指定することも可能。**第1→2と第2→3の2遷移は未確証**である。
