# Phase 2：サポートカード563枚の独立収録範囲リスク監査（2026-10-22）

## 目的と母集団

固定GameToraとCheckerの差分65件をゼロにしても、**両方が同じイベントを収録し損ねた場合には検出できない**。対策として固定UmaSimのサポカ**563枚すべて**に対し、GameTora由来連続イベントの段階数、イベント区分、固定Checker収録数、固定GTスキル数値候補、独立編集記事による確認状態を組み合わせた**レビュー優先順位**を生成する。

使用版は `systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`、`Cilda/UmaUmaChecker@8cf9fcb3cc7239041161be75c84daf9f8f22d29f`、UmaSimカード母集団`cf9366f6a487bd8f197b53d8a11981207beb9f6c`。入力はCIが既に生成している全カード統合索引・GT連続トポロジー・GT数値候補・完全性例外台帳。固定GTのイベント**2,488件**とCheckerの**2,109件**を保持し、新たに第三者イベント原文を大量取得しない。

## 実装上の保証

`poc/src/phase2_independent_roster_coverage.cjs`とCLIで全563枚のカードID、GTイベント数、連続イベント数、元イベント区分、Checker件数・未対応行数を照合し、非公開の候補キューを生成する。元GTカード欠損・友人／シナリオ等・R・正規の1段階・真の不足を区別。SR20075はCheckerの元IDと未対位置・GT最終段階IDを固定し、30221/30240は前PRの監査証拠を照合する。30244／30286の単発も元GT IDで失効ゲートを設ける。新しいデータ出力はCI一時成果物とし、`poc/data/`への書き込み・未承認イベントのランタイム採用を明示的に禁止する。

**全件の固定元出典間差異は65件のまま**（Checker-only40、非R GT-only24、GT元の3択構造不足1）。SR20075は既存Checker-only40のうち1件。30240の両固定元外3候補も従来どおり別枠。独立資料での比較可能性が上がったことを正式配信や実ゲームの全件網羅達成とは呼ばない。

**A 機構**：カード区分・版固定・イベント区分・数字の変化拒否、数値と公開フラグの合成回帰。**B データ**：全563枚の固定GT＋Checkerインデックス＋独立掲載を限定引用した記事照合。**C 実環境**：CI上ChromiumとNode。Windows／Android物理端末・ゲーム内の発生条件と正しい報酬の実証・第三者素材の公開条件は未実施。正式公開イベント0件。

## 追加資料：SR20075の初段階に見える数値差の意味

[U-toolsの20075イベント別ページ](https://xn--gck1f423k.xn--1bvt37a.tools/supports/20075/event)では、固定GTが未収録の初段階について**根性+15・絆+15**と**根性+5・絆+5**が同一イベント欄に**それぞれ独立した報酬行**として併記されている。[Checker由来固定元とGameWith（2026年10月12日更新）](https://gamewith.jp/uma-musume/article/show/441770)は前者、[ゲームエイト](https://game8.jp/umamusume/600213)は後者だけを掲載する。

したがって初段階の報酬数値を「サイトの誤記」と決めつけず、**別々の結果として報告された二つの数値候補**を非公開監査に残す。U-toolsの欄は上・下の選択肢を明示した構造ではなく、成功・失敗のラベルも付いていないため、**プレイヤーの2択・結果の排他性・発生条件・確率は未確定**とする。ゲーム内の原文選択肢・数字の正式承認はしない。

`editorialNumericOutcomeDraft` には原文を含まない位置1／2と「根性+15・絆+15」「根性+5・絆+5」という数値のみ保持し、全行の`choiceTextStored:false`・`triggerConditionVerified:false`・`routeProbabilityVerified:false`・`publicationApproved:false`・`noAutomaticRuntimeAdoption:true`を検査する。先行の「報酬数値に編集資料間の相違がある」という記述は**一方の数値を誤りと断定するのではなく、候補2結果を見分ける条件が不明**という意味で維持する。

固定GT最終段階のスキル数値ID202462 Lv1と、この欠落初段階の数値報酬を混ぜない。優先レビュー7カード、固定元間の重点差異65件、正式公開イベント0件は不変。
