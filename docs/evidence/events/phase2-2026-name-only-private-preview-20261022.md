# Phase 2：2026年の別資料による名称を使った全イベント非公開変換（2026-10-22）

## 目的と境界

従来の[2025年旧マスター限定補完](phase2-2025-master-missing-skill-overlap-20261021.md)は、古いマスターからスキル名原文を読み、**固定GameToraの2,488イベントの技術変換を検証**してきた。この経路とは**別に**、2026年10月4日版の公開スキルメタデータ（[名前の全件照合](phase2-2026-independent-skill-name-fingerprint-audit-20261022.md)で28ID/28名前が一致）を取得して、**スキル名の出所だけ2026年別資料に置き換えた非公開技術プレビュー**を検証する。

重要：2025年資料への依存が全部なくなったわけではない。**スキル名の原文は2026年の別データから、rarity（通常／レア）分類および日本語名の照合ハッシュは2025年の数値だけの監査レポートから採る。** 新しい外部メタデータの `rarity` 数値を同じ意味だと推測しない。2026年のゲーム実機で効果やレア度を検証したと主張しない。

## 機構

- `poc/src/independent_2026_skill_dry_run.cjs` は固定GameToraソース版、UmaSimスキル固定版、旧2025年の監査レポートの出典版、欠損28ID／79記載の位置と件数、日本語名ハッシュを検証。名前は別資料 `Tsuyuchan-jp/umamusume-data@0cacbb1aaf9dca10283d5b9ea20b205b9d204535` の生データから**メモリ内のみ**で取得し、すべてNFKC正規化ハッシュの一致が必須。
- `poc/src/gametora_app_schema_dry_run.cjs` は`historicalPreview`と`independent2026Preview`を**排他的**に受け取る。元GameToraイベントの位置・分岐・ヒント数値IDのルールを変更しない。旧経路と別に`independent2026NamePreviewUsed`と`candidateIndependent2026NameHintMentions`／`candidateIndependent2026NameEvents`を監査可能なフィールドとして持たせる。歴史的な分類の根拠も明示する。
- `poc/tools/probe_gametora_app_schema_dry_run.cjs` は独立版のGit blob SHAとファイルSHA-256、名前ハッシュの全件照合レポート、旧マスターの**数値だけ**のレポートの相互整合をチェックした場合だけ、固定全件のスキーマ変換に進む。独立版の入力JSONはGitHub Actionsの一時フォルダに配置し、名前原文とイベント名を本番ファイルへ出力しない。
- CIは「2025旧名の一時補完なし」「2025旧名の非公開補完あり」「2026別資料の名前＋2025数値分類の補完あり」の**3モードを個別に実行**する。既存モードの母集団ゲートと公開ゲートを緩めない。

## 論理的な合格基準

| 比較軸 | 期待される観測 | 何を保証しないか |
| --- | --- | --- |
| 旧マスター追加なし | 2,378／2,488技術変換、保留110 | 元ゲームの欠損が110件という意味ではない |
| 2025年旧マスターの名前と分類を使う非公開補完 | 2,488／2,488技術変換 | 現行ゲームにおける効果・取得条件は未検証 |
| 2026年10月版の名前＋2025年の名前ハッシュ・分類数値を使う非公開補完 | **2,488／2,488技術変換を目標** | 2025分類からの完全独立、現行ゲーム一次確認、正式公開の承認はしていない |
| 3モードすべての公開承認 | **イベント0件** | ソース再配布やアプリ収録は未承認 |

出典元データの固定ハッシュ、元イベント分母2,488、元選択肢4,129、元経路4,376、旧名系が必要とする数値ID28個の保存を緩めない。あわせて、各テストでソース文面・スキル名の原文を成果物やログに漏らさないことを検査する。

## 2経路の全イベント候補SHA-256比較

[固定全件CI（3モード＋構造ダイジェスト）](https://github.com/Nimrodx0/Umasupport/actions/runs/39691292029)で、2025旧名由来プレビューと2026独立名由来プレビューの**全2,488イベントの候補JSON内容**を、公開しないままSHA-256で比較し、**完全一致**を確認した。

- ダイジェスト：`28804b0e034fb39c456e03e622fb8b4d8b520d839dada39fcead5f4ae7666317`
- `poc/src/private_schema_digest_parity.cjs`は両レポートの母集団・未承認状態・入力モードを検査し、候補全体のダイジェストが1文字でも違えば不合格にする。
- `poc/tools/check_private_schema_digest_parity.cjs`がCIの一時集計レポートのみを読み、名前や選択肢原文を吐かずに合否とハッシュを出力する。
- これは**固定版データに対する技術変換の同一性**であり、2026年のゲームでイベント／スキル効果が実在することや、第三者データの公開権利が確認されたことを意味しない。

## 別工程で残ること

この変更はPhase 2の**技術検証経路の多重化**であり、ゲーム内効果の真実性・レアリティ分類の独立検証・第三者データの公開利用条件・イベントの本番登録を解決しない。GameTora固定版に収録のないSSR4枚とChecker候補20イベントは[別の欠損台帳](phase2-missing-gametora-cards-20261022.md)で扱う。A（機構の合成テスト）、B（固定版全件のクロスソース再現）、C（実ゲームおよび物理端末の確認）を区別する。
