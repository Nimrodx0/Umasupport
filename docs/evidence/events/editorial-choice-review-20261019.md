# 2026-10-19：先行3イベントの選択肢別ヒント・2攻略記事照合

## 対象と検証境界

PR #103では「171グループ・450候補」のうち、別数値候補の `selection:single` が存在し、選択肢ごとに数値ID・Lvが一致する3イベントを検出した。今回はそれらを公開攻略資料のGameWithとGame8の**掲載値を目視照合して記録**し、今後の経路モデル化に使う監査記録にした。記事のイベント名・選択肢原文・効果原文はPublicに追加しない。

重要な証拠の限界：
- 候補CheckerはGameWith由来。GameWithとCheckerの一致を、独立した二資料による裏付けと数えない。
- Game8は編集が独立に見えても元となったゲーム内抽出や上流の独立性は未確認。**記事2ページの一致 ≠ 一次情報による確認**。
- 「成功・失敗の別表記がない」という掲載状態を「結果確率0、獲得率100%」には変換しない。ゲーム内の分岐確率、打ち切り可否、イベント到達条件、データ公開利用条件を別途確認する。
- GameWithとGame8の数値が異なるとき、ユーザー指定の既存設定 `poc/config/event-source-priority.v1.json` に従いGameWithの数値を**暫定採用**し、食い違いも残す。正式な2026ゲーム内検証ではない。

### 重要な相違：30256の絆ゲージ

`30256 / 830256002` 連続2段目の選択肢1・2の絆増加量は、GameWithがそれぞれ**+7**、Game8がそれぞれ**+5**。2か所不一致を `nonSkillSourceDifferences` として格納。ユーザーの既存優先ルールに沿って暫定値はどちらも+7と記録し、**ゲーム内部値として確定していない**ことを保持する。

異なるイベントの非スキル効果についてまで今回検査済みだとは主張しない。上記3イベントの体力・スピード・スタミナ・スキルPtなどの細目も今回の照合の正式な対象外とする。

## 確認プログラム

- 保存先：`poc/data/candidates/editorial_choice_review.v1.json`
- 検査器：`poc/src/editorial_choice_review.cjs`
- CLI：`node poc/tools/verify_editorial_choice_review.cjs`
- テスト：`poc/tests/editorial_choice_review.test.cjs`

検査器は、登録した3件が**既存171先行チェーンの一意なstrictタイトル仮リンク**であり、別数値候補にも同じ9桁story IDがあり、数値・選択肢位置が一致していたレコードであることを全件検証する。さらに編集資料に記録した各選択肢のスキルID＋Lvが既存Checker由来のヒントDBと一致すること、URLドメイン、出典来歴の未確定フラグ、GameWith優先ルール、食い違い記録、正式承認ゼロを確認する。

この自動検査ができるのは**保存済みDBとの整合性とレビュー対象の根拠が取り違えられていないことまで**。GitHub ActionsからGameWith/Game8の記事を自動収集しないため、第三者記事の記載更新を常に自動検知できるわけではない。

## 次に必要な検証

1. ストーリーIDを現行ゲームマスターまたはゲーム内で確認し、2025年仮IDと2026年イベントの同一性を確定する。
2. 選択後の**次段階進行・打ち切り・成功／大成功・確率的結果**を確認。今回の掲載記載から発生率・経路継続可否を推測しない。
3. その他の報酬や出典間差分を検証し、未解決の `30256` 絆+7／+5も現行ゲームで裁定する。
4. 第三者資料の利用・転載許可とイベントリリース審査を通したものだけを `reviewed_events.v1.json` に採用する。

**成果：3イベント・6選択肢・11ヒント数値記載が攻略記事2系統とも整合。実ゲームで経路まで承認したイベントは0。**
