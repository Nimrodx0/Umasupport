## 何が立証され、何が立証されないか

**立証できたこと**：2つの異なる年代・異なる公開元にある**28個のスキルIDと日本語表記が一致する**。現行UmaSimの収録不足は、必ずしもそのスキルのゲームからの消滅を意味しない。

**立証できないこと**：2026年10月22日現在のゲーム内で全28スキルが実装・ヒント提供されること、条件やヒントLvが正確なこと、独立元の加工工程が他資料に依存しないこと、ゲームの一次資料としての確実性。新しい資料は非公式の生成配布物であり、抽出ロジックも非公開である。

**非常に重要な差分**：新しい資料の`rarity:1`は、UmaSimでは`minus`（マイナススキル）に分類されるID `200283`・`200353`・`200521`にも付く。従って、**公開資料のrarityコードを、UmaSimの`normal`・`rare`・`minus`へ単純翻訳しない**。本監査はレアリティ／効果型を「独立検証済み」としない。

## 開発上の到達点と次工程

- 歴史的な旧名だけの同定より確証が増したが、技術変換成功率の分母・現行ゲームでの正しさ・本番承認数を水増ししない。
- 110の旧名補完なし保留イベントには、単一スキルのID不足による上流イベント保留と下流の到達依存が混在する。28 IDの新資料による名称一致と、110イベントの実ゲーム検証は**異なる作業**。
- 次に、28 IDのうち最新ゲーム内の実際のスキルヒント取得、スキル属性、収録イベントの分岐まで裏付けたものから、公開条件を含めて利用者向けデータを整備する。新版データをそのまま技術用本番辞書へ自動挿入しない。
- GameTora固定元にないSSR30318〜30321のイベント候補20件は別監査で管理：[未収録カード台帳](phase2-missing-gametora-cards-20261022.md)。名前の再照合でこの欠損が解消するわけではない。

本作業はA（合成ロジック試験）・B（数値IDと文面ハッシュの固定全件比較）の範囲。C（現行ゲームの確認、Windows・Android端末による操作受け入れ）は**未実施**。
