# Phase 2：スキル直接付与をヒントと分け、マイナススキルを獲得候補から除外（2026-10-21）

## 分類上の発見

固定 [GameTora由来イベント版](https://github.com/systemless10/UmamusumePS/tree/6e38b54af4fad397ff4491e63007a90705a4fe67/server/data/events/gametora) の `obtain_skill` は、`skill_hint` のヒントLv付与とは異なる効果。元データ全2,488イベント・4,129選択・4,376経路の `obtain_skill` 7件を、固定 [UmaSim skill_data.txt](https://github.com/mee1080/umasim/blob/cf9366f6a487bd8f197b53d8a11981207beb9f6c/data/skill_data.txt) と**数値IDで**照合した。

| 固定データID | UmaSim rarity | 出現先（カードID） |
| --- | --- | --- |
| 200283 | `minus` | 10074、30080 |
| 200353 | `minus` | 10074、30080 |
| 200521 | `minus` | 10074、30042、30080 |

合計 **7付与経路／5イベント／3カード**。固定マスターに存在しないIDではなく、**すべて通常の有益な`normal`や`rare`でない、`minus`分類のスキル**だった。今回の試験で実際の直接習得として技術変換した有益なスキルは0件。これを通常の「獲得できるスキル」としてカウントしない。

注意：これは「固定版で記載のあった`obtain_skill`の全件」についての結果。現行2026年ゲーム全体で直接スキルを習得する効果がすべて`minus`という主張ではない。

## 実行時の意味論と実装

スキル報酬は、従来の `{skillId,level?}` を変更なしで`hint`（ヒントLv獲得）として扱い、次の任意項目を追加する。

| 報酬 `kind` | 解釈 | ヒントLv | 通常のカバー率・提供枚数 |
| --- | --- | --- | --- |
| 省略／`hint` | スキルヒントの獲得 | 任意の正整数 | カウントする |
| `obtained` | スキルそのものの直接習得 | **指定不可** | 獲得候補として計上、直接習得と明示 |
| `negative` | マイナススキルの直接付与 | **指定不可** | **カウントしない** |

- `src/event_schema.js` は報酬種類を3種類に制限し、直接付与にLvが設定された場合は全カタログを拒否。
- `src/skill_bridge.js` は固定数値IDと名称を照合し、`kind:negative` はUmaSim `rarity:minus` の場合だけ受け付ける。通常のヒント名への名寄せは行わない。欠損IDも従来の検証エラーとして拒否。
- `src/core.js` は`negative`のルートを、有益スキルの`directRoutes`／デッキ別`aggregate`／`goalStatus`に**絶対に追加しない**。イベント発生条件を満たすかどうかと、プラスのスキル提供を区別する。
- `src/live_app.js` のイベント候補表示ではマイナススキルを「マイナススキル付与」と記載。直接習得なら「スキル直接習得」、ヒントなら「ヒントLv」と表示を区別。
- `src/gametora_app_schema_dry_run.cjs` はすべての`directSkillGrantFacts`についてクロスウォーク元の位置番号・数値ID・レア度を照合。未確認なら全イベントを保留し、スキル獲得ではなく害のある結果へ仮変換。原イベント本文・選択肢原文は含まない。

## 固定全件の技術試験結果

[GitHub Actionsの全件監査](https://github.com/Nimrodx0/Umasupport/actions/runs/39605472722) を出典として、**元データ母数は変更なし**。技術適合のみを報告する。

| 条件 | 前回 | 今回 |
| --- | ---: | ---: |
| 2025旧名補完なしの技術変換適合 | 2,364 | **2,374** |
| 同上保留 | 124 | **114** |
| 2025旧マスターで旧名を限定補完する非公開変換 | 2,471 | **2,483** |
| 同上保留 | 17 | **5** |
| 変換済みマイナススキルの付与 | 0 | **7**（旧マスター補完あり。なしでは6） |
| 安全にお出かけ開始と初回お出かけをつなげたカード | 12 | **14** |
| 公開承認済みのイベント | 0 | **0** |

保留5件の一次理由は**未確認の特殊条件4件、同一結果での重複スキル1件**。旧2025年マスターを補完して変換した候補は2026年の現行ゲームで検証したことにならない。「2,483/2,488」は技術スキーマ変換率であり、イベント効果の現在性・網羅性・正確性の達成率ではない。

## 検証と次工程

A：合成データで `negative` はヒントLvを持てない・数値IDの分類差で落ちる・通常の直接提供に混ざらない・開始お出かけの終了処理を維持することを確認。B：固定GT全件を、UmaSim固定SHA・マスター併用有無の両方でfail-closed試験。C：実Chromiumの回帰テストを実施。**現行ゲームの実体験とWindows/Android物理端末の受け入れは別であり未実施。**

次工程は特殊条件4件の意味論／相互依存を個別に検証し、結果重複1件を架空の獲得に変えず調査する。同時に公開に向けた現行ゲームの独立確認、独自のイベント表示語、転載・再利用条件と正式な公開ゲートを進める。
