# Phase 2 イベントデータ提供経路の判断（2026-10-30）

## 結論

**ユーザーがアプリを開けば自動的にイベントを使える状態が完成目標。** ローカルJSONの作成・ファイル選択は技術検証用の補助手段に留める。固定563サポカ・非公開2,512イベントは全件の技術的変換・ローカル読込と自動Chromium操作まで成功しているが、**2026-10-30現在、公開承認済みイベントは0件**。

**優先する経路は「ウマサルタント独自の数値・事実データを、公開可能な範囲を確定して既存の同一オリジンJSONから自動配信する」こと。** これは既存の `poc/src/public_event_catalog.js` と `poc/live.html` の起動時読込・IndexedDBへの検証済みキャッシュを再利用できるため、第三者サイトの全件取得器や新しい表示／集計コードを開発する前提がない。

現状、全2,512件を一括公開してよいとする法的・出典別の根拠はまだ成立していない。単なる事実の採用、第三者の創作的な文章・体系的構成の複製、第三者サービスへのアクセスは別々の判断とする。**GitHubで公開されていること、AGPLの表示、GitHub rawで技術的に読めること、CORSが通ることは、元データの再利用許可を意味しない。**

## 方法別の優先順位

| 順位 | 提供方法 | 実装と現状 |
| --- | --- | --- |
| **主経路** | 独自編纂した数値・事実だけを、条件確認後に `poc/data/reviewed_events.v1.json` 等の独自公開DBとしてGitHub Pages配信 | 起動時自動読込／ID・分岐・数値検証／キャッシュは実装済み。**配信可能な情報範囲の判断・バッチ公開ゲートの設計が未完** |
| 補完経路 | 適切に利用できる構造化元データをブラウザが直接取得し、その場で正規化 | CORS、利用条件、559ファイル相当の通信・キャッシュ、旧2,512変換との実行時同等性が未確認。**初期採用しない** |
| 開発専用 | 既存固定2,512件をローカルJSONで手動読込 | Chromiumの実2,512件まで検証済み。一般利用者にファイル生成や選択を要求する方式にしない |

## 一括公開の最小ゲート（イベント1件ずつの手動署名を求めない）

1. **公開対象を項目ごとに分類**する。固定ID、ヒントLv、選択肢の位置・発生条件・排他的結果と、第三者のイベント名・選択肢の発話・効果の文章を分ける。特にユーザーが指定した**男性トレーナー向け選択肢文言**は元ゲームや攻略記事の表現に該当し得るため、元文の転記を一括許可しない。出典を確認できなければ未検証ラベルのまま。
2. **独自JSONの構成**が第三者の創作的な編纂の複製になっていないか、固定2,512件の全体と例外コホート単位で確認。技術的に2,512件を変換できることだけで、全件公開の条件成立としない。
3. **出典・利用契約・必要な表示条件を確認**。大規模アクセス方式には別途アクセス条件を設定。明示的な権利者許諾が必要な表現・行為は、その範囲に限り許諾を確認する。
4. **公開データ形式を一括ゲート**にする。出典固定SHA、収録範囲、schema/skill-IDの整合、独自ラベル・原文非掲載、例外・保留、公開責任・更新手順を機械的に検査し、承認範囲を同一条件の集合単位で記録。既存のイベント別公開ゲートを勝手に迂回しない。
5. 条件成立したレコードだけ**既存の同一オリジン公開ローダーで自動配信**。未確定のイベントと報酬を0や無条件の報酬に偽装しない。2,512件を満たしたように見せるために他者の本文を同梱しない。

**先行しない作業**：一般利用者向けローカルJSON生成ツール、第三者GitHub各ファイルのブラウザ一括取得器、GameTora HTMLスクレイパー再開、既存2,512件の再変換、イベント全件への個別手動公開署名。これらが主経路を止める理由ではない。

## A/B/Cの現時点での判定

- **A（技術）**：旧2,512一括変換・本番互換・ローカル読込成功。既存公開JSONの自動取得・検証は実装済み。**新しい公開可能な数値DBのリリースは未実装**。
- **B（情報・出典）**：GameTora派生元、GameWith、UmaSim、文化庁、GitHubの規約・表示を確認。**数値・表現別の公開根拠、ゲーム現行全件性は未確定**。
- **C（実環境）**：固定候補のChromium読込・実イベント選択は合格。**公開用DBの2,512件自動ロード、ユーザーのWindows／Android端末は未実施**。

正式公開イベントは依然0件。今回の結論は**提供方式の優先順位と公開判断の境界**であり、利用許諾・公開承認の宣言ではない。
