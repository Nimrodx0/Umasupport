# Phase 2：GameTora全イベントの短い見出しを非公開公開候補へ照合（2026-10-23）

## 目的

PR #167/#168の技術用2,488イベント全件投影は表示名が「イベント001（仮）」等に固定され、**そのまま本番公開しても利用者がイベントを識別できない**。正常なGameToraイベントごとにGameWith記事を見直す代わりに、固定GTの元短見出しをカードID・元位置・SHAで結び付ける。プロジェクトの決定に従い、ゲーム内story_idの全件照合やゲーム実機再現は必須にしない。

## 実装

- `poc/src/gametora_short_event_title_intake.cjs`：非公開GT正規化候補・本番スキーマ形式の一時投影・固定GTソース文書を受ける。カードID＋ソースordinalを厳密照合し、各イベントの既存 `sourceTitleFingerprint` と、元イベント名をNFKC・空白正規化してSHA-256化した値を照合。タイトル名が一致しても2イベントのIDは**併合しない**。
- 問題ない短い見出しだけ、**一時カタログのイベント名**を差し替える。90文字超、空欄、改行やHTMLに該当するものは個別レビューへ。第三者の選択肢セリフ、報酬説明、画像は取得・複製・出力しない。出典のタイトルそのものをGitコミットしない。
- `eventSha256`、元カード、元位置、出典タイトルSHA、未承認状態からなるレビュー索引をメモリ内生成。公開用 `reviewed_events.v1.json`、イベント承認台帳、利用者アプリに書き込まない。
- `poc/tools/probe_gametora_app_schema_dry_run.cjs`：専用の固定全件ワークフローの**2026年数値スキル名照合済みの最終工程に限り**環境変数 `UMASUPPORT_GT_EVENT_DIR` を渡し、短見出し紐付けを2,488イベントに適用。出力は件数とSHA-256だけで、候補JSONや見出しの一覧はActionsへ保存しない。全559元カード・2,488投影に満たなければ失敗。
- Nodeテスト：同名イベント2件の分離、タイトル/元位置/カードID改変拒否、元投影の不変、長いイベント見出しの保留、固定全件と少数合成の区別。通常CIと固定全件CIへ接続。

## 未完了・公開条件

本工程は**見出しの一括紐付け**であり、現行ユーザー向けの正式収録ではない。出典にない分岐、未照合数値ID、版差、元GTが欠くSSR4枚、重点65差異は従来どおり別工程。技術用変換では一部の数値IDについて2026独立名称と2025レアリティ根拠を併用しており、これを最新ゲーム全件の事実保証とみなさない。

公開前には、短見出し・上／下選択肢の独自表示、イベントを識別できるか、公開利用範囲、データ版・出典、6観点の人手承認と本番ブラウザの検証が残る。これらをいっさい自動署名しない。

A：機構と改変防止を合成Nodeで試験。B：固定GT全件の実入力は専用CI（実行結果に従う）。C：公開Pagesでの2,488イベントは未配信、実端末は未実施。
