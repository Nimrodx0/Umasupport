# Phase 2：GTの同じ状態操作を元効果の順序つきで区別（2026-10-26）

## 対象と出典

[前工程の元数値順序の統合](phase2-gt-ordered-repeated-numeric-effects-20261026.md)後、GameTora固定派生データの非スキル構造保留は86イベントであった。今回の対象は同じ1結果の中に`condition`（同じ状態IDへの付与候補）または`heal_status`（悪い状態をランダムに一つだけ治す処理）が複数回現れる場合の`DUPLICATE_STATUS_OPERATION_UNADJUDICATED`。

固定版`systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`の[実行コード](https://github.com/systemless10/UmamusumePS/blob/6e38b54af4fad397ff4491e63007a90705a4fe67/server/app/event_engine.py#L1363-L1372)は元の`effects[]`を**配列順で1行ずつ処理**する。[状態付与・悪い状態の回復](https://github.com/systemless10/UmamusumePS/blob/6e38b54af4fad397ff4491e63007a90705a4fe67/server/app/event_engine.py#L1476-L1517)には状態IDに依存する個別条件・確率、および`heal_status`の「現在の悪い状態の中からランダムに1つ」という意味がある。

よって同じ条件IDの記載を1つの確定付与に集約せず、`heal_status`が2行あっても「必ず二つの状態が治る」「すべての悪い状態を治す」と断定しない。各回に出典で明示された`chance`があれば各行へ個別に保持する。

## 実装と安全な採用条件

- `poc/src/event_schema.js`の`statusEffects[]`は従来どおり`kind:'add-condition'`（正の整数`conditionId`）と`kind:'cure-one-bad'`、常時`possible:true`を必要とする。同一種別＋同じ状態IDが複数回出る場合には、**全該当行に元GT効果配列内の1始まりの`sourceEffectOrdinal`が必要**。正の安全整数かつ出現順に厳密な増加でなければ拒否。
- `poc/src/phase2_gt_whole_nonskill_effect_inventory.cjs`は元の配列を走査し、同じ操作を再発見した場合は前の行と今回の行の各実際の位置`effectIndex+1`を保存する。別IDの状態条件は独立して保持し、元の配列順・各明示確率を変更しない。未知の効果コード、元条件セグメント、結果マーカーや別の保留理由は引き続きイベント全体を隔離。
- `poc/src/core.js`の`UmaCore.directStatusRoutes`は元位置を結果へ返し、両操作を**個別の条件付き候補**として保持。元の状態がない場合・個別の状態適用ガード・確率とランダムな回復対象を仮定して確定報酬にしない。
- 既存非公開2,512件のスキル結果への結合はカードID／GT元イベント順位／選択肢／元結果祖先／打ち切りが一致した場合のみ行い、`statusEffects`だけを追加する。スキル側の`rewards`・`terminal`・`requires`・スキル出力SHAは一切変更しない。
- 合成Aテスト`poc/tests/phase2_gt_ordered_status_effects.test.cjs`は、異なる確率の2回回復、同ID状態の再付与、別状態IDの区別、元位置欠損・重複・逆順の拒否、結果・選択肢未確定の非保証、結合後の元スキル報酬不変を検証。従来の不正形状試験では、正しい元データの繰返しを誤って不正扱いしないよう分離した。

### 既存のスキル報酬との結果別結合

同じ全件監査で固定GTの**2,404イベントの元位置をすべて照合**し、スキル専用の非公開2,512件に**2,403イベントを結合**。結合成分は数値**10,961**、状態操作**96**、動的効果**22**。未変更109イベント。固定の全563カードについて元スキル`directRoutes`のSHAが完全一致し、本番`public_event_catalog.preflight`・使い捨てモデル`attach`も全2,512件に成功した。元の出典のランダム結果や技能を無条件取得として改変していない。

唯一の結合保留はSSR30080のGT元イベント#6。既存GameWith裁定で3択に補正済み、GT元はautoであるため、報酬を3択の各枝へ推測で割り当てない。
