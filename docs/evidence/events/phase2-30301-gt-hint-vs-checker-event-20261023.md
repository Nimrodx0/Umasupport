# Phase 2：SSR30301 グランアレグリアのChecker-only位置を個別裁定（2026-10-23）

## 事実と出典

固定GT/Checker差異の一つは**SSR30301／Checker元イベント位置1**（`checker:30301:3b1cb9d61ef50cb538c9`）。Checker側の基礎資料である[GameWithカード記事](https://gamewith.jp/uma-musume/article/show/561921)は、連続イベントに「成長のヒント」（「足任せ」ヒントLv4）を載せる一方、GT収録の中段「勝利へのマイルストーン」を連続一覧に記載していない。

[同カードのGameTora公式ページ](https://gametora.com/ja/umamusume/supports/30301-gran-alegria)では、「足任せ」は**通常のサポートヒント**の欄にあり、連続イベントは「最強≒ミューズ」「勝利へのマイルストーン」「最強のミューズへ」の3段階、さらに通常イベント2件という構成。[Game8の同カードイベント記事](https://game8.jp/umamusume/785657)でも、このGT側の3段階を記載し、中段2択の下段で「ハイピッチ」ヒントLv1を報告している。

今回の編集決定は**GameToraを基準として、Checker位置1を追加イベントとして採用しない**こと。GameWithとGTの現行記事に記述差があることは記録に残すが、GameWithの「足任せ」Lv4を本アプリの追加連続イベントとして扱う根拠にはならない。すでに固定GTにあるイベント（連続2番目・元GTイベント位置4）と無理に同一イベントとしてペアにもせず、**GT元の選択肢／ヒント経路を保持**する。これは「全ゲーム版で追加イベントが絶対にない」と実ゲーム内で証明した、という主張ではない。

## 実装と検査

- `poc/data/curation/adjudicated/30301_checker_hint_event_conflict.v1.json`：双方のカード記事URL、固定GT/Checker版、Checker安定sourceKey、固定GTの連続3段階・通常2件、下段「ハイピッチ」Lv1の数値事実、出典の記述差を最小構造化。外部記事の台詞・画像・文章は収録しない。
- `poc/src/phase2_30301_identity_resolution.cjs`：上記と固定差異の`GT-only`元位置4を照合。非公開2,511イベント内でGT側の3連続段階、ID、短いイベント名、元中段2択とハイピッチ数値ID `203352`、Lv1を再検査する。
- `poc/src/phase2_2511_gap_reconciliation.cjs`：Checker未対17位置から、この1位置だけを**出典差の編集裁定済み（新イベント追加0）**と区別。Checker起点の未対位置は16、GT/Checker両方にないSSR30240の連続3段階を加えた調査対象は**19位置**となる。もともとの65差異位置数・2,511技術候補の件数は不変。
- CIの固定GT全件・全Checker差異で正確なカードID、イベント位置、ID、2択構造と報酬を再照合。誤ったカード版、削除・報酬改変、Checker位置ずれ、偽の公開承認は失敗させる。

## 判断上の境界

- **本番スキル経路を勝手に増やさない修正**であり、既存の通常ヒント「足任せ」を二重計上しないことを優先する。編集上の出典優先順位は[GameTora→GameWith疑義裁定契約](event-adjudication-enforcement.md)に沿う。
- GameWithのイベント見出しの記載とGameToraの違いは現存するため、完全な記事間一致と呼ばない。GameWithの報告を消したわけではなく、編集裁定台帳に記録する。
- **正式公開イベント0件**、GameTora全体の2,488＋独自補完23＝2,511非公開イベント候補、実端末受け入れ未実施という境界は維持する。
