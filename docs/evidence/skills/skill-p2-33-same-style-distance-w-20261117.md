# P2.33：同一元部分条件・同一脚質の距離別Wの比較（2026-11-17）

**状態：監査コードと固定出典CIを追加。元データでの再解析と結果判定を実行する工程。** ウマ娘実ゲームの発動率やP3正式評価ではない。

## P2.17/17bとは異なる対象

[P2.17](skill-p2-17-distance-context-style-gap-20261112.md)と[P2.17b](skill-p2-17b-distance-split15-20261112.md)は、2脚質間のW差が距離によって変わるかを研究した。P2.33は**同じ元部分条件の同じ脚質そのもののW**が、短距離／マイル／中距離／長距離でどう異なるかを検査する。別のスキルのWを「同一スキルの芝・ダート差」と偽って比較しない。

## 固定対象と方法

- **出典固定**：UmaSim元skill_data.txt SHA-256 4c036527bbe6b5aad34d7f12110a06094c9071514e37fdfc68ae195403333be5、GlobalSim v77 commit 80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1、[元部分条件32種](../../../poc/data/p2_position_condition32_research.v1.json)。固定フル30シード四編成出力と0～14／15～29の分割出力を[既存のP2.13ワークフロー](../../../.github/workflows/p2-source32-split15-w.yml)で再利用する。新たなレース・実ゲーム観測は追加しない。
- **母集団**：距離無制限の元順位帯×時期部分条件10種類（芝4／ダート6）。距離限定22種類は対象外距離での架空の検証を避けるため除外。
- **比較単位**：元部分条件ID・芝ダート・順位帯・時期・距離制限、脚質、相手編成、頭数9/12、能力モードを揃える。距離内の複数コースについてW下限の最小と上限の最大で外包し、コース平均が反例を隠さないようにする。順位不明は区間で保持し、逃げ不在は欠測であってW=0ではない。
- **距離差**：2距離のW区間差 [W1下限−W2上限, W1上限−W2下限] が全て正／負の場合のみ方向を確定。区間重複は保留。5ポイントは従来の**仮の感度確認**であり正式採用閾値ではない。
- **15＋15再検証**：フル30で厳密差が出ても、同じ元条件・脚質・編成・頭数・能力・距離ペアで両15シードが同方向でなければ分割追認にしない。実ゲーム独立試行とみなさない。
- **追加対照**：東京競馬場の芝4コース（10501／10502／10504／10506）でも同じ比較を行う。競馬場固定でもコース幾何と距離は交絡する。
- **馬場軸の保留**：この固定10元条件では同じ元IDの芝・ダート両方の観測がなく、同一スキルの芝／ダートWの比較は**不可能**。芝4・ダート6を合算しない。馬場状態（良／稍重／重／不良）も未評価。
