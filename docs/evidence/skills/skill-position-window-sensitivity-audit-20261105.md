| 脚質 | 終盤前半のさらに前半（2/3～75%） | 終盤前半全体（2/3～5/6） | 変化 |
| --- | ---: | ---: | ---: |
| 逃げ | 100.0% | 99.7% | -0.3ポイント |
| 先行 | 96.7% | 96.3% | -0.3ポイント |
| 差し | 27.3% | 28.8% | +1.4ポイント |
| 追込 | 12.3% | 10.8% | -1.5ポイント |

**この条件では**前半から全体へ区間を延ばしても前方脚質の優位は大きく変わらず、「発動区間が75%を超えたら後方脚質が同程度に上位条件を満たす」という基準は導けない。差しが前方条件を満たす機会は存在するが、**スキル効果・芝ダート・距離などの他条件を同じにして実スキルを比較した数字ではない**。

## 2. 脚質の人数構成による違い

コースID10504、9頭、同能力、終盤前半全体での上位半数成立率：

| 参加構成（シミュレーション用） | 逃げ | 先行 | 差し | 追込 |
| --- | ---: | ---: | ---: | ---: |
| 均衡型 | 99.7% | 96.3% | 28.8% | 10.8% |
| 2026年1月の観測比率型 | 100.0% | 67.9% | 22.3% | 1.7% |
| 2025年12月の観測比率型 | 87.5% | 86.5% | 29.4% | 22.9% |
| 2025年10月の観測比率型 | 100.0% | 93.2% | 32.0% | 0.0% |

脚質編成を入れ替えるだけで、例えば先行は67.9～100.0%、差しは18.6～40.0%の幅を示す。**この幅には、構成比率だけでなく少数シードから生じる揺らぎも含まれる**。0.0%の列も、モデルのこの標本で成立数がゼロであっただけで「不可能」の意味ではない。

比較対象の観測実例は[出典別の脚質分布と限界](skill-position-population-priors-20261105.md)を参照。3大会を混ぜた参考比率を「対人レース全体の平均」とは呼ばない。

## 3. コース／出走頭数／能力差の影響

均衡9頭・同能力・終盤前半全体の6コースにおける幅は、逃げ**94.0～100.0%**、先行**94.5～100.0%**、差し**28.8～34.3%**、追込**0.0～15.2%**。これはモデル上の同一構成の条件付き比較で、ゲームの普遍的な脚質優劣を表すものではない。

同じモデルセルで能力差のみ「各馬に人工的な±10%」へ変えた場合、終盤前半全体の上位半数成立率の絶対差は、9頭で最大**17.5ポイント**（追込）、12頭で最大**23.75ポイント**（追込）に達する。実際の対人能力分布を±10%と決めたわけではない。

12頭は人数による感度確認であり、**LoHの6人NPCを含む実編成の再現ではない**。GlobalSim上の上位半数境界は9頭1～5位、12頭1～6位として処理している。JP現行の順位割合仕様の全条件を独立検証したわけではない。

## 4. 次の判断

1. モデル上では、前方順位条件が逃げ・先行寄りになる基本方向は、今回の主要な設定で比較的強い。ただし**適性の対象範囲・閾値・実ゲーム発動率は未決定**。既存のP2 v3脚質ラベル53件は維持する。
2. 今回の区間平均は**9地点の線形補間**である。発動位置の条件付き抽選、順位変動の急峻な区間、コーナー制限、追い抜きなど他条件を扱わない。実際の判定基準へ利用する前に、**密なリプレイからの区間直接積分と比較し、疎な9地点近似の誤差を調べる**。
3. 15シード／セルで少ない脚質は偶然の影響も受ける。少なくともシード数と脚質構成を変える頑健性確認が必要。
4. 今回の差分と構成・頭数・能力差は[自動感度監査](../../../poc/tools/globalsim_window_sensitivity.cjs)で再計算し、次回のCI成果物に `sensitivity.json` として保存する。数値・ソース版を変更したら**本書の表を更新**し、過去の成果物は履歴として扱う。
