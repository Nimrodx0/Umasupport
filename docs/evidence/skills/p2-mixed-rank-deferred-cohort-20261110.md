# P2：順位条件と推定保留条件が混在する17スキルの全件監査（2026-11-10）

**状態：固定UmaSim辞書をID・名前で厳密照合した818スキル中の、条件構造の調査。実スキル全体の発動率・脚質適性・カード価値・効果有用性の測定ではない。**

## 目的と調査方法

[前段の125条件型スクリーニング](p2-condition-research-triage-20261110.md)で「同じスキルに順位系条件と、一般化が困難で脚質傾向を推定しない／未検証の条件が共存する」と判断された**17スキル**について、元の `Invoke`、`conditions`／`preConditions`、各OR候補のAND式を個別に検査する。

条件型が1つのスキルに登場するという事実は、**同じAND経路で同時に必要とされることの証明にはならない**ため、同じAND、同じInvokeの別OR・別side、別Invokeを排他的に集計。別に根拠を持つ `running_style` 等の明示条件は消去しない。元スキル辞書全体は公開レポジトリへ複製せず、研究用監査結果だけをGitHub Actions成果物に保存する。

## 実測結果（同一ANDは17件）

| 保留する元コード | 件数 | 対象スキル（固定辞書上の日本語名） |
| --- | ---: | --- |
| `bashin_diff_behind`（後方の他馬との馬身差） | **7** | 空回り、圧倒的リード、大きなリード、先陣の心得、リードキープ、踏ませぬ影、粘り腰 |
| `distance_diff_top`（先頭との差） | **6** | 風雲の志、向上心、トップギア、キレる脚、完全燃焼、たぎる血潮 |
| `activate_count_heal`（回復スキル発動回数） | **2** | 明鏡止水、冴える思考 |
| `temptation_count`（掛かり関係） | **2** | 抜群の切れ味、切れ味 |
| **合計** | **17** | |

- **17/17件が、同じAND経路に順位コードと保留コードを両方含む**。
- 同じInvokeの別AND／OR・前提条件だけで共存するケース：**0件**。
- 異なるInvokeだけで共存するケース：**0件**。
- 元順位コードは `order`、`order_rate`、`order_rate_out50_continue` を含む。すべてを同一の「順位割合」へ変換しない。

**解釈**：17件はいずれも順位の部分研究だけでスキル全体の成立機会や脚質適性を計算できない。前後の馬身差13件は、一般的な4脚質の判定を作る根拠が不安定／環境依存となるため、現時点ではこの条件の独自脚質推定を行わない。ただしその13スキルを「全脚質共通・高適合」「どの脚質でも等しく発動する」とは認定しない。その他4件も未実測の追加条件を無視して数値化しない。

## サポカ集約への境界

- 研究値のある順位サブ条件と、未研究の必須ANDを**別の属性**で保持し、未研究ANDを0%あるいは脚質差ゼロと扱わない。
- 明示脚質・距離・馬場条件がある場合、それ自体の制限は保全する。未研究条件があることだけを理由に明示制限を外さない。
- 金白や同じ条件のスキルに複数の獲得経路があっても、研究対象が17件だからとサポカ17枚と数えない。
- 将来の研究で同じANDの交差が測れたときのみ、元スキル全体の推定を見直す。ランクと未研究条件の周辺確率を独立と仮定して乗算しない。
- スキル発動後の効果有用性は将来の拡張候補。P2/P3の初期評価には入れない。
