# P2：77スキルの順位条件成立機会の文脈感度監査（2026-11-07）

**研究結果：固定77件の元スキル・81元AND/OR経路から、同一元条件を重複除去した32種類×4脚質＝128組を対象として、コース・頭数・能力条件の設定ごとに10m順位条件成立機会を比較した。現モデル内では頭数／脚質編成の違いによる感度が特に大きい。高／中／低の境界値は未採用。実ゲームの発動率、有用性、サポカP3/P4への反映は未承認。**

前提資料：[芝・短窓の77件監査](skill-subphase10-77-audit-20261107.md)、[ダート17件の独立再計測](skill-dirt17-10m-audit-20261107.md)、[2軸評価の設計](skill-position-two-axis-research-20261106.md)。

## 1. 元データ・検証可能な範囲

- 固定UmaSim辞書 `f6e4501ee6c6c2d4ac8698e7796e309d31575bde`、SHA-256 `4c036527bbe6b5aad34d7f12110a06094c9071514e37fdfc68ae195403333be5` を使い、元条件77スキルを監査で取得。元スキル全体に別の追加ANDがないか、明示距離と芝／ダートが一致するかを既存監査器で照合する。
- 固定GlobalSim v77 `80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1`。均衡編成の**芝720レース＋ダート720レース＝1,440レース**を同じ手順で再実行。9頭（逃2・先2・差3・追2）、12頭（逃3・先3・差3・追3）、全員スキルなし、馬場・距離・脚質適性A、同等能力と人工±10%能力差。各6コース×2頭数×2能力モード×30シード。ダート／芝コース群は異なる形状であり、両者の差を馬場だけの因果効果と呼ばない。
- 元の全局面10m窓レポートSHA-256 `f512e24b2987ccd642f17f21f92865e965a43b90985ef37d622f1ae2f2ec9e58`、芝細分窓SHA-256 `206d9db77299189f91fea649a40effbe9ca2d2203c9d0b69c7873bfacee04c27`、ダート両窓モデルSHA-256 `242273c0903f37f4c8817e2d8c95325c6f14758fb8edc544974f78f3bf2328d1` の完全一致を検証してから集計。
- [文脈感度解析器](../../../poc/tools/skill_context_stability_77.cjs)は、元の81条件経路の**324脚質ケース**を照合し、金白等の同一発動条件をまとめた**32種類の元条件×4脚質＝128ケース**を集計する。うち芝104ケース（26種類×4）、ダート24ケース（6種類×4）。
- 各元条件の明示距離に一致するコースだけを使い、1条件・1脚質あたり**4／8／24文脈**（対象1／2／6コース×9/12頭×能力2モード）の平均・分位点・最小／最大・標準偏差、9頭／12頭別、能力モード別、コース別平均と1コース除外感度を算出。**全条件を6コース一律に平均しない**。
- 実験上の「1文脈」は、そのコース・頭数・モードでの複数走者・30シード集計値。128ケースも独立標本ではなく、重複を除いた元条件と脚質の組である。ここでの標準偏差・分位点は**モデル設定間の記述統計であって実際の発動率の信頼区間ではない**。

## 2. 仮の高・中・低区分を設定した場合

数値の分類の頑健性を検査するためにのみ、成立機会の仮境界を置いた。「低」は下限未満、「高」は上限以上、それ以外を「中」とする。実際のアプリの適合性ラベルへは適用しない。

| **仮**区分境界 | 128ケースの全設定で同じ区分 | どこかで区分が異なる |
| --- | ---: | ---: |
| 低：20%未満・高：80%以上 | **103（80.5%）** | **25（19.5%）** |
| 低：10%未満・高：90%以上 | **91（71.1%）** | **37（28.9%）** |
| 低：5%未満・高：95%以上 | **75（58.6%）** | **53（41.4%）** |

20%／80%の仮区分に対する脚質別の「全設定一致」内訳：

| 脚質 | 一致 | 不一致 |
| --- | ---: | ---: |
| 逃げ | 32 / 32 | 0 |
| 先行 | 32 / 32 | 0 |
| 差し | **7 / 32** | **25 / 32** |
| 追込 | 32 / 32 | 0 |

**不一致25ケースはすべて差しの元条件**。しかも25ケースのすべてについて、9頭／12頭それぞれの平均値だけを区分しても結果が異なる。したがって「平均が20%未満なので全頭数で低適合」といった表示は、この研究の感度差を隠してしまう。

この結果は**20/80を採用すべき根拠ではない**。候補の区分を少し動かすだけで安定度が変わるほか、対象の元77件は順位帯・局面の特定条件によって先に選ばれたもので、全スキルの代表標本でもない。

| 設定を変えたときの平均成立機会の変化 | 128ケース中、差5ポイント超 |
| --- | ---: |
| **9頭と12頭（均衡編成ルールも変化）** | **43ケース** |
| 同一元条件の候補コース間の平均最大差 | 3ケース |
| 同等能力と人工±10%能力差モードの平均差 | 0ケース |

さらに、頭数で10ポイントを超える差があるものは**35/128**、文脈別の最大・最小値の差が10ポイント超は**45/128**、20ポイント超は**24/128**。最大の頭数差は**34.46ポイント**だった。

**注意**：頭数を9→12へ変えると、固定均衡脚質構成も「逃2・先2・差3・追2」から「逃3・先3・差3・追3」へ変わる。また順位割合の整数順位への換算にも影響する。したがって、この差を純粋な「頭数だけの因果効果」とは呼べない。コースの差も競馬場・坂・コーナー等の要因が混在する。

選定した元条件には対象モデルコースが**1つしかないケースが40/128**あり、これらのコース除外感度は**評価不可（null）**としている。これをコース差0だから頑健だと誤読してはならない。また、モード差が5ポイント以内だったという結果も、現実の能力差やスキル相互作用に対して感度がないと証明したわけではない。

## 5. 評価設計に関する提案（**採否未決**）

今回のデータだけから単一の区分閾値を確定せず、**成立機会の数値と、その適用範囲・安定性を分けて扱う**ことを次段階の設計方針候補とする。

1. **計測の本体**は、元順位帯・元抽選窓・明示距離・芝／ダート・脚質をキーとした10m成立機会の連続値とする。順位条件以外の追加AND、複数ORの同時成立・合併、実際の技能発動抽選・効果有用性は別枠の保留。
2. **9頭／12頭の両方を独立して保存**し、利用者の対象レース頭数が決まる場合にはその条件のモデル値を優先する案を検討する。頭数未指定時は単一数値だけを強調せず、両方と設定幅を表示できるようにする。
3. 高／中／低の候補区分が**すべての対象文脈で同じ場合**と、頭数などで変わる場合を区別する。後者には「条件依存」「設定によって変動」などのメタデータを併記する。例えば平均だけで一律に「低適合」と断定しない。
4. 固定均衡編成の外側（逃げ不在、偏った対戦脚質構成）、実ゲームの発動処理、順位の整数境界の照合と、幅広いスキル条件への拡張を終えるまでは、**20/80も10/90も5/95も採用しない**。
5. 以前合意した**第2軸「脚質特異性」**および別課題の**効果の有用性**を、この絶対成立機会の候補区分と混合しない。本番アプリのサポカ評価、公開UI、ユーザー保存データは変更しない。
