# P2.15：スキル装備時にGlobalSimが抽選した判定窓の直接観測（2026-11-12）

**位置づけ**：前回の[スキル未装備・固定抽選値0.5の反実仮想](skill-p2-15-pre-skill-position-20261112.md)から、**スキルを実際に装備した固定GlobalSim v77モデル**へ進む独立の研究。これはGlobalSimの実行窓とモデル内発動イベントの観測であり、元UmaSimの抽選結果・実ゲームのスキル発動率・P3カード適性ではない。

## 対象と固定条件

GlobalSimの固定コミット 80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1 に含まれる examples/v77-race.jsonl の元skillDataをCI実行時だけ読み込む。retail初期化・runtimeの両方を有効にする。元UmaSimの別ソースと同一視しない。

| 固定モデル数値ID | 固定モデルの条件式 | 検証対象 |
| --- | --- | --- |
| 200451 | phase_random==0 | 単純な局面0ランダム窓 |
| 200501 | phase_random==2 | 単純な局面2ランダム窓 |
| 200701 | distance_type==2 ＆ phase_random==2 ＆ order_rate>50 | 距離制限と順位条件のANDを持つ対照 |

上記3スキルを全走者に装備し、条件式が固定モデルの元データと一致しなければ停止する。対象は固定8モデルレース。**元UmaSimで先に監査した102スキル・371経路を、この実験ですべて研究した意味ではない**。

## 追加した測定方法

[計測器](../../../poc/tools/globalsim_p2_15_equipped_runtime_windows.cjs)は、元モデルをCIの一時ディレクトリだけで計測版へ変更する。元のスキル組立・RNG・発動判定の処理は変更しない。

1. 元GlobalSimのPendingSkill.windowsをフィールド構築直前に読み、モデルのretail初期化で実際に採用された**抽選後の数値区間**を記録。新たな乱数を引かない。
2. 前回P2.15の計測器と同様に、priority=1／0のスキル処理直前の位置を直接記録。両位置が等しく、前tick移動後位置と一致することを検証。
3. **無改造版にも同じ3スキルを装備**した条件を再生し、全位置・速度・体力・レーンとskillEventsが完全一致することを検証。異なる場合は停止。
4. 元応答にない数値窓だけを追加。Gate順内部並び替えが行われるときも元の走者対応を復元する。
5. 未知技能ID・不正区間・重複技能詳細・元Rustアンカー変化には失敗を返す。

スキルの装備と実際のGlobalSim数値抽選は確認できても、**ランダム区間内に入ったこと、他のAND条件、モデル内スキル発動イベント、元UmaSimの発動、実ゲームの発動**は別の事実として扱う。

## CIと証拠

[専用Actions](https://github.com/Nimrodx0/Umasupport/actions/workflows/p2-phase-equipped-runtime-windows.yml)で元／計測版エンジンを別ビルドし、固定8スキル装備レースを実行する。モデル数値・窓・元との比較結果だけを成果物として14日保存。第三者の技能辞書全文・ビルド成果物は公開レポジトリに同梱しない。

[人工単体テスト](../../../poc/tests/globalsim_p2_15_equipped_runtime_windows.test.cjs)は、モデルイベント差異・物理値差異・同一判定時刻の不一致を検出する。**実測：[GitHub Actions #43169410849](https://github.com/Nimrodx0/Umasupport/actions/runs/43169410849) 成功。** 元版／一時計測版を別々にビルドし、同一8レースを比較した。

| 検査項目 | 固定GlobalSimモデルの結果 |
| --- | ---: |
| 実スキルを装備して元／計測版で比較したモデルレース | 8／8 |
| リプレイの一致フレーム | 10,413 |
| 位置・速度・体力・レーンが一致した数値 | **437,364／437,364** |
| priority=1／0の技能判定直前位置の一致 | **108,769／108,769走者・tick** |
| 同じ走者の直前post位置との一致 | **108,769／108,769** |
| 同一モデルのskillEventsの完全一致 | **181／181** |
| 対象3技能のモデル内発動イベント | **173** |
| 元モデルのPendingSkillから読んだ区間エントリ | **252** |
| **有効なコース内のモデル抽選窓** | **210** |
| **発動対象外の9999m予約区間** | **42** |
| 有効窓と技能判定直前位置の重なり（技能ID別に重複計上） | **1,512走者・tick相当** |

**重要な識別**：GlobalSimの元コードは、実行条件を満たすdetail-0が組み立てられないとき、窓を `Region(9999,9999)` に置いた無効な予約detailを作る。この42件は「スキルを装備した」事実ではあるが「ランダム窓を有効な位置で抽選した」件数ではないため、210件から除外した。予約detailに発動機会は割り当てない。

| モデル技能ID | 実行用の有効窓 | 対象外9999m予約detail | 有効窓に重なった走者・tick相当 | モデル内発動イベント |
| --- | ---: | ---: | ---: | ---: |
| `200451` | 84 | 0 | 679 | 74 |
| `200501` | 84 | 0 | 554 | 78 |
| `200701` | 42 | 42 | 279 | 21 |

モデル技能イベントには抽選窓以外の成立条件・スキル発動判定が含まれるため、窓の重なり数とイベント数は同じにならない。1,512は複数tick・技能を跨いだ累積観測であり独立試行ではない。モデル上のイベント件数173を元UmaSim・実ゲーム発動率の分子にしない。

[数値監査成果物（GitHub Actions、14日保持）](https://github.com/Nimrodx0/Umasupport/actions/runs/43169410849/artifacts/)は実装ログ、出典ソースのハッシュ、集計JSONを含み、第三者マスターデータ全文やビルド成果物は含まない。

## 未完のゲート

- GlobalSim v77のretail初期化で得た抽選値は、固定UmaSimのSkillCheckerが抽選した値ではない。両者の抽選窓・浮動小数点計算に差異がある。
- 元UmaSimの全AND／OR・preConditions履歴・複数Invokeを同一tickで評価できたわけではない。
- 試験にあるモデル発動イベントは実ゲームの発動率・脚質適性を表さない。
- 距離・馬場の明示的な適用範囲、脚質・距離・馬場での条件成立しやすさ、発動後の効果の有用性は別概念。効果の有用性は将来拡張のまま。
- 公開P3カード評価・P4 UIは更新しない。
