# P4：D-052適性ラベルのローカル試用（2026-11-25）

公開版に未承認の研究データを同梱しない。D-052固定CIで生成された全881件の元ID、明示必要マスク、適性ラベルと限定文脈だけを最小JSONに出力する。元辞書・イベント本文・全研究明細を含めない。固定現行・歴史辞書のSHA-256と全アプリID・元ID、3状態件数、マスク・ラベル形式、行のダイジェストを照合。行ダイジェストは整合性検査であり署名・真正性証明ではないため、利用者は検証済みCIの成果物を用いる。配布や自動ダウンロードは未承認。

`poc/live.html?suitability=local` でのみ表示パネルを起動し、利用者がローカルJSONを選択する。初期はラベルOFF（試用の設計判断、正式な初期値は未決定）。ON/OFFは表示だけ、元条件の対象候補／対象外／範囲未確認と取得経路・提供枚数を変えない。脚質・距離・芝ダート・馬場状態は任意、限定向けには任意の固定コース／頭数／編成の研究文脈指定が必要。指定なしは未判定。元データのIDが一致しない場合は拒否。絞込「適用候補」は未判定を残し、カード検索は既存取得経路と同じスキルIDの一致を使う。カード詳細に現在候補・全記録候補を別表示する。得点・カード自体の適性ラベルなし。表示設定は一時メモリ、通常のデッキ設定は別キーで保護する。

固定データで本番コードと同じlive画面をChromium 1280/390pxで操作し、ローカル読込、表示切替前後の行数と適用範囲の一致、絞込、壊れたファイル拒否、通常版への復帰を確認する。実際のWindows／Android物理端末、Pages、本番公開、公開データの配布方式は別。CI待ち。
