# P3.4h：81短窓技能の実用差感度（2026-11-25）

P2.28とP2.36の同一文脈内の観測明細（全30、先15、後15）を使う。P2.41の固定元IDと枝を保持し、追加のレース走行は行わない（既存CIが固定入力を再生成）。69直接技能中30は単一脚質、39は4脚質比較可。例外12技能の22距離・順位枝を含めると、81技能・91枝中61枝が4脚質比較可。別の6ダート指定技能は引き続き芝転用保留。

脚質ペアごとに同一コース・頭数・能力条件・試行分割のW差とD差の最小・最大を別々に求める。0/5/10/20ptの仮差幅で対象群内のW差が幅以内、かつ全対象脚質が全非対象脚質を幅より大きく上回ることを確認する。非対象同士の順位付けは要求しない。Wのみと、全対象対非対象のD差が全観測で正の二方式を比較する。後者は別指標の支持が得られる候補の確認で、Dの重み付けや正式な必須条件ではない。異なる元距離枝で結果が一致しなければ全体の候補として保留し、枝別結果を維持する。同値幅内という結果は汎用認定しない。

固定均衡編成・芝・モデル短窓の成立機会を使うため、実ゲーム発動率や効果価値、全条件の一般ラベルに昇格させない。4fの固定8文脈モデル全論理とWの分母や意味が異なる。候補数を無条件に加算しない。正式採否と実用差は利用者確認前、固定CI未確認。
