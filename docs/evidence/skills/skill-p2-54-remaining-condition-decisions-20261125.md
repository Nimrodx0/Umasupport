## 限定実験の前に行うこと

既存の[P2.42](skill-p2-42-dynamic-AND-impact-gates-20261119.md)・[P2.43](skill-p2-43-exact-three-spurt-AND-source-mechanisms-20261119.md)・[P2.39](skill-p2-39-original-race-natural-spurt-same-tick-20261119.md)を採用範囲内で使う。元UmaSimの[固定Checker](https://github.com/mee1080/umasim/blob/f6e4501ee6c6c2d4ac8698e7796e309d31575bde/race/src/commonMain/kotlin/io/github/mee1080/umasim/race/calc2/SkillChecker.kt)の時間・SP・スパート状態、近傍の特殊状態近似を確認済み。定性方向を確定できる証拠はまだない。先頭／最後尾の不在は必要条件の仮説であり元特殊状態の判定式を検証したものではない。

新規コードは計算状態6型の全比較可能元経路から、時間下限単独、履歴依存、他動的条件依存、状態と位置窓の限定観測候補を抽出する。元演算子・値は実行時にのみ読み、原データを配布しない。時間下限候補も閾値までの到達を保証しない。D-049の条件が含まれる場合も未知のまま残る。現時点で新規シミュレーションは開始していない。固定CI待ち。
