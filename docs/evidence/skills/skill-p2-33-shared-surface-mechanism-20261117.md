# P2.33：芝／ダートの共通順位・時期条件機構と、元スキル経路の照合（2026-11-17）

**状態：固定GlobalSim v77の元30／前後15シードのモデル再解析、および固定UmaSim元スキル818件の構造監査がともにCI成功（2026-11-17）。** これは**同一スキルの芝／ダートWの実測ではない**。[先行距離別W](skill-p2-33-same-style-distance-w-20261117.md)では、芝側とダート側で元スキルIDが重複しなかったため、元の10部分条件間で芝とダートのWを混同することを禁止した。本研究でもその原則を維持する。

## 研究上の二つの異なる検証

### A. 固定モデル：同じ順位・時期条件「機構」を両馬場で比較

[元32条件の固定マニフェスト](../../../poc/data/p2_position_condition32_research.v1.json)に含まれる**距離無制限10条件（芝4／ダート6）**から、元順位帯の比較演算子・数値と、元局面ランダム窓の種類・値が**同一**の芝／ダートペアを抽出する。両者の元スキルIDは異なる。以下の4組は、順位帯・時期の部分条件式だけが共通である。

| 共通部分条件 | 芝側の元ID | ダート側の元ID |
| --- | --- | --- |
| 局面序盤後半のphase_laterhalf_random:0・順位50%以内 | 204751 | 202951 |
| phase_laterhalf_random:1・順位50%以内 | 204071 | 202261 |
| phase_random:1・順位40%以上 | 203361 | 101902211 |
| phase_random:1・順位50%以内 | 203031 | 202841 |

**用途**：同じ順位帯と窓の部分条件について、芝ダート両方の無スキルモデルのW差が大きいか、条件・編成・距離によって方向が安定するかを試験する。これは各部分条件の**共通判定機構の観察**であり、列挙した**別々の元スキル同士を同一スキルとして扱わない**。元スキルの全AND、他のOR、preConditions、追加Invoke、効果・発動抽選は測定しない。

[研究用監査器](../../../poc/tools/skill_p2_33_surface_w.cjs)は、固定GlobalSim v77・UmaSim源スキルSHAを検査した既存5,760レースの再解析（4相手編成、9/12頭、2能力モード、30シードと0～14・15～29の分割）を用いる。同じ共通順位帯・窓・脚質・編成・頭数・能力モード・距離区分で芝／ダートのWを比較する。各距離区分の芝側・ダート側で複数コースがある場合は、W下限の最小・上限の最大で外包し、片方のコースを都合よく選ばない。芝とダートでコース形状・競馬場・条件が同時に変わる交絡は残る。

比較可能な同条件セル数は、4機構×4脚質×4編成×2頭数×2能力モード×4距離区分＝1,024候補から、逃げ不在編成の**64距離セル**を除いた**960セル**。1距離セルに対応するnoFront欠測は4機構×2頭数×2能力モードの**16編成・頭数・モードセル**であり、0%として処理しない。元30シードで区間差が厳密に正／負でも、同じ条件の両15シードで同方向を確認できない場合は追認しない。仮5ポイントは研究の感度確認のみ。

### B. 元スキル818件：同じ機構を含む「元のAND経路」を照合

別の[元スキル経路監査](../../../poc/src/skill_p2_33_surface_crosswalk.cjs)は、既存の[原数値パラメータ付き3軸静的ゲート](skill-p2-15-parameterized-axis-gates-20261113.md)を再利用し、source-matched 818スキル／970条件経路から次を絞り込む。

1. 同じ**conditionsのAND**内に、元演算子・数値を保ったorder_rateと、元phase_random等があり、Aの共通機構の一つと一致すること。
2. 4脚質×4距離×芝／ダートについて、**同じ馬場状態**（ground_condition）の条件を両馬場で同時に静的非除外とできること。芝だけ良、ダートだけ不良という別条件のすり替えは不可。
3. 別の追加AND条件・履歴preConditions・別Invoke・競馬場ID track_idなどは**検証済みとしない**。適用可能性は「元の静的必要条件で否定されていない」範囲に止める。

ここで候補を発見できても、そのスキル自体を芝とダートで装備して同時条件の成立機会を測ったものにはならない。Aの共通機構WをBのスキル全体のWへそのまま転写しない。原スキルIDと分岐・条件位置のみ保存し、元の大量スキル辞書や全文は再配布しない。

## 実測：固定モデルと元スキル監査の別々の結果

### A. 共通順位・時期機構の芝ダートW（固定GlobalSimモデル）

[固定モデルCI #43997116831](https://github.com/Nimrodx0/Umasupport/actions/runs/43997116831)で、元フル30シード・両15シードの復元検査を通過し、共通条件機構の芝・ダート比較も**成功**した。比較単位は4機構×個々の脚質×4編成×9/12頭×2能力モード×4距離区分。芝ダートでは**元スキルIDは異なり、同一スキル発動条件の実測ではない**。

| 対象と指標 | 4距離区分の全対象 | 東京芝／ダート1200m同一競馬場・同一距離 |
| --- | ---: | ---: |
| 比較可能セル | **960** | **240** |
| フル30で芝W／ダートWの保守区間が厳密に分離 | **469** | **189** |
| 同じ芝／ダートの方向を**両方の15シード**で追認 | **187** | **95** |
| フル30で保守区間が仮5pt超離れたセル | **14** | ※全体14の内数（別途件数未採用） |
| 仮5pt超を**両方の15シード**で同方向追認 | **5** | **2** |

東京1200mのコースは元UmaSim／GlobalSimの[独立した競馬場ID照合](skill-p2-15-track-id-venue-static-gate-20261112.md)済みで、芝10501・ダート10508、どちらも競馬場ID10005・距離1200mである。この条件なら**競馬場と距離の交絡は制御**できるが、芝／ダートコース形状・レース軌跡・馬場自体の違いは残る。**芝ダートそのものの因果効果は識別していない**。

4距離の両15シード追認数は、短距離95、マイル10、中距離7、長距離75。仮5pt超の追認数は順に2、0、0、3。これらの構造上の比較は同じ元機構の再利用・重複があり、960件の独立した実レースでも960種類のスキルでもない。

**観測の解釈**：小さくとも方向が一定の区間分離は187セルあるが、仮5ptという感度設定を両分割で超えたものは5セルだけ。この固定デザインの単純な機構差を、距離4区分・全脚質へ一般化できる大きな馬場適性として採用する根拠は得られない。一方、仮5ptは正式な実用差閾値ではなく、差が小さい・追認されないことを「馬場の影響ゼロ」と解釈しない。

## 合否・不足・次の実験

固定モデル側の[CI](../../../.github/workflows/p2-source32-split15-w.yml)と、元スキルの[出典監査CI](../../../.github/workflows/skill-condition-inventory.yml)を**別ゲート**で検証する。全体の判定で最低限確認することは、同一「部分条件機構」の4組、未対応2組、960比較可能セル、元スキルとモデルの同一性を否定するフィールド、source-matched 818／元条件経路970を保つこと。

上表のW件数は固定モデルCIで確認済み、元スキル候補数は固定UmaSim元出典CIで確認済みである。**前者の異なる元スキルIDのモデル機構比較と、後者の元スキル静的許容監査を合成して元スキル全条件のWを確定したものではない**。

**G5の判定：部分進捗・未Pass**。今回の実装は、同一元スキルでの芝ダートWを実証したことにはならない。次段階では、Bで静的に両面適用可能だった元スキルのうち、条件機構の追加AND・競馬場制約が少ない候補を元の完全なスキル条件式のまま選び、**同一ID・同一脚質・同一距離／編成／能力を揃えた芝／ダート両面の元条件成立機会**を追加モデルで測る必要がある。複数コース対照は交絡を軽減するが、距離・コース形状・馬場状態の因果分離を達成したとはしない。元スキル全条件・実ゲーム発動率・正式P3適性採点は保留を維持する。
