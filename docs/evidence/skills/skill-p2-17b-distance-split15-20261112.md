# P2.17b：距離区分に伴う脚質間の差が15＋15シード分割で再現するか（2026-11-12）

**研究上の区別**：元の `distance_type` はスキルの適用範囲を制限する。同じレースでは全脚質に共通する値だが、他の順位・時期条件との組み合わせによる脚質差がコース・距離文脈によって変わり得る。[利用者の確定方針D-045](../../decisions/log.md#decision-d-045)。この研究で**実ゲーム発動率、全スキルAND/OR、距離だけの因果効果、P3適性**を判断しない。

## 研究方法と分母

[P2.17の距離区分比較](skill-p2-17-distance-context-style-gap-20261112.md)は、元UmaSimの**距離無制限の順位・時期部分条件10種類**（芝4・ダート6）について、固定GlobalSim v77の12モデルコースを短距離／マイル／中距離／長距離に分けて、同じ元条件・脚質ペア・芝ダート・相手編成・頭数・人工能力設定のもとで条件成立機会Wを比較した。距離を限定する元22条件は、元条件から外れた距離への外挿になるため除外している。元の計5,760無スキルモデルレース、各コース・設定30シードは出典固定。比較数は元の部分条件×脚質ペア**60組**、同一競馬場の東京芝コースに限定した補助解析は**24組**。

P2.17では、距離区分内の各コースについて**先行側の脚質（ペアの第1脚質）のWから第2脚質のWを引く**差の保守的な上下限を求めた。距離区分に複数コースがある場合、各コースの差の最小下限～最大上限を採用した。比較した2距離区分で脚質の優劣が**明示的に逆転**するか、保守的な脚質間差の変化が**仮5ポイント超**になるかを別に数える。5ポイントは**製品採用済みの閾値ではない**。

**P2.17bでは、元の15＋15シード分割が示す同じ比較を二度計算する。** 固定モデルの `rep=0..14` と `rep=15..29` は重複しないが、同じエンジン・レース計画の人工標本であり、統計学的に独立な実ゲーム標本ではない。

- [既存のP2.13検証器](../../../poc/tools/skill_source32_split15_w.cjs)を**全行に適用**し、15+15の走者数・元順位不確定数・W上下限を重み付きで組み合わせ、固定30シード元報告を完全に再構築できなければP2.17bの評価を停止する。
- [新しいP2.17b検証器](../../../poc/tools/skill_distance_split15_reliability.cjs)は、先に固定元のP2.17報告を再計算する。各元部分条件・脚質ペアについて、同じ相手4編成、9/12頭、能力2モード、**同じ距離区分ペアの同じ比較設定**を前半15と後半15で再評価する。別の編成や別の距離で逆転しただけの結果は「元の逆転を追認」と数えない。
- **符号逆転の再現**：元30シードと前半15シードと後半15シードの全てで、2距離区分の脚質優劣が**同じ向きで**逆転した場合だけ「両分割で追認」とする。片方の分割が同値・不確定・方向違いなら「元30のみ、両群追認なし」。
- **5ポイント超の差の変化の再現**：元30シードで保守的差幅の変化が仮5ポイントを超えた同じ距離区分ペアについて、前半・後半が両方**元と同じ増減方向の5ポイント超**を示す場合だけ追認する。偶然の別条件の変化を混ぜない。
- `noFront` で逃げが存在しない比較は勝敗0に置換せず、**欠測（未観測）**のまま保持する。元P2.17の比較可能な設定数は全対象コース840、東京芝336。逃げ不在の除外設定120および48を別管理する。
- 主結果の単位は**元部分条件×脚質ペア**と、その内側の**同一編成・頭数・能力×距離区分ペア**。この2つの分母を混同しない。芝とダートを同じ元条件として組み合わせない。

## 結果

[元GlobalSim v77とP2.13の検証ワークフロー](https://github.com/Nimrodx0/Umasupport/actions/workflows/p2-source32-split15-w.yml)を拡張し、P2.17bの条件ごとの元30／前半15／後半15の方向を研究専用JSON `p2-17b-distance-split15.json` として保存する。

[実行済みCI #43131802243](https://github.com/Nimrodx0/Umasupport/actions/runs/43131802243)で、元5,760モデルレースを固定GlobalSim v77の同じ種子0..14／15..29で再実行した。8シャードと完全なP2.13再構築、P2.17b固有の同一条件・同一方向の比較は**すべてCI成功**。研究専用の[15＋15監査JSON](https://github.com/Nimrodx0/Umasupport/actions/runs/43131802243/artifacts/13906030705)も保存した（GitHub Actions成果物、保持14日）。

**この結果はP2.17の解釈を実質的に絞る**。固定30シードをまとめると距離区分間の逆転を認める5部分条件×脚質ペアがあったが、両15シード分割の**同じ条件で同じ方向**という厳密な再現ゲートを通る逆転はゼロだった。従って**「脚質の優劣が距離によって安定して逆転する」という主張は現時点では支持されない**。それでも、仮5ポイント超の脚質間差の変化が元56組中46組（東京23組中20組）で少なくとも1つの同一比較セルに再現したため、**脚質差の大きさがレース距離・コース文脈に依存する傾向**には固定モデル内の分割安定性がある。

**注意**：「46組で再現」というのは、46個の別スキルが発動しやすくなったことではない。各組には複数の比較セルがあり、元770セル中385セルしか両分割で追認されていない。また、他のAND、発動抽選、実レースの独立標本、コース形状と距離の因果分離、実用的な効果の大きさは一切実証していない。東京芝の5組と全対象コースの5組は必ずしも同じ組ではなく、数字を加算しない。

## 解釈の限界と次の段階

コースの距離が変われば形状・コーナー・直線等も変わるため、**距離区分自体の因果効果は識別できない**。東京芝の同一競馬場比較でも同様。各半分の観測結果が一致しても、現実のレースでその差が再現する確率や統計的信頼区間は求めない。

P2.17で「短距離・マイル・中距離・長距離を一律の脚質差にまとめると危険な場合がある」と分かったことに対し、P2.17bは**固定シードの分割によって傾向が安定しているか**を判定する安全ゲートである。結果は「逆転は追認されず・脚質差の大きさの変化は一部追認」という別々の結論になった。次に実装するP3適性データ契約では「適用範囲」「元部分条件による成立機会」「距離・コース文脈への依存」「保留」を区別し、未研究ANDや効果を偽の実発動率として足し込まない。
