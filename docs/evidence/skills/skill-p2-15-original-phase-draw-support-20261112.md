# P2.15：元UmaSim `phase_random`の抽選位置全域と判定直前モデル位置の照合（2026-11-12）

## 検証する問い

直前の[元スキル経路102スキル／315脚質セル／371経路の監査](skill-p2-15-phase-random-source-window-20261112.md)では、元UmaSimの`phase_random`窓生成式と元AND／ORの構造は分かったものの、抽選結果を同じ走者・判定時刻に重ねた測定は0件だった。[続くモデル判定直前位置の実測](skill-p2-15-pre-skill-position-20261112.md)では、元GlobalSim v77を改変しない32無スキル人工レースの位置を独立計測版と完全一致させ、**抽選位置を固定0.5と置いた反実仮想**を調べた。

今回の新規研究は、**0.5という1つの固定値に依存せず、元UmaSimのソース式に従って取り得る抽選位置の全域**を対象にする。これは**元のモデルで実際に抽選された値の観測ではない**。対象は、元スキル条件を含む経路に対し、同じ条件キーの抽選位置をレース中固定したと仮定したとき、GlobalSimで実際に記録したスキル判定直前位置のいずれかがその窓に入る抽選値の範囲である。

## 出典と計算式

固定出典：
- UmaSim `mee1080/umasim@f6e4501ee6c6c2d4ac8698e7796e309d31575bde`：`SkillChecker.kt`の`checkInRandom`、`initPhaseRandom`、`chooseRandom`、`RandomEntry`、`RaceState.kt`の`getPhaseStartEnd`。
- 元スキル辞書`skill_data.txt`：SHA-256 `4c036527bbe6b5aad34d7f12110a06094c9071514e37fdfc68ae195403333be5`、元出典照合済み818件からの限定371経路。
- GlobalSim v77 `daftuyda/GlobalSim@80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1`：[計測位置と物理値不変性の監査](skill-p2-15-pre-skill-position-20261112.md)。

元UmaSimのRANDOMモードは、1つの抽選値`u`を`[0,1)`から選び、局面区間`[a,b]`に対して次の**閉区間**をキャッシュする。

\[
s(u)=\min\{a+u(b-a),\ b-2\},\qquad
e(u)=\min\{s(u)+10,\ b\}
\]

ここで、レース距離を`L`として局面0／1／2／3はそれぞれ`[0,L/6]`、`[L/6,2L/3]`、`[2L/3,5L/6]`、`[5L/6,L]`。判定直前モデル位置`x`が`s(u) <= x <= e(u)`に入る抽選値の区間を求め、**同じモデル走者・同じレース内の全観測位置に対して区間和集合を取る**。同一技能の同じ条件キーについて抽選を毎tick独立に引き直す仮定は置かない。

特に元式は`s(u)`を`b-2`でクリップする。したがって末端`2/(b-a)`の抽選値が同じ窓`[b-2,b]`に対応する場合を別に加算する。単に`10/(b-a)`という固定値を使わない。

出力の**「観測された判定直前位置と交差する抽選値の割合」**は、以上の固定元ソースの一様抽選式と**固定の人工モデル走行軌跡を条件とした幾何学的割合**である。抽選結果を実測した割合でも、実ゲームや元UmaSimの**スキル発動率**でもない。抽選値を変えた際の走行軌跡・獲得スキル・発動済み制御が変わらない反実仮想のみの計算であり、現実の脚質適性として転用しない。

## 対象と保留

P2.15既存の元AND/OR・preConditionsを保持した371元経路を入力する。**同じ元条件の`conditions`側に`phase_random`が1つだけあり、その他の有限条件が固定レースの脚質・距離・芝／ダートと一致すると確認できるもの**だけについて、抽選値の全域を計算する。静的条件の適用外、馬場状態など観測できない条件、**`preConditions`側の履歴**、同じANDに複数の`phase_random`がある場合は**独立率の積やORの和で推測せず保留**する。

集計単位は`元スキルの元経路×人工GlobalSim走者×人工モデルレース`である。同一走者の位置は相関しており、同一スキルの複数OR経路やInvokeを足してスキル全体の評価を作らない。モデル上で1回以上窓に入る抽選値範囲がゼロでも、元ゲームの実発動が不可能とは判断しない。
