# P2.15：元スキルの同じAND行にある順位率＋ランダム区間を既存研究から接続する（2026-11-13）

**狙い**：既存の[P2.15順位同tick研究](skill-p2-15-source-rank-plus-distance-20261112.md)、[GlobalSim装備サンプルの抽選窓＋順位同tick AND](skill-p2-15-equipped-phase-rank-conjunction-20261112.md)、[元UmaSimランダム窓の幾何学検証](skill-p2-15-original-phase-draw-support-20261112.md)を基礎からやり直さず、**元スキルの同じ条件AND行**について、確実に再利用できる情報とまだ必要な観測を分離する。

## 出典から確認できることと、今回の検証範囲

- 元条件辞書の1つのInvokeの同じ**`conditions` OR行のAND要素**に`order_rate`と`phase_random`が両方存在することを確認する。`preConditions`にだけ存在する順位条件、別のOR行・別Invokeの順位条件とは混ぜない。元の比較演算子・数値パラメータ・条件位置・厳密構造グループと共通カーネルを保持する。
- 既存の[順位境界とモデル順位の橋渡し](../../../poc/src/skill_source_rank_tick_bridge.cjs)を使い、**9頭・12頭の実順位候補それぞれ**に、元`order_rate`の比較式を再適用する。`order_rate`は固定UmaSimのSkillChecker実装では無視されており、9/12頭の順位率境界は二次資料によるモデル上の意味づけである。実ゲーム仕様で独立に検証したとは主張しない。
- `phase_random`は、既存の全抽選範囲に対する幾何学的可能性まで研究済み。しかし**元UmaSimスキルに対応する実抽選値・同一走者同一tickの判定ログは未取得**。GlobalSimに装備した別サンプルスキルの実抽選窓を、元UmaSim辞書のスキルに無条件で転写しない。
- 条件ANDの論理：順位条件が偽なら**そのAND経路だけは偽**、順位条件が真でもランダム窓未観測なら**当該経路は未判定**。別のOR経路や別Invoke、履歴`preConditions`の状態は独立に保持する。実スキル発動率や脚質・距離・馬場の適性には未昇格。

## 実装

- [同一ANDの対象抽出・9/12頭の順位率ゲート算出](../../../poc/src/skill_p2_15_rank_random_same_and_handoff.cjs)：固定元スキルに共通化した判定機構を適用した[P2.15明示ゲート監査](skill-p2-15-parameterized-axis-gates-20261113.md)に接続。元スキル数値ID、Invoke番号・配列位置、conditions/preConditionsのOR位置を区別し、元順位条件が各モデル順位で成立する・不成立・境界未確認の区分を出力する。
- 同じソースには、**単一走者の外部入力されたモデル順位系列を用いる研究用補助関数**を置く。既存の[全元条件三値判定器](../../../poc/src/skill_source_whole_tick_monitor.cjs)へ元述語IDと測定した順位率の解釈を渡し、ランダム抽選値は渡さない。同じレース・走者・出走頭数・固定文脈と連続した判定tickだけを許可する。この補助関数だけでGlobalSimやUmaSimを実行した証拠にはならない。
- [合成反例テスト](../../../poc/tests/skill_p2_15_rank_random_same_and_handoff.test.cjs)：別ORから順位を借りない、事前条件の履歴を真にしない、同じANDでも閾値が異なる、9/12境界の0位の不確実性を維持する、順位が真でも抽選不明ならUNKNOWN、別ORの可能性を元スキル全体のFALSEと誤認しない、混在する走者・レース・判定tickを拒否する。
- [固定元辞書CI](../../../.github/workflows/skill-condition-inventory.yml)：元辞書SHA固定、881アプリ技能／818照合／63未照合、970条件経路の分母一致を自動チェックし、`p2-15-rank-random-same-and-handoff.json`を14日保持の研究成果物として出力。第三者の元条件全文は公開リポジトリに複製しない。

## 実測件数と範囲

固定データで実行したCIの成功確認後に、元同一AND条件を持つ経路数・元スキル数・元構造グループ数、静的に除外される数を記録する。**9/12頭それぞれの全順位を列挙した結果は、順位による条件の真偽がどう変わるかの算術的表であり、モデルレースの頻度でも実ゲームの発動率でもない。**

## 次の観測実験

候補の同じ元経路について、元UmaSimの`phase_random`抽選値、位置、元技能判定時刻を共通の識別子で取り出せることを先に検証する。モデル間同等性が確認できないなら既存GlobalSim実抽選サンプルとの結合を保留する。観測を統合する場合も、元のAND全条件・preConditions履歴・別Invoke・クールダウンと技能イベントを別々に評価する。P3/P4の正式スコアは未承認のまま維持する。
