# P2.59：時間・順位変動・近傍の同一tick結合（2026-11-25）

P2.56の59技能とP2.57の73技能は重複するため、未知解消数を単純加算しない。固定GlobalSimの3ビルド（無改変、時間順位probe、近傍probe）で同じ32レースを再生成し、位置・速度・HP・レーン・時刻・元rankと前回rankが一致する判定tickを結合する。P2.56/57の全体集計の再現を必須とする。期限付き成果物への依存なし。

元条件のAND/OR/Invoke・履歴を保ち、既存順位位置、時間順位、近傍、両方の4段階の論理を比較。既知判定を反転させない。スキル×走者レースのTRUE/FALSE/UNKNOWNに基づき、同じコース・頭数・編成の脚質対を比較する。元の3軸必要条件が全馬場状態にわたって両脚質を許容しない場合は比較を保留する。未知が全て偽／真の場合の下限・上限を出し、区間が完全に離れた方向のみ記録。同値もこの固定標本だけの事実であって汎用認定ではない。信頼区間・発動率・W/D・実用差閾値ではない。4seedの固定標本内の記述結果であり標本外の一般化はしない。
