# P4：全スキル一覧（D-053、2026-11-25）

デッキ獲得候補比較とは独立の「全スキル一覧」をヘッダーに追加。アプリ収録の全skill ID（通常/金・白、確認済みイベント、未照合等）を対象に、名称・ID・分類・脚質・距離・芝ダート・馬場状態・適性を検索する。提供カードがなくても掲載し、既存の詳細・逆引き・編成追加を再利用。既存の比較表や集計、保存スキーマは変更しない。60件ページング、ラベル表示ONを初期値とする（表示だけ切替）。元のOR/ANDとpreConditionsを維持した静的必要マスクを実行時プロフィールから算出。動的条件を真と認定せず、未確認は既定で残す。各軸の周辺集合の積と実際の組合せが異なる場合「組合せ条件あり」と表示し、検索は完全な必要マスクを参照する。
