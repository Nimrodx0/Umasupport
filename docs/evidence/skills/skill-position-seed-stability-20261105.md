# P2：乱数初期値による順位条件成立割合の変動を調べる（2026-11-05）

> **資料の位置づけ**：スキル・発動条件に関する固定調査（時点付きの証拠）。本文の測定対象・出典版・留保を確認してください。
> **現行の参照先**：[正本の入口](../../index.md) ／ [分野別の証拠索引](../catalog.md)。執筆当時の「現在」「次工程」は現行の指示ではありません。

**対象はGlobalSimの順位計算モデルだけ。実ゲームのスキル発動確率・脚質適性の判定値ではない。**

## 目的

[全記録時刻の走行位置データを用いた検証](skill-position-dense-frame-validation-20261105.md)で、固定9地点による近似には最大約7.5ポイントの誤差が確認された。次に、より詳細な走行位置データを使った方式でも、少数回のシミュレーションだけで脚質ごとの順位条件成立割合を安定して推定できるか調べる。

ここでいう「乱数の初期値（シード）」とは、シミュレーション内の確率的処理を再現可能にするための整数値。同じ入力条件とシードなら同じレースを再現できるが、**出走頭数・コース・脚質構成・能力設定を変えたケースは同じ母集団に混ぜない**。

## 指標と統計上の単位

1. **1走者×1発動候補区間の割合**：その走者が、指定された走行距離区間を走る間に上位半数に位置した距離の割合。GlobalSimの各記録時刻の走行位置と、記録時刻間の線形補間で計算する。9頭で上位半数は1～5位、12頭では1～6位という固定モデルのルールを使用。
2. **脚質ごとのモデル推定値**：該当脚質の全走者の割合の平均。たとえば1レースに先行3頭・追込0頭なら、先行3頭のデータは含むが追込0頭のデータは含めない。後者は**観測なし**であり、0%ではない。
3. **試行回数による収束状況**：同条件でシードを3個、10個、15個使った累積平均を比較。さらに最初の7シードと残り8シードを**重複しない2群**として平均の差を計算する。
4. **レース単位のブートストラップ法**：同じレース内の走者の順位が互いに関連しているため、走者ではなく**レースを単位**に復元抽出を400回繰り返し、推計値の中央95%区間（2.5～97.5パーセンタイル）を記録する。これはモデル実験内の有限試行数に伴う変動を記述する**参考区間**であり、実ゲームやプレイヤー全体の母集団に対する「95%信頼区間」とは呼ばない。

レースにその脚質が不在の場合、当該レースは走者数0として平均の分母へ含めない。ある比較群に走者が一人もいない場合、データ不明・実際の計算失敗の場合も、0%とは記録しない。ブートストラップ抽出の5%以上で分母がゼロとなる場合も区間を表示しない。

## 固定試験条件

- エンジン：GlobalSim v77（コミット 80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1）を無変更でビルドする。
- コース：10501（1,200m）、10504（2,000m）、10506（2,500m）。
- 出走頭数：9頭と12頭。12頭は頭数感度確認であり、LoH等の実レース編成を再現するものではない。
- 脚質構成：均衡型と、2026年1月のチャンピオンズミーティングで観測された4脚質の人数比をモデル上で抽選する型。観測記録の実際の同一レース編成を復元したものではない。
- 能力値：全走者同一／各走者の能力5値を人工的に±10%変更。
- 各条件のシード：15個。**3コース×2頭数×2脚質構成×2能力設定×15シード＝360レース**。
- 対象区間：中盤全体、終盤前半の前半／全体／後半。直線・コーナー限定のランダム発動条件はこの集計に含めない。

計算コードは[globalsim_seed_stability.cjs](../../../poc/tools/globalsim_seed_stability.cjs)、回帰試験は[globalsim_seed_stability.test.cjs](../../../poc/tests/globalsim_seed_stability.test.cjs)、実行CIは[GlobalSim race-seed stability study](../../../.github/workflows/globalsim-seed-stability.yml)。

出力は脚質・距離・頭数・脚質構成・能力設定・発動候補区間ごとに分け、**該当脚質が出走したレース数**、観測した走者数、累積推計、2群の差、レース単位で再抽出した参考区間を記録する。

## 適性評価への接続を保留する理由

- レース内のウマ娘同士、同一レースの4つの候補区間の観測、同一シードの能力値違いのレースは、互いに独立とは扱わない。
- GlobalSim v77の固定入力とシード分布を条件とした数値であり、実際の日本版レースでのスキルの発動抽選率ではない。
- 脚質の順位条件成立率が高くても、追い抜き条件、位置関係、直線・コーナー、他のAND条件や効果の有用性は別問題。
- **割合を何%以上なら「適性あり」と分類するかの閾値は新設しない**。既存の53件の定性的なP2脚質ラベル、サポカ集約、Web UIは更新しない。

## 固定GlobalSimの実行結果（2026-11-05）

固定版の[GitHub Actions実行 #41980732030](https://github.com/Nimrodx0/Umasupport/actions/runs/41980732030)が成功。成果物 \`globalsim-race-seed-stability\`（artifact ID **13393233496**、保存期限付き）の \`stability.json\` のSHA-256は \`ea368d2ff0c4d743a36f1993412bc27dec7de83257797a2623c0d8672d32dbd8\`。これは実際のGlobalSim v77を実行した**固定条件のモデル上の測定結果**であり、日本版ゲームの発動確率ではない。

### 脚質別の違い

| 脚質 | 比較セル数 | 2群の絶対差の中央値 | 2群の絶対差の最大値 | 参考区間の幅の中央値 | 1セルに含まれる走者数の最小値 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 逃げ | 96 | 0.00ポイント | **50.00ポイント** | 0.00ポイント | 10頭 |
| 先行 | 96 | 2.71ポイント | 14.89ポイント | 12.80ポイント | 30頭 |
| 差し | 96 | 5.44ポイント | 20.00ポイント | 14.98ポイント | 13頭 |
| 追込 | 96 | 3.53ポイント | 17.96ポイント | 10.00ポイント | 21頭 |

逃げの中央値が0でも、すべての条件が安定していることを意味しない。逃げがほぼ常に上位半数となる条件では割合が100%付近で変わりにくい一方、逃げが少数しか出走しない編成では、標本差が著しく大きくなる。

例えばコース10501（1,200m）・12頭・2026年1月の観測比率型・人工±10%能力差では、**逃げ・終盤前半の前半区間**のモデル推計値が85.71%、前半7シードと後半8シードの差が**50ポイント**。逃げを含むレースは15レース中9レース、逃げ走者は計14頭のみであった。この50ポイントは**1頭の標本重みが大きい条件での有限試行の差**であり、どの脚質が実ゲームで優位かという判定ではない。

### 解釈と次の未完工程

1. 3シードだけの結果は、15シードの結果から大きく動く場合がある。10シードまで増やしても最大差は約10.7ポイント残った。15シードも最終値・十分な試行数の証明ではない。
2. **必要な観測件数は脚質別に異なる**。全体の試行回数だけを増やしても、出走率が低い脚質の出走数が十分になるとは限らない。
3. 次は、少数脚質の観測数を明示したまま、対象を絞ってシードを増やし、**条件付き順位帯成立割合が試行数に対して安定するか**を確認する。実際の大会全体の脚質比率を、恣意的に均した数値へ置き換えない。
4. 現時点では「成立率が何%以上なら実用的なスキル」といった**新しい適性閾値を決めない**。既存53スキルの定性評価、P3サポカ集約、P4表示は未変更とする。
