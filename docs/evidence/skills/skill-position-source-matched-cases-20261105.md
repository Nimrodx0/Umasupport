# P2：実スキルの順位条件とシミュレーション結果の対応付け（2026-11-05）

**結果：固定UmaSim辞書の53件の定性推定対象スキルについて、条件が一致する範囲に限定して固定GlobalSim v77の実測を照合。16件は条件付き比較可能、8件は距離の一致するコースが未計測、29件は今回の順位モデルで扱えない条件があるため比較保留。既存の適性ラベル・スキルの発動率・本番UIは一切変更していない。**

## 調査の目的

従来は大量のレースをシミュレーションし、「ある脚質のウマ娘が、特定の距離区間において上位半数の順位にいる割合」を集計していた。このモデル上の**順位条件成立割合**と、**実スキルの発動条件**の対応関係を明確にし、どの条件ならシミュレーションを脚質適性の検討材料に使えるかを調べる。

対応付けに用いた固定出典：

## 対応付けのルール

1. **明示条件を必ず優先**。既存監査で明示脚質がある291件は今回の53件の対象外。条件のAND、OR、複数Invoke、未知の補助条件を無視しない。
2. 順位条件は`order_rate<=50`（上位半数）と`order_rate>50`（後方半数）の**完全一致**のみ対応付ける。例えば`order_rate<=40`、`order_rate>=40`や`30～80`には代用しない。
3. 発動候補区間は`phase_random==1`（中盤全体）、`phase_random==2`（終盤前半全体）、`phase_firsthalf_random==2`（終盤前半の前半）、`phase_laterhalf_random==2`（終盤前半の後半）の4種類に限定。非ランダム発動やコーナー・直線限定を混同しない。
4. `distance_type`で指定された距離区分があるスキルは、**実験したコースの距離区分と一致する場合だけ**照合。今回の360レースは1,200m・2,000m・2,500mであり、**マイル（例：1,600m）は未計測**。
5. 頭数、脚質構成、能力設定、コースごとの結果を分け、勝手に全条件の「全国平均」にまとめない。脚質が出走しない場合は欠測であり、0%ではない。
6. 「成立しやすい」は**指定区間内で、順位条件に該当する位置を走っていた距離の割合**である。発動候補位置の一様抽選・発動条件の全AND成立・スキル抽選・最終発動率は測定していない。

## 固定出典を使った実際の結果

| 53スキルの扱い | 件数 | 意味 |
| --- | ---: | --- |
| 条件を照合できた | **16** | 既存の順位モデルが扱う区間・順位帯・距離に限定した比較が可能 |
| 距離が一致するコース未計測 | **8** | マイル条件のスキル等を別距離のシミュレーションで代用しない |
| 追加条件や対象外区間などで未評価 | **29** | 実条件がより複雑、または今回の4区間の対象外。スキルが弱いことを意味しない |

### 実例1：テンポアップ（ID 200722）

固定辞書の対象経路：`distance_type==3`（中距離）、`phase_random==1`（中盤ランダム）、`order_rate<=50`（上位半数以内）。比較可能な中距離は今回2,000mの**1コース**だけ。

**9頭・2,000m・逃2/先2/差3/追2・全馬同能力・15レース**で、中盤（進行率1/6～2/3）に上位半数に位置した距離の割合の走者別平均は以下。数字はスキルの発動確率ではない。

| 脚質 | モデル上の順位条件成立割合 | 観測走者数 | レース単位の再抽出による参考区間 |
| --- | ---: | ---: | --- |
| 逃げ | **100.00%** | 30頭分 | 100.00～100.00% |
| 先行 | **99.15%** | 30頭分 | 97.44～100.00% |
| 差し | **30.09%** | 45頭分 | 27.52～32.40% |
| 追込 | **5.71%** | 30頭分 | 2.11～9.78% |

この具体条件では「逃げ・先行が上位半数にいる機会が多い」という既存の**定性的な**推定と整合する。ただし1レースに複数の同脚質が存在し、相互の順位が関連する。30頭分や45頭分は独立した30／45レースを意味しない。

同じ2,000mでも、**9/12頭・2脚質構成・2能力設定の計8条件**では、順位条件成立割合は逃げ**98.68～100%**、先行**68.12～100%**、差し**1.48～32.79%**、追込**0～5.71%**の幅があった。各条件で脚質の出走数や能力が変わるため、この幅を誤差棒や実ゲーム全体の変動範囲とみなさない。

### 実例2：ギアシフト（ID 201052）・上昇気流（ID 200702）

- ギアシフト：`distance_type==2`（マイル）、`phase_random==1`（中盤ランダム）、`order_rate<=50`。
- 上昇気流：`distance_type==2`（マイル）、`phase_random==2`（終盤前半ランダム）、`order_rate>50`。

**両方とも「距離一致のモデルデータなし」として数値を出していない**。中距離のテンポアップ用数値をそのままギアシフトへ割り当てていない。

### 実例3：他の条件を持つスキル

`202312`（意気込み十分）、`202311`（目指せセンター！）などは、今回の順位モデルでは扱えない追加条件があるため、単純な順位割合からスキル全体の成立率を出さず**未評価**。多経路や発動区間が一致しないものも同様に保留。

## 次の作業順序

1. **不足しているマイル1,600m**を同じ固定GlobalSimで計測し、ギアシフト・上昇気流など8件の「距離未計測」を解消する。これはシミュレーション件数の無目的な拡大ではなく、**現に比較不能と判明した具体的なスキル条件**を埋める作業。
2. 29件の未評価について、**対象外の区間**と**追加のAND条件／複数経路**を区別し、調査の優先順位を決める。追加条件が未計測なのに「実質的に汎用」などへ昇格しない。
3. 各脚質の「基本的な順位条件の有利不利」がどの場面まで頑健かを、**具体的なスキルを基準に**評価し、P3のカード別候補集約へ進む。
