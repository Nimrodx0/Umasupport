## 条件ごとの判定範囲

今回のモデル数値を**元の順位帯・局面部分**に対応付けるには、以下のすべてが必要。

1. `order_rate`の**元AND条件の積集合**が11個の固定順位帯のどれかに厳密一致する。
2. 時期条件が`phase_random == 0..3`で、**局面全体の10mランダム窓**に一致する。局面前半／後半などへの適用は、既存の全局面モデルから**推測しない**。
3. `distance_type`などのレース共通条件とモデルコースを照合する。たとえば`distance_type==2`なら固定のマイル1600m×2コース、9/12頭×2能力条件＝**8文脈**だけを使用。距離指定なしは6コースを同重みに扱う比較基準であり、現実の出走分布ではない。
4. ダート限定などの芝モデルで未検証な明示馬場条件は、順位部分だけ**参考値として保持**し、全条件を評価可能にしない。他のAND・preConditions・OR・複数Invokeも、全経路を分離して未対応を保留する。

なお**10m範囲内成立機会**は、無スキルモデルの順位軌跡に「抽選された範囲のどこかで順位条件を満たせるか」という幾何学計算をした**モデル指標**。ゲームでの賢さ抽選、離散フレーム、他のスキル・他条件を含む**実スキル発動率ではない**。

- 34スキル単位では、同じ元条件が繰り返し数えられるため、中央値がかなり変わる。**条件の重複除外後の12種類を別に示すことが必須**。
- 12条件は**上位50%・下位50%・40%以上の順位割合**など、そもそも従来の2群比較研究で選定された候補に偏る。全2,162スキル、全11順位帯、全時期を代表する標本ではない。
- 5%、20%、50%、80%の区間分けは**分布記述だけ**であり、「高適合」の候補閾値として承認したものではない。
- 値が二極化する脚質があり、たとえば逃げでは12条件のうち8条件が5%未満、4条件が80%以上。**これだけを根拠に画一的な50%や80%閾値を選ぶことは不適切**。

## 今回の検討で得たこと・まだ決めないこと

**今回確かめられたこと**：単一の`phase_random`局面全体と順位ANDの組だけで、かつ検証済みモデル範囲に合う場合には、**10m窓の順位条件成立機会を脚質別の連続数値として比較できる**。元出典のID・条件・距離を合わせた34件の研究集合を確認した。

**現時点で閾値を確定しない理由**：(a) 非常に少ない**12独立条件**に選択バイアスと重複がある、(b) 43件が別の抽選窓や未検証馬場のため保留、(c) 無スキルモデルであり実ゲームの発動率に置き換えられない、(d) コース・頭数・能力条件の文脈依存性を分布上の分位点だけでは表現できないため。

**次の推奨ゲート**：
1. 局面前半・後半の10m窓を**正しい距離範囲で**再実測し、既存53件の未評価30件を先に減らす。
2. ダートに対する順位条件成立機会を適切なモデルコースで測るか、馬場による順位分布への感度を調査して、13件の馬場保留を検証する。
3. さらに順位帯と時期の条件を広げ、少数の選択済みスキル集合だけから恣意的に閾値を決めず、**独立した条件の分布＋反例**を確認して評価段階（例えば高／中／低）を別途合意する。
4. 高・低区分と**第2軸の脚質特異性**を別属性でP3へ渡す。**発動後効果の有用性は引き続き独立した将来課題**であり、この研究では評価しない。

**検証の境界**：A＝元条件と集計・保留の単体テスト／B＝固定辞書SHA、固定720レース再実行、ID重複・分布全件監査／C＝実ゲームの発動検証とP3/P4画面の現物検証は未実施。CI成功をCの合格と呼ばない。
