# P2 課題①：順位帯占有率を発動条件の成立機会へ近似する条件（2026-11-07）

> **資料の位置づけ**：スキル・発動条件に関する固定調査（時点付きの証拠）。本文の測定対象・出典版・留保を確認してください。
> **現行の参照先**：[正本の入口](../../index.md) ／ [分野別の証拠索引](../catalog.md)。執筆当時の「現在」「次工程」は現行の指示ではありません。

**研究中。今回確認するのは `phase_random` と順位帯条件だけを組み合わせたモデル上の10m範囲内機会であり、実スキルの発動率・高低閾値は未判定。** 採用可否は利用者の後続判断と実機/資料検証が必要。[2軸の合意](skill-position-two-axis-research-20261106.md)と[GlobalSim固定順位研究](skill-position-balanced-four-style-rule-20261106.md)を前提とする。

## 元実装・外部資料で確認したこと

固定版UmaSim `f6e4501ee6c6c2d4ac8698e7796e309d31575bde`の[SkillChecker.kt](https://github.com/mee1080/umasim/blob/f6e4501ee6c6c2d4ac8698e7796e309d31575bde/race/src/commonMain/kotlin/io/github/mee1080/umasim/race/calc2/SkillChecker.kt) で、`phase_random` は `initPhaseRandom` → `chooseRandom` → `checkInRandom` を通る。標準の `RandomPosition.RANDOM` は一様乱数を使い、対象局面内から長さ最大10mの判定範囲を作る。`chooseRandom`では末尾に `min(U, zoneEnd-2)` の特殊処理がある。結果を計算済み条件として保持し、`checkSkillTrigger`でスキルの他条件と一緒にチェックする。内側AND・外側ORの区別も維持する。処理の単位はランダムな1点の瞬間チェックではなく**10m範囲**。

独立の非公式資料 [Umamusume Wiki: Skill Conditions](https://umamusu.wiki/Game:Mechanics) も10mランダム領域と事前の賢さ判定を区別している。ただし、コードはあくまで**UmaSimの公開実装**であり、日本版2026年現行ゲームの非公開コードと完全一致すると確認したわけではない。

## 候補となる2つの量（同じ順位AND条件・局面について）

`I=[a,b]` を対象局面のコース距離区間（長さ `L=b-a`）、`S` をそのうちウマ娘が元の順位AND条件を満たす距離の集合とする。

- **従来の順位帯占有率** `O=|S|/L`。局面内の位置を一様ランダムに1点抽選したとき、順位条件を満たすモデル上の割合と対応する。
- **10m範囲内の成立機会** `W`：`U`を `I` から一様抽選し、`s=min(U,b-2)` とする。シミュレーション軌跡上、`[s,min(s+10,b)]` のいずれかに元の順位AND条件を満たす点がある、という `U` の割合（**幾何学的連続近似**）。

この幾何学モデルでは `O <= W <= 1` が成立する。連続した順位帯成立区間が長い場合は2つの値は近く、短い条件成立区間が局面内で何度も発生する場合は `W-O` が大きくなる可能性がある。順位条件を満たす距離の**合計長さだけからは `W` は計算できない**。モデルの順位変化地点を保持した軌跡が必要。

`W` は「ある地点で条件を満たす機会」の指標であり、実際のゲームのフレーム離散判定・スキル内の発動抽選・他のAND条件・複数OR・クールダウンを再現していない。ゲームエンジンとUmaSimの実装差がありうるため、実スキルの発動率とは区別する。以下を独立したファクターとして扱う。

1. レース前の賢さなどによる発動可否抽選：`O`にも`W`にも含まない。
2. ランダムに選ばれる発動範囲と順位AND条件の交差：この研究の対象。
3. 抜け出し・追い抜き・時間・距離・脚質制限等の複合条件：元コードの完全一致と未測定条件の保留を優先。
4. スキル発動後の効果の有用性：2軸とは別の将来評価。

## 実験方法と検証

[独立検証器](../../../poc/tools/globalsim_phase_random_10m.cjs)は、GlobalSim v77の固定コース・能力・脚質構成・シード（元の2,160レース研究と同じ計画のうち**均衡編成720レース**）を対象とする。各走者・局面ごとに全記録フレームから相対順位が変化する時点を線形補間で復元し、11個の固定元順位AND帯について `O` と `W` を比較する。

- 元の[順位帯ヒストグラム](../../../poc/tools/globalsim_rank_distribution.cjs)の `O` を別途全走者で再計算し、実験の独立実装と一致しない場合は中断する。
- 境界・終端の特殊処理・複数順位変化・欠測を[人工試験](../../../poc/tests/globalsim_phase_random_10m.test.cjs)で検証する。
- 固定モデルの再実行は [専用GitHub Actions](../../../.github/workflows/p2-phase-random-10m.yml) で行い、`phase-random-10m-opportunity.json` を数値のみの成果物として保管する。出典コードや外部データの無断転載はしない。
- 4局面×11順位帯×4脚質＝176組について、全24均衡設定の占有率平均・10m機会平均・差の分布を保存する。**平均だけで高／低を決めない**。

## 固定GlobalSim実験の実測結果（A/Bで検証）

[研究用720レース再実行（Actions #42274562056）](https://github.com/Nimrodx0/Umasupport/actions/runs/42274562056)で成功。固定GlobalSim v77の**均衡編成のみ**を30シード×6コース×9/12頭×2能力モード＝720レース再実行し、元[histogram](../../../poc/tools/globalsim_rank_distribution.cjs)で測った単純占有率と10m機会を全走者・全局面・全11順位帯で一致照合した。出力はActionsの `globalsim-balanced-phase-random-10m` アーティファクト `phase-random-10m-opportunity.json`（artifact ID `13532677116`、保持期限あり）。

**中盤・順位帯40～80%（局面1、均衡24設定の各設定を等重み）**：

| 脚質 | 点占有率 O | 10m窓の成立機会 W | 増分（ポイント） |
| --- | ---: | ---: | ---: |
| 逃げ | 1.49% | 1.58% | +0.09 |
| 先行 | 56.68% | 57.27% | +0.60 |
| 差し | 84.14% | 84.39% | +0.25 |
| 追込 | 37.70% | 38.42% | +0.72 |

**44局面×順位帯×4脚質＝176組全体**の`W-O`は中央値約**0.29ポイント**、最大**4.17ポイント**。142/176組では1ポイント以下、34/176組では1ポイント超だった。最大例は**序盤・70～75%の差し**：O=42.81%、W=46.98%。順位帯が狭い場合や順位変動の影響は、単なる滞在割合からは分からない。44局面×順位帯の平均順位の並びには**3組で入れ替わり**が生じたが、元の数値差が小さいペアであり、24設定・半シードにおける一貫した比較ゲートの逆転と同義ではない。

**出典の距離制限を適用した代表条件の参考値**：`distance_type==2`（マイル）を含む条件に6コース全体の平均を使うことは適切ではない。固定研究の**マイル2コースのみ**（1600m、9/12頭×2能力条件＝8設定）の条件部分だけを再集計すると、次のようになる。元の条件は[固定順位・局面監査](skill-rank-timing-audit-20261104.md)を参照。

| 元スキル条件の順位・時期部分 | 脚質 | 10m範囲内成立機会W（マイル8設定） |
| --- | --- | ---: |
| ギアシフト：中盤・上位半数以内 | 逃げ／先行／差し／追込 | 99.43%／98.68%／17.35%／2.19% |
| 上昇気流：終盤前半・後方半数 | 逃げ／先行／差し／追込 | 3.84%／7.84%／76.80%／95.64% |

これは**元スキル全体の発動率ではなく、限定した順位条件と局面の機会**である。距離・馬場・脚質明示制限がある場合には、サポカ適性へ渡す前に**合致するコース・頭数・他条件に絞って**母集団を作り直す必要がある。固定実験はそもそも全脚質同じ能力条件・無スキルの制御実験なので、同じゲーム条件での実際の発動機会を断定できない。

**採用判断**：モデル上の`phase_random`でランダム10m範囲を検査するのであれば、**WはOより条件検査の仕組みに近い候補指標**である。一方、元順位帯占有率Oも大半の組でWに近い。これはゲームの発動率や閾値を確定したことではない。新しいWを高／低に丸めず、正式なP2スキル分類やP3カード集約へ昇格させない。局面内の部分範囲、直線・コーナー、追加AND、現ゲームの10m仕様・抽選タイミングは次の検証ゲート。

## 評価方針の候補（未採用）

- `phase_random == 0..3` が厳密に一致し、追加の未検証AND/ORがなく、明示距離・馬場・脚質等のレース条件も成立する場合には、10m範囲内の`W`を**より発動機構に近いモデル成立機会の研究指標**として採用することを検討する。
- `phase_firsthalf_random`／`phase_laterhalf_random`は、その**正確な発動窓**で同じ検証をした後でないと`W`を適用しない。直線／コーナー・連続時間・特殊地点・追加発動条件は当面保留。
- 実スキルの「高適合／低適合」区分は、`O`や`W`の値を無根拠に閾値で分けず、53＋24件の元条件経路の例と実機の反例を確認してから決める。既存の2軸での脚質特異性・効果の有用性評価と混同しない。
- 本番P3/P4へ自動反映しない。利用者との閾値・対象条件の検討を続ける。
