## 1. 二軸を混ぜない計算定義

| 指標 | 定義 | 説明と制限 |
| --- | --- | --- |
| **第1軸 W** | `10m順位条件成立機会` | 元の局面／局面前後半のランダム窓内10mの**どこかで**順位条件が成立するモデル上の割合。実発動率ではない |
| **第2軸の参照 O** | `1地点での順位帯占有率` | 同じモデル・元時間窓の**1地点**で元順位条件が成立する距離割合 |
| **仮想基準 U** | `100 × (順位帯に含まれる整数順位数) / 頭数` | 9/12頭の元整数順位換算を保持し、全順位が等確率と**仮定した場合の1地点基準**。現実の対戦環境ではない |
| **第2軸の参照差 D** | `D = O − U`（ポイント） | どれくらい順位帯の幅から見た一様基準より前後に偏るか。順位帯の広さを補正した**モデル記述量** |
| **脚質間の相対比較** | `W(style A) − W(style B)` を同一コース・頭数・能力モードで比較 | すべての元条件適合設定で優劣が厳密に同方向の比較だけを残す。逆転や同値は保留して4脚質の部分順序にする |

**重要：`W−U` は第2軸 D として計算しない。** Wは10m窓のどこかで成立する事象、Uは1地点の順位が一様であるという別種の基準だからである。たとえWがUを上回っても、それだけでは本来の「1地点の脚質偏り」を示さない。Wの脚質ペア比較は第1軸の**脚質相互の相対関係**として第2軸の補助情報にするが、WとDを平均・加算して単一の適合点にしない。

参照順位の例：上位50%（`order_rate<=50`）は9頭で1～5位、12頭で1～6位。したがって、同じ50%条件でも **Uは9頭55.56%、12頭50.00%** となる。順位割合40%以上（`order_rate>=40`）は9頭で4～9位、12頭で5～12位、いずれもU=66.67%。これらは[確認済みの整数順位投影ルール](../../../poc/src/skill_order_rate_bounds.cjs)によるモデル基準で、日本版ゲームエンジンの独立実機照合ではない。

## 2. 出典・解析の範囲

- モデル：固定[GlobalSim v77](https://github.com/daftuyda/GlobalSim/tree/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1)、無スキル・全適性A。固定UmaSim元辞書 `f6e4501ee6c6c2d4ac8698e7796e309d31575bde` の元時間条件・順位AND・明示距離・馬場を検証した旧77件から、重複を除いた**芝26・ダート6＝32条件**。
- [固定出典の32条件](../../../poc/data/p2_position_condition32_research.v1.json)に一致するコースだけを採用。芝6／ダート6、9/12頭、equal／jitter10の各能力モード。従来の**均衡編成**（9頭2/2/3/2、12頭3/3/3/3）を標準研究基準とし、前方偏重・後方偏重・逃げ不在は**比較用の人工感度試験**。
- [研究計算器](../../../poc/tools/skill_specificity32_research.cjs)は、[先行PR #370の5,760レース出力](https://github.com/Nimrodx0/Umasupport/actions/runs/42413671565)から4編成の各コース・頭数・能力モードの集計を読み、**出力ファイル5本それぞれの固定SHA256を検証してから計算**。元の32条件×4脚質×2頭数＝256脚質ケース、32×6ペア×2頭数＝384ペアを対象とする。第三者の元スキル辞書・レースの生フレームの再配布はしない。
- **同順位の扱い**：位置軌跡が同順位で解けない走者は下限・上限を保持し、ペア比較で範囲が重なる場合は保留。逃げ不在の逃げは**対象走者なし**として比較しない。0%や脚質差なしに置き換えない。
- **判定基準**：「確定」は全ての対応するコース×能力モードの30seed集計値の差が符号付きで厳密に一方向という意味。統計的な有意差、誤差つき確率分布、シード別での必ず同方向な優劣を示すものではない。最小の数値比較誤差の許容値は `0.00001` ポイントであり、脚質適性の高／低区分の閾値ではない。

## 3. 384脚質ペアの厳密な方向検査

32元条件×9頭／12頭の2頭数×4脚質の6ペア＝**384ペア**。

| 均衡編成の元条件に一致する全コース・能力設定 | 件数 |
| --- | ---: |
| 先に記載した脚質がすべての設定で上回る | 222 |
| 後に記載した脚質がすべての設定で上回る | 115 |
| 設定によって方向が逆転する | **13** |
| 同値・区間の重なり・設定間の不一致などで保留 | **34** |
| 合計 | **384** |

**337/384ペア**では全対象設定での方向が厳密に揃った。一方、**47/384ペア**は保留であり、平均だけで優劣を付けない。

4脚質全体の6比較をすべて一方向と確認でき、完全な1～4位の並びを作れるのは **21/64条件・頭数**のみ。

| 頭数 | 全6ペアが厳密に一方向 | 少なくとも1ペアが保留 |
| --- | ---: | ---: |
| 9頭 | **1/32** | **31/32** |
| 12頭 | **20/32** | **12/32** |

9/12頭の両方で同じ脚質ペアの方向が全設定で揃ったのは **156/192ペア**。残る**36ペア**は少なくともどちらかの頭数で保留された。**全設定で厳密に逆向きとなったペアはゼロ**だったが、保留ペアに逆転が絶対起きないことを証明したわけではない。9頭と12頭は整数順位境界・均衡脚質構成が同時に変わるため、これらの差を純粋な頭数効果とは解釈しない。

全4人工編成でさらに同じ厳密方向を確かめた結果：

| 全4編成での比較 | ペア数 |
| --- | ---: |
| 4編成とも厳密に同方向 | **143** |
| 逃げ不在で逃げの走者がいないため4編成比較不可 | **192** |
| 少なくとも1編成で同値・逆転・部分未確定等を含み保留 | **49** |

この143ペアは現実の脚質編成の出現頻度を示すわけではない。**均衡編成での優劣を実対戦一般の脚質適性とみなさない**ための感度情報である。逃げ不在の192ペアを「逃げが負ける」と数えない。

## 4. 第1軸と第2軸が異なる意味を持つ具体例

以下は元スキルの**順位帯・時間窓の部分条件**に限った固定均衡編成の研究値（小数点以下2桁に丸め）。Uは脚質に依らず同じ整数順位帯に対する仮想的な1地点基準。

| 元条件・脚質・頭数 | 第1軸 W：10m窓成立機会 | O：1地点占有率 | U：一様順位基準 | 第2軸 D=O−U |
| --- | ---: | ---: | ---: | ---: |
| マイルの支配者・差し・9頭 | **35.54%** | 32.58% | 55.56% | **−22.98pt** |
| マイルの支配者・差し・12頭 | **1.08%** | 0.99% | 50.00% | **−49.01pt** |
| ハイボルテージ・差し・9頭 | 31.94% | 31.65% | 55.56% | −23.90pt |
| 砂の玄人と同じ元条件・先行・9頭 | **50.04%** | 49.55% | 66.67% | **−17.12pt** |
| 砂の玄人と同じ元条件・先行・12頭 | **65.73%** | 65.20% | 66.67% | **−1.47pt** |

**砂の玄人と同じ中盤・40%以上順位条件**では、先行12頭のWは65.73%と、10m窓で条件が成立する機会自体は比較的大きい。しかし、Dは−1.47ptであり、一様な1地点順位基準をわずかに下回る。さらに固定均衡編成では、先行は差し・追込より厳密に低く、逃げより厳密に高い。**絶対的な条件成立機会と脚質間の相対的な位置付けは別の説明になる。** Dの大小から実戦の有用性やサポカ評価を決めない。

**マイルの支配者・差し**は9頭W35.54%、12頭W1.08%であり、同じ元条件でも頭数・編成によって成立機会が大きく変わる。上位50%の条件で先行・逃げが同点近傍になる場合、平均値の大小にかかわらずペア比較を保留する。特に9頭のマイルの支配者では「逃げ／先行の優劣」はモデル全設定で一方向とは言えないため、完全な4脚質の順位を付けない。一方、両脚質とも差しより高いという確定した部分順序は記録する。
