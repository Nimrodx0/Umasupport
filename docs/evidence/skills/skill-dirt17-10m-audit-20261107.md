## 2. 実験条件と再現性

- **元モデル**：GlobalSim v77のスキルなしの全フレーム軌跡を記録し、相対順位が変化する交点を線形補間で計算する。
- **人数・脚質**：9頭（逃2・先2・差3・追2）と12頭（各3）の均衡編成で、各選定コース×2頭数×2能力モード（同等／人工±10%）×30シード＝**720レース**。全走者の馬場・距離・脚質適性を **A** に固定し、スキルを取り除く。`groundCondition=Good`とする。
- **時期・順位**：`phase_random==0..3` の全局面4種類、および `phase_firsthalf_random` / `phase_laterhalf_random` の厳密一致した短窓4種類。対象は元の固定11順位帯。各判定窓の位置抽選点`U`について、開始`min(U,窓末尾-2m)`から最大10mの区間の**どこかで順位条件が成立**する割合を計測する。
- **数値・検証**：ダート6コースの全局面176組＋短窓176組（それぞれ24設定別）を作成し、別実装の順位帯ヒストグラムで走行距離割合を照合。CIでは以前の芝720レースも再実行し、芝全局面SHA-256 `f512e24b2987ccd642f17f21f92865e965a43b90985ef37d622f1ae2f2ec9e58` と芝短窓SHA-256 `206d9db77299189f91fea649a40effbe9ca2d2203c9d0b69c7873bfacee04c27` が完全一致することを確認した。
- **今回のダートレポート SHA-256**：`242273c0903f37f4c8817e2d8c95325c6f14758fb8edc544974f78f3bf2328d1`。出力は元辞書全件や生モデルを含めず、**17件の元ID＋限定された元条件＋派生した数値**のみの成果物にする。

## 5. 高／中／低の閾値検討への示唆

今回の17件も重複を除けば**6元条件**にすぎない。芝側の26種類と合わせても、コース／馬場が異なる**32種類の元条件・対象シナリオ**であり、すべての独立したサンプルを意味しない。特定の位置・時期条件に偏って収集されたコホートなので、中央値や上位分位点を使って高／中／低の閾値を機械的に決めるべきではない。

次の候補は、①**モデルの文脈別の値**（コース・頭数・能力モード）を使って、平均値だけでは見えない幅を検査する、②元辞書からこれまでの選定条件とは別に反例を抽出し、閾値の妥当性を検討する、③日本版ゲームの10m抽選・順位条件判定・発動フレームの照合を進めること。**第2軸の脚質特異性と第3の「効果の有用性」は別評価のまま**。P3/P4へ元数値を無断で足さない。

**A**：数値集合・コース出典・元条件・否定例の人工テスト。**B**：芝720＋ダート720の固定計算、元辞書2162件のSHA、17件・6条件・68脚質ケースを照合。**C**：実ゲーム内の発動率・有用性・公開アプリの適性表示の確認は未実施。今回の成功はA/Bのみ。
