# P2.31：条件横断の順位傾向を個別コース・能力モードへ分解（2026-11-11）

**対象：P2.29・P2.30で扱った元スキルの順位・時期「部分条件」32種類×4脚質6ペア＝192比較。研究目的は、人工的な代表条件へ固定せずに得られた傾向の頑健性の検証であり、元スキル全体の発動率・正式なサポカ適性表示ではない。**

## 研究上の問題

[P2.29](skill-p2-29-reference-context-and-consensus-20261111.md)では全シナリオで同方向69組、出走した脚質間で同方向66組、逆転29組、保留28組と確認した。[P2.30](skill-p2-30-context-margin-sensitivity-20261111.md)では0/1/3/5ポイントの仮差幅に対し、135/134/131/127組の成立を示した。

ただしP2.30の差幅は、**脚質構成×頭数に適合したコースと能力モードの「平均差」区間の下限**に対して適用した。同じ平均値でも、個々のコースや能力モードに、平均ほどの差がない可能性がある。

今回は**各元条件に適用可能なコースごと、能力モード（equal／人工jitter10）ごと**の元のW成立機会の下限・上限を取り出し、個々の差の中で最も小さい保守的な下限を採用する。

## 判定の対象と制約

- 元研究出典：`GlobalSim v77`の固定コース12種類、9頭／12頭、4種類の人工脚質編成、equal／人工±10%能力設定。固定報告は各コース×頭数×編成×能力について30seed集計済みで、合計5,760モデルレースに由来する。元スキル条件に**不適合なコースを比較に含めない**。
- 元データ：4編成の不変JSONをSHA-256で照合し、固定条件32種類とP2.30の192比較に対応させる。脚質不在の `noFront` では逃げとの比較を行わず、**欠測**として記録する。
- 各コース・能力モードで先行側が上なら `W(first)下限 − W(second)上限`、後方側が上なら符号を逆転した区間の保守的下限を計算する。
- **区間下限の最小値**を0/1/3/5ポイントの研究用仮差幅と比較する。平均差の下限を超えることと、個別コース・能力モードの全てで超えることは区別する。区間の同値や未解決順位タイブレークを都合よく除外・勝敗に置き換えない。
- 仮差幅は**科学的に採用した表示用閾値ではない**。差の大きさの実用上の有意性や、個々の対戦の結果を推定したものではない。
- 固定JSONは**30seedの集計結果**であって、個々のシードの実測ログは含まない。**15＋15シード分割の独立再現性はこのJSONからは計算不能**であり、別途シミュレーション再実行または元の種子別計測成果物が必要。
- 二軸の第二軸 `D=O−U` は**一地点の順位特異性**であり、今回の10m窓の成立機会 `W` と同一視・合成しない。
- 本研究で方向を分類できても、元スキルに残るAND/OR/preConditions、複数Invoke、効果の有用性は未評価。P3・P4の実装へ一方的に昇格しない。

## 測定結果と検証証拠

[研究CI](https://github.com/Nimrodx0/Umasupport/actions/workflows/p2-specificity32-two-axis.yml)は、過去の固定研究成果物を読み込み、[P2.31監査器](../../../poc/tools/skill_context_individual_margin.cjs)で元のコース別行と照合する。比較対象192組を保ったまま、P2.30の平均差方式と今回の個別条件下限方式を**同一元データで比較**する。

出力項目は `scenarioMeanPass`、`minimumAcrossIndividualCourseModePass`、`scenarioMeanOnlyNotEveryCourseMode`。平均値を満たしても個別条件では満たさないケースを、スキルごとの元条件ID・脚質ペアごとに保留・追跡できるようにする。

**実測数値は固定研究CIでの全数照合成功後に追記する。** 単体テストは、平均では5ポイント以上だが1つのコースで0.5ポイント差となる人工例、逃げ不在の欠測、改変された元データの拒否を対象にする。

## 次の工程

本結果が十分な数の部分条件で安定しても、それだけではP3へ正式な評価を渡さない。特に**個々のシード・レースの再現性（P2.13）**、モデルとゲーム内の非順位条件の同時成立（P2.15／P2.20）、第二軸D、ユーザー向けの「共通傾向」「条件依存」「不明」の採用基準を独立に判断する。
