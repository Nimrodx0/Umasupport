# P3.4a：明示対象外・欠測・部分W/D・不安定な比較を単一スコアに潰さない研究設計（2026-11-19）

## この工程で「決めること」と、まだ決めないこと

[P3工程](../../plans/skill-conditions/p3.md)の正式なP3.4は、同値・逆転・不確かさと数値の扱いを決める工程であり、**評価ラベル・しきい値・カード適性の正式規則は未承認**である。ここでは、[P2.44でP3へ実際に渡した全881スキルの固定元研究受領書](skill-p2-44-g6-881-three-axis-research-handoff-20261119.md)に対し、**何を区別して解釈する必要があるか**の型を研究段階で確認する。

**固定するのは誤推論を防ぐ契約だけ**である。UIの高・中・低の語彙、点数、重み、閾値、元AND未検証の採用条件、カード間の順位付けを利用者に無断で決定しない。新しい実ゲーム発動率や別モデルの試行も作らない。

## まず3つの別の問いを分ける

1. **明示条件で対象レースから除外されるか**：元条件の必要条件に、脚質・距離・芝ダート・馬場状態のどれかが**矛盾する**かどうか。元P2.15の`4脚質×4距離×2芝ダート=32`セルに馬場状態4値ビットを保持。必要条件を満たすことは**元AND全体の成立ではない**。元`track_id`など、この32セルで評価しない明示条件は独立に確認する。
2. **条件の一部がモデル上どれだけ成立したか**：W（短窓内に順位条件が成立する機会）とD=O−U（順位帯の点時刻占有率Oから一様順位基準Uを引いた相対偏り）。**WとDは別の測定量**であり、数値の大小や符号が同じである必要はない。サポカへの平均点も作らない。
3. **その根拠はどこまで通用するか**：固定GlobalSimの芝コース・9／12頭・編成・シード・元条件の**一部分**に限った結果か。元の他AND・OR・事前履歴、近傍・追い抜きの元モデル乱数近似、カードからの取得可能性、実ゲーム発動率が未検証か。根拠の「部分採用」と、技能全体の「発動しやすい」は別の命題。

## 6つの概念は排他的ではない

| 観測した状態 | 元データから**言える**こと | **言えない**こと／P3.4aが返す値 |
| --- | --- | --- |
| 元条件未照合 | 881スキル中63件は固定元レジストリとの対応が未確定 | 対象外とも無条件とも言えない。`source-unmatched-applicability-unknown`／静的マスク`null` |
| 元静的必要条件で対象外 | 元条件の認識済み静的ゲートをある`脚質×距離×馬場×馬場状態`文脈が満たさない | その技能を「低適性0点」と判定しない。`excluded-in-this-context-by-known-source-static-necessary-gates` |
| 元静的必要条件では除外されない | 元の認識済み静的ゲートに矛盾がない | 元動的条件・`track_id`・元全ANDが真とは限らない。`not-excluded-by-known-source-static-gates-dynamic-unknown` |
| モデル上の部分W/Dがあり、脚質ペアの方向が固定範囲で安定 | その元条件分岐の**固定モデル部分窓**では比較方向が追認された | スキル全体の順位、ゲーム発動率、普遍的な優劣へ転用しない。`direction-repeated-in-fixed-model-only` |
| モデル上の比較が安定しない | P2.41が「同値・コースまたはシード間の逆転／不整合」をひとまとめにして保留した | **同値と逆転を元データなしに分離しない**。`held-tie-reversal-or-context-seed-instability-undifferentiated` |
| 固定元モデルの前提が不適合、元ANDが未測定 | ダート元制限6件に芝モデルを転用不可。動的近傍・追い抜きは乱数近似。条件・取得経路は別研究 | モデルで見かけの差があっても正式スキル適性やカード得点にしない。**複数の保留理由を同時に保持** |

元出典の「静的マスク0」は、**その文脈を当該認識済み元静的条件が排除する**という論理判断である。「スキルが実ゲームで0%発動する」という観測結果ではない。逆に静的マスク15は馬場状態1～4での**静的非排除**だけであり、100%発動を意味しない。元のスキル全条件を読まない本工程で`track_id`など未評価の別制限も網羅したとは言わない。

### 同値・逆転をどう扱うか

元P2.41の短窓研究の脚質ペア比較は、方向が固定モデル・条件・シード分割で同じなら`model-only-same-direction`、そうでなければ`held-context-or-seed-inconsistent`に整理されている。

後者は**細かいケースごとの元データをすべて保持した「厳密な同値」「厳密な逆転」のどちらかではない**。この段階では、低い閾値を仮設して無理に勝敗を付けることをせず「**固定モデルの方向を確定できない**」と表現する。今後本当に表示を分けたければ、当該ペアの元コース／シード別の観測値を参照し、その表示を根拠に検査する必要がある。

また**WとDは別**なので、ある脚質AがWではBを上回り、DではBを下回っても、「データが矛盾した」と判断してはいけない。例えば、説明用の**架空のモデル値**として

| 脚質 | W：短窓で順位帯を一度でも満たす機会 | D=O−U：順位帯の占有偏り |
| --- | ---: | ---: |
| A | 80% | −10pt |
| B | 60% | +5pt |

の場合、Aは順位帯を一度でも通過する機会が多くても、滞在時間割合は相対的に低いことがあり得る。**これらの数値はUmaSim・GlobalSimの実測値ではなく、定義の違いを説明する架空例**。AをBより「適性が高い」と自動で採点しない。

### 距離別の元OR・脚質不適用も別扱い

[P2.36の中長距離OR](skill-p2-36-short-window-exception-wd-20261118.md)にある10スキルの20枝は、元距離3（中距離）と4（長距離）が**相互排他的**である。どの元分岐に対するW/Dなのか、`sourceDistanceType`・固定コース・順位帯を保持し、平均して「このスキルの総合W」にしない。ほかの2スキルは短距離の狭順位帯を再評価した別モデル条件であり、上位50%全体の別値を流用しない。

[P2.34の69スキル](p2-g3g4-short-window-881-skill-decision-20261118.md)では、30スキルが元の明示条件によって1脚質だけを許す。こうしたスキルの「他脚質とのペア」は**比較可能な観測対象外**であり、モデルW=0点を意味しない。

## 計算機で行う部分

[読取専用の解釈器](../../../poc/src/p3_4_uncertainty_semantics.cjs)は、[P2.44 G6受渡し](../../../poc/src/p2_g6_research_handoff_881.cjs)と[P3独立再計算受領書](../../../poc/src/p3_g6_research_intake.cjs)を**元P2.15・P2.41・P2.42・P2.43から再検証した場合にだけ**受け取る。

各スキルの状態を`staticSourceApplicability`／`modelPartialWD`／`dynamicSourceDispositions`／`selectedSourceANDDisposition`／`unresolvedReasons`へ**分けて**投影する。スキル元全ANDの成立、元ゲームでの発動率、カードからの取得確定・正式配点・高低ラベルはいずれも出さず、全技能`cardScore:null`である。

[反例テスト](../../../poc/tests/p3_4_uncertainty_semantics.test.cjs)は、元未照合をマスク0で表現する誤り、静的必要条件を発動率と見なす誤り、WとDの方向の混合、元脚質排除をW=0にする誤り、同値／逆転の勝手な分離、中長距離ORの加重平均、ダート根拠を芝へ転用する誤り、カード採点への昇格を拒否する。

[固定モデルCI #44485044630](https://github.com/Nimrodx0/Umasupport/actions/runs/44485044630)では、元881全件と研究モデル脚質ペアの比較スロット数・同一分母を監査した。**源モデル脚質ペアの「スロット」や「中長距離の分岐」は、独立した実ゲーム試行ではない**。モデルのW方向の安定性を「スキルの発動率・有効性」には換算しない。

**[固定CI #44485044630](https://github.com/Nimrodx0/Umasupport/actions/runs/44485044630)は全体成功**。同一元4研究成果から再構築・改竄検証済みのP2.44 G6受領書に基づいて、**881スキル（元照合818／未照合63）、短窓部分W/D条件付き81／元ダート保留6／追加窓研究なし794**を再現した。モデル比較の単位の内訳は**546ペア枠（P2.34の69技能×6枠＝414＋P2.36の元22分岐×6枠＝132）**、元明示脚質制限で**比較不可180枠**、残る**比較可能366枠**である。そのうち**Wの固定モデル方向が追認287／保留79**、**Dも方向追認287／保留79**。WとDが反対の方向の固定研究ペアは**0**だったが、別定義の指標が常に一致するという事実ではない。79の保留について、元の同値・逆転・シード不整合の内訳はこの台帳から**復元できない**。脚質ペア・条件分岐のスロット数は、独立実ゲーム試行でも独立スキル発動回数でもない。

[研究専用の881件解釈台帳](https://github.com/Nimrodx0/Umasupport/actions/runs/44485044630/artifacts/14510223615)をActionsで14日間保存。**実ゲーム発動率0件、元全ANDの実測済み0件、正式スキル・カードスコア0件**。P3.4aは**研究用の解釈型の実装**であり、P3.4の最終選択、G6親Pass、正式UI・適性数値・カード集計は保留する。

## 利用者に確認したい正式設計上の3判断（今回は未決定）

**論点A：スキルの情報をどう見せるか**。推奨の初期案は「明示的に適用可能な距離・馬場・脚質」と、「脚質間の成立機会W／脚質特異性Dの**参考比較**」と、「元条件未確認・研究適用範囲外の理由」を分離すること。高・中・低の**ひとつの総合ラベルを作らず**、根拠がない箇所を「？」として保持する。

**論点B：安定しない比較をどう扱うか**。推奨の初期案は「比較保留」とし、**同値・逆転・低信頼の内訳を示すのは、元コース／シード値を再展開した場合のみ**。最小限の有益な判断に必要なら後から限定追加する。

**論点C：将来のカード集約の形式**。推奨の初期案は、当面「元の3軸で適用する可能性のある候補スキルと、取得経路の検証状況」をサポカごとに一覧できる研究表を作り、**カード単一得点と順位付けは採点規則・未測定の扱いが決まるまで導入しない**こと。P3.2/P3.3の元数値ID・直接候補経路と元W/D研究を、独立照合せず結び付けない。
