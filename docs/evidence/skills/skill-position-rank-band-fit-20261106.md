# P2：順位帯×4局面の厳密な脚質間比較（2026-11-06）

> **資料の位置づけ**：スキル・発動条件に関する固定調査（時点付きの証拠）。本文の測定対象・出典版・留保を確認してください。
> **現行の参照先**：[正本の入口](../../index.md) ／ [関連する工程・契約](../../plans/skill-conditions/p2.md)。執筆当時の「現在」「次工程」は現行の指示ではありません。

**結論：固定GlobalSim v77の2,160レースで、11順位帯×4局面＝44条件のうち20条件だけが、全72設定と前後15シードの両方で同一方向の厳密優位を示した。中団を指定するAND条件では、脚質構成に依存して優劣が混在する。** これはモデル上の走行距離占有割合の研究であり、実ゲームのスキル発動率や有用性を測ったものではない。

## 固定研究条件

GlobalSim固定コミット **80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1**。6コース×9／12頭×3編成（均衡、2026年1月CM長距離予選の観測比率に基づく抽選、逃げ不在）×2能力モード（同能力、人工±10%）×30シード＝**2,160レース**。

全記録時刻の走行位置を線形補間し、追い抜きで順位が交差する地点を分割。90,720走者×局面の**整数順位別の走行距離占有割合**を積算。元のorder_rate条件は[9/12頭の整数順位換算 #350](skill-order-rate-integer-mapping-20261106.md)を使い、ANDでは順位集合の共通部分を取る。日本版ゲーム内部の完全再現は未検証。

比較設定は6コース×2頭数×3編成×2能力＝**72設定／局面**、全4局面、11順位帯＝**3,168セル**。30シードを前後15ずつに分けた場合の方向も検査。同一レース内の走者・順位帯・局面は統計的に独立ではない。

### 判定方法

**前方優位**＝逃げ・先行の最小割合が、差し・追込の最大割合より大きい。

**後方優位**＝差し・追込の最小割合が、逃げ・先行の最大割合より大きい。

**混在・同値**＝上のいずれでもない。**不確定**＝必要脚質の順位が確定できない。逃げ不在時には先行だけを前方群に使い、存在しない逃げの値を0%にしない。

前方優位でないことは、必ずしも後方優位であることを意味しない。前方・後方で**対称な厳密判定**を採用した。

### 中団 >=40 AND <=80 の編成差

該当順位は9頭で**4～7位**、12頭で**5～10位**。中盤の編成別比較は次のとおり。

| 編成 | 前方優位 | 後方優位 | 混在 |
| --- | ---: | ---: | ---: |
| 均衡 | 0 | 0 | **24/24** |
| 2026年1月観測比率による抽選 | 0 | 0 | **24/24** |
| 逃げ不在 | 0 | **24/24** | 0 |

単純な >=40 は中盤72/72で後方優位であっても、**>=40 AND <=80を後方優位と断定できない**。相手の脚質構成で成立傾向が異なる。

終盤後半の一条件（コース10502、1600m、12頭、逃げ不在、同能力）では追込の順位を確定できず、**不確定**として保存。終盤前半の <=80 も混在1設定があるため、この局面の一律優位は保留する。

## 既存評価基準への限定的な拡張

[研究用発動条件適合性v1.3](skill-activation-condition-fit-v1-20261106.md)では、元の順位割合演算子・AND範囲・局面全体のphase_random条件がすべて一致し、上記20条件の一方向モデル証拠がある経路だけ高／低を追加評価。新たに採用する順位帯は、序盤・中盤・終盤前半の **<=30、<=40、>=40、>=70** と、序盤・中盤に限る **<=80**。以前の<=50・>50の適合性は保持する。中団の複合条件や局面内の部分区間は無条件に昇格しない。

固定UmaSimの**全2,162スキル**を監査したところ、**追加24スキル×4脚質＝96ケース**について、元の必要条件を保ちつつ高／低の定性方向を研究用に判断できた。**中盤 >=40 が22件、終盤前半 >=40 が2件**。これは元辞書全体の研究対象であり、Umasupportの公開収録スキルが24件増えたという意味ではない。既存の53件（高106／低106）は変更していない。芝・ダート・距離の絶対レース条件は独立保持、未知AND契機や解釈不能OR／preConditionsは保留する。
