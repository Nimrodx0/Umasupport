# P2 発動条件適合性 v1.3：6区分の判定基準と研究用脚質適合性（2026-11-06）

**採用した判定の意味：スキルの「発動条件が各脚質の走り方に合うか」という定性的な適合性の研究基準。実ゲームのスキル発動確率、スキル効果・獲得価値、サポカ全体の評価ではない。** 判定器と監査結果は研究用に追加したが、**既存53件の初期定性ラベルとアプリUI、カード集計・公開データは変更していない**。

## 1. 評価対象と6状態

出典のスキルごとに、**逃げ・先行・差し・追込を別々に評価**する。

| 状態（内部コード） | 採用基準 | 読み違えてはいけないこと |
| --- | --- | --- |
| **高適合** (high) | 当該脚質群が順位条件を満たす割合が、比較対象の脚質群より高いという**方向性**が、直接比較できた固定モデルの主要条件で揃った | 発動確率が何％以上、他脚質では発動不可、とは言えない |
| **低適合** (low) | 相手の脚質群より順位条件を満たす割合が低いという方向性が揃った | 発動しない、取得価値が低い、と断定しない |
| **条件依存** (dependent) | 同じ順位帯と局面でも脚質構成・コース等によって群間の逆転がモデルで観測された | どのコースで必ず逆転するかはまだ確定しない |
| **脚質差なし** (neutral) | 判定に必要な元のAND条件が、確認した範囲では距離・馬場等の**レース共通条件だけ**で、脚質・順位・未知の契機条件を持たない | スキルの強さ・発動のしやすさが全脚質で等しいという実測ではない |
| **評価保留** (held) | 追加のAND条件、未測定の区間、検証外の順位帯、異なるOR経路、出典不一致等でスキル全体を判定できない | 部分的に判定できた順位条件は、別属性として保持する |
| **発動不可** (ineligible) | 元の構造化された**明示running_style**条件が、すべての適用可能なAND／OR経路で当該脚質を除外する | 括弧タグやモデル上の0%だけを理由に発動不可としない |

高適合・低適合は、絶対的な成立割合の閾値ではなく、**同じ順位条件についての脚質間の相対的な方向性**を記述する。単一脚質の「発動しやすさ」の絶対値や確率に代用しない。

## 2. v1.3で実際に判定できる条件

**従来v1.2の検証済み順位帯**は、order_rate<=50 と order_rate>50 の2帯域。**v1.3では**[整数順位換算 #350](skill-order-rate-integer-mapping-20261106.md)と[11順位帯×4局面の厳密研究 #351](skill-position-rank-band-fit-20261106.md)を照合し、**元の順位帯と局面全体のランダム窓が完全一致**かつ72設定・前後15試行で一方向のモデル優位が確認された20条件だけ追加する。

- [GlobalSim 6コース・2,160レースの位置帯比較](skill-position-six-course-generality-20261105.md)：中盤と終盤前半の4窓で上位50％の前方／後方脚質群の優位方向が全576比較条件で維持。ただし9地点近似。
- [全記録時刻の順位別占有割合・1,080レース](skill-position-rank-phase-foundations-20261105.md)：序盤・中盤・終盤前半の順位条件方向を確認。**終盤後半**には逆転例。
- [固定脚質編成・1,440レース](skill-position-fixed-roster-paired-control-20261105.md)、[相手編成だけを変える5,760レース](skill-position-focal-opponent-roster-study-20261105.md)：モデルでの相手脚質構成への依存を確認。普遍的な数値の成立割合は設定しない。

**高／低が可能なランダム窓**：\`phase_random==0\`（序盤全体）、\`phase_random==1\`（中盤全体）、\`phase_random==2\`（終盤前半全体）、\`phase_firsthalf_random==2\`（終盤前半の前半）、\`phase_laterhalf_random==2\`（終盤前半の後半）。

**新たに証拠が揃った元の部分区間条件（#349）**：phase_laterhalf_random==0（序盤後半）、phase_firsthalf_random==1（中盤前半）、phase_laterhalf_random==1（中盤後半）。[2,160レースの全記録時刻の順位解析](skill-position-subphase-fit-20261106.md)で、各72条件のすべてが前方群優位、前後15シードのどちらでも方向が一致した。出典と解析報告の固定SHA・人数・時期が一致した場合にだけ研究用v1.2へ適用する。

**新たにモデル支持を得た順位帯（#351）**：序盤・中盤・終盤前半の <=30／<=40／>=40／>=70 と、序盤・中盤に限る <=80。従来の<=50と>50は別根拠で維持する。中盤の>=40 AND <=80は均衡・観測抽選で24/24ずつ混在し逃げ不在で24/24後方優位なので、一律の高／低へ昇格しない。元AND・ORと局面条件が一致するモデル根拠のみ採用する。

**条件依存が可能な窓**：\`phase_random==3\`（終盤後半全体）について、モデルの順位群の逆転例が存在。終盤後半の一部分（\`phase_laterhalf_random==3\`等）は個別検証していないので保留。

**今回も保留する条件**：今回の3区間以外の未測定部分窓、直線・コーナー依存、phase==2のような時点判定、追い抜き等の追加AND条件。これらは順位方向を別の局面から類推して確定しない。

距離カテゴリ（\`distance_type\`）、馬場種別（\`ground_type\`。芝／ダート）、馬場状態（\`ground_condition\`。良／稍重／重／不良）は**レース全体の絶対的な発動条件**として脚質適合性から分離する。元の演算子・値を\`raceRequirements\`にそのまま保持し、対象外のレースではスキルの発動可能性自体を認めない。明示条件と順位条件は別軸であり、「ダート限定」を「ダートだと脚質適合性が低い／評価保留」に変換しない。

**暫定的な横断適用（v1.1）**：芝での固定GlobalSimモデルで得た**前方群／後方群の定性的な順位傾向**は、ダートで逆転する具体的根拠がない間、ダート・馬場状態にも共通の基本傾向として適用する。\`surfaceTransfer.status=provisional-cross-surface-direction-not-verified\` を根拠に併記し、芝・ダート・馬場状態別に同じ成立割合が実測されたとは一切主張しない。認識不能・実現不能な馬場条件、未知の追加AND条件、未検証の区間・コース形状・複数OR条件は引き続き保留。

### 元条件の論理構造

条件は **AND内を一つずつ評価し、OR経路は一経路ずつ評価してから統合**する。条件が一つでも未評価なら、順位部分が高／低であってもスキル全体は保留。複数OR経路の全てが同一方向の判定で合意する場合のみ、その方向をスキル全体へ適用する。

明示脚質によって発動できない経路はORから除外するが、**一つでも可能な経路が残れば「発動不可」にしない**。preConditionsのOR・複数のInvokeも保持し、解釈できないものを確率的に合成しない。未知の条件は条件不在ではない。タグ表記は\`running_style\`の厳密な制限に格上げしない。

### 9頭・12頭の順位条件の部分投影（#350）

[人数別の整数順位換算の全件監査](skill-order-rate-integer-mapping-20261106.md)で、元のorder_rateの比較演算子（<=、>=、<、>、==、!=）と複数条件のAND積集合を9頭・12頭の整数順位として確認できるようにした。評価器のsourceRankProjection属性は、従来の50%以外の順位条件を保留する場合にも**部分的な順位範囲**を表示する。ただしこれは脚質適合性を確定する根拠ではなく、元の局面に対応するシミュレーションの順位分布と結び付けるまでは高／低判定へ昇格しない。固定UmaSimのSkillCheckerはorder_rateを直接判定しないため、日本版実ゲームでの丸めの一致は別の境界として記録する。

### v1.3：追加の固定元辞書24スキルについて

[全2,162スキルの原条件レビュー](skill-position-rank-band-fit-20261106.md)で、元順位帯×局面のモデル支持条件を利用し、**新たに24スキル×4脚質＝96件**の研究用高／低を追加可能と確認した。中盤>=40が22件、終盤前半>=40が2件。**これは固定元辞書全体の対象であり、現在の公開アプリに24件追加した意味ではない。** 既存53件の高106・低106は不変。元の明示脚質・追加AND・OR・距離／芝・ダートの絶対条件は引き続き個別の条件として扱う。

## 4. 採用・未承認と次の条件

- **判定規則v1.2は馬場条件の独立性を維持し、固定GlobalSim上で検証した3部分区間だけ定性的な脚質方向を追加**。実装：[評価器](../../../poc/src/skill_activation_fit_v1.cjs)、[53件レビュー作成器](../../../poc/tools/skill_activation_fit_v1_report.cjs)、[固定元データ照合とゲート](../../../poc/tools/verify_subphase_model_direction.cjs)、[再現CI](../../../.github/workflows/skill-activation-fit-v1.yml)。
- **根拠のA／B境界**：A：人工データテストで未知AND・複数OR・明示脚質除外・補助条件保留を検証。B：固定UmaSim源から53件×4脚質を再計算し、元の53件の脚質ラベルとの一致を確認。
- **未承認**：他の828スキルへの正式判定、明示脚質・距離以外の様々な条件の実ゲーム照合、適合性をアプリで常時表示すること、数値による発動率計算、スキル効果の有用性、カード集約P3。
- **次の検証先**：今回の53件の研究用判定は全件完了。他のスキルへの適用前に、元のorder_rate>=40等の演算子・整数順位への変換、複雑なAND/OR・複数Invoke・明示脚質制限を検証する。モデル上の順位割合は実発動確率ではない。

**何より、モデル上の順位占有走行距離割合は実ゲームのスキル発動確率ではない。**
