# P2.13：元32順位・時期部分条件の15＋15シード分割検証（2026-11-11）

**位置付け：P2.29～P2.31で示した「複数のレース条件を横断して一貫する脚質間W成立機会の傾向」を、固定30シードの前半と後半で別々に再計算し、一方の標本だけで成立した結果を区別する研究。元スキル全体の発動率、正式な脚質適性、サポカ評価ではない。**

## なぜ再実行が必要か

[P2.31の個別コース・人工能力条件の監査](skill-p2-31-course-mode-margin-20261111.md)で、元順位・時期部分条件32署名×脚質6ペア＝192組のうち、モデルの全対象個別条件で仮の0/1/3/5ポイント差を超える比較が135/131/121/118組となった。しかし、P2.31の実験結果は**各コース・人工能力設定・脚質編成・頭数について30シードをまとめた集計値**で、個々のシードのばらつきは失われている。

実ゲームの代表条件を一つに固定せずに共通する傾向を探す方針であっても、モデルの固定seedの選び方への依存を無視できない。このため、元GlobalSim v77を同じ設定・同じ元シード列で実際に再実行し、0～14番目／15～29番目の**重複しない2つのグループ**のW下限・上限を別々に測定する。

## 検証設計

- 出典：固定 `GlobalSim@80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1`、元条件の出典 `UmaSim` skill SHA-256 `4c036527bbe6b5aad34d7f12110a06094c9071514e37fdfc68ae195403333be5`。12コース（芝6・ダート6）、9頭／12頭、4人工脚質編成、equal／jitter10人工能力モード、各30シード、無スキルモデル計5,760レース。
- 元シード列：`globalsim_roster32.cjs` の従来 `rep=0..29` の生成方法を変えない。分割Aは `0..14`、分割Bは `15..29`。出走脚質のゲート割当も元repから計算する。1グループは各コース×頭数×能力×脚質編成15レース、4編成×2半分×720モデルレース＝5,760回を再実行。
- **再現性ゲート**：各分割の15シード実測の走者数、評価保留順位数、10m窓W下限・上限を重み付きに合成し、**事前固定したオリジナル30シード成果物を全コンテキストで再構築できる場合のみ**P2.31と比較する。元30シードのJSON自体は不変SHAに照合。
- **個別条件の比較**：各元部分条件×脚質ペアについて、出典が許す対象コース・能力モード・9/12頭・人工編成ごとに、前半・後半の**W区間の保守的な差の下限**を取得する。前段の脚質ペア優位方向を両半分が保つか、仮差幅0/1/3/5ポイントを両半分で超えるかを別々に計数する。
- **保留ゲート**：どちらか半分で差幅未達または判定保留があれば、30シードでは差幅超であっても「分割追認できず」にする。元条件の脚質不在は未観測であり、勝敗0・成立率0に変換しない。
- **分母**：対象は元の32部分条件×4脚質6ペア＝192比較。これは192独立スキルではない。仮差幅0/1/3/5ポイントは、表示用として承認された適性閾値ではない。

**この分割はもともと固定した30シード集合の2つの非重複部分集合**であり、外部ゲームから取得した独立の実戦標本でも、新たに抽出した乱数集合でもない。統計学的な信頼区間や「実際に何％発動するか」をこの結果だけから導かない。

## 固定実行で確認した分割結果

[再実行済みGitHub Actions #43024129516](https://github.com/Nimrodx0/Umasupport/actions/runs/43024129516)は、固定元GlobalSimエンジンのビルド成功、8つの分割シャード（各720、計5,760モデルレース）成功、元の4編成分30seed固定JSONとの**全コンテキスト再構築成功**、P2.31の192元部分条件×脚質ペアとの照合成功を確認した。両分割の結果は研究専用成果物 `p2-source32-15plus15-W-study` に保存。

両群で成立したというのは、**元のP2.31で優位と判定した脚質ペアの方向について、各対象コース・人工能力設定・頭数・編成のW下限が、分割Aと分割Bの両方で指定の仮差幅を厳密に超えた**ことを意味する。個々のシード・実レースでの勝敗や、同じ確率でスキルを発動できるという意味ではない。

仮5ポイント差で元30seedの118組のうち2組が両群で不成立となった。たとえば元条件ID `203351` の「先行対差し」の比較では、前半の最小下限4.649132ポイント、後半5.941094ポイントとなり、**前半は5ポイントを超えない**。30seedの平均や両群の合計だけから「各部分標本でも一定幅がある」とは言えない。

**研究上の意味**：この元モデル条件群では、シード分割をしても116／118件の仮5ポイント差は再確認できた。条件集合と固定エンジン内の頑健性の根拠は強くなった。一方、「0pt超」の厳密な方向で5件は少なくとも片方の分割で成立しないため、30seedの符号だけで一貫傾向を断定するのは危険である。

**安全な一般化の上限**：これは32種類の**元スキル順位・時期部分条件**に由来する比較192件であり、116の別スキルの発動可能性や、サポートカードの4脚質適性を確定したわけではない。15＋15分割はもともと固定したシードの分割である。今回の結果から、モデル外の実ゲーム・未実験コース・実対戦編成・未観測AND/OR条件・効果の有用性・統計的信頼区間へ外挿しない。

## 以降の研究課題

分割で頑健であっても、1地点占有の特異性D=O−U、元スキル全AND/OR・preConditions・複数Invoke、現実の対戦環境・コース出現分布はなお未検証。個別コースとseed分割によるWの検証結果を、他の軸やスキル実発動率へ無断で昇格しない。将来P3/P4の表示方式は、単一の標準条件への固定だけでなく「共通の傾向」「条件依存」「根拠不足」を保持できるか比較する。
