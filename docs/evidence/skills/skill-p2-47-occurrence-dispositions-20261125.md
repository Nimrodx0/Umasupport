# P2.47：G4全元述語出現の採否判断（2026-11-25）

P2.45の全件横断監査に続き、既存P2.32仕様省略候補台帳、P2.15機構研究、P2.42/43元動的経路判断、P2.44受領を同一固定CI内で照合する。元Invoke・condition OR・preConditions OR・AND出現位置で追跡し、別分岐の条件を混ぜない。

| 判断 | 範囲 |
| --- | --- |
| 静的必要条件採用 | 4脚質・4距離・2馬場・4馬場状態の有限ゲートに限定 |
| 元文脈保持 | 競馬場、能力、天候等の前提を維持し、実際の比較条件で確認 |
| 固定状態限定省略候補 | motivationの同じ満足値を全比較で固定するときだけ。実際の省略0 |
| 機構参考 | P2.15の固定モデル・抽選窓・位置等の限定根拠。全ANDや実用差は未確定 |
| 元動的条件保留／近似不採用 | P2.42/43の元経路に一致する判断を保持し、順位変動・追い抜き乱数近似を実ゲーム根拠にしない |
| 未測定保留 | 既存triageの理由を保持。評価判断を変える可能性と観測可能性を示せる場合のみ再開 |

元条件型の有無と、元スキル全体の成立機会を区別する。未知は無影響・0点・汎用ではない。63件は元条件未照合理由を保持する。元数値・原文全件を新規配布しない。実測母数と分類数は固定CIの合格後に記録する。G4親ゲート完了を先取りしない。正式ラベル・カード採点・公開UIを変更しない。

実装：[判断台帳](../../../poc/src/p2_g4_occurrence_disposition.cjs)、[反例テスト](../../../poc/tests/p2_g4_occurrence_disposition.test.cjs)。
