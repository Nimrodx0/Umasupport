## 収録率の定義と実測

**分母は「その時点のモデルに登録された異なるスキルID」**。ゲームに存在するすべてのスキルや発動経路の網羅率ではない。スキル名の存在と、効果説明を表示できることを区別する。

| 対象 | 説明あり / 全レコード | 率 |
| --- | ---: | ---: |
| UmaSimスキル辞書全体（全種別） | **2,162 / 2,162** | **100%** |
| ウマサルタント実行時モデル全体 | **818 / 881** | **92.85%** |
| 通常ヒントとして登録される名前ID | 354 / 387 | 91.47% |
| 公開イベントの報酬で参照されるID | 465 / 495 | 93.94% |
| 金スキル登録ID | 330 / 330 | 100% |
| 白スキル登録ID | 485 / 485 | 100% |
| マイナススキル登録ID | 3 / 3 | 100% |
| 種別未照合の既存登録ID | 0 / 63 | 0% |

通常ヒントとイベントにはIDの重複があるので表の行は加算できない。上記の未表示63件は**33個の名前ベース通常ヒント + 30個の旧イベント用数値ID**、両集合のスキル名は27件重複しており、**独立した名前では36種類**。

## 2026-11-04 後続：旧イベント用30スキルのIDと名前を両方検査

[UmaSim固定コミット `f6e4501` の実データ照合](https://github.com/Nimrodx0/Umasupport/actions/runs/41751377455)で、旧イベント報酬30種類を **数値IDと正規化したスキル名の両方**で現行辞書とリリース固定辞書に対照した。

| 照合項目 | 該当数 |
| --- | ---: |
| 旧イベント報酬ID | 30 |
| 現行辞書内の同ID | 0 |
| 現行辞書内の同名（別IDを含む） | 0 |
| 固定辞書内の同ID | 0 |
| 固定辞書内の同名（別IDを含む） | 0 |

「IDだけ違うが名前は掲載されている」例は**0件**だった。これは **UmaSimの `skill_data.txt` にスキル自体の登録が見当たらない**という意味であり、実ゲームに存在しないことは意味しない。

通常ヒントの元ファイル `support_card.txt` には30種類中27種類が名前として残る。UmaSimの通常ヒント元ファイルと効果辞書で収録範囲が異なることが、以前の「33通常ヒントID + 30イベント数値ID」の重複に現れている。

**利用者の後続決定**：UmaSim効果辞書に存在しないスキルも掲載を継続し、**効果文・発動条件等の欠損部分だけ「未収録」**とする。イベント報酬と計算・保存設定から削除しない。直前の「アプリからスキルを除外する」方針は撤回。効果説明の独立出典からの補完は、この依頼では行わない。

## 未表示の原因

- **通常ヒント33種類**：カード名簿 `support_card.txt` に存在する一方、現行 `skill_data.txt` の名前辞書に該当がない。例：`目くらまし`、`かく乱`、`束縛`、`お見通し`、`逃げけん制`、`先行駆け引き`、`まなざし`、`読解力`。同名で別スキルを勝手に代替しない。
- **旧イベント報酬30数値ID**：公開承認済みイベントに利用される例外ID。現在のUmaSimと2026年の固定辞書の双方から欠ける。名前とIDは既存の限定承認で受け入れているが、説明文まで承認・収録されたわけではない。**76カード・88イベント記録**が、これら効果説明未収録の数値IDを参照（イベントごとの異なるスキルIDとして90組）。これは報酬本体の未収録件数ではない。
- 30 IDと33通常ヒントの内訳が重複するため、欠落の**原因は主に「現行スキル辞書から除外された旧スキルの効果説明」**であり、いまの登録済み金・白スキルの効果文には欠落がない。
- 旧2025年の元マスターのうち28IDは過去に独立資料と名称照合したが、当時の照合は効果説明の現行ゲームでの正確性を保証しない。個別の効果説明は出典版を確認して採用し、古い値を現行スキルへ無条件で流用しない。

## 説明の「有無」と「詳細の完全表示」は別

- UmaSimの `info[0]`（日本語説明）と `info[1]`（発動条件・効果量の補足）は、**2,162 / 2,162件に存在**。構造化発動情報 `invokes` も同数収録。
- 一方、`info[2]` 以降の複数効果・複数発動段階の情報が、UmaSimの**532件**に存在。ウマサルタントのモデル内では**35スキル**が対象。
- PR #320のUIは `info[0]` と `info[1]` のみを使用する。このため35スキルでは説明文は「収録あり」と計数されても、**詳細の2行目以降を閲覧できない**。収録率92.85%を「完全な発動条件まで閲覧可能な率」と取り違えない。
- `invokes` の条件評価は別機能。ここでいう収録率はデータの存在／表示可能性であって、実ゲームの効果量・確率・現行性・再現精度の全件保証ではない。

### 後続修正：複数の効果詳細の全行表示（PR #322）

2026-11-04 09:44 JSTに同じ固定UmaSimコミット `f6e4501` と同じ公開イベント2,487件で再計測した結果：

- 元辞書の `info[2]` 以降を持つスキルは前回と同じ **532件**。実行時モデルの対象も **35件**。
- `skill_bridge.parseSource` は `info[1..]` の空白でない有効文字列を配列で保持し、`skill_effects.attach` はID・名前を照合して表示専用属性へ複製。スキル詳細の展開欄へ番号付きで**全行表示**する。
- 監査で元の `info[1..]` と表示用モデルの配列をスキルごとに順番込みで比較したところ、**35 / 35件が完全一致、不一致0件**。全体の説明文の存在率は **818 / 881（92.85%）**のまま。
- [固定UmaSim全件再監査 Action](https://github.com/Nimrodx0/Umasupport/actions/runs/41749048770)。概要説明および詳細文は本レポジトリへ同梱せず、外部辞書を実行時参照する。
- これは**記述行を漏れなく表示できることの検証**であって、ゲーム内での正確性・全発動経路の実装や端末表示の全件確認とは別。未収録の旧ID30件、通常ヒント33名称も不変。
