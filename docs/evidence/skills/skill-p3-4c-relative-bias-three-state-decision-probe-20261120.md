# P3.4c：脚質の「～向け／汎用／未判定」の相対差による判定を検証する研究試作（2026-11-20）

[P3.4bの製品表示契約](../../plans/skill-conditions/p3-4b-label-presentation-policy.md) ／ [P3工程](../../plans/skill-conditions/p3.md) ／ [P2.44受渡し](skill-p2-44-g6-881-three-axis-research-handoff-20261119.md) ／ [P3.4aの不確実性整理](skill-p3-4a-uncertainty-semantics-20261119.md)

## 判断対象とユーザーが確定した原則

「汎用」は**発動条件を満たしやすいこと**のラベルではない。**脚質間に実用上意味のある適性の偏りがない**という相対的な性質を示す。全4脚質で成立機会が非常に低くても、偏りのなさを確かめられれば分類上は汎用とする。

「～向け」は、**1つ以上の脚質で相対的な偏りが合理的に認められる**場合に付けられ、複数脚質への同時付与を許す。「未判定」はそのどちらかを確定できる根拠が欠ける場合。これらは**脚質評価軸の状態**であって、元スキルがどの距離・脚質・馬場で使えるかという**明示的適用範囲とは別表示**する。将来の距離・馬場評価にも同じ分類構造を用いる想定だが、現時点の非明示的距離／馬場差の追加詳細研究は標準工程に戻さない。

**「差が観測されなかった」＝「差が小さいと判断できた」ではない**。未調査、試行不足、比較不能、元条件の未解決、結果の逆転・不安定を、汎用の根拠と取り違えない。

## 「どれだけ差があれば？」の研究用プローブ

[実装](../../../poc/src/p3_4c_relative_bias_decision_probe.cjs)は、**人為的に作成した同一適用文脈・4脚質の全6ペア比較**だけを対象にする分類例と、後述する**本物のP3.4a研究出力881件の保留監査**という2機能を明示的に分離した。

人工プローブでは、比較指標の差を`[下限,上限]`という**同じ比較文脈に適用する仮の差の範囲**で入力する。「有意差が出なかった」という1点判定ではなく、**差がどれくらい小さい／大きいと保証されるか**をモデル化するための仮想例。指標の単位は仮の差のポイントであり、**実ゲーム発動率・元WとDの加重和・統計的な信頼区間ではない**。パネル内の`materialMarginPoints`も、**実用上重要とみなす差の幅を人が指定した思考実験用パラメータ**であり、正式な5pt基準等をここで採用しない。

| 人工的な脚質ペア差の範囲 | 仮の「実用差」幅 δ との関係 | 試作の解釈 |
| --- | --- | --- |
| 差の範囲全部が`[-δ,+δ]`の内側 | この範囲内での実用的な偏りを積極的に否定できる | 6脚質ペア全てで揃えば、**汎用**の人工判定 |
| 差の範囲が`δ`より完全に上、または`−δ`より完全に下 | 固定の比較で一方が明確に有利 | **～向けの候補**。ただし、他の脚質全ペアと矛盾しない**最上位グループ**である場合のみ人工判定 |
| 差の範囲が`±δ`の境界をまたぐ | 偏りが小さい可能性も大きい可能性も残る | **未判定**。狭く確かめられていないことを「汎用」にしない |
| 6ペアが欠ける／別コース／比較不能／順位が循環・矛盾する | 共通文脈での一貫した判断を作れない | **未判定または入力拒否**。複数の異なる距離OR分岐を合算しない |

この分類は**絶対的な成立機会を入力に取らない**。「全脚質とも仮想W=0.1%」であろうと「95%」であろうと、同じ相対差の範囲なら同じ人工ラベルになる。

### 複数の「～向け」と不安定な同値をどう扱うか

例えば、仮の値で逃げと先行の相互差は`[-1,+1]`、両者と差し・追込の差は`[+12,+14]`、差しと追込の差は`[-1,+1]`とすると、実用差の仮幅を`3`や`5`ポイントにした場合の人工分類は**「逃げ・先行向け」**となる。

ただし、幅を`0`に変えると逃げ・先行の小さな差も「同程度」と確かめられなくなり、`13`にすると下位グループとの差が十分に大きいか確定できない。このように**閾値によってラベルが変わる**ことが、人工例から確認できる。**これらの0／3／5／13はすべて思考実験用で、元のP2.33研究にある「仮5pt」とも、製品の採用閾値とも無関係**。

「ほぼ同じ」の関係が推移的でない（A≈B、B≈CだがAよりCが明確に下）ときは、明確な最上位集団を認定せず**未判定**とする。結果の同値・逆転・シード不整合を隠して、見かけの一番手を作らない。

## 既存の881スキルにどこまで適用できるか

[研究用の閲覧専用監査](../../../poc/src/p3_4c_relative_bias_decision_probe.cjs)は、[P3.4aの元P2.44/P3受領からの再検証結果](../../../poc/src/p3_4_uncertainty_semantics.cjs)を入力とする。母集団881技能、照合818／元照合未完63、P2.41部分W/Dあり81、元芝モデル転用保留6、短窓追加研究なし794が変わっていないことを検査する。

**現在のP3.4aの部分モデルはスキル元AND/OR全体の発動条件を評価していない。** また、元P2.41で「脚質ペア比較の固定モデル方向が同じ」とされたW/Dの情報は、**同じ元スキル全体に対する6ペアの差の大きさ・不確実性の限界を全て確認したものではない**。したがって、ここに人工プローブをそのまま適用して「～向け」「汎用」を認定する根拠はない。

**この工程の実881件の出力は全て正式ラベル`null`・サポカスコア`null`の保留台帳**であり、表示上の製品`未判定`ラベルを新たにDBへ記録したわけでもない。公式ゲーム発動率、効果の強さ、サポカからの獲得確定も、この工程では扱わない。

## テストと終了基準

[人工反例テスト](../../../poc/tests/p3_4c_relative_bias_decision_probe.test.cjs)で、次を独立に検証する。

- 絶対成立機会が低い／高い例が同じ**汎用**になり得る（相対差だけを入力にする）。
- **逃げ・先行向け**という複数ラベルの人工認定。
- 差が検出されないだけで範囲が広い場合は**未判定**。
- 閾値の設定によって変わる判断を、一律の正式閾値に昇格しない。
- 矛盾したペア比較、欠けた脚質ペア、異なる文脈・距離OR枝の混合は、未判定または入力拒否。
- 実881件の研究データにスキル得点・正式ラベルが混入した場合は拒否。

[固定モデルCI](../../../.github/workflows/p2-subphase10-77-skill-review.yml)で、元P3.4a受領成果から881件の研究用保留台帳を生成・チェックし、14日間のActions artifactとして保存する。結果とActionリンクは**実際のCI成功を確認した後**に追記する。

**これで完成するのは「相対差だけで分類するなら、どのような追加根拠が必要か」を試すための判定原則と反例検査**であり、絶対成立機会の採点でも、元WとDの恣意的な合算でも、製品向けラベルの認定でもない。

次に実スキル別のラベルを採用する前に、必要最小限で次を判断する。

1. **元の条件の論理と3軸相互作用**から、比較の結論を覆し得る未知条件の扱いを、スキル別に限定判断できるか。
2. **どの代表条件・文脈**に関してなら「実用的な偏りがある／ない」と言えるか。異なる距離OR枝や芝・ダートへ無条件に外挿しない。
3. **比較差の大きさと、その不確実性の範囲**を研究成果からどう検証するか。差が見つからないだけの`汎用`への誤認定を防ぎ、閾値の選択はユーザーにレビューしてもらう。

研究深度は、[P2の研究継続／終了判断](../../plans/skill-conditions/p2.md#p2全体に適用する研究の深さと終了判断2026-11-18利用者確認)に従い、**判断が変わり得る場合だけ追加調査する**。
