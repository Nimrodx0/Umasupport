# P2 G3/G4：既存75短窓研究を全881スキルの評価判断へ接続（2026-11-18）

**目的**：4脚質の成立機会・脚質特異性を研究しながら、毎回ゼロからスキル判定を作り直さない。[P2.26の全881スキル根拠一覧](skill-coarse-four-style-review-20261111.md)と[P2.28の75スキル二軸研究](skill-halfphase-two-axis-75-20261111.md)を、**元スキル数値ID・名前の完全一致**で接続し、研究結果を適性の判断にどこまで使えるか／何が保留かをスキル別に決める。新しいレース計算、仮の評価閾値、カードスコア、公開UIは導入しない。

## 研究対象と既存根拠

- P2.26の固定アプリ881スキルは、元辞書のID／名称／条件を照合できる818件と未照合63件を含む。既存の明示脚質制限・均衡編成4脚質比較・旧2群の参考情報・保留・不明は破棄しない。
- P2.27は研究不足620スキルから元の順位帯＋前後半ランダム窓が同じANDにある87件を抽出し、**単一Invoke・単一OR・追加の未計測ANDなし**で既存モデルを使える75件を特定。
- P2.28は同じ固定720芝モデルレースを再利用し、**75件中69件でWとDをモデル測定**、芝固定モデルの対象外となる**ダート指定6件を保留**。69件中39件は4脚質を許容、30件は元条件で1脚質のみ許容。比較可能234脚質ペア中、元の対象コース・9/12頭・能力モード・15＋15シードでWが厳密同方向なのは185件、同値・逆転などで49件保留。WとDは独立指標であり、特にDは**1地点の順位帯占有率O−一様順位基準U**であってW−Uではない。

## G3・G4の評価への反映判断

| 対象 | 採否 | 最終的な評価で使える情報／残る制限 |
| --- | --- | --- |
| 元ID・名称一致の69件、芝固定コース | **条件付き採用（部分研究の根拠として）** | 該当スキルの順位×短窓部分条件のW方向とDを、元の脚質・距離・芝条件および観測対象文脈付きで保存。**185ペアのモデル内同方向**は部分条件の相対比較として利用可。49ペアの同値・反転は優劣保留 |
| 上記69件のうち、元条件で1脚質しか許容しない30件 | **明示制限を採用、他脚質との数値比較は不適用** | 他脚質は条件で対象外。許容1脚質のW/Dはモデル部分情報で、単独で「高適性」と結論しない |
| ダート指定6件 | **芝モデルを不採用、保留** | 出典上のダート制限を尊重する。芝からW/Dを転写したり0点と見なしたりしない |
| P2.28対象外の806件 | **今回の短窓研究による追加判断なし** | P2.26に既存の別根拠があるスキルはその根拠をそのまま維持。今回の対象外＝未知・不適性ではない |
| **上記すべてのスキル全体の発動適性／P3カード評価** | **現段階で未確定** | 元スキル全条件の実測、実ゲームの発動率、発動後の有効性、正式ラベル・閾値はこの研究から得られない |

**例**：P2.28の「マイペース」（元ID202072）は、固定芝2500m／12頭の順位×中盤前半窓のモデルで、Wが**差し＞先行＞追込＞逃げ**。一方「積極策」は、前方2脚質が後方2脚質よりWが高いモデル傾向があるが、**逃げ対先行の大小は保留**。この違いを4脚質の強制的な単一順位へ変えない。同じ発動窓・順位帯の金白スキルを独立実験として数えない。

**終了／追加研究判断**：この75件の**元の順位×短窓部分条件については既存モデル証拠を条件付きで活用**し、同じ固定短窓の精密シミュレーションを繰り返す必要はない。G4で本当に必要なのは、**脚質の評価判断を変える重要な他AND／別Invoke／preConditions／追い抜き等**だけを選び、代表例で同一条件機構・元値を確認すること。モデルの対象外6件は、実用上の評価に必要になった場合にだけダート条件に合う根拠を追加確認する。P2.26の現状保留584件を「短窓の不足584件」と読み替えない。

## 実装・検証・保持

[元IDによる読み取り専用結合器](../../../poc/tools/p2_g3g4_skill_window_decisions.cjs)は、P2.26元スキル一覧と[P2.28の元SHA固定CI](../../../.github/workflows/p2-subphase10-77-skill-review.yml)で再生成した短窓研究を受け、881スキルについて旧4脚質根拠と今回の評価判断を**両方保持**する。各条件で明示的に許容されない脚質はW=0へ変換しない。出力は正規の製品データではなくCI成果物として保持する。元の第三者データ本文は公開レポジトリに複製しない。

固定版と母数、W安定185／保留49、39件4脚質・30件1脚質、元の63未照合をCIで照合する。比較方向の「厳密」は**固定モデルの比較設定・15シード分割で一貫**という意味であり、統計的有意性・ゲーム発動率の検証ではない。P2の[G1〜G6](../../plans/skill-conditions/p2.md)は引き続き未完で、P3の正式採点は承認しない。
