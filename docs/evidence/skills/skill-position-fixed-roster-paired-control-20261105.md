# P2基礎研究：固定脚質編成と同一シードでの終盤後半順位傾向（2026-11-05）

> **資料の位置づけ**：スキル・発動条件に関する固定調査（時点付きの証拠）。本文の測定対象・出典版・留保を確認してください。
> **現行の参照先**：[正本の入口](../../index.md) ／ [関連する工程・契約](../../plans/skill-conditions/p2.md)。執筆当時の「現在」「次工程」は現行の指示ではありません。

**結果：固定GlobalSimモデルでは、終盤後半の上位50%について固定編成の47/48条件で前方脚質群が後方群より高く、逆転は0件、順位未確定による保留1件。ただし上位20/30/70/80%では逆転が残り、脚質・距離・局面を無視した普遍則を採用する根拠にはならない。**

## 目的・前の研究との違い

[前の1,080レース実験](skill-position-rank-phase-foundations-20261105.md)では、終盤後半・上位50%条件に**5/71比較可能条件の逆転**があった。うち4条件は2026年1月の観測脚質割合から**毎レース脚質編成を抽選する設定**、残り1条件は逃げ不在の固定編成だった。編成が変わることと少数走者の影響を区別する必要があった。

今回は脚質編成を必ず固定し、6コース間で同じ脚質構成・枠番・乱数初期値を使用した。**前の実験の発動確率を再計算したのではなく、新しい対照条件下でモデル上の順位割合を比較**している。

## 固定実験条件と検証可能性

- シミュレーター：GlobalSim v77、コミット \`80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1\`。既存の計算モデルには変更を加えず、出走馬はスキルなし。
- 6コース：1,200m（10501）、1,600m（10502/10304）、2,000m（10504/10604）、2,500m（10506）。
- 9頭・12頭。固定均衡型は9頭で逃げ2/先行2/差し3/追込2、12頭では各3頭。固定逃げ不在型は9頭で先行3/差し3/追込3、12頭で各4頭。後者は「逃げ0%」とは計算しない。
- 全走者同能力／各馬の5能力値に人工±10%のばらつきを与える設定。**2頭数×2脚質構成×2能力設定×6コース×30シード＝1,440レース**。
- 同一の頭数・脚質構成・能力設定・試行番号に対し、6コースで同じ疑似乱数シード・枠番・走者の初期能力を使用する。ただしコース内部の計算によって**疑似乱数が使用される順序や回数は異なり得る**ため、「全レースで同じ確率事象を強制した」とは言えない。
- 全記録時刻の走行位置を記録間で線形補間し、各馬の順位を追い抜き地点で区切って走行距離比率として積算。序盤・中盤・終盤前半・終盤後半の4局面、上位20/30/40/50/60/70/80%の7順位帯を比較。
- **前方群と後方群の比較式**：同一コース等の条件について、逃げ／先行の割合の最小値から、差し／追込の割合の最大値を引いた差。正なら前方群全体が優位、負なら少なくとも1組に逆転がある。逃げ不在では先行だけを前方側とする。
- 出走しない脚質や順位不明を0%へ置換しない。不明走者がいる比較セルは保留し、出走馬を独立レースとして数えない。

## 実測1：上位50%の脚質群の優劣

各局面につき6コース×2頭数×2固定編成×2能力設定＝**48条件**（各30シード）。表中の「前方優位」は、逃げ・先行の該当する全脚質が差し・追込の全脚質よりモデル上で上位50%条件を満たす距離割合が高いことを表す。

| 局面 | 前方優位 | 逆転 | 保留 |
| --- | ---: | ---: | ---: |
| 序盤 | **47** | 0 | 1 |
| 中盤 | **48** | 0 | 0 |
| 終盤前半 | **47** | 0 | 1 |
| **終盤後半** | **47** | **0** | **1** |

終盤後半は、均衡型**24/24件で前方優位**、逃げ不在型**23/24件で前方優位、1件保留**。全対象47件の前方群－後方群の最小差は**0.90ポイント**。値が正でも小さい条件があり、「必ず差が大きい」という規則は成り立たない。

前の1,080レース実験における**終盤後半5件の逆転が今回0件となったことだけから、逆転の原因が「ランダムな編成」だったとは証明できない**。脚質構成の固定と同時に、各条件の試行数を15から30へ変更し、シードの割り当ても揃え直しているからである。

## 実測2：順位帯ごとの例外は残る

全4局面×7閾値×48条件＝**1,344条件比較**。このうち**21セルは保留**（局面別の3条件×各7閾値）。後方群が一部前方群を上回ったのは**5セル**、すべて終盤後半・9頭・逃げ不在型だった。

| 上位順位条件 | 終盤後半の前方群優位 | 逆転 | 保留 |
| --- | ---: | ---: | ---: |
| 上位20%以内 | 45 | **2** | 1 |
| 上位30%以内 | 46 | **1** | 1 |
| 上位40%以内 | 47 | 0 | 1 |
| 上位50%以内 | 47 | 0 | 1 |
| 上位60%以内 | 47 | 0 | 1 |
| 上位70%以内 | 46 | **1** | 1 |
| 上位80%以内 | 46 | **1** | 1 |

例えば1,600m・コース10304・9頭・逃げ不在・人工±10%能力差・終盤後半・上位20%以内では、モデル上で先行23.09%、差し30.71%、追込12.87%。**差しが先行を7.61ポイント上回った**。先行・差し・追込はそれぞれ**90走者分**で、前回の抽選編成の少数走者条件とは異なる。

ただし、**前半15シードと後半15シードでも同じ逆転方向を示したのは5件中2件**。残り3件は逆転方向が前後半で変わっており、30シードでも「必然的な逆転」とまでは言えない。したがって今回の5件は、**全局面共通の絶対規則に対する実験上の反例**であって、恒常的な順位優劣の証明ではない。

## 実測3：同じ距離の別コースでも数値は変わる

コースごとに同じシード・出走馬の条件を使った**レース対応のある比較**のうち、終盤後半・上位50%を抜粋。脚質・頭数・編成・能力設定別の各比較単位に対し、対応する30レースの成立割合の差を平均した。

| 同距離のコース比較 | 比較可能な脚質・設定の単位数 | 平均差の絶対値の中央値 | 同最大 |
| --- | ---: | ---: | ---: |
| 1,600m（10502と10304） | 28 | **4.80ポイント** | **17.08ポイント** |
| 2,000m（10504と10604） | 28 | **4.24ポイント** | **11.88ポイント** |

1,600mの28単位のうち1つは、順位不明を含むレースを除き29件で比較した。数値は**対応するモデル標本の比較**であり、コース形状の「真の効果」を推定した信頼区間ではない。同距離でも差があるため、距離だけをモデルの説明変数にして全コースの数値を共通化するには根拠が不足している。

## 適性規則の判断・次の研究

- **基本方向性の候補**：固定編成では上位40～60%条件について4局面のほぼ全条件で前方群優位。ただし今回の固定編成だけを日本版対人レース全体へ一般化しない。
- **厳密な普遍則は保留**：終盤後半・順位帯20/30/70/80%には逆転例がある。固定4脚質序列、数値のコース共通化、上位順位を満たすこと＝スキル発動率、いずれも不採用。
- **不足している因果分離**：出走編成の影響を単独で評価するには、コース・試行シード・能力値を同一にしたまま、編成だけを変える追加の対応実験が必要。「乱数を揃えた＝レース内部のすべての乱数事象が一致」ではない。
- **統計的な安定性**：少数サンプルの例外は前後半で符号が逆転し得る。必要に応じて前方群－後方群の差を、レースを単位に再抽出する等の方法で再評価する。
- **数値の汎用化ではなく判定の共通化**：必要な一般則は、元スキルの実順位条件と発動局面を主軸にし、距離やコース等が無視できる範囲を独立に確認して採用する。

**製品への影響：なし。** 53スキルの既存定性評価・カード集計・検索UI・公開イベントデータは変更していない。
