# P2.15：元スキルのAND/OR・複数Invoke・preConditionsを保全した必要条件監査（2026-11-11）

**判定：固定元データの構造監査が成功。P2.15全体、元スキル全条件の同時成立評価、P3への適性集約は未完。**

## 何を確認したか

[P1の元スキル構造モデル](../../../poc/src/skill_condition_profiles.js) と [P2の4脚質モデル研究](../../../poc/src/skill_balanced_four_style_fit.cjs) は、すでに条件の配列を保存している。しかし、順位・時期の部分条件で得た研究結果を**元のスキル全体**へ昇格するには、別の必須AND条件、OR代替、preConditions、複数Invokeを調べる必要がある。

今回追加した [P2.15構造監査器](../../../poc/src/skill_full_condition_path_audit.cjs) は、独立に元の各 `Invoke` と `conditions` のOR行、`preConditions` のOR行を列挙する。4脚質（逃げ・先行・差し・追込）別に、有限の**元コード上の明示条件** `running_style`（1～4）、`distance_type`（1～4）、`ground_type`（1～2）、`ground_condition`（1～4）だけを必要条件として照合する。同一AND内、またはpreConditionsの各OR選択肢とconditionsのANDを組み合わせたときに、数値演算子の矛盾があるかを判定する。

- **明示的に除外**：列挙した条件のどの経路も、その脚質を許さない。元ソースの明示脚質制限に由来する結論であり、モデル上の低い成立機会のことではない。
- **既知条件では除外されない**：少なくとも1経路の明示有限条件に矛盾がない。ただし、元条件の他の述語を満たす証拠にはならない。**発動可能／高適合／汎用の判定ではない**。
- **既知のレース文脈に矛盾**：距離・芝ダート・馬場状態の明示有限条件が両立しない。人工ケースのテストに含むが、今回の固定実データでは該当する脚質セルは0。
- **構造不明**：元条件のInvoke自体が取得できない場合や、条件行が存在しない場合。未照合を評価0に置換しない。

`order_rate`、`phase_random`、`is_overtake`、`change_order_onetime` などは、今回の**有限明示条件の矛盾検査では測定しない**。別のP2モデルで順位／時期の一部を研究済みでも、AND結合した発動率が実証されたことにはならない。「未検証型」は**この全条件ゲートで未検証**という意味で、従来研究がすべて存在しないという意味ではない。

## テストと残るP2.15課題

[人工条件テスト](../../../poc/tests/skill_full_condition_path_audit.test.cjs) では次を検査した。

- `preConditions`のOR片方が脚質で矛盾し、別のORが距離条件で矛盾するケースを、誤って「成立可能」としない。
- 元の複数Invoke・複数OR行の位置を保持し、一つのORが除外されても他の行を消さない。
- 距離・馬場のANDが互いに矛盾する場合も、推定脚質に転換しない。
- 無条件行と条件行の欠落を混同しない。
- 元条件未照合、未知の条件型、元データが壊れている場合を個別に扱い、カードや公開データは変更しない。

**ここまででP2.15の「全経路を失わずに把握する」部分は進んだが、「各経路の全条件を元ゲーム・モデル上で同時評価する」部分は残る。** 今回は順位条件と追い抜き等を同時に再現する新しいレース研究を行っていない。特に35件の複数Invokeについて、各Invokeがどの発動・追加効果を表すかは構造のみでは断定できない。ORやpreConditionsを確率的に合算・独立扱いしない。

次は、元条件の位置まで保持した **追い抜き／スパート／順位変動**などの代表スキルを選び、従来P2の順位研究の部分結果と重ねたときに、どこで全条件の評価が妨げられるかを**経路単位で限定検証**する。研究の収束状況を見て、P2.18へ渡す契約とP3集約の条件を判断する。

**境界**：固定GlobalSimのモデル事実と、実ゲームのスキル発動率・脚質適性・効果の有用性は別。研究中の高／中／低閾値、WとD=O−Uの合成、P3カード評価、P4公開UI変更は行わない。
