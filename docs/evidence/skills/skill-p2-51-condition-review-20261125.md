1. 型別レビュー表の固定CI照合・同一ANDの共起（順位、他動的条件、事前履歴）を集計。件数・型名・元位置を検査する。
2. 省略候補の単独中立性と組合せでの影響を区別して、利用者に判断を提示する。定性候補は具体的な方向・根拠・反例の確認が必要。追加研究候補は観測方法・対象経路を絞る。
3. 利用者が研究方針を確認し、必要な限定研究と再判定を終えるまでG4再Passにしない。G6研究受領の更新後にP3正式採用に進む。
