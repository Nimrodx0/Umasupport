# P3.5／P4.1～3：カード集約と表示・検索アダプタ（2026-11-25）

D-052の適性ラベルからカードの得点を作るのではなく、現在選択の取得候補と全記録候補の件数・一覧を提供する。凸別通常ヒント、承認イベントの全分岐、現在の選択・到達可能性は既存core.directRoutesの結果を使う。候補は実獲得確定ではない。上位技能からの間接経路は既存core.coverageに従ってデッキ単位で別集計し、直接提供数を増やさない。同一カードの複数枠も既存coreの提供枚数を保持。カード得点はnull。

ブラウザ互換APIで、明示必要条件から対象候補／対象外／範囲未確認を区別し、適性の汎用／向け／未判定と別に返す。条件なしの向けは未判定、明示適用文脈外への転用はしない。元IDが一致しないラベルは利用しない。表示OFFは文字列だけ非表示にし、検索や元取得経路を変えない。適用候補の検索では未判定を残し、他脚質向けを不適合と同一視しない。根拠あり／向けのみ等の絞込は明示選択時に限る。適用範囲と適性は強さを表さない。

固定実データの公開承認カタログ・元辞書のSHAを再照合し、566カードの全0～4凸（2,830組）と各記録選択肢の単独選択をcoreと照合する。人工反例で分岐・凸・未知・範囲外・表示切替・元IDのずれ・間接取得を検査。まだ実際の画面へ接続せず、公開ラベルデータの配布とPC/スマホ実操作は別ゲート。D-052の研究根拠と同一実行のCI成果物を利用し、過去の期限付き成果物に依存しない。固定CI未確認。
