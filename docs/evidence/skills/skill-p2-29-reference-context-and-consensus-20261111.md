# P2.29：単一代表条件と条件横断の脚質傾向を比較する研究（2026-11-11）

**段階：P2研究専用。固定実験対照としての均衡編成は継続するが、現実の平均を代表するものではない。ユーザー向け正式脚質適性・P3/P4・単一スコアの採用は未決定。**

## 背景と研究方針の変更

[従来のD-002](../../decisions/log.md#decision-d-002)は「P3の通常評価は均衡編成を基準にする」だった。しかし、[P2.7研究](skill-roster-sensitivity-32-20261108.md)では脚質編成によって部分条件Wに大きな変化があり、[実出走編成の観測調査](skill-real-joint-roster-evidence-20261109.md)では9頭同時編成の公開実例は1レースしか確認できず、代表的な編成分布は特定できていない。

2026-11-11の利用者指示に従い、目標を「現実の平均的な脚質人数を最初にひとつ決めること」から、**スキル・サポカのユーザー向け脚質傾向を根拠付きで示すこと**へ戻す。[後続の研究方針D-043](../../decisions/log.md#decision-d-043)として、**多様な研究条件を通して脚質の相対的な方向が一貫するか**を独立に検証する。正式なP3の標準方式は再検討対象であり、モデル標準設定のままアプリの適性ラベルを変更しない。

## 旧「均衡」基準の位置付け

- 9頭：逃2／先2／差3／追2、12頭：逃3／先3／差3／追3。これは**既存の人工比較対照**であり、実対戦で最頻・平均・妥当と確認できた分布ではない。
- 既存の研究対象は芝6／ダート6の**計12コース**、9・12頭、同能力と人工±10%能力モード、各条件30シード、無スキルモデル。コースは元スキルの明示距離・芝ダート条件に合う対象だけを採用。通常スキルの発動効果・実トレーナーの育成差や同時編成は未反映。
- 以前の4編成（均衡、前方偏重、後方偏重、逃げ不在）×コース×頭数×能力の5,760レースは、**現実の出現頻度で加重された標本ではない**。
- P2.5で128脚質条件中43件は9/12頭で大きく変動、3件はコース間の平均最大差が5ポイント超、能力モードの平均差5ポイント超は0件。ただし能力差の実代表性や、元スキル母集団全体への一般化は別の問題。
- 相手の**代表編成を確定する課題**は残すが、それがないために、研究対象範囲内で認められる一貫性まで諦める必要はない。

## 対象と手法

[既存P2.9の二軸実験](skill-specificity32-two-axis-20261109.md)で固定した32種類の**順位・時間窓部分条件**と、各4脚質の6ペアを対象とする。元スキル単位で重複した条件はこの32種類へ集約されており、32件はランダム抽出や独立した実験とはみなさない。

- **比較の単位**：元部分条件1件 × 脚質ペア1組。32×6＝**192組**。
- **比較する条件**：9頭／12頭 × 4人工脚質編成＝各組最大8のシナリオ・頭数セル。各セルは、その元条件に適用可能なコース×能力2モードの内部比較で、全コンテキストで厳密に同一方向の場合だけ「そのセルでの一方向」とする。元条件の不適合コースは比較しない。
- **方向が一定**：すべての**比較可能な**条件で同じ脚質の10m順位条件成立機会Wが相手より大きい。数値差の実用的な大きさ、全スキルの発動確率は別途判断する。
- **対象脚質不在**：逃げ不在編成に逃げがいない場合は、その条件を**欠測**として別に記録する。この条件が欠測の場合、残りの条件で一貫していても「全8セルで一貫」とは言わない。
- **条件依存の逆転**：条件間の大小方向が反対になる、または同一セル内の対象コース・能力モードで明確に逆方向が出現する。
- **保留**：重複する順位、不確定区間、同値、混在があるとき、厳密な一定傾向は示さない。
- **既存2軸の区別**：今回は**Wの脚質ペアの相対方向**の検査。1地点占有Oと一様基準Uから得るD=O−Uの条件横断の方向や符号は、別の検証が必要。W−UをDの代わりに使わない。

単一の総合適合度、出現確率で加重した平均、現実のスキル発動率へは変換しない。P2.15で残るAND/OR・preConditions・複数Invokeが未評価なら、元スキル全体を「適性あり」と断定しない。

## この実験で検証可能な既存の部分結果

| 既存の比較対象 | 件数 | 意味 |
| --- | ---: | --- |
| 32部分条件×9/12頭×6脚質ペア | **384** | 同じ対象条件の9頭／12頭をまだ統合しない |
| 均衡編成の対応コース×能力条件で厳密に同方向 | **337** | 人工的な均衡編成内の結果 |
| 均衡編成で保留 | **47** | 同値・混在・不確定など |
| 4編成すべてで厳密に同方向 | **143** | 各頭数を別に数えた値。走者不在を0としない |
| 9頭と12頭の両方で厳密に同方向 | **156／192** | **均衡編成内**での脚質ペアについて。残り36件は保留。 |
| 逃げ不在編成で比較対象の逃げがいない | **192／384** | 一部の条件には比較対象そのものがいない。発動不能・低適合ではない |

**今回のP2.29追加監査の実測**（[CI #42972103606](https://github.com/Nimrodx0/Umasupport/actions/runs/42972103606)、元5,760レースの固定成果物から派生。元の再シミュレーションは行わない）：

| 192元条件×脚質ペアの分類 | 結果 | 読み方 |
| --- | ---: | --- |
| **8/8比較条件で厳密な同方向** | **69組** | 9/12頭×4人工編成の全8セルで、該当する元コース×能力設定の比較が同方向 |
| **比較可能な範囲だけで厳密な同方向** | **66組** | 一部の編成で対象脚質（主に逃げ）が出走していない。観測可能条件は全て同方向だが、欠測条件へ一般化しない |
| **比較条件で方向の逆転が観測された** | **29組** | 9/12頭や相手編成、対象コース・能力設定によって、少なくとも1つ反対方向の厳密差が記録された |
| **不確定・同値・区間重なりなどで保留** | **28組** | 一方向の成立を証明できない。平均だけから強制的に順位を付けない |
| 比較対象が全条件で存在しない | 0組 | 今回の母集団には該当なし |
| **合計** | **192組** | 32元条件×6脚質ペア。複数条件を同一スキルの完全な発動率として合算しない |

各組は8つの編成×頭数セルで検査するため、形式上192×8＝**1,536比較セル**。このうち**192セルは「逃げ不在」によって相手がいない欠測**であり、0％や劣位にしない。1セルはさらに元の対象コース×能力2モードを内包するので、比較セルを独立したレース母集団として扱わない。今回の対象には、各条件・頭数で1コースが10件、2コースが12件、6コースが10件（頭数別の64件では20／24／20）。コースの出現頻度は不明なので均等重みを現実の出現割合とは言わない。

**69＋66＝135組が固定研究条件で同方向という観測**だが、66組には比較不能条件があるため、**「全ての条件で成立する135組」とは表記しない**。また、厳密な符号一致が微小差や特定seedへの依存まで排除するわけではない。結果を完全スキルやサポカの適性表示へ直接渡すこともしない。

## 適用と残課題

この方法を使えば代表条件が確定しなくても、**検証した条件群で変わりにくい相対的な傾向**を抽出できる可能性がある。しかし、研究対象外のコース・現実のレース編成・大逃げ・能力差、スキルを積んだ相互作用まで含めて普遍的という意味ではない。

次に必要なのは、(1)実際のゲームモードや大会条件を想定した条件範囲の整理、(2)微小差を実用的な優劣とみなすかの効果量とシード分割の判定、(3)WとDを混同しない信頼性と適用範囲の表現、(4)元スキル全AND条件を踏まえた実スキル単位への昇格ルール、(5)P3で「共通傾向」「条件依存」「判断保留」をカードへどう集約・表示するかの比較。

P2.29は**評価方法の妥当性研究**であって、P2.15・P2.20の実スキル同時発動条件の研究を中止するものではない。両者が揃うまでP3/P4の正式適性ラベルは保留。
