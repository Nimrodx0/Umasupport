# P2.20：元の順位変動条件と脚質・距離の同時必要条件（2026-11-11）

**判定：固定32レースのGlobalSimで、実際のスキル判定直前の順位変動と、元スキルの `running_style`・`distance_type` を同じ走者・同じ観測時刻に限定して照合した。P2.15の限定的な前進であり、全AND同時成立、元スキルの発動判定、実ゲームの発動確率ではない。**

## 研究の意図

[P2.15全経路の固定構造監査](skill-p2-15-full-path-gate-audit-20261111.md)では、出典照合済み818スキル／954条件OR経路の構造と明示脚質制限を記録した。だが、元スキルの順位条件だけの成立観測では、同じANDにある脚質・距離・局面・追い抜き・スパート等を満たすかが分からない。

[P2.20の判定直前順位計測](skill-change-order-skill-tick-20261110.md)は固定GlobalSim v77の**実際のpriority=1/0判定直前**の順位キャッシュを、無スキルの32モデルレースで読み取る。後から保存されるtick更新後の順位とは7,561走者・tickで違うため、位置リプレイの後処理で代用できない。

今回、[元スキル30件の構造監査](../../../poc/src/skill_change_order_source_paths.cjs)に、各 `change_order_onetime` の元数値演算子・元のANDの `running_style` と `distance_type` の数値条件、`preConditions` のOR構造、未観測条件型を追記した。それを [固定モデルとの結合器](../../../poc/tools/skill_change_order_joint_context_review.cjs) で先の**検証済みモデル結果**と突き合わせた。元スキルの辞書本文はGitHubレポジトリへ格納しない。

## 評価できる条件とできない条件

1. **固定脚質**：各走者の元GlobalSimモデル脚質 `Nige/Senkou/Sasi/Oikomi` をそれぞれ元スキルの `running_style=1/2/3/4` と照合。
2. **固定距離**：対象モデルコースID `10502`（芝1600m・マイル、`distance_type=2`）と `10504`（芝2000m・中距離、`distance_type=3`）を、元の数値演算子に従って照合。これ以外の距離は**今回の観測対象外**。
3. **順位変動**：その走者の同じレースにおける**判定直前**の符号付き順位差を評価。元条件 `change_order_onetime<0` は順位上昇、`>0` は順位下降。モデルの保存集計が「負／ゼロ／正」だけなので、**差の大きさを区別する演算子は評価保留**し、単純な符号に丸めない。
4. **未評価**：レース局面・区間・角・累積時間・後方馬との位置関係・追い抜き・スパート、馬場の追加値、履歴preConditions、OR代替、複数Invokeの合算、スキル装備・発動抽選・クールダウン。元のANDから消去せず、各経路に未観測コードを保持する。

同じモデル走者の脚質・距離は当該レースの全tickで一定なので、既存の脚質／コース別の順位変動回数と元条件を照合しても、その**観測済み3要因（脚質・距離・順位変動）に限れば**独立確率を掛けた近似にはならない。ただし残りのAND条件が成立したとは言えない。

今回の4つの観測ゼロ経路も、対応する未計測距離・出走状況・局面等の存在と混同しない。モデル観測内のゼロであり、ゲーム内での発動不可ではない。

## 何が解決し、次に何を調べるか

**今回分かったこと**：順位変動の**元AND経路**に対して、元スキル指定の脚質・距離と、実際のスキル判定直前の内部順位差の3要因を同じ走者・tickで交差できた。静的制限を無視した順位変動の周辺集計より具体的だが、それでも必要条件の一部に限る。

**依然未解決**：順位変動と `phase`、`corner`、`distance_rate`、`accumulatetime` 等の元AND条件を**同一判定tick**で評価する計測がまだない。全30件に未観測の必須条件があり、元スキルを実際にロードした判定も行っていない。

**次のP2.20 / P2.15研究**：元条件の `phase` とコース内距離など、観測時刻を誤解しにくい単純な追加条件から代表経路を選ぶ。GlobalSimの内部条件計算を計測して、先の3要因と同じ判定時刻で取得できる場合のみ範囲を広げる。追い抜きやスパートは既存リプレイから代理計算できないため、内部状態観測手段を確認するまでは評価保留。

**最終境界**：元スキルの全条件成立や実ゲームの発動確率、4脚質の正式高・中・低区分、P3サポカ適性、P4の検索・UIは未採用。P2研究は継続する。
