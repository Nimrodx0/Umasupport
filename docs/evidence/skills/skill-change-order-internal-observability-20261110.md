# P2：change_order_onetime のモデル内部状態を直接観測する予備研究（2026-11-10）

**段階：モデル内部条件の可観測性を実証。元スキル全体の発動率や実ゲームの脚質適性を測定したものではない。** 発動後の効果有用性とUI・サポカ評価は当面対象外。

## 目的と根拠

固定[GlobalSim v77（commit 80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1）](https://github.com/daftuyda/GlobalSim/tree/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1)の[activation_conditions.rs](https://github.com/daftuyda/GlobalSim/blob/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1/src/activation_conditions.rs#L1538)で、`change_order_onetime` は内部の `field.order_of(i) - field.previous_order_of(i)` を使用する。

従来の順位研究用リプレイは現在・前回の内部順位を直接出力しない。そのため、走行位置の順位差から内部条件を推測するのではなく、元モデルが判定に使う値を測定する実験を作った。

## 測定方法と保護策

1. 固定GlobalSimをGitHub Actions内の一時ディレクトリへチェックアウトし、元のソースを変更しない**基準エンジン**をビルド。
2. 同じ固定版の**一時的な実験コピーのみ**で、[lib.rsのpost-stepフレーム出力](https://github.com/daftuyda/GlobalSim/blob/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1/src/lib.rs#L930-L941)の格納先2つを研究用テレメトリーに置換して別エンジンをビルド。元のスキル発動条件・物理演算には手を触れない。
3. **格納先に注意**：[ReplayFrames::restore_order](https://github.com/daftuyda/GlobalSim/blob/80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1/src/replay_frames.rs#L76-L91) は元の6番目の値をブロッカー馬IDと見なして並べ替え時に変換する。最初の実験ではここに順位差を格納して値が変換されたため失敗。修正後は**5番目に順位差**、**6番目に現在順位×64＋前回順位**を保存（この値は出走頭数を超え、馬ID再配置の対象外）。両方を各tickで照合する。
4. 固定テンプレートでは`experimentalRetailRuntime=true`。時刻0には別コードパスで元の状態フレームを出力するため、これを**未計測の初期状態として保持**して集計から除外する。ゴール済み走者も専用の欠測マーカーを使い、0回の順位変動と混ぜない。
5. 基準エンジンと実験エンジンに、同じ人工編成・シード・レース入力を与える。全フレームの**走行位置・速度・HP・レーン**が数値上一致しなければ失敗にする。その上で現在と前回の整数順位から計算した差が、元の内部判定式と全tickで一致することを確認。

## 研究上の意味と残る不確実性

**確認できたこと**：固定GlobalSimで、`change_order_onetime`の判定に使われる**符号付き内部順位差そのもの**を、一定の走者・時刻について取得できる。計測導入が今回の32レースの走行物理値を変えていないことを直接検証できた。

**確認できていないこと**：

- 一つのモデルtickを独立したレースやスキル発動試行として数えること。2,044・2,096は走者・tickの事象数であり、ゲームでの発動率ではない。
- スキルの条件判定が行われた**正確なサブステップ時刻**とpost-stepフレームの完全同一性。元スキルのAND・OR・preConditions・複数Invokeの条件評価、抽選、発動停止条件との交差。これらの照合前にスキル全体の成立率を求めない。
- モデルの順位変動頻度が日本版ゲームを忠実に再現しているか。今回の2コース・2人工編成・4シードだけから4脚質の一般的な優劣を決めない。
- 追い抜きの内部対象リスト・横ブロック継続時間・スパートフラグの測定。`change_order_onetime`の成功を他コードへ自動転用しない。

## 次工程

固定スキル辞書中の`change_order_onetime`元演算子・値・AND/OR経路と、**モデルが当該条件を評価するサブステップ時刻**を一致させる別の研究器を設ける。次に元の発動区間と重なる走者・tickだけを対象にする。1シード内の連続tickや金白同条件の重複を独立サンプルと数えない。必要な観測機構・ゲーム検証が揃わなければ脚質別の定量判定を保留する。
