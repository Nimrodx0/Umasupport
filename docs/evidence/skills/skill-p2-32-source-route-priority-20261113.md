# P2.32：P2.15再開のための元スキル条件経路別研究候補（2026-11-13）

**位置づけ：P2.32の第2段階、研究対象選別用の読取専用出力。** 脚質・距離・馬場の適性や実際の発動率は評価しない。元スキルに付随する出典・元AND/OR・前提条件・複数Invokeの意味を、別経路から寄せ集めて変更しない。

## 意図と既存監査の接続

直近の[P2.32第1段階](skill-p2-32-game-spec-omission-20261113.md)では、ゲームモデル仕様に基づく条件付き省略候補は、元辞書と照合できた818件のうち `motivation` の**2スキル・2条件出現箇所**のみだった。これは「ゲーム仕様に基づいて全条件を省略できない」という意味ではなく、第1段階では機構を確実に確認できた1種類だけを許可した結果である。P2.15を効率的に進めるには、単純な出現数だけでなく、**検証で新たにどの元条件経路の知識が増えるか**を評価する必要がある。

[元スキル経路監査](../../../poc/src/skill_full_condition_path_audit.cjs)と[未確認条件の経路別候補](../../../poc/src/skill_source_path_blocker_impact.cjs)、[P2.32仕様ベース省略監査](../../../poc/src/skill_condition_spec_omission.cjs)を照合して、[新しい選別器](../../../poc/src/skill_p2_32_research_queue.cjs)に元の各Invoke・condition OR・precondition ORごとの**同一条件経路**を固定する。これにより「スキル全体が未知」と「比較可能な脚質に現れる具体的な未確認元条件経路」を分ける。

## 次の実験を決めるための区分

| 研究区分 | 対象と次の行動 |
| --- | --- |
| `rank-source-join-first` | 同じ元条件経路で複数の脚質に論理的な矛盾が証明されず、元順位系の未確認条件がある。未確認条件が少ない場合、元順位・時期窓の**同一走者・同一判定tick**でANDを検証する候補 |
| `event-state-pilot-next` | 複数脚質の比較が候補で、元追い抜き・スパート等の状態条件が含まれる。状態のゲームモデル上の意味・観測可能性を先に確認する |
| `complex-dynamic-route-hold` | 比較候補はあるが、複数の未確認状態条件が残り、簡単な1条件の観測で判断を完成できない |
| `single-style-opportunity-study` | 元制限により比較可能な脚質が1つ。脚質**間**の優劣よりも、その脚質内の成立機会を確認する |
| `context-or-setup-gate-first` | 競馬場・季節・能力など、有限4軸モデルで未確認の静的・育成状態条件が残る。コース／状態の確認を先に行い、対象外を低適性と誤認しない |
| `source-structure-only-hold` | 研究方法や差が実用上重要かの根拠が足りない。出現件数だけで高優先度にしない |

この区分はスキル適性の評価ではなく**追加研究の選択規則**である。既存の順位・時期条件研究があっても、元スキルの同一ANDが成立したことにはならない。特に `track_id` は元のコースIDとは異なる競馬場識別子であり、静的な元条件を正しく照合しなければ評価を進めない（[既存根拠](skill-p2-15-track-id-venue-static-gate-20261112.md)）。

**固定状態の条件付き省略は別扱い**：`motivation` を元の未確認条件から外した場合の「残件数」を、**比較時に同じやる気を固定し、その値が元の比較条件を満たす**という仮定の下の数としてだけ表示する。実際に省略した条件数は0。元の発動条件が満たされると断定しない。

## 最初に着手する小規模研究候補の抽出

候補スキル数をそのまま個別に研究するのではなく、同じ未確認条件型の組み合わせを大量に反復しないよう、`rank-source-join-first`から最大4経路、`event-state-pilot-next`から最大3経路を抽出する。**同一スキルIDの重複を避け、異なる条件型の組み合わせを優先したうえで、より多くの元スキルに関係する条件群を先に選ぶ**。7件は「サポカに効く順」として計算した順位ではなく、次のP2.15検証で使う**少数の代表的な実験単位**である。

重要：`complex-or-external-hold`の乱数や他スキル依存条件が追加のANDに残る経路を、単に未確認タイプが少ないというだけで研究の第一候補にしない。元条件の効果・全経路発動・出走分布の実際の確率は引き続き保留する。固定CIで抽出した具体的な元スキルIDと経路位置は下記の実測欄へ記録する。

## 重要な制限

「有限条件で除外できなかった」は「その脚質で元スキルが発動する」ではない。複数脚質に共通の元経路があっても、それだけで脚質差の大きさが分かるわけではない。固定モデルの部分的順位観測は実ゲームの発動確率ではない。**`completedSourceRouteEvaluations=0`、`actualAppliedOmissions=0`、`officialP3OrP4Ratings=0`** を継続して検証する。
