# P2.30：条件横断の「方向一致」は、どの程度の差で裏付けられているか（2026-11-11）

**対象：P2.29の固定元順位・時期32部分条件×4脚質6ペア＝192比較のうち、全条件一貫69組、比較可能範囲のみ一貫66組。正式なスキル適性・サポカ適性や発動率ではない。**

## 課題

[P2.29の条件横断比較](skill-p2-29-reference-context-and-consensus-20261111.md)は、9/12頭×4人工編成×元の適用コース×2能力モードで、4脚質間の順位・時期条件成立機会Wの**大小方向**が揃うかを測定した。しかし「差が0.0001ポイントでも一貫」と「差が10ポイントで一貫」は製品上の有用性が違う。方向だけの確認では、微小差の過大解釈が起き得る。

今回[P2.9元の厳密比較器](../../../poc/tools/skill_specificity32_research.cjs)の各脚質ペア／編成／頭数の比較結果へ、**すべての適用コース×能力条件にわたる最小保証差（百分率ポイント）** `minimumCertifiedLeadPoints` を追加した。

- 元の区間を `W_A ∈ [L_A,U_A]`、`W_B ∈ [L_B,U_B]` とすると、AがBを必ず上回る最小保証差は `L_A − U_B`、BがAを上回る場合は `L_B − U_A`。
- 同一のコース・能力・頭数・人工編成で比較した各セルの最小保証差を取る。さらに同方向のセルだけについて**9頭・12頭および4人工編成全体での最小値**を取る。平均差を使って弱いセルを隠さない。
- 比較対象の脚質が出走しないセルは **欠測** とし、差0や敗北に変換しない。「8/8全比較可能」と「6/8比較可能」を分離する。
- 途中で差の方向が逆転したり、数値区間が重なったりしたら、全条件における保証差は `null`。順位付けを行わない。

ここでの「区間」は固定GlobalSimで曖昧な同着・軌跡から生じる**測定不確実性の上下限**で、**統計的信頼区間ではない**。

## 数値の読み方

[P2.30監査器](../../../poc/tools/skill_context_margin_sensitivity.cjs)は、元のP2.29固定条件と元条件から集計された各セルの正当性を再照合したうえで、以下の研究用仮しきい値を試す。

| 研究上の仮の最小差 | 意味 |
| --- | --- |
| 0.1ポイント | 最も弱い比較セルでも0.1ポイント以上を保証できるか |
| 1ポイント | すべての比較可能セルで1ポイント以上の差があるか |
| 5ポイント | すべての比較可能セルで5ポイント以上の差があるか |
| 10ポイント | すべての比較可能セルで10ポイント以上の差があるか |

**どの値もP2.14で正式採用したしきい値ではない。** 差が基準を下回ったという理由で「適性なし」と断定してはならず、「その差を保証できない」だけ。元ソースの順位・時期の部分条件に限った相対比較であり、実スキルの全AND/OR、能力発動後の効果、サポカの取得経路は評価していない。

### 固定モデルの検証結果

[固定5,760レースの派生JSON再計算CI #42977386598](https://github.com/Nimrodx0/Umasupport/actions/runs/42977386598) **成功**。P2.29で厳密方向一致した69＋66＝135組について、保証できる最小のW差を横断監査した結果：

| 仮の最小差（百分率ポイント） | 全8条件で比較可能・方向一致 | 走者不在条件を除いた範囲で方向一致 | 合計 | 方向一致135組のうち差を保証できない |
| --- | ---: | ---: | ---: | ---: |
| 0.0超（P2.29の方向一致） | **69** | **66** | **135** | 0 |
| 0.1以上 | **68** | **66** | **134** | **1** |
| 1以上 | **66** | **65** | **131** | **4** |
| 5以上 | **54** | **64** | **118** | **17** |
| 10以上 | **52** | **64** | **116** | **19** |

P2.29で方向逆転・保留だった**57組は全行から除外している**。この57組を「最小差が0」として比較可能集計に混ぜない。また66組は「逃げ不在」の比較不能条件があり、全8条件の強さと同列にしない。

比較可能135組の最小保証差は**0.045919～95.073536ポイント**だった。これは各対象コース×能力×編成×頭数の**順位同着などに由来する数値区間に対する最小差**で、30seedの統計的信頼区間ではない。特に「116組で10ポイント以上」を実ゲームの適性確証としてP3へ渡してはいけない。元モデルでの条件成立機会Wの相対差だけを測っており、出典・レースモデルの版、現実に未測定の対戦分布とゲーム内のスキル発動条件が評価を限定する。

[保存された研究JSON（GitHub Actions成果物）](https://github.com/Nimrodx0/Umasupport/actions/runs/42977386598/artifacts/13836525602) は14日保持。差の小さいものを含め、192組すべての個別研究状態と仮閾値ごとの判定を含む。

## P2の次の判定ゲート

1. **シード分割の再現性**：元データは30seedをまとめたもの。15＋15に分割した各条件の脚質間方向・最小差について、固定元データまたは新しい再現実験が必要。今の保証差を統計上の確信度として扱わない。
2. **WとDの区別**：今回は短窓の成立機会Wの相対差のみ。位置占有の脚質特異性D＝O−Uの条件横断安定性は別途監査する。
3. **元スキル条件**：P2.15・P2.20のAND/OR、preConditions、複数Invokeを解決したときだけ、今回の順位部分条件の比較を元スキル全体の適性へ昇格できる。
4. **表示方式の検討**：「一貫」「比較可能条件では一貫」「条件依存」「保留」に、差の大きさ、対象コース／頭数／脚質構成、信頼性・出典を併記するか比較する。実ゲームへの転用・P3のサポカ集約・P4正式UIは未承認。

**根拠と再現性**：元UmaSimとGlobalSimの版固定、5,760レース成果物のSHA-256検証、P2.29由来の192組の一貫性判定を維持する。新しい成果物は研究用の数値JSONのみで、元スキル本文の再配布はしない。GitHub Pagesの公開アプリやユーザー設定には変更しない。
