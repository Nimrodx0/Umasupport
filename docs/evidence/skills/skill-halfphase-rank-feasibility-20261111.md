# P2.27：脚質適性の追加研究に直結する短窓順位条件の全件調査（2026-11-11）

**結果：既存モデルに入力できる候補が見つかった。4脚質評価が確定したわけではない。**

## 目的とデータ

スキル別の逃げ・先行・差し・追込の**大まかな発動条件適性**を改善するため、先に「新しい物理モデルや条件型の実装が本当に必要なのか」を検証する。

- [全881スキルの研究段階レビュー](skill-coarse-four-style-review-20261111.md)で使用した元辞書ID・名称照合818スキル、未照合63スキルを維持。
- 追加研究が必要な集合は、4脚質のどこかが「判断保留」、旧2群のみ、または順位条件の部分情報のみである **620スキル**。このうち「判断保留」の584スキルは従来の数字と一致する。
- 固定UmaSimの条件構造を読み、`phase_firsthalf_random`／`phase_laterhalf_random` と `order_rate` が**同一AND経路**に存在し、[既存11種の順位帯](../../../poc/tools/globalsim_rank_band_dominance.cjs)に**元の演算子・境界が完全一致**するかを調べた。
- OR、前提条件、複数Invoke、他の未測定ANDの存在を別々に記録し、複数経路からスキル全体の発動確率を組み立てない。

実例：積極策、差し切り体勢、スタミナキープ、ワンチャンスなど。いずれも**発動条件の脚質評価が妥当かを測るための候補**であり、現状で特定脚質の適性が高いと断定する資料ではない。

## 既存P2研究との接続

**上記の4種類の時期窓は、新規に発見された未計測窓ではない**。[2026-11-07の固定720レースによる短窓10m研究](skill-subphase10-77-audit-20261107.md)ですでに**同じ元時期コード・4窓・11順位帯**の研究プログラムがあり、24均衡設定・全4脚質の窓別/順位帯別分布を計算できる。モデルの出力は4,224文脈セル。

一方、現在の[全881スキル用4脚質比較器](../../../poc/src/skill_balanced_four_style_fit.cjs)は、元スキルの時間条件が `phase_random` である場合にだけ、局面全体の既存4脚質順位比較を取り出す。元スキルの4短窓に合う情報は、**既存モデル研究に存在するが、全件4脚質比較器へ未統合**である。

このため、次工程の第一候補は、既存短窓研究で検証した元順位割合窓から**4脚質の比較方向が安定して導けるか**を、均衡編成・コース・頭数・能力条件で調べること。既存の4短窓×11順位帯・元スキルの同一ANDとの一致を保持し、条件が成立する場合に限って研究用4脚質比較器へつなぐ。**新たなエンジンや未検証の発動率式の構築は現段階で不要**。

## 検証の制限と次のゲート

1. 75スキルのうち、4脚質の比較方向が十分安定しないケースは**保留を維持する**。単に順位条件が計測可能なだけで高・中・低に分類しない。
2. `running_style` などの明示制限は、モデル内の比較順序とは独立に保持する。芝の実測値をダートへ自動的に転用しない。
3. 12件にある追加AND／ORを、75件の直接候補と混ぜて「87スキル全体が評価可能」とは記述しない。追加条件が本当に脚質依存の結論を変えるかは個別に検証する。
4. 元辞書の条件成立機会は**発動後の有用性や実ゲームでの発動確率ではない**。機会W、特異性O−U、モデルの文脈依存と欠測を区別し、公開UI・P3サポカ集約・数値閾値の判断は引き続き別工程とする。

**結論**：今回の実データ調査から、次は75候補に関係する既存短窓モデルを4脚質比較として再分析すべきだと判断できる。研究打ち切りでも、全125条件の完全再現でもない。目標に影響する部分に研究を集中する。
