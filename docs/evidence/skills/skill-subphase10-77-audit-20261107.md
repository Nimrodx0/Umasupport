## 1. 元コードと4つの窓

固定UmaSim `f6e4501ee6c6c2d4ac8698e7796e309d31575bde`の[SkillChecker.kt](https://github.com/mee1080/umasim/blob/f6e4501ee6c6c2d4ac8698e7796e309d31575bde/race/src/commonMain/kotlin/io/github/mee1080/umasim/race/calc2/SkillChecker.kt)は、`phase_firsthalf_random`に局面前半 `(0.0,0.5)`、`phase_laterhalf_random`に局面後半`(0.5,1.0)`を渡して`initPhaseRandom`を実行する。ランダム領域の`chooseRandom`は、局面内の一様抽選点`U`に対して`s=min(U,windowEnd-2m)`とし、判定範囲を`[s,min(s+10m,windowEnd)]`とする。**抽選対象はレース全体／親局面ではなく、その細分化された窓内**。

固定辞書の保留30件で実際に現れた4種類（レース全体の距離比率）：

| 元時期条件 | 10m窓を抽選する正確な走行距離範囲 | 対応する短窓のモデル |
| --- | --- | --- |
| `phase_laterhalf_random==0`（序盤後半） | **1/12～1/6** | 序盤後半 |
| `phase_firsthalf_random==1`（中盤前半） | **1/6～5/12** | 中盤前半 |

| `phase_firsthalf_random==2`（終盤前半の前半） | **2/3～3/4** | 終盤前半前半 |

すべて元の[時期条件解釈器](../../../poc/src/skill_rank_timing.js)の局面境界から計算し、内部の距離位置では8桁丸めを避ける（表示だけ丸める）。**これらと`phase_random`親局面全体は別の母集団**。

## 3. 実測カバレッジ

| 分類 | 前回（全局面のみ） | 今回（全局面＋正確な短窓） |
| --- | ---: | ---: |
| 単一AND/OR経路の順位条件と対象モデルが一致 | 34件 | **56件** |
| 複数OR経路を個別に数値化（スキル全体は保留） | 0件 | **4件** |
| 未検証のダート等の馬場条件 | 13件 | **17件** |
| 局面の抽選窓不一致による保留 | 30件 | **0件** |
| **合計** | **77件** | **77件** |

- 前回保留していた**30スキル＝34元条件経路**について、全件に対応する短窓を測定した。うち**30経路**は追加でモデル数値の集計対象、残る**4経路**はダート条件のため**順位部分のみ参考値**。追加の元条件窓不足は0経路。
- **合計81条件経路**のうち、**64経路×4脚質＝256ケース**を順位部分の記述的分布に含める。**金・白・同一順位条件の重複を除外すると、元の条件は26種類**（4脚質×26＝104観測）。
- 4件の複数OR：**曙光・光明・超然・存在感**。各OR経路の条件を個別に測れたが、同一スキル全体の**OR合併イベントの確率は算出していない**。距離などの条件が異なる経路を、根拠なしに単純平均・加算しない。
- 残る17件はダート限定。従来のモデルで順位条件部分が99%でも、芝に対する順位挙動をダートへ**実測済みとして転用しない**。新たに保留へ増えたように見える4件は、もともと抽選窓の理由で保留だったが今回ダートという**別の未解決条件**が明らかになったもの。

## 4. 発動条件を限定した代表例

すべてモデル上の**順位条件部分の10m範囲内成立機会**。**実ゲームのスキル発動率ではない**。脚質の列順は逃げ／先行／差し／追込。

| 元スキル（条件） | 親局面全体の研究値（%） | 元の正確な短窓の研究値（%） |
| --- | --- | --- |
| **マイルの支配者**、序盤後半・前方50%・マイル | 95.18 / 93.11 / 21.39 / 12.00 | **99.43 / 99.68 / 18.31 / 1.07** |
| **慧眼**、序盤後半・後方50%・マイル | 6.46 / 8.87 / 82.13 / 90.05 | **0.58 / 0.38 / 84.53 / 99.38** |
| **真打**、中盤後半・前方50%・長距離 | 99.93 / 99.36 / 15.49 / 3.23 | **99.86 / 98.72 / 15.13 / 4.73** |
| **ハイボルテージ**、終盤前半の前半・前方50%・マイル | 96.48 / 92.64 / 23.69 / 4.55 | **98.26 / 94.26 / 21.46 / 3.60** |

親局面の値は**比較用**であり、短い窓の条件が実際に親局面のどこでも判定されるという意味ではない。例えば「マイルの支配者」の追込では、親局面を流用すると**12.00%**だが、正しい短窓で計算すると**1.07%**。前回の慎重な保留は必要だったことが、数値でも確認できた。

**ORの例**：「超然」は中盤前半・前方50%条件を持つが、距離条件の異なる2つの元経路を保持する。各経路で逃げ99.78%／100%、先行99.99%／100%と測れた。ただし**スキル全体の発動確率として足したり平均したりしない**。

**馬場保留の例**：「勝利の機運」は中盤後半・前方50%の順位部分を計算できたが、ダート限定を満たすモデル環境が未検証。「砂の開拓者」も同様に序盤後半の窓を検証したが、スキル全体はダート条件が未検証のため保留。

| 脚質 | 中央値（26条件） | 5%未満 | 80%以上 |
| --- | ---: | ---: | ---: |
| 逃げ | 99.40% | 9 / 26 | 17 / 26 |
| 先行 | 96.35% | 2 / 26 | 17 / 26 |
| 差し | 18.36% | 0 / 26 | 7 / 26 |
| 追込 | 3.32% | 16 / 26 | 9 / 26 |

**注意**：この集合は、そもそも「逃げ・先行寄り／差し・追込寄り」の旧ルールで選ばれた53件と、特定の順位帯で追加された24件に偏っている。26条件になっても**全スキルの発動条件の無作為代表標本ではない**。また短窓の成立機会は文脈差・順位変化・脚質構成に依存する。中央値の大小や区間の「5%」「80%」は**適合性ラベルの閾値として採用しない**。

## 6. 次のゲート

1. **ダート限定の17件**：実際にコースの芝・ダート設定を変えたGlobalSimで計測可能か、固定モデルのコース定義とスキルなし軌跡の再現性を先に検証する。ダートのコースIDへ切り替えるだけで同じ性能条件・同じ道中挙動・同じ抽選母集団だとは限らない。安易な芝データ流用はしない。
2. **閾値の前提**：26種類を高・中・低へ即座に割らず、未測定のダートと多様な位置・脚質イベント条件を含めて、モデルの**連続機会と文脈別ばらつき**をどう評価すべきか議論する。
3. **2軸は独立**：第1軸の条件成立機会を数値化できたことは第2軸の脚質特異性や、別の**効果の有用性**を測ったことを意味しない。P3集約・公開UIへの自動反映はしない。
