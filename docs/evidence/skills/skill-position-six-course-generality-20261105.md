## 1. 脚質群の優劣：すべての対象条件で維持

各条件で次の差を計算した。

\[
D = \min\bigl(P_{\mathrm{逃げ}}, P_{\mathrm{先行}}\bigr)
 - \max\bigl(P_{\mathrm{差し}},P_{\mathrm{追込}}\bigr)
\]

`P` は**指定されたレース区間内でその脚質が上位50%にいた走行距離の割合**。逃げ不在の場合は逃げのデータを除いて先行だけを前方側に採用する。負なら「少なくとも前方側の一脚質より、後方側の一脚質が有利」の反例である。ここでの「後方側が有利」は上位50%条件についてであり、下位50%条件なら反対の関係となる。

| 対象 | 条件数 | `D>0` | `D=0` | `D<0` | 最小差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 中盤全体 | 144 | **144** | 0 | 0 | 34.81ポイント |
| 終盤前半の前半 | 144 | **144** | 0 | 0 | 32.00ポイント |
| 終盤前半全体 | 144 | **144** | 0 | 0 | 31.56ポイント |
| 終盤前半の後半 | 144 | **144** | 0 | 0 | 25.78ポイント |
| **合計** | **576** | **576** | **0** | **0** | **25.78ポイント** |

576件のうち**480件**は逃げ・先行・差し・追込の4脚質を比較。残り**96件**は逃げ不在の編成なので、**先行と差し・追込**だけを比較。脚質不在の成立割合を0%として扱っていない。

頭数・脚質構成・能力設定・区間を固定して6コースすべてを比較できた**96組**についても、各組の6コースすべてで`D>0`が維持された。ただし同一レースの4区間は相関しており、96組を独立な実験96件とはみなさない。

**最小差の例**：2,500m（10506）、9頭、2026年1月の観測比率から脚質編成を抽選する設定、全馬同能力、終盤前半の後半。逃げ100.0%、先行66.84%、差し41.05%、追込9.60%で、前方群の最小値（先行）と後方群の最大値（差し）の差は25.78ポイント。これは実ゲームの発動率ではない。

## 2. 群内の脚質序列は一律にできない

| 同じ条件で比較する組 | 左が高い | 右が高い | 同値 |
| --- | ---: | ---: | ---: |
| 逃げ と 先行（逃げ不在を除く480件） | 逃げ 415件 | 先行 44件 | 21件 |
| 差し と 追込（576件） | 差し 553件 | 追込 23件 | 0件 |

これは**「逃げ ＞ 先行 ＞ 差し ＞ 追込」という4脚質の固定序列が常に成立するわけではない**ことを示す具体的な反例。群全体の方向性と、各脚質間の厳密な順序を別の規則として扱う必要がある。

## 3. 成立割合の数値はコース・条件で変わる

同じ9／12頭、脚質構成、能力設定、発動候補区間を揃えた6コースの成立割合の**最大値と最小値の差**を計算した。

| 脚質 | 同条件を比較した組数 | コース間の差の中央値 | 最大差 |
| --- | ---: | ---: | ---: |
| 逃げ | 80 | 9.89ポイント | **37.50ポイント** |
| 先行 | 96 | 9.93ポイント | **19.08ポイント** |
| 差し | 96 | 12.97ポイント | **30.15ポイント** |
| 追込 | 96 | 13.18ポイント | **31.50ポイント** |

同じ距離の別コース同士でも差がある。例えば1,600mの2コースで、同一設定における逃げの成立割合の差は最大37.50ポイント（対象脚質の観測が少ない条件）。2,000mの2コースでは追込で最大31.50ポイント（対象脚質の観測が特に少ない条件）。

**重要な制約**：この差は「距離だけが引き起こした差」を表していない。同距離でもコースの形状が異なり、さらにコースごとに乱数初期値が異なる。各セル15レースと少なく、脚質の出走人数が小さいと偶然の影響が大きい。したがって、現状のデータから「コース形状による確実な影響が37.5ポイント」とも「距離による影響はない」とも言えない。

## 4. 一般則への採用判定

- **候補として支持される**：上位50%条件について、調査した中盤・終盤前半の4区間では、各コース・編成等で逃げ・先行の方が差し・追込よりも上位半数にいる距離割合が高かった。これは**定性的な方向**の一致であり、脚質への厳格な専用制限を意味しない。
- **成立しない**：逃げ＞先行＞差し＞追込という無条件の厳密な序列、すべてのコースで同じ成立割合の数値を使えるという仮定。
- **未検証**：上位30%・順位40～80%等の異なる順位条件、序盤・終盤後半、直線・コーナーや他馬依存の追加条件。さらに実際の日本版レースの順位条件成立割合、スキルの抽選／発動率やスキル効果の有用性。
- **原因の切り分けが未完成**：距離、コース形状、乱数初期値、少数出走脚質のばらつきが重なっており、観測された数値変動をそれぞれの効果と断定できない。
- **方法の精度**：今回の全6コースは9地点の線形補間を使用。別の[72レースの全記録時刻データ検証](skill-position-dense-frame-validation-20261105.md)では9地点近似との差が最大7.49ポイント。全576条件の計算誤差上限として7.49ポイントを外挿してはいけない。

## 次の基礎研究の優先順位

1. **50%以外の順位帯と序盤／終盤後半**が実際の発動条件でどれほど利用されるか固定スキル辞書を集計。必要な一般則の範囲を定め、50%だけで全スキルに適用しない。
2. 現在の「距離によらない方向性」をより厳密に検証するなら、**同じ条件・乱数系列を異なる距離／コース形状で制御する対照実験**と、各記録時刻の走行位置を用いた計算を実施し、距離とコース形状を区別する。能力値や脚質構成の乱数は同一条件に固定する。
3. 現在のモデルの代表性は実ゲームの対戦記録との照合で別途検証する。少なくとも実ゲームとの照合以前にモデル値を「スキル発動率」扱いしない。

**実装判断**：現時点では**一般則候補をレポートに限定**し、定性的な53スキル分類、P3サポカ集約、P4検索UI、公開イベントデータを変更しない。数値や普遍性を過大評価しないため、ルール化は上記の未検証条件を明示して次工程で判断する。
