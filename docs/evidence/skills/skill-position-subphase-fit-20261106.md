# P2：序盤後半・中盤前後半の順位条件適合性の検証（2026-11-06）

> **資料の位置づけ**：スキル・発動条件に関する固定調査（時点付きの証拠）。本文の測定対象・出典版・留保を確認してください。
> **現行の参照先**：[正本の入口](../../index.md) ／ [関連する工程・契約](../../plans/skill-conditions/p2.md)。執筆当時の「現在」「次工程」は現行の指示ではありません。

**結論：固定GlobalSimモデルの6コース・2,160レースにおいて、検証対象の序盤後半／中盤前半／中盤後半の3区間それぞれで、上位50%以内にいる距離割合は前方脚質群が後方脚質群より高かった。各72比較条件すべてでその方向が一致し、試行を前後15件に分けても全件で方向が一致した。** この結果はモデルに限る定性的な根拠であり、ウマ娘の実発動率ではない。

## 1. 元スキルのどの条件を調べたか

[脚質発動条件適合性v1.1](skill-activation-condition-fit-v1-20261106.md)で残った保留22スキルは、順位条件の境界自体は分かっていたが、指定された細かな発動区間での脚質別順位傾向が未検証だった。固定UmaSim辞書と既存の条件解釈器 [skill_rank_timing.js](../../../poc/src/skill_rank_timing.js) を照合し、**元のAND/OR条件を保ったまま**次の3つに分類した。

| 元の発動区間条件 | レース全体の進行率 | 該当スキル | 代表例 |
| --- | --- | ---: | --- |
| phase_laterhalf_random==0（序盤後半） | 8.33～16.67% | **8** | マイルの支配者、慧眼、アドバンテージ、砂の開拓者 |
| phase_firsthalf_random==1（中盤前半） | 16.67～41.67% | **2** | 超然、存在感（いずれも距離条件が異なるOR経路を持つ） |
| phase_laterhalf_random==1（中盤後半） | 41.67～66.67% | **12** | 真打、勝利の機運、初志貫徹、順風満帆 |
| **合計** | | **22** | |

表示する境界は四捨五入値。機械的な定義は [固定派生データ](../../../poc/data/p2_subphase_model_direction.v1.json) に元の型・演算子・値とともに保存した。順位条件は上位50%以内（order_rate<=50）または後方50%（order_rate>50）のみ。時期のランダム窓と時点判定（phase）、コーナー等のコース依存条件を混同しない。

## 2. 実験条件と計算方法

- **固定GlobalSim v77**：コミット 80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1、すべての馬はスキルなし。
- **6コース**：1,200m（10501）、1,600m×2（10502／10304）、2,000m×2（10504／10604）、2,500m（10506）。
- **9・12頭**、脚質構成は均衡固定／2026年1月長距離CM A予選の240人調査の脚質比率を用いた抽選／逃げ不在固定の3種、全馬同等能力／人工±10%能力差の2条件、**各30シード**。計6×2×3×2×30＝**2,160レース**。
- **全記録時刻の走行位置**を線形補間し、走者同士の交点をすべて分割して**1位から最下位までの走行距離占有割合**を積算。約9地点の疎な抽出ではない。
- **各条件の前方群－後方群の差**＝逃げ・先行それぞれの上位50%占有割合の最小値－差し・追込それぞれの最大値。逃げ不在では先行のみを前方群に使い、逃げを0%として扱わない。
- **72比較条件／区間**（6コース×2頭数×3編成×2能力設定）。各条件を30シードの前半15／後半15へ分割した結果も別に確認。曖昧な同順位・不足走者は条件ごと保留とし、ほかの走者と独立した試行数として誤加算しない。

## 3. 実測と独立した追試に向けた根拠

[GitHub Actions #42070972985](https://github.com/Nimrodx0/Umasupport/actions/runs/42070972985) が成功。**2,160レース、68,040走者×区間の順位観測、216比較セル**で、各72セルに欠測・同値・群間逆転なし。

| 発動区間 | 前方群優位 | 逆転・同値・未確定 | 15シードずつの両方で前方優位 | 最小差 |
| --- | ---: | ---: | ---: | ---: |
| 序盤後半 | **72/72** | 0 | **72/72** | 34.12ポイント |
| 中盤前半 | **72/72** | 0 | **72/72** | 33.85ポイント |
| 中盤後半 | **72/72** | 0 | **72/72** | 34.10ポイント |

**あくまでも前方脚質群と後方脚質群の相対的な方向の支持**である。逃げと先行、差しと追込の群内順位、実発動抽選、スキル効果の有用性についての結論ではない。脚質人数・能力設定などはモデル内のシナリオであり、日本版対人レースの代表標本や独立した72大会ではない。

## 4. v1.2の53スキル監査へ反映する範囲

- 今回の3区間に**正確に一致**し、順位条件が上位50%以内または後方50%で、他の必要なAND条件が未評価ではない経路に限り、**前方群優位・後方群優位という相対的な方向性**を研究用の高適合／低適合に変換する。
- **22スキル**の内訳は、上位50%以内を要求する20件、後方50%を要求する2件。長距離／中距離のORで異なる経路がある「超然」「存在感」も、経路ごとに同じ方向の証拠があるときだけ全体を確定する。
- 馬場種別・馬場状態・距離の制限はこれまでどおり**脚質適合性とは独立した絶対レース条件**として残す。ダートへ基本方向を暫定適用することは[後続決定](../../decisions/log.md)によるもので、ダートで同じ割合が直接実測されたという意味ではない。
- **旧v1.1で31/53件判定、22件保留**だったものを、研究用v1.2で**53/53件を脚質の相対的な高／低方向として判定**する。これはもともと順位×局面による推定ラベルが存在した53件に限る検証であり、全スキル818件が分類可能という意味ではない。

**製品への変更なし**：旧53件の初期推定脚質、ユーザーのカード集計、スキル検索UI、公開イベントを自動書換えしない。

## 5. 今後の研究上の制約

モデルで使用した頭数別の順位丸めの式と日本版ゲームの実際の順位割合判定の完全一致は独立確認していない。今回の3区間での方向一致は他の時期やコーナー・直線・追い抜き条件へ外挿できない。また順位条件の成立距離割合はスキルの発動確率ではない。

次の実用的な検証先は、**上位50%以外の実条件（order_rate>=40など）の正確な整数順位解釈**、元条件のAND／OR・複数Invokeの安全な扱い、およびサポートカードのスキル集合へ評価を集約する際の保留表現である。
