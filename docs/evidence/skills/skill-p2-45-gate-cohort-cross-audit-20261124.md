# P2.45：G1/G2/G6の全件横断監査（2026-11-24）

[D-047](../../decisions/log.md#decision-d-047)の受入工程。G1理由台帳と、P2.15の静的必要条件、P2.44とP3独立再計算の研究受領を、同じ固定元データを再取得する既存720レースCI内で照合する。別runの期限付きArtifactを入力にしない。

- 元IDで一致した818件はapp ID、数値ID、32文脈、OR経路、馬場4ビットを確認する。個別AND経路のビット和を再計算し、条件空Invokeは保守的な全15の保留と区別する。
- 63未照合は数値IDを捨てず、要求されたIDと確定した元IDを別に保持する。未知マスクはnullとし、全0や全15に置換しない。
- 期待母数：881、818／63、33同名なし／30IDなし、970元経路、26,176既知必要条件セル／2,016元不明セル、部分W/D 81／芝転用保留6／その他794。これらは**固定CIで照合すべき期待値**であり新実測を主張しない。
- 未解釈型を対象ID別に保持する。元AND条件の実成立率、ゲーム発動率、正式な適性ラベル・サポカ採点は承認しない。G3/G4の採否判定及び親G6 Passは別。
