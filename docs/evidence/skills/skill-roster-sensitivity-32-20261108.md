[32元条件の限定派生マニフェスト](../poc/data/p2_position_condition32_research.v1.json)は、以前の固定77件監査の128条件×脚質ケースを重複除外した32種類から、代表元ID・芝／ダート・明示距離範囲・元の`phase_random`または厳密な前後半ランダム窓・元順位AND帯のみを取り出したもの。監査元データのSHA-256は `71251951444fbe4cbef8502422deebaf489941f817a8830c5038176be59f9fcd`。元辞書全文や第三者の全件データを再配布していない。**同じ順位・時期条件でも距離・馬場が異なるなら別の研究条件とする**。対象は芝26・ダート6の計32種類。元77スキル全体を無作為抽出したわけではなく、選ばれた順位条件へ偏っている。

- **9頭／12頭の比較は編成・整数順位境界が両方変わる**ため、この資料の主眼は**同じ頭数の中で**各編成を比較することにある。

## 2. 検証：均衡編成との連続性とモデル未確定条件

固定均衡編成30シードの再実行値は、以前の77件・128ケース監査の検証値に一致した。例えばマイルの支配者／差しは9頭35.536379%、12頭1.076901%、ハイボルテージ／差しは9頭31.944075%、12頭10.978271%、砂の玄人と同一の元順位条件／先行は9頭50.043284%、12頭65.726951%。初期種・抽選範囲・順位AND・コース範囲が以前と一致したことの検査であり、実ゲームの真値との一致を示すものではない。

**モデルの「同順位のまま推移する区間」への対処**：後方偏重または逃げ不在の一部の走者で、位置軌跡の厳密な同点が起こり、どちらが上位かを参照モデルだけでは確定できない。以前の研究規律どおり、ゲート・レーンで独自に決めることはしない。各未確定走者が順位条件を満たす可能性を下限0%・上限100%とする保守的な区間へ置き換え、該当文脈の**確定数値はNULL**にする。**0%とみなさない**。

| 編成 | 順位未確定の文脈セル | 順位未確定の走者・抽選窓 |
| --- | ---: | ---: |
| 均衡 | 0 | 0 |
| 前方偏重 | 0 | 0 |
| 後方偏重 | 3 | 6 |
| 逃げ不在 | 4 | 6 |

32元条件×4脚質×2頭数＝**256ケース**のうち249ケースは編成ごとの数値が全て確定し、7ケースは一部の編成で上限・下限区間を保持。**逃げ不在での逃げ**に相当する64ケースは出走した対象走者がゼロなので、当該編成のみ**「対象脚質なし」NULL**とし、ほかの3編成で比較。未確定の7ケースを持つ場合は、全編成での「最大差」は数値断定せず、取り得る下限・上限と**少なくとも何ポイントの差が確実か**を評価する。

## 3. 実測：同じ頭数の脚質編成感度

9頭・12頭それぞれで、**元条件×脚質の各128ケース**を異なる人工編成と比較する。元順位条件部分の10m成立機会であり、ゲームの発動率ではない。

| 実測の集計指標 | 9頭（128ケース） | 12頭（128ケース） | 合計 |
| --- | ---: | ---: | ---: |
| すべての対象編成で確定値を取得 | 125 | 124 | **249/256** |
| 一部で順位同点のため区間評価 | 3 | 4 | **7/256** |
| 編成間差が**確実に20ポイント超** | **58** | **65** | **123/256** |
| 少なくとも50ポイント超の編成間差（確定ケースのみ） | 26 | 30 | **56/249** |

**仮の**「低・中・高」の3段階区分の安定性も比較した。これは候補境界の感度検査であり、閾値を推奨・採用したのではない。

| 仮の区分境界 | 全編成で同区分が確定 | 異なる区分が存在すると確定 | 区分比較も不確定 |
| --- | ---: | ---: | ---: |
| 低<20%・高≥80% | **133** | **123** | **0** |
| 低<10%・高≥90% | **100** | **156** | **0** |

注：7ケースでは順位同点のため**連続値そのものが区間**だが、その上下限を含めて照合しても、この3つの仮区分については「同区分が確定」または「区分が異なることが確定」と判定できた。区分の確定は平均値が確定したことを意味しない。逃げ不在の逃げは比較から除外したもので、安定・変動の根拠に0%を加えていない。

## 5. 評価設計への含意（今回決定・変更しないこと）

- **従来の均衡編成**は、研究の連続性と比較条件として引き続き使用する。[現行ロードマップ](roadmap.md)ではP3の標準編成も均衡編成のみを基準とする方針が記録済みであり、**今回の感度研究でそれを覆さない**。
- ただし均衡編成は「最も現実に多い相手編成」ではない。他編成を不確実性・感度として示すのと、通常スコアへ確率加重して統合するのは**別の判断**。現実の対戦編成の同時分布が未検証なので、均衡/前方/後方/逃げ不在の各値へ**確率重みを付けた総合発動率を作らない**。
- 仮の20/80、10/90、5/95を高／中／低ラベルの正式境界として採用しない。元の位置条件成立機会の**連続値と頭数・編成・未確定の根拠**を別属性として保持する方向の材料である。
- 第2軸の**脚質特異性**は今回の絶対的機会の区分と混合しない。実スキルの発動処理、前提条件・OR合併・発動後の効果有用性、カード獲得経路のP3集約も独立して未検証。
- **逃げ不在で逃げに対応する「0%」を表示しない**。評価対象不在としてNULLを保ち、将来の別編成モードを導入する場合にも「該当脚質の観測なし」と「成立機会0%」の意味を分離する。
