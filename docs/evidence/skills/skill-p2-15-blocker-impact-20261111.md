# P2.15：元スキルAND/OR・preConditionsを保った未検証条件型の研究効果監査（2026-11-11）

**状態：元出典・構造の静的監査は成功。元スキル発動条件を新たに実測・解決したわけではない。** 本研究は「追加でどの元スキル条件型を調べると、スキル・脚質単位の評価可能範囲が広がりやすいか」を選ぶためのもの。

## 設計と対象

[従来のP2.15全条件構造監査](skill-p2-15-full-path-gate-audit-20261111.md) は、元スキルの各Invokeと条件ORとpreConditionsのORを列挙し、有限の明示条件 `running_style`、`distance_type`、`ground_type`、`ground_condition` から4脚質の必要条件を検査した。859脚質セルを明示除外したが、残る2,413セルについて何種類の条件をさらに研究すべきかまでは経路単位で最小化していなかった。

新しい[監査器](../../../poc/src/skill_source_path_blocker_impact.cjs)は、同じ出典照合済みスキル881件（元条件照合818・未照合63）の `Invoke × conditionsのOR行 × preConditionsのOR行` を**一つずつ組み合わせたAND候補**として評価する。対象は4脚質で、明示有限条件の矛盾を既存P2.15判定器と同じ実装で検査する。

各候補では、有限の4条件型以外を「未検証の条件型」として**そのAND候補だけで重複排除**する。経路同士やpreConditionsの別OR行を勝手に結合しない。たとえば「`phase` または `is_overtake`」という前提があるなら、必要条件型は `phase` と `is_overtake` の**個別候補**になり、`phase AND is_overtake` という架空の経路を作らない。

各スキル・脚質セルについて、その条件型が最も少なくなる候補の種類を分類する。**未検証条件型がゼロという分類は、元スキルの演算・発動が成立した証拠ではない。** 既知型を有限のドメインで「矛盾がない」としただけで、実レースの馬場・距離・時刻を選んで評価したわけでもない。

### P2.20の順位変動スキル30件との関係

[P2.20の32レース実測](skill-p2-20-signed-rank-static-context-intersection-20261111.md) は、元の脚質・距離・順位変動符号の**3要因のみ**を同一判定tickで照合している。今回の静的構造監査では、30スキル×4脚質＝**120セル**のうち**36セルは有限明示条件で除外**、**84セルは最少でも未知条件型が2つ以上**だった。未知の条件型 `change_order_onetime` 自体も今回は「測定済み」として差し引いていない。P2.20は限定された32モデルレースだけの部分実測なので、そのデータを使って無条件に残り84セルを完全評価したとは扱えない。

この結果は「30件の順位変動スキルは無意味」ということではなく、**1種類の条件を追加計測しただけでは全体の元ANDを網羅できない**という研究範囲の説明である。

## 次の実装候補と終了条件

1. **高い潜在的効果**：`phase_random` の元演算子・ランダム評価点・位相を正確に確認し、ANDに他の未計測条件がない候補だけを実エンジンの同一判定時刻で評価する。これが成功すれば102スキルを対象とする候補経路のうち、どれほどを実際に検証できるかが分かる。成功件数はまだゼロ。
2. **較正しやすそうな静的条件**：`track_id` を元のコースID体系に突き合わせ、複数条件・頭数・距離等が同時に成立するか確認する。ただしID対応は未検証であり、コードだけを見て既知のコースIDと同じと推定しない。
3. **形状・時間窓の研究**：`all_corner_random` と `straight_random` を、内部判定時刻・コース形状が参照可能な場合に限って調べる。既存の10m W結果を抽選成立率の代用にしない。
4. **P2.20の複合AND**：上記の研究で積み上げた各条件の評価を、同じモデル走者・判定tickに限定して交差させる。個別条件の確率を掛け算しない。preConditionsの履歴と他Invokeは引き続き別検証に残す。
5. **評価可能範囲の成果指標**：今後は「未知の型がゼロになった候補数」だけでなく、「元の演算子・数値・位置・時刻・必要条件の全てについて実観測を持つスキル×脚質セル」と「依然残るAND/OR」を別カウントする。P3へ正式適性を渡すのはさらに後の判断。

**重要な境界**：WとD=O−Uは別軸であり、P2.13のシード安定性は部分順位条件Wのみ。今回の研究で元スキルの実発動率、四脚質の正式高/中/低、サポートカード評価、公開UIを更新しない。
