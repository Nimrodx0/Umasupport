## 1. 出典・計算方法

- **順位条件の出典**：固定UmaSim辞書コミット f6e4501ee6c6c2d4ac8698e7796e309d31575bde。skill_data.txt SHA-256: 4c036527bbe6b5aad34d7f12110a06094c9071514e37fdfc68ae195403333be5。元の順位割合の数値と演算子の頻度だけを集計し、第三者の辞書本文を再配布しない。
- **順位計算モデル**：固定GlobalSim v77（80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1）。6コース×9/12頭×3脚質編成（均衡／2026年1月の観測割合から抽選／逃げ不在）×同能力または人工±10%能力差×15シード＝**1,080レース**。走者にはスキルを付けない。
- **対象局面**：序盤（進行率0～1/6）、中盤（1/6～2/3）、終盤前半（2/3～5/6）、終盤後半（5/6～ゴール）。固定UmaSimの局面定義を基準にする。
- **計算法**：GlobalSimが記録した各時刻の全出走馬の位置を利用し、記録時刻間の走行位置を線形補間。追い抜き地点で各区間を分け、走者が1位・2位……最下位にいた**走行距離の割合**を計算した。従来の9地点だけの推定とは異なる。
- **上位順位の定義**：固定モデルの式 round(出走頭数×順位割合/100) で具体的な上位順位の境界を決める。これは現行日本版ゲームの全条件を独立検証したものではない。

## 3. 脚質間の傾向：局面・順位帯ごとの結果

各局面・順位帯で、6コース×2頭数×3編成×2能力設定＝**72条件**を比較した。各条件には15レースが含まれる。

前方群の逃げ・先行で最も低い成立割合と、後方群の差し・追込で最も高い成立割合の差を評価する。**正なら前方群の全観測脚質が後方群を上回る**。負なら一部の前後脚質の関係が逆転している。逃げ不在の編成では逃げを0%とせず、先行と後方群を比較した。

表中は「前方群が上回った条件数／比較可能な条件数」。終盤後半には多くの逆転例がある。

| 上位順位帯 | 序盤 | 中盤 | 終盤前半 | **終盤後半** |
| --- | ---: | ---: | ---: | ---: |
| 20%以内 | 72/72 | 72/72 | 72/72 | **63/71**（逆転8） |
| 30%以内 | 72/72 | 72/72 | 72/72 | **66/71**（逆転5） |
| 40%以内 | 72/72 | 72/72 | 72/72 | **66/71**（逆転5） |
| 50%以内 | 72/72 | 72/72 | 72/72 | **66/71**（逆転5） |
| 60%以内 | 72/72 | 72/72 | 72/72 | **66/71**（逆転5） |
| 70%以内 | 72/72 | 72/72 | 72/72 | **65/71**（逆転6） |
| 80%以内 | 72/72 | 72/72 | **71/72**（同値1） | **64/71**（逆転7） |

終盤後半の1条件は追込走者2頭の順位が確定できず保留。0%や逆転とはしていない。9頭では上位50%と上位60%の境界はどちらも5位以内となるなど、複数の順位割合が**同じ整数順位帯を指す**場合がある。72条件や7順位帯を統計的に独立の試行とみなしてはいけない。

### 具体的な逆転例（終盤後半・上位50%以内）

コース10502（1,600m）、9頭、2026年1月の観測比率から抽選した脚質構成、人工±10%能力差、15レース：

| 脚質 | 上位50%以内にいた走行距離割合の平均 | 観測した走者 |
| --- | ---: | ---: |
| 逃げ | 94.22% | 7頭分 |
| 先行 | 57.54% | 95頭分 |
| **差し** | **73.44%** | 9頭分 |
| 追込 | 29.71% | 24頭分 |

この条件では差しが先行を約**15.90ポイント**上回った。ただし逃げ7頭分・差し9頭分と観測が少なく、結果の不安定性に注意する必要がある。

5シード（360レース）の先行試験では終盤後半・上位50%に逆転13/72件があったが、15シード（1,080レース）では逆転**5/71比較可能件**まで減少した。これは**少数レースで例外の頻度を判断すると大きく揺らぐ**証拠であり、5件が実ゲームでの一般的な逆転頻度を示すものでもない。

## 4. 規則の採否

- **支持された方向性**：今回のGlobalSim条件では、序盤・中盤・終盤前半の上位20～80%のほぼ全比較で、逃げ・先行群は差し・追込群より上位順位帯に位置した距離割合が高い。
- **普遍則への反例**：終盤後半は全ての上位順位帯に逆転例があった。レース局面に関係なく同じ脚質群の順位を採用することはできない。
- **適用外**：実スキルのAND／OR全体、他馬の行動やコース上の直線・コーナー制限、スキル発動抽選、効果の有用性、実ゲームの発動確率。
- **未解決の因果**：距離とコース形状、コースごとに異なる乱数、脚質の少数出走、能力差が絡む。モデルの定量値を「距離に関係なく使える」とは結論しない。
- **モデル精度の境界**：全記録時刻間の走行位置は線形補間という仮定に依存する。15レース／条件でも少数脚質の占有率の不確かさは解消しない。

## 次の基礎研究

1. 終盤後半で起きた逆転の中から、**脚質構成を固定したレース**を優先して増やし、少数脚質の標本数の影響と能力差の影響を切り分ける。
2. **同じ乱数系列を使った対照実験**で距離・コース形状の違いを分ける。
3. 元スキル条件の order_rate ≥ 40 や複数順位範囲を、測定した順位別距離割合に対応付ける変換方式を検証する。
