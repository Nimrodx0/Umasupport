# P3.3b：全566カードの直接取得候補の研究用集約（2026-11-25）

既存直接候補列挙器で、0～4凸の通常ヒント、元イベントID・choiceId・outcomeId・報酬位置を保持する。否定効果は除外。デフォルト選択の本番core.directRoutesと凸別の候補整合性、全肯定イベント報酬のID照合を検査。未選択分岐を一括獲得とみなさない。欠測スキルは取得候補から消さず、元条件研究状態を明示する。全カードを保持し、未収録・候補なしと適性0点を混同しない。

カード×技能組の研究分類別件数と凸別候補数、直接候補経路数を出す。P2.58/P3.4eを正式ラベルへ昇格させない。金白・上下位間接取得、実際の獲得、スキル発動、効果の価値、カードスコア、公開UIは未評価。全結果は研究専用の期限付きCI成果物に限り、元ゲームデータを再配布しない。固定元コードから再生成できる。
