# P2.28：75スキルの短窓順位条件をP2.9の二軸（W・D）で再評価（2026-11-11）

**状態：固定720レースの全データを再生成し、元レポートの厳密SHAと15＋15シード内訳を検証済み。75元スキルの二軸を部分条件として評価した研究結果であり、実ゲームの発動率・正式適性区分・UIではない。**

## なぜ二軸を維持するか

[P2.9の二軸定義](skill-specificity32-two-axis-20261109.md)を直接引き継ぐ。各スキルの元条件の局面前後半ランダム10m窓について：

| 軸・参照値 | 定義 | どう解釈するか |
| --- | --- | --- |
| **第1軸 W** | モデルの10m抽選窓のどこかで元順位条件が成立する割合 | 発動条件の**機会**。実ゲームの抽選・スキル発動率ではない |
| **第2軸の参照 O** | 元条件の局面窓の**1地点での順位帯占有率** | 順位帯の幅を基準化する前の占有率 |
| **仮想参照 U** | 同じ元順位条件を9／12頭の整数順位へ投影し、対象順位数÷頭数×100 | 全順位が同等に現れる仮想基準。ゲーム内の対戦相手分布ではない |
| **第2軸 D** | **O−U（ポイント）** | 均衡編成モデルにおける、その脚質の順位帯への偏り。**W−Uは誤り** |

**WとDは合成しない**。Wの脚質ペアは、元の1局面窓・コース・頭数・能力条件が完全に同じセルで比較する。Dは各脚質の符号・大きさの文脈別分布を別々に残し、参考としてDの脚質ペア方向もWとは独立して評価する。

## 元スキルの適用条件

[P2.27の元辞書全件監査](skill-halfphase-rank-feasibility-20261111.md)で直接候補とした**75スキル**だけを対象にする。元データのAND経路が単一であり、元の \`phase_firsthalf_random\`／\`phase_laterhalf_random\` と \`order_rate\` の演算子・値・局面位置を保持。追加ANDやORをまとめて発動率にしない。

- 距離指定は元の \`distance_type\` に一致する**芝モデルコースだけ**を使う。距離条件がない場合はモデル全6コース。馬場・コース限定条件が固定モデルで未検証なら保留する。
- \`running_style\` の元条件で明示的に対象外の脚質は「発動不可」であり、測定0%として順位比較に加えない。
- 元順位帯を9頭／12頭の**整数順位条件**へ元通り投影する。元条件の順位集合が空になる頭数は、モデル上の欠測や0%と混同しない。
- 全75件を「評価できた」とみなすのではなく、元コース・明示制限・モデルの保留事由を個別に記録する。

## 実験と厳密な方向一致の意味

[固定720レース・4短窓×11元順位帯](skill-subphase10-77-audit-20261107.md)の計算器を再利用。均衡編成、芝6コース、9／12頭、equal／jitter10、各30シード。モデルは固定GlobalSim v77、元辞書は固定UmaSimと完全な出典SHA照合を行う。

既存の720レースを**同じ固定seedで再計算し、一度のリプレイから**30シード全体のW・Oと、**前半15／後半15シード**のW・Oを並行算出する。既存の30シード短窓レポートSHAを不変のまま再生成できることと、分割2群を再統合して元のW・OになることをCIで要求する。

- Wの脚質ペアが「厳密な同方向」となるのは、**元条件に合致する全コース×9/12頭×equal/jitter10**の全コンテクストと、**その各15シード集計**で常に同じ脚質が相手を上回る場合だけ。
- Dでは、**各脚質の D=O−U の正負符号**が各コンテクストと15シード群で揃うかを記録する。Dの脚質ペア比較も別々に評価するが、Dの符号と脚質間の差は別の意味を持つ。
- 同値・方向逆転・未確認のコース・元条件の適用不可があれば、当該関係を保留。完全な4脚質順位を無理に作らず、安定ペアだけ残す。
- 厳密一致は**固定モデル内の記述的な方向整合**であって、実ゲームの発動確率の有意差や統計的信頼区間ではない。比較許容差 \`0.00001\` ポイントは浮動小数の誤差であり、適性の高／中／低区分の閾値ではない。

## 固定モデルの実測結果（2026-11-11）

[原レース再計算・旧SHA保持・P2.28モデル研究のCI](https://github.com/Nimrodx0/Umasupport/actions/runs/42941100071) は成功。元の短窓720レース出力SHA-256 `206d9db77299189f91fea649a40effbe9ca2d2203c9d0b69c7873bfacee04c27` を再照合し、新たな二軸研究出力SHA-256は **`10dcb03daf7ecab60ed88694b6ba2d465291aeda460adcb8a9bd74556c928e14`**。同じレースの15＋15シード分割を再統合すると、元の30シード集計W・Oが一致することを確認した。

| 内容 | 固定モデルでの実測 |
| --- | ---: |
| 元の直接候補 | **75スキル** |
| 芝モデルで元条件に一致して二軸を計算できた | **69スキル** |
| ダートの `ground_type==2` 指定のため芝データから転用せず保留 | **6スキル** |
| 69件のうち、4脚質すべてが元条件で許容される | **39スキル** |
| 69件のうち、元の明示制限で許容される脚質が1種類のみ | **30スキル** |
| 元条件と一致するコンテクストで比較可能な脚質ペア | **234組** |
| **第1軸W**：全対象コース・頭数・能力条件・15＋15シードで厳密に同方向 | **185／234組** |
| Wの同値・方向逆転などにより比較保留 | **49／234組** |
| **第2軸D＝O−U**：符号が全条件・両シード群で同じ脚質別セル | **183／186セル** |
| Dの符号が混在・同値で保留 | **3／186セル** |
| 全6ペアのW比較が確定し、完全な4脚質順位を作れる | **2スキル** |

**「脚質別セル」と「脚質ペア」は異なる母集団**。Dの183／186はモデル対象脚質に対する一様順位基準からの**偏りの正負**であって、Wの185／234は**二脚質の10m成立機会の厳密な大小**。Wに一様基準を引いたわけではない。Dによるペアの相対方向も185／234組で一致したが、これは固定モデル内の値の関係であり、**W・Dを単一点数へ合成する根拠ではない**。

全6ペアが成立した2スキルは**マイペース（202072）と泰然自若（202071）**で、同じ順位帯・時期・距離の元条件を共有する。実質1種類のモデル研究プロフィールであり、2件の独立した再現実験ではない。69件のモデル対象を元時間窓・順位帯・距離・許容脚質で重複整理すると**35種類の研究プロフィール**。そのうち4脚質すべてが許容されたものは20種類で、6ペア完全確定は1プロフィール。ゴールド・白などの重複を独立証拠と数えない。

### 二軸が別の意味を示す例

**マイペース（長距離・中盤前半、40～80%順位帯）**の固定芝2500m・12頭、equal／jitter10能力条件での範囲（小数点以下2桁に丸め）：

| 脚質 | 第1軸 W：10m成立機会 | 第2軸 D：1地点O−U |
| --- | ---: | ---: |
| 逃げ | 0～0.43% | −50.00～−49.61pt |
| 先行 | 67.19～67.30% | +16.28～+16.67pt |
| 差し | 88.94～91.07% | +38.57～+40.73pt |
| 追込 | 43.54～45.63% | −7.40～−5.23pt |

モデルのW順序は**差し ＞ 先行 ＞ 追込 ＞ 逃げ**。Dの正負を見ると、先行と差しはこの順位帯を一様基準より占有しやすく、追込と逃げは占有しにくい。ただし数値は固定モデルの短窓・順位部分条件であり、実ゲームでそのスキルの効果を活用できるかを説明するものではない。

**積極策（マイル・序盤後半・順位上位50%）**では、逃げ・先行のWがともに高く、**両者間の大小は保留**。その一方、逃げ・先行のいずれも差し・追込よりWが高いという安定した部分順序がある。4脚質すべての完全な順位付けができなくても、このような有用な部分情報は残せる。

**適用外6スキル**：明るい兆し（202262）、パイオニア（202952）、砂の開拓者（202951）、勝利の機運（202261）、踏みしめる大地（203081）、力の限り（203082）。これらはダート条件を持ち、**芝のWとDをコピーせず保留**した。

## 安定性の解釈で過大評価しない事項

- 234ペアは39スキルの6ペアで、同じ順位条件を持つ金・白スキル等の重複を含む。重複整理すると**20研究プロフィール×6＝120ペアのうち、95ペアがWの厳密同方向**。95も独立レース標本数ではない。
- 30シードと15＋15シードの比較方向が揃うことは、モデルの当該固定条件での**記述的安定性**。実戦の適用範囲・統計的有意差・発動確率の真値は示さない。
- Dの符号が保留された3セルはすべて先行であり、0近傍の揺れを無理に「脚質差なし」または「高／低」と決めない。
- WとDの結果は、元条件に合致する全6芝コースのうち適用可能な距離・能力・頭数のみに基づく。元スキルが長距離専用なら芝2500mだけになる。距離条件を無視して他距離へ一般化しない。
- **P2.9の固定32条件における15＋15シード独立検査を、この75条件の研究成功だけで完了と見なさない。** P2.13の未完ゲートは別管理とする。

## 次工程への境界

本研究は**順位と時期の部分条件**を定量化する。スキル発動後の有用性、スキルを実際に所持した際の発動確率、他条件との結合、ゲーム側の実編成分布、P3サポカ評価は対象外。第1軸Wと第2軸Dの研究結果を**単一点数に統合する仕様や高／中／低閾値は未合意**であり、勝手に採用しない。
