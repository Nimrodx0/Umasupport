# P2：ランダム発動区間における順位帯成立割合の探索的近似（2026-11-05）

**状態：研究用・出典固定の位置分布の後処理。スキルの実発動率ではない。既存P2 v3の53件の推定やWebアプリ表示は変更しない。**

## 背景と目的

[9／12頭、6コース、脚質構成と能力差の実験](skill-position-population-priors-20261105.md)では、レース進行率の9地点で「そのウマ娘が自身の距離上の地点に到達した時刻に、同時刻で全出走馬を比較した順位帯成立割合」を求める。一方、発動条件の phase_random == 2 と phase_firsthalf_random == 2 は、同じ上位半数条件でも**判定候補となる区間の幅が異なる**。

1地点の割合から区間全体の傾向を推測することを避ける。今回の実験では既存9地点のモデル上の割合を、**区間内の発動位置を仮に一様に選ぶ場合**という仮定の下で台形積分し、位置条件成立割合の区間平均を作る。

## 対象区間と出典契約

対象の境界は手入力の判断値ではなく、既存の[発動時期の構造解析](../../../poc/src/skill_rank_timing.js)の timing() 関数により取得する。

| 条件 | レース進行率 | 現在の9地点における観測点 |
| --- | --- | --- |
| phase_random == 1 | 1/6～2/3（中盤） | 1/6、1/3、1/2、2/3 |
| phase_firsthalf_random == 2 | 2/3～3/4（終盤前半の前半） | 2/3、70%、75% |
| phase_random == 2 | 2/3～5/6（終盤前半全体） | 2/3、70%、75%、80%、5/6 |
| phase_laterhalf_random == 2 | 3/4～5/6（終盤前半の後半） | 75%、80%、5/6 |

直線やコーナー限定のランダム発動は、この均一な区間平均へ**混ぜない**。また、phase == 2 は「その局面にいる」条件であって、区間内の均一なランダム発動位置を指定するものではないため対象外。

## 集計方法とデータの境界

- 入力：PR #336で作成した固定GlobalSim v77の summary.json（派生した位置分布の9地点集計）。
- 処理：[globalsim_window_profile.cjs](../../../poc/tools/globalsim_window_profile.cjs)。各脚質・コースID・9/12頭・実測別脚質構成・ステータス設定を**混ぜずに**、各区間の隣り合う地点の割合を台形積分し、区間長で規格化。
- 出力：window-profile.json。上位半数と後方半数の割合、元区間ID、サンプル地点数、各地点の順位有効件数と不明数、固定ソースのコミットを保持。CIでは元のサマリーとともに同一artifactへ保存。
- **欠測をゼロと見なさない**：区間内の観測地点が1つでも欠落していれば incomplete-grid、地点の有効順位件数が0なら no-valid-ranks として数値を出さない。
- **統合の対象は地点別のモデル上の順位割合**：同じレースの馬や地点の相関を独立サンプルとみなした信頼区間は付けない。

## 解釈してよいこと／まだできないこと

この数値は、**元シミュレーションの条件下で、位置が一様に選ばれると仮定した場合の、順位帯の成立割合の疎な9点からの近似**。順位帯の比較という研究用途に限定する。線形補間は地点間の激しい順位変化を捕捉できないため、真の区間積分値との誤差は今回測定していない。

次の用途には使わない：

- ゲーム内のスキル発動率や実対戦の脚質成立割合として提示する。
- 追い抜き・コーナー・他馬との位置関係などの追加条件も満たした確率に読み替える。
- P2の53件の定性的ラベルを自動更新し、P3/P4の利用者表示へ無審査で転用する。
- 「75%を超えると後方脚質が有利」のように、測定の外から新しい閾値を作る。

**次の判定ゲート**：異なる構成・距離・能力差で「前半区間と全体区間の違い」がどの程度安定するかを実数値で比較し、必要ならリプレイ密フレームからの直接的な発動位置標本抽出へ進む。区間平均だけでスキル全体の発動確率を断定しない。

## 実行

固定GlobalSimをビルドし、[拡張実験ワークフロー](../../../.github/workflows/globalsim-position-expanded.yml)で位置分布の summary.json を生成した後：

~~~sh
node poc/tools/globalsim_window_profile.cjs \
  /tmp/global-position-expanded/summary.json \
  /tmp/global-position-expanded/window-profile.json
node --test poc/tests/globalsim_window_profile.test.cjs
~~~

追加するのは研究用NodeスクリプトとCI artifactのみ。ゲームデータ本文、GlobalSim本体、モデルの生リプレイ、Webアプリ実装、公開イベントは変更しない。
