# P2.30：条件横断で一貫する順位傾向の「差の大きさ」への感度（2026-11-11）

**結果：固定モデルの既存5,760レースから派生した32元順位・時期部分条件×6脚質ペア＝192組を再解析。仮の差幅0/1/3/5ポイントを用いた**研究用**の感度監査であり、実ゲームの発動率、スキル全体の適性、正式な高／中／低閾値ではない。**

## なぜ追加したか

[P2.29](skill-p2-29-reference-context-and-consensus-20261111.md)は、9/12頭×4種類の人工的な相手脚質編成を横断した方向の一致・逆転・保留を分類し、69組が全8設定で同方向、66組は比較可能な設定で同方向、29組が逆転、28組が同値や不確定などで保留となった。

しかし、「一貫して先行が差しより上」でも**差が0.01ポイントしかなければ製品表示として意味が薄い可能性がある**。また、同じ編成・頭数でもコースや能力設定によって差が変わる。そこで、正式な閾値は決めず、研究結果が仮の差幅にどれくらい敏感かを調べた。

## 方法と限界

- 固定[UmaSimスキル32元部分条件](../../../poc/data/p2_position_condition32_research.v1.json)と、GlobalSimの同一成果物から導いた[P2.9二軸W/Dデータ](skill-specificity32-two-axis-20261109.md)、[P2.29条件横断データ](skill-p2-29-reference-context-and-consensus-20261111.md)を出典版とIDで照合。出典を確認できない比較は失敗終了する。
- 各脚質ペアについて、各**頭数×脚質編成**セル内の「元条件に適用可能な全コース×2人工能力モード」について、順位の10m窓成立機会Wの**差の区間の平均**を参照する。脚質A優位なら区間下限、脚質B優位なら区間上限の符号を反転した値を使う。
- 8セルすべて／走者不在を除く比較可能なセルで、優位方向に合わせた**最も小さい平均差の下限**を記録する。各セルの一票を現実の出現確率とみなした加重平均はしない。
- あらかじめ決めた0、1、3、5ポイントを**仮の差幅**として順番に当て、最小の平均差下限がその値を厳密に上回る組だけ数える。**この4値に科学的・ゲーム上の意味が確定したとはみなさず**、どれか一つを製品表示の正式基準として採用しない。
- **注意：セル内の「平均値」に基づく下限であって、個々のコース・能力モード・seedすべてで当該差を満たした保証ではない。** そもそも二軸データは30seed集計であり、15+15分割シードに基づく個別閾値の再現性や統計的信頼区間を検証していない。元条件の全AND/ORも実験対象ではない。
- 「逃げ不在」では比較対象がいないセルを**欠測**として保持し、一貫性の根拠を水増ししない。P2.29で逆転・保留だった比較は、差幅の適用だけで一貫に格上げしない。
- 第2軸 D=O−U（1地点の脚質特異性）は**Wの脚質間差とは別**であり、合成したスコアは出していない。

## 固定元データからの結果

[GitHub Actions #42978374671](https://github.com/Nimrodx0/Umasupport/actions/runs/42978374671) で固定研究成果物のSHA検証、P2.9再算出、P2.29分類との整合検証、P2.30の全192組・仮差幅比較を完了。

| 仮のW差幅（百分点） | 全8設定で一貫し、差幅より上 | 比較可能な設定で一貫し、差幅より上 | 合計 | 今回の条件では保留・逆転または差幅未達 |
| ---: | ---: | ---: | ---: | ---: |
| **0** | 69 | 66 | **135** | 57 |
| **1** | 69 | 65 | **134** | 58 |
| **3** | 67 | 64 | **131** | 61 |
| **5** | 63 | 64 | **127** | 65 |

単位は**部分条件×脚質ペア**であり、人数・レース件数・別々のスキル数ではない。1件の元部分条件が複数スキルに対応するため、合計を新たに「127スキルに正式適性あり」などと読まない。

**今回の条件群では、符号だけで一貫した135組のうち127組は仮5ポイントを上回る最小シナリオ平均差がある。** そのため、一致方向がたまたま僅差だった比較だけで結果が説明されるわけではなさそうだが、これはモデルの**シナリオ算術平均**であり、個別コースやseed、現実の発動機会の安定性を示していない。また逆転29組、保留28組は依然残る。

## 残る重要な研究

1. **同一対象条件の15+15seed等の別標本比較**：今回は30seed平均差の閾値を変えるだけ。一定差とみなせるかを個々のシードに対して直接調べる必要がある。異なる元スキル条件・競走展開と同じ種の疑似独立性を仮定しない。
2. **コースと能力モード単位の最小差**：今はセル平均に下限があるだけで、個々の固定コースすべてでの最小差とは違う。元スキルを評価する適用レースの選択にも依存する。
3. **元AND/OR、複数Invoke・スキルを積んだ相互作用**：本研究は順位・時期の部分条件だけ。未計測の追い抜き・スパート・ブロック条件で方向が変わり得る。
4. **ユーザーに見せる情報設計**：P3/P4では、正式な脚質「高/中/低」より、まず**比較対象、検証済み条件、傾向一致／条件依存／保留、元条件の未評価部分**を失わない表示・集約が望ましいか検討する。まだ採用判断ではない。
