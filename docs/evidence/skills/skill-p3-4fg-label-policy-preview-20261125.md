# P3.4f／4g：実データの適性判定案と全カード候補プレビュー（2026-11-25）

既承認の[P3.4b表示契約](../../plans/skill-conditions/p3-4b-label-presentation-policy.md)に従い、正式ラベルと研究用プレビューを分離する。

## 仕様からの汎用案（4g）

P3.4eの324件について、全ての静的適用可能文脈で4脚質の元残存条件・元経路が同一であれば、D-049/D-051の専用研究省略方針を前提に「汎用」のプレビュー案を出す。絶対的な成立機会に下限を置かない。単一脚質限定は適用範囲表示のみ（適性は未判定）、異経路・未照合・未研究を汎用としない。257件が候補、624件を未判定とする案。実行時に881件の既存W/D研究状態との重複を計数し、直接取得候補の全566カードに接続する。カードの得点や選択済み獲得ではなく、凸別ヒント数と全直接候補を区別する。元論理同一と実ゲーム力学の完全な中立性は別。正式採用には利用者確認とG4/G6更新が必要。

## 動的条件の方向・実用差感度（4f）

固定98技能、各8文脈（2コース×9/12頭×均衡/後方過多）の同一文脈4脚質を使用。静的適用範囲が全馬場状態で一致しない比較は保留。各走者レースの未知FALSE/TRUE範囲から、脚質間の差の下限と上限を計算。0/5/10/20ポイントの**仮**の実用差幅について全8文脈で同じ比較関係が成立するかを調べる。全6対が同じ幅内に収まる場合も固定標本内の同値候補に過ぎず汎用認定しない。すべての対象脚質が非対象を上回り、対象内が同等、順序が整合する場合だけ固定標本の向け候補を出す。文脈による方向反転、欠測、比較不能、同等性の非推移は保留。試行の統計的信頼区間・実ゲーム発動率・W/Dとは異なるため、正式ラベルの判定閾値は未承認。芝モデルの結果をダートや全距離へ転用しない。

両者の実装は独立で、正式ラベルとカード採点は0。既存CIと同じ入力から再生成し、期限付き成果物に依存しない。新規CIは未確認。
