# P2.42：動的条件のG4研究継続・保留の元経路別判断（2026-11-19）

## 対象と研究判断

[P2.41の固定881スキル別W/D判断台帳](skill-p2-41-combined-short-window-881-ledger-20261119.md)で、69スキルの直接元順位×時期条件と12スキルの元距離OR・狭順位帯から、**81スキルの条件付き部分W/D**を安全にまとめた。一方、これ以外の元条件にある追い抜き・順位変化・スパート状態を、スキルの4脚質評価に使えるかは別問題である。

この小工程は、[P2.32の970元条件経路](skill-p2-32-mechanism-reuse-20261113.md)と[P2.37の3つの動的条件型](skill-p2-37-dynamic-state-source-approximation-20261118.md)を**アプリ881スキル・現行固定元818照合スキル・元数値ID・Invoke・条件OR・事前条件OR**ごとにP2.41へ突き合わせる。元データの経路を別スキルの根拠で埋めたり、研究済み81件の数値を無条件に動的ANDへ昇格させたりしない。

特に**「元のUmaSimで実装された機構」「その固定モデルでの観測」「実ゲームの真の発動条件」**を区別する。

## 元実装からの判断と限定的な次工程

| 元条件 | 固定出典に確認済みの機構 | 今回の採否 |
| --- | --- | --- |

| `is_overtake` | 元UmaSimは脚質別パラメータを使う乱数近似。元21スキル／27経路 | **近似から実ゲームの追い抜き頻度を推定しない**。追加研究はゲーム・モデルの実運動状態を独立観測できる場合に限定 |
| `is_lastspurt` | 元UmaSimのスパート計算状態・位置を読む。元55スキル／61経路 | **機構の解釈だけ条件付き採用**。元条件のほかのAND、OR、事前履歴と同じ元走者・元tickで照合でき、脚質判断への寄与を調べる理由がある場合のみ限定研究候補 |
| 元200511 全身全霊／200512 末脚 | [P2.38](skill-p2-38-original-spurt-halfphase-same-and-20261118.md)で同じ元ANDの制御状態を検査し、[P2.39](skill-p2-39-original-race-natural-spurt-same-tick-20261119.md)では**200512のみ**固定元自然スパートで同一tick・技能イベントを観測 | **同じ機構の小実験を漫然と再実行しない**。200511の自然スパート実走は確認済みと扱わない。200512の12人工レースは4脚質のゲーム発動率ではない |

事実と未検証の範囲は[P2.37](skill-p2-37-dynamic-state-source-approximation-20261118.md)、[P2.38](skill-p2-38-original-spurt-halfphase-same-and-20261118.md)、[P2.39](skill-p2-39-original-race-natural-spurt-same-tick-20261119.md)に従う。元コードの乱数近似は**実ゲームにその条件がないという証拠ではない**。

## 機械的な研究ゲート

[読取専用P2.42判断器](../../../poc/tools/p2_g4_dynamic_impact_gates.cjs)に以下を導入した。

1. P2.41全881行とP2.32全970経路をIDで結合し、P2.37の元条件3型の**元スキル・Invoke・OR・preConditions・有限脚質適用候補**が同じ経路へ一致する場合のみ判定する。出典SHAが変わったら停止。
2. 乱数近似の2型は、元モデルの出現頻度を脚質適性へ使わないと固定する。4脚質比較に使える独立観測がない限り、研究を連続再計算しない。
3. 元スパート状態の経路では、200512の自然スパートAND実験と200511の制御検査を**別の既存証拠**として扱い、再試験による根拠の水増しを防ぐ。
4. 元の脚質適用候補が2種類未満、別のORやInvoke・事前履歴が存在、追加の未照合条件型が3種類以上の場合は、**今すぐ単一ANDの新規測定に進まず**元論理の再確認を先に置く。2という数値は**研究用の小規模調査の上限**であり、正式適性の許容誤差・スキルの発動可能性判定ではない。
5. 対応する元スパート経路だけから、追加条件型の種類・元スキルの重複・脚質の明示適用可能性を見て**最大3経路**を機構研究の候補として選ぶ。このサンプルは実測効果の大きさ・優先度点数を測ったものではない。選定が0件なら無理に研究を作らず、出典・観測可能性を見直す。

全元AND、4脚質W・Dの正式値、無条件の状態省略、P3カード取得経路、P3/P4スコアを**生成しない**。未判定を0や無影響へ変換しない。

## 検証と次の判断

[反例テスト](../../../poc/tests/p2_g4_dynamic_impact_gates.test.cjs)は元IDの入替、OR混同、元AND条件値・種類の矛盾、元データSHA変更、近似頻度の適性転用、元ダート制限、すでに実験済みの機構の二重計上、製品スコア漏洩を拒否する。

既存の[固定720レースCI](../../../.github/workflows/p2-subphase10-77-skill-review.yml)のP2.41統合直後に、保存済みの元P2.32/P2.37固定出典監査を結合して**型別30／27／61経路（計118型別経路行）**の判断台帳を作る。元の970経路の中で同じ経路が複数条件型を含む可能性があるため、型別経路行数と元経路・スキルの重複除去件数を別に出す。台帳は研究用CI artifact（14日間）で保存する。

**固定CI検証結果・分類内訳・候補元IDは実行結果が確認できてから反映**する。P2のG4完了判定ではなく、「新たなモデル走行を実行する前に、研究の価値と現実に観測できる機構を絞る」ゲートを増やした部分進捗とする。G3/G4/G6と正式P3採点の未完は維持する。
