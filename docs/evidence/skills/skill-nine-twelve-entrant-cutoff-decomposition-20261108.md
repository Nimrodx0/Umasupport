## 2. 「順位境界」と「追加馬を含む変化」の正確な分け方

例として、元の`order_rate<=50`は固定参照ルールでは**9頭＝1～5位**、**12頭＝1～6位**。`order_rate>=40`では9頭＝4～9位、12頭＝5～12位。参照変換は元の条件演算子を保持する。

`P_9(k_9)`を9頭レースの元9頭についての成立機会、`P_{12}(k_{12})`を同じ9頭が12頭レースに参加するときの元順位境界による成立機会とする。また、**同一の12頭の軌跡**で、9頭の元境界 `k_9` を12頭の順位全体に当てる反実仮想量`P_{12}(k_9)`を計算した。

差を次のように**代数的に厳密**に分解できる。

```text
総変化 = P12(12頭境界) - P9(9頭境界)

整数順位境界の成分
       = P12(12頭境界) - P12(9頭境界)

残差（追加馬・展開などの複合変化）
       = P12(9頭境界) - P9(9頭境界)

総変化 = 境界成分 + 残差
```

この境界成分は**同一の12頭の軌跡で条件判定だけを取り替える**ため、計算上の境界差を他の要因から切り出せる。ただし、その反実仮想の境界は12頭の現ゲームに実装される条件ではなく、**分解用の仮想基準**である。残差を「純粋な頭数効果」と呼ぶことはできない。頭数を変えるには対戦相手を追加する必要があり、その脚質・能力・展開を同時に変更することになる。

| **マイルの支配者・差し** | **36.09%** | **0.02%** | **−36.08pt** | **+0.02pt** | **−36.09pt** |

特に「マイルの支配者・差し」は、12頭の整数境界を上位5位から上位6位に広げる成分が**+0.02ポイント**しかないのに対し、追加馬・展開に由来する残差は**−36.09ポイント**。元の9頭の能力差を消すような編成実験ではなく、**同じ初期9頭での**比較によってもこの変化が発生した。

「マイルの支配者・先行」は反対に、整数境界が**+34.64ポイント**、残差が**−34.55ポイント**で、総変化はほぼゼロ。**結果の平均が変わらないことは、内部の2要因が小さいことを意味しない**。相殺を見逃すと評価の頑健性を過大評価する。

「砂の玄人・先行」は`order_rate>=40`のため、9頭用の下限4位→12頭用の下限5位で条件が**厳しくなる**。整数境界成分は−26.31ポイントでも、追加馬の展開残差+41.55ポイントが上回り、モデル成立機会は15.24ポイント増加した。

## 4. 12頭で追加3頭の脚質を変えた感度

ここでは**頭数を12に固定**、元の9頭は同一初期条件、追加3頭の脚質だけを変える。

| 追加馬の編成 | マイルの支配者・差し | 砂の玄人・先行（ダート） |
| --- | ---: | ---: |
| 逃1＋先1＋追1（均衡型） | **0.02%** | 65.65% |
| 逃げ3 | 0.00% | 96.06% |
| 先行3 | 0.00% | 63.12% |
| 差し3 | **24.70%** | 1.74% |
| 追込3 | **55.92%** | 1.57% |
| **5編成の最大－最小** | **55.92ポイント** | **94.48ポイント** |

**順位が相対的に決まる仕組みに整合する直感的な構造**：マイルの支配者の上位50%条件は、9頭なら5位以内、12頭なら6位以内。元9頭は逃げ＋先行が合計4頭なので、9頭時には差しが5位以内に入る余地がある。12頭の均衡型にすると逃げ＋先行が6頭になり、上位6位が前方脚質で占められやすい。追込3頭を増やす場合には逃げ＋先行は4頭のままであり、差しが上位6位に入る余地が残る。

これは元条件・編成・出力に整合する**説明仮説**である。個々のレースでその順序になっていた原因、レース中の追い越し、エンジン内部の相互作用を直接分解したわけではない。

**対象5条件×4脚質＝20ケース**の均衡12頭では、整数順位境界成分の絶対値より残差の絶対値が大きいのは**15/20ケース**。しかしもともと代表的な前後順位条件だけを選んだ5件なので、77件や全ゲームスキルでの普遍的な比率ではない。

## 5. 成立機会の評価設計への結論

1. **順位境界の換算だけでは、9頭・12頭の違いは説明しきれない**。同じ軌跡の境界切替で正確に測れる成分と、新しい対戦相手による展開残差を分けて保持する。
2. **想定編成を固定しない成立機会の「高／中／低」判定は、特に差しと先行の順位条件で大きく変わりうる**。12頭の同一頭数でも元9頭と追加馬の脚質が異なれば、モデル成立機会が数十ポイント動く代表例がある。
3. 研究上の**均衡編成は比較用の標準条件**であり、実際に最も多い対戦編成だと確認したわけではない。通常のサポカ表示に採用するか、編成選択可能な別モードを用意するかは、ユーザーの合意と追加の根拠が必要。
4. **不明な編成を無条件にゼロとして扱わず、研究で測った対象条件・分母・頭数・編成を明示**する。頭数別・脚質人数別の研究値は別々に保持する。
5. 前回の**仮の20/80・10/90・5/95閾値は引き続き未採用**。第2軸「脚質特異性」と発動後の効果の有用性も独立した将来課題として保持し、P3/P4のコード・公開カード適性ラベル・ユーザー保存データは変更しない。
