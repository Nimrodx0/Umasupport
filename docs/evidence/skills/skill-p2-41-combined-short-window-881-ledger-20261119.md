# P2.41：既存短窓根拠のスキル単位統合（2026-11-19）

**位置づけ**：P2 G3／G4の「条件付き採用できる元順位×短窓の部分W/D」を、固定対象881スキルに1つの読取専用の台帳として配置する小工程。**実ゲーム内の元スキル全AND発動、適性スコア、P3カード採点は実施しない。**

## なぜ新しいモデル走行を増やさないのか

[P2.34の全881スキル判断](p2-g3g4-short-window-881-skill-decision-20261118.md)では、元ID・名前を照合した75件について、固定720の無スキル芝モデルから**69件の順位×短窓部分W/Dを条件付き採用、ダート指定6件を保留**した。[P2.35の元AND/OR監査](skill-p2-35-short-window-source-logic-decisions-20261118.md)と[P2.36の既存モデル再解析](skill-p2-36-short-window-exception-wd-20261118.md)では、別の**12スキル**が中／長距離の排他OR10件と、絶対順位と割合順位の狭い交差2件に分かれ、元のモデル文脈と15＋15シードを維持したW/Dを得た。

両成果は同じ固定出典の**87件（75＋12）の異なるスキル**を扱っているが、現状ではP2.34の全件一覧にP2.36の12件がまだ掲載されていない。今回、**P2.34の分類を変更せず、同じ元数値ID・アプリスキルID・名前が一致し、かつ「今回新しい短窓根拠なし」の行にだけP2.36を接続する**。P2.36の22件は元条件の分岐であり独立レース標本ではない。

## 判定内容と採否

| 対象 | 元技能数 | P2.41の扱い |
| --- | ---: | --- |
| P2.34で元条件と固定芝モデルが対応済み | **69** | 既存の部分W／D、脚質明示除外、モデル文脈と保留ペアを変更せず維持 |
| P2.36で元距離ORを限定照合済み | **10** | 元条件の距離区分3／4を**別々の分岐**として記録。W/Dの距離横断加算・平均・別距離へ外挿を禁止 |
| P2.36で元絶対順位ANDを限定照合済み | **2** | 短距離の「2位以上後ろ、かつ50%以内」の狭い順位帯のW/Dを個別保持。従来の上位50%だけのWに差し替えない |
| 固定芝モデルの対象外となったダート指定 | **6** | 芝からの転用は禁止、保留のまま |
| その他のスキル | **794** | **この短窓研究による追加判断なし**。従来の別根拠は維持、未知を0や汎用としない |
| **合計** | **881** | 条件付き部分根拠を持つ**81件**。どの技能も全元AND／正式適性／採点が成立したとは認定しない |

今回の統合後もP2.34の「69件中、元条件で1脚質だけ許容30件／4脚質許容39件」という区分は維持する。P2.36の12件では固定出典から4脚質を許容することを既存P2.35で独立照合しているが、モデルW差を実ゲームの脚質優劣とは断定しない。

**比較単位の区別**：

- P2.34：比較可能な脚質ペア**234件**、固定モデルWが同方向**185**／保留**49**。元スキル別ペアであり独立試行数ではない。
- P2.36：元距離別分岐を含む脚質ペア**132件**、W同方向**102**／保留**30**、D同方向**102**。そのうち**22分岐／11個の研究プロフィール**。これも独立レース標本ではない。
- 両集計の単位が元スキル別／元分岐別で異なるので、**366ペアを統計的な新標本数として合算しない**。Wの機会とD=O−Uの偏りは別の指標であり、DをW−Uとしない。

## 実装とCIによる検証

新しい[読取専用のP2.41結合器](../../../poc/tools/p2_g3g4_combined_short_window_881.cjs)は、P2.34/P2.36の固定成果JSONだけを入力として、**元ID・元名称・元辞書SHA-256・各枝の距離／元順位集合・元窓・対象芝モデルコース・W/O/Dの値域・15＋15モデル比較の方向**を壊さずに結合する。条件値の全文や第三者ゲーム辞書をリポジトリへ同梱しない。

[合成反例テスト](../../../poc/tests/p2_g3g4_combined_short_window_881.test.cjs)は、同一技能の二重登録、別ID／名前、芝保留への誤差し込み、元距離ORの分岐欠落・重複、短距離狭順位を別距離へ外挿、モデル方向の未知を強制＋、比較ペアの欠落、スコアへの漏洩を拒否する。[固定720レースCI](../../../.github/workflows/p2-subphase10-77-skill-review.yml)に、既存P2.34とP2.36を再生成した**直後に**P2.41の全881行を検証するステップを追加した。公開ページの新規読込機能はない。成果物は研究用JSONで14日間保管する。

**元固定モデルのCI確認値**：881全行／818元スキル照合／**69＋12＝81**条件付き部分根拠／**6**芝ダート保留／**794**今回対象外、元例外10距離OR＋2狭順位、計22距離・順位分岐、Wペア比較234と132は別単位で保存。**検証CIの成否と実際の出力はPRのActionsを確認してから確定する**。

## 終了条件と次工程

1. 固定モデルの原条件に一致する81件の採用・6件の保留・794件の対象外が、**固定出典CIで再現**されること。
2. 出力全行が `eligibleForP3CardScoring:false` / `cardScore:null` を保持し、OR経路を合算しないこと。
3. 今回の統合済み部分機構について同じ720レースを再実行して精度だけを稼ぐ追加研究は不要。G4の未解釈動的AND等が**実際に4脚質の判断を変え得る場合**にのみ出典と同時判定時刻を確認する。
4. G1～G4・G6の親工程、およびP3の正式カード評価と公開UIの採用判断は保留を維持する。

既存P2.37～P2.39の追い抜き・順位変化の元UmaSim乱数近似を、実際のゲーム脚質差の根拠に変換しない。末脚の限定自然スパートAND実測を81技能全体へ転用しない。
