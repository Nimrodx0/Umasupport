# P2.17：距離区分別に脚質間の順位条件成立機会が変化するか（2026-11-12）

**状態：固定GlobalSimモデルの距離区分別・同一元条件での実測済み観察。** 距離条件を「適用範囲条件」とすることと、他の発動条件の脚質差が距離によって変化し得ることは両立する。今回は後者が実験条件内で観測されるかを検証した。**距離そのものの因果効果、実ゲームでの発動確率、スキル全体・サポカ適性は未確認**。

## 研究設計と前段との関係

[意思決定D-045](../../decisions/log.md#decision-d-045)のとおり、`distance_type`（短距離1、マイル2、中距離3、長距離4）はレース条件であり、同一レースの4脚質に同じ値が適用される。しかし、別の元順位・局面条件が成立する傾向が距離・コース形状によって異なる可能性を排除しない。

[P2.31の元32部分条件](skill-p2-31-course-mode-margin-20261111.md)には、**距離区分に制限のない元順位・時期条件10種類**（芝4・ダート6）がある。残り22種類は元の距離範囲が限定されており、異なる距離区分に移した場合は**元のスキル条件に反する架空の比較**となり得るので対象から除外する。

**比較対象**：同一元の順位帯・時期の部分条件、芝／ダート、脚質ペア（6通り）、9頭／12頭、相手4編成（均衡／前方偏重／後方偏重／逃げ不在）、能力2モード（equal／人工±10％）を揃える。そのうえで、対象コースを短距離・マイル・中距離・長距離の4区分に分ける。すべて元のSHA固定モデル5,760レース由来の、コース・脚質別**30seed集計**を利用する。新しいゲーム内スキルをロードしたものではない。

### 判定する量

- `W`：元の「順位帯×時期」**部分条件**が10m順位判定窓のどこかで成立するモデル上の機会。実ゲームの発動率ではない。
- 同一コース・編成・頭数・能力・元条件での脚質ペアの差：`Δ = W(第1脚質) − W(第2脚質)`。順位不確定があれば各Wの上下限から差の区間 `[Δ下限, Δ上限]` を計算。
- 1距離区分に複数コースがある場合は、**コースごとに計算したΔの最小下限と最大上限を含む保守的な区間**を採用する。平均を用いて一方のコースでの逆方向を隠さない。
- 同じ編成・頭数・能力で2つの距離区分の間を比較し、両区分が明確に**逆方向**なら「距離区分間の脚質差の符号逆転」、2区分の保守的差分が**仮5ポイントを厳密に超える**なら「距離区分に関連した脚質差の変化」として数える。単に片方が0.1pt高いこととは区別する。5ptは**研究用感度試験**で、採用済みの脚質適性閾値ではない。
- 逃げ不在編成の逃げを含む比較は、0％や敗北扱いをせず**未観測**とする。比較するのは同一の脚質ペアと元条件のみ。

**補助解析**：芝のみ、東京競馬場 `raceTrackId=10005` のコース `10501/10502/10504/10506` を短距離／マイル／中距離／長距離の各代表とする。これらは[元コースID照合](skill-p2-15-track-id-venue-static-gate-20261112.md)で同一競馬場であることを確認済み。**競馬場IDを揃えても、距離・コース形状・レース展開が同時に変わるため、距離の因果効果を独立に証明しない**。

## 固定元データの実測結果

[研究CI #43128382600](https://github.com/Nimrodx0/Umasupport/actions/runs/43128382600)にて、元の5,760モデルレースのSHA照合済み研究成果物を再解析した。[距離差の監査コード](../../../poc/tools/skill_distance_style_interaction.cjs)と[人工反例テスト](../../../poc/tests/skill_distance_style_interaction.test.cjs)で検証し、元条件・脚質ペア別のメタデータを14日保持のCI成果物 `distance-style-interaction.json` に保存。

| --- | ---: | ---: |

| 部分条件×脚質ペア | **60組** | **24組** |

| 脚質が不在のため比較しなかった設定 | **120** | **48** |
| 距離区分2つを比較した設定 | **5,040** | **2,016** |
| **どこかの比較条件で脚質間の優劣が厳密に逆転した組** | **5組** | **5組** |

| 5pt超の脚質差の変化を観測した設定 | **341設定** | **148設定** |

1行の「組」は**個別スキルの数ではなく、元の順位・時期部分条件と脚質ペアの組み合わせ**である。複数のコース・編成・距離比較は互いに独立したゲーム内試行ではない。東京4コースの「5組」は全対象コースの「5組」と必ずしも**同じ5組ではない**。区分ごとのコースが異なるため、集合を単純に足したり確率の推定分母に用いたりしない。

**観測例**：元部分条件ID `204751`（芝・序盤後半・順位50％以内に対応する部分条件）の「逃げ／先行」は、相手編成等を揃えた距離区分間で方向逆転が観測された比較の一例である。同じ競馬場・東京芝4コースの感度試験にも含まれる。ただし他の元AND条件やランダム発動窓は未検証であり、そのスキル自体の逃げ／先行適性が逆転したとは言えない。

### どう解釈するか

距離区分ごとの元の**順位・時期部分条件**の成立傾向を、距離区分と無関係に一律の脚質差として扱うのは安全でない可能性が高い。これは「`distance_type` 自体が4脚質を直接判別する」という意味ではなく、**距離・コース文脈が別の脚質依存条件と相互作用し得る**ことを示す。

一方、本研究はコースの距離を変えれば、そのコースの形状・直線・コーナー・位置取りの変化も一緒に生じる**観察比較**であり、距離のみを変えた統制実験ではない。芝とダートも同一元条件として混ぜていない。比較対象には実ゲームの相手編成分布・大逃げ・育成能力分布・スキル効果・全AND/OR・preConditions・発動抽選が入っていない。区分差が**ない**場合も「実ゲームで距離の影響がない」と確証したことにはならない。
