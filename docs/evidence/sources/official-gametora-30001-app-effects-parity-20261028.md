# 既存SSR30001：GameTora本体の非スキル数値とアプリ用effects候補の照合（2026-10-28）

## 比較の位置づけ

[前段の実アプリ用スキル報酬投影](official-gametora-30001-app-schema-parity-20261028.md)で、SSR30001の元GameToraサイト5イベント・9経路・5件のスキルID+ヒントLvは、固定GameTora派生データ→既存スキル投影器の結果と一致した。しかし当該投影は**スキル報酬専用**であり、能力値・体力・やる気・絆ゲージなどの**31件の非スキル数値**は対象外だった。

今回の比較は、**固定版の既存非スキル変換器`phase2_gt_whole_nonskill_effect_inventory.analyze`が出力する、実アプリイベントスキーマの隔離`effects[]`候補**と、同じ既存SSR30001の[GameTora本体](https://gametora.com/ja/umamusume/supports/30001-special-week)から**別途取得した描画上の効果種類・符号付き数値**を一つずつ比較する。

比較位置は既存の`originalSiteVsAppSkillProjection`で独立確認済みの各イベント／選択肢／結果番号と同じ。元GTデータを「元サイトの本来は未表示の事実を埋める材料」にはせず、**GameTora本体から独立に得た`kind:delta`と、アプリ用`effects[]`の`kind/delta`だけを照合する**。

元固定：`systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`、固定Git blob `6aca60590854f402a67da82c2ffa7295e564b40f`。
