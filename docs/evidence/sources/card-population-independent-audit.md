# サポートカード母集団の別系統ID照合（2026-10-17）

関連：[Phase 1](roadmap.md) / [検証計画](verification-plan.md) / [Issue #28](https://github.com/Nimrodx0/Umasupport/issues/28) / [PR #36](https://github.com/Nimrodx0/Umasupport/pull/36)

## 目的と今回の結論

UmaSimのサポカ563枚を単にロードできることと、**現在の日本版サポカ全件に対応すること**は異なる。別の公開提供者の一覧に対して**カードID集合**を照合し、どこまで言えるかを分離した。

**観測：GameTora日本語版サポカ一覧の563件に含まれる563個の異なるIDと、UmaSim固定版の563個のIDが完全一致した。双方にのみ存在するIDは0。** また別の2データソースによる個別レコード304枚の一致も確認できた。

したがって、「2026-10-17に取得したGameToraの日本版一覧と2026-10-13版UmaSimとの間にサポカIDの漏れがない」ことは確認した。ただし、**GameToraがゲーム内実装全件を正確に収録していること、両者の情報が真に独立した原マスターを用いること、今後実装されるカードを含むこと**は保証しない。ゲーム内の独立実測による全件証明ではない。

## 全件照合と部分照合

| 検証ケース | 母集団 | 実測 | 判定 |
|---|---|---|---|
| UmaSim内の5段階完備 | 563カード×5 | 2,815行、SSR316/SR101/R146、全カード5段階 | Pass |
| **GameToraの日本語版カードID一覧との相互差分** | GameTora563 ID vs UmaSim563 ID | **共通563、GameToraだけ0、UmaSimだけ0** | **Pass（両公開資料のID集合一致）** |
| 日本版の別系統JSONでID・名称・レアリティ照合 | 選択掲載45 | **45一致、差分0** | Pass（この45枚のみ） |
| 英語版の別系統台帳でID・レアリティ照合 | 英語版259 | **259一致、差分0** | Pass（この259枚のみ） |
| 上記二つのレコード単位監査のユニオン | IDが重複しない45+259 | **304/563**。残る259枚はここでは個別レコード照合されていない | 部分確認 |
| ゲームの正式マスター全件との同時点照合 | ゲーム内全実装 | 現時点では公式の独立分母・同時点マスターは未取得 | 未実施 |

**重要な限界：** GameToraとの563件一致は全IDの相互確認であり、**全563枚の名前、レアリティ、通常ヒントや性能がGameToraと一致したことを意味しない**。一致するIDがあるだけでゲーム内実装、入手可能性、現行性が独立証明されたと呼ばない。別資料の更新が遅れたり先行登録されたカードが混在する可能性も残る。

## Rタッカーブラインの訂正

以前の「Rタッカーブラインは未照合」の記述は、**他の候補リスト／イベントソースとの突合での未照合**であって、UmaSim未収録を意味しなかった。固定版UmaSimのレコードで以下を直接確認した。

| カード | ID | レアリティ | UmaSim収録 |
|---|---:|---|---|
| [無人島PJ責任者]タッカーブライン | `10128` | R | **あり** |
| [本能は吼えているか！？]タッカーブライン | `30257` | SSR | **あり** |

Rカードの存在については[GameWithのRタッカーブライン記事](https://gamewith.jp/uma-musume/article/show/505047)（2026-10-12更新）も別系統の根拠となる。Rの**イベント全経路の公開DB照合**まで完了したという意味ではない。イベント候補の資料差異はPhase 2で管理する。

## 実行・再現・次の判断

- 照合コード：[audit_card_coverage.cjs](../poc/tools/audit_card_coverage.cjs)、架空データ回帰：[card_coverage.test.cjs](../poc/tests/card_coverage.test.cjs)。
- [ワークフロー](../.github/workflows/independent-card-coverage-audit.yml)：そのワークフロー/監査実装のPR変更、または手動起動に限定。通常のPoC CI/Pagesデプロイに外部サイトへの自動GETを追加しない。
- 実ソース照合：**[Actions #38955129930](https://github.com/Nimrodx0/Umasupport/actions/runs/38955129930) 成功**。元の生データは成果物化せず、ソースの版／SHAと件数／差分IDだけを出力した。

**A（機構）**：人工入力のID重複・欠損・レアリティ・名称衝突・解放段階欠落のテストを追加してCIで合格。

**B（データ）**：GameToraが実際に列挙する全563のIDとUmaSimの全563のIDが一致。今回設定した**公開一覧間のID差分ゼロ**は合格。別ソースの45+259=304件のID・レアリティ等も一致。ゲーム正式実装の独立完全性や全カードの性能・ヒント／GameTora以外との同一版照合は未完。

**C（実機）**：この検証はCLIとGameToraのLinux Chromium上の一覧ページ。**ウマサルタントのAndroid/Windows実端末検証ではない**。既存Pages受け入れテストとは別。

**運用：** 今後いずれかのソースのID集合が変わったら、この差分監査を再実行し、追加／削除／改名・収録範囲／日本版英語版の差異を分類してからアプリの変更要否を判断する。自動的なデータ転載・カード生成はしない。
