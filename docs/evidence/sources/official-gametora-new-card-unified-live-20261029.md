# 元GameToraの新SSR2枚でイベント結果を四系統統合する限定実測（2026-10-29）

## 目的と対象

前工程 [SSR30080の四系統統合](official-gametora-unified-site-route-draft-20261029.md)では、元GameTora本体の1イベントで同一表示結果に数値効果・ヒントID/Lv・直接スキル取得候補・進行マーカーを結びつけた。今回、**現行新カードSSR30322とSSR30323の各表示イベント**へ共通変換器を適用した。旧GameTora派生GitHub JSONを入力とする全イベント監査とは異なり、**元GameTora本体の2ページ、計18表示パネル**だけを実Chromeで取得した非公開試作である。GameWithの情報や旧固定GTのスキルID・報酬を補填していない。

## 新しい共通アセンブラ

`poc/src/official_gametora_live_event_assembler.cjs` を追加。元サイトで既に確認された各DOM表示結果の断片から、[数値効果候補](official-gametora-site-only-numeric-draft-20261028.md)、[ヒントIDとLv候補](official-gametora-hint-locality-shared-20261028.md)、[直接スキル取得候補](official-gametora-direct-skill-candidate-20261029.md)、[進行表示](official-gametora-visible-flow-20261029.md)の四種類を生成し、既存の結果別統合器へ渡す。

- **厳格な位置照合**：表示カードID、イベント位置、グループ番号、グループ内の結果番号が連続・一致すること、同じグループのDOM文字断片系列が同一であることを検査。飛び番・二重経路・別グループのデータ混入をエラーにする。
- **ヒントの独立二系統照合**：従来の結果別ヒント読取から得た数値スキルID＋Lv＋結果座標と、四系統統合用の数値断片から得たヒントが**全件同じ多重集合**になることを確認。前者で検出できたスキルを別結果へ補完して正解扱いしない。異なるIDや結果位置は停止する。
- **保留を保留として扱う**：表示結果グループがないイベントは `no-visible-result-groups`、ORの構造を分離できないイベントは `unresolved-or-layout`。それぞれ統合対象の母数に入れない。これらが「報酬なし」「ゲーム上のイベントなし」を意味するわけではない。
- **内部進行を創作しない**：マーカーから `requires`、`terminal` を自動設定せず、元サイトの文章・選択肢名・スキル名称・HTML・画像をPublicやCIログへ保存しない。未公開の技術用候補であり、正式公開用 `rewards[]` を作らない。

## 実Chromeの限定測定

[元GameTora2ページのCIによる実測](https://github.com/Nimrodx0/Umasupport/actions/runs/40796746405)で、両カードとも本体表示で経路の欠落やヒントID/Lvの二系統不一致が**0件**となり、次の中間候補を生成した。

| 観測対象 | SSR30322 | SSR30323 | 合計 |
| --- | ---: | ---: | ---: |
| 表示イベントパネル | 6 | 12 | **18** |
| 四系統で統合できたイベント | 5 | 11 | **16** |
| 結果グループが取得できず保留 | 1 | 1 | **2** |
| ORの分離失敗で保留 | 0 | 0 | **0** |
| 結果別に統合した経路 | 13 | 14 | **27** |
| 元サイトで読めた非スキル数値効果の行 | 40 | 68 | **108** |
| 結果別に独立ID・Lvを照合したヒント | 14 | 4 | **18** |
| 明示的スキル直接付与の一意候補 | 0 | 0 | **0** |
| 結果別に読めたお出かけ解放マーカー | 0 | 2 | **2** |

SSR30322のサイト表示で、イベント別の数値行は第1イベント0（結果グループなし）、残り第2～6イベントに**4／7／21／5／3件**。SSR30323では第1イベント0（同じく結果なし）、第2～12イベントに**7／5／9／6／6／7／10／6／3／4／5件**。この**限定したサイト表示のスナップショット**を実Chromeの回帰判定に固定した。変化したら黙って期待値を書き換えず再調査する。

**注意**：数値効果108行は、サイトDOMに表示された符号付き増減を変換器が分類できた件数であり、元ゲームの全効果数・受け手・適用先・発生条件を証明したものではない。直接付与スキルの**0件も不存在を表さない**。少なくともSSR30323の第8イベントには「獲得」に関係する不明な表示断片2件が別監査で検出されている。スキル報酬、成功失敗、連続イベントの後続、必要な選択肢表現は引き続き未確定である。

## A／B／Cと残件

- **A 機構**：合成6試験で一致する結果別の数値・ヒント・直接付与・進行の分離、表示結果なし／OR未解決の保留、グループ位置ずれと重複、ヒント二系統差異による停止、未公開フラグを検査。既存の四系統単独試験・SSR30080統合試験もCIに残す。
- **B データ**：元サイト2ページ18表示イベントのうち、**16イベント27経路に限定**した数値行・ID+Lv照合。固定UmaSim独立辞書に基づく。全カード母集団の網羅率や全イベントのゲーム内分岐確認ではない。
- **C 実環境**：GitHub Actionsで実際のChromeを使い元GameToraを2カード限定読取した。GitHub Pages公開サイトのユーザー端末（Windows／Android）の動作を今回実測したとは言えない。

次は全サポカへ一気にサイト取得する前に、**選択肢の表示グループとゲーム内の選択肢・ランダムな結果の区別、連続内部の次段への到達**を出典根拠で裁定する必要がある。該当事実がGameTora元サイトで不明である場合は、[GameTora→GameWith例外裁定](event-adjudication-enforcement.md)を適用する。公開条件・権利の審査は別で、**正式公開イベント0件**は維持する。
