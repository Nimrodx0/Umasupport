# Phase 3 F-05：スキル一覧のフィルター・並べ替えと逆引き

更新：2026-10-18。対象：F-05の部分実装。[要件定義](requirements.md)、[検証計画](verification-plan.md)。

## 実装範囲

- スキル一覧で名称/ID、金/白/分類未確認、**現在編成の直接提供**（通常ヒント・選択済みイベント・両方）、直接/間接のみ/未カバーの目標/条件付き経路、重複・共通と目標を組み合わせて絞り込む。
- 並び順は名称順・**直接提供枚数**合計順・本育成枚数順・継承育成枚数順・目標優先から選べる。
- 金スキル→下位白スキル→さらに下位の表示は、比較対象に両者が残っている限り親子を連続表示。集計値・上下関係自体は変更しない。並べ替えの代表値には親の直接提供枚数を用い、子孫の枚数を勝手に合算しない。
- スキル詳細の逆引きは、既存の**4凸のみ**から、照合済み0〜4凸のいずれかに含む通常ヒントの和集合へ拡張。公開承認済みイベントの選択肢と結果に現れるスキルも検出し、通常ヒント/イベント/所持のみのフィルターがある。
- 「提供候補」と「編成内の想定凸での直接提供」は厳密に異なる。逆引きで表示したからといって現在の0凸や4凸で獲得できるとは保証しない。未選択のイベントや未検証のChecker候補を現在の編成の集計へ加算しない。
- 旧master、Checkerの未承認候補、参照用referenceSkills、間接の上下関係は**直接提供枚数・経路フィルターへ混入させない**。上下の間接カバーは既存の計算結果をそのまま読む。

## A/B/Cの合格条件

| 軸 | 検証と制約 |
|---|---|
| A 機構 | 人工集計5種の分類・通常ヒントと選択イベント・条件付き・親子並び順・提供枚数による安定ソート・編成範囲ごとの「未カバー」を検証。データを変更せず表示のみ更新。 |
| B 現実の採用データ | 公開起動データ563枚を引き続き利用。新しいカード、イベント、スキルを今回承認・追加することはない。カードの真正な数値ID/イベント全件の独立照合には該当しない。 |
| C ブラウザ | Chromium人工563枚で、選択済み通常ヒントと承認済みイベント0件を別表示、未カバーの目標、ソート、逆引き所有フィルター、編成や保存情報の非改変を確認。AndroidとWindowsの物理端末は後日まとめて未受入れ。 |

## 残件

画像付き比較表の正式画像、全経路の正確なイベント収録、適性条件・スキル区分・因子化対象の確定IDと根拠、ゲーム内標準表示順の小標本実機検証は未完了。ユーザーの現在の編成に現れるスキルと目標だけを比較する既存ポリシーも維持し、未収録のカードが「提供していない」と断定しない。**F-05全体の完了やPhase 3完了ではない。**
