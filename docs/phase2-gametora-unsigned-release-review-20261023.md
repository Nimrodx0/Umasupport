# Phase 2：GameTora全2,488件の未署名公開審査キュー（2026-10-23）

## 目的

GameTora固定版 **559カード／2,488イベント**の変換成功・短見出し全件照合の次に、**正式公開のために何を確認するべきか**を各イベントID単位で追跡する。これまでの「投影は全件成功したがリリース対象として個別審査できない」という運用上のギャップを埋める。公開承認を行う機能ではない。

## 入力と検査

非公開の固定全件 GitHub Actions で、以下の**同一出典・同一実行内**の結果を照合する。

- 数値正規化データ（母集団563／固定GT存在559／固定GT欠損SSR4／2,488イベント）。
- GameToraの元カード・イベント位置＋短い見出しのSHA-256で結合した一時本番スキーマ投影。各投影イベントの内容SHA-256を再検査する。
- **固定UmaSim辞書のみ**で投影した際のイベント除外110件と、そのイベント位置・原因。
- 2026年版の独立スキル名等を補完した**非公開の全2,488件**投影・最終レポート。補完後の投影除外0件を必要条件とする。

新しい `poc/src/gametora_publication_review_queue.cjs` がカードID・元イベント位置・独自ID・見出しSHA・本番候補SHA・元コードの注意マーカー・旧辞書除外原因を結び付ける。元の名前を取り違えたり、候補を手で改変したりした場合は発行を拒否する。同名イベントは同一視しない。

## 非公開レビュー索引の内容

`whole-event-output/gametora_unsigned_release_review.v1.json` は、既存の限定GitHub Actionsアーティファクトにのみ含める**メタデータ索引**である。内容は数値ID、元位置、各SHA、区分、注意すべき原因コードのみ。**イベント名、選択肢の原文、結果の原文、スキル辞書の実データ、元のイベントDBを含めない**。元イベント本体は引き続きCIプロセスのメモリだけで投影し、GitHub Pages／gitへ配信しない。

各イベントの状態は一律 `PENDING_HUMAN_PUBLICATION_REVIEW` とし、最低限次の未完を保持する。

- `PUBLIC_DISPLAY_NEEDS_REVIEW`：見出し・選択肢の独自表示を受け入れ審査する。
- `PUBLICATION_BASIS_NEEDS_REVIEW`：公開利用の根拠を判断する。
- `HUMAN_SIX_CATEGORY_APPROVAL_MISSING`：カード、イベント、選択、結果、内部到達条件、公開の6分野を根拠URLと対象SHAに結び付けて承認する。

さらに元GameTora自体のレビュー注意マーカーがある位置は `SOURCE_BRANCH_OR_EFFECT_NEEDS_REVIEW`、固定UmaSimのスキル辞書だけでは投影できなかった位置は `BASELINE_SKILL_REGISTRY_GAP` と、原因コードを残す。**旧辞書の除外110件は固定元だけの状態であり、2026年ゲームの誤データ110件という意味ではない**。

## 検証と境界

- A：Node合成テストで全イベントのID・元位置・タイトルSHA・イベントSHA・未承認状態の一致、改変／重複／スキル未投影／公開済みフラグの拒否を検査。
- B：限定固定GT全件CIで563枚・559枚・4枚、元イベント2,488、補完後投影2,488、旧辞書による除外110に厳密照合し、注意位置の実測件数を出す。最終結果をもとに status を更新する。
- C：これは非公開審査資料生成であり、正式配信ページの操作検証には当たらない。既存のGitHub Pages試用8イベントは変更しない。

**正式公開イベント数は0件のまま。** 通常8イベントの公開用独立審査票、GT2,488イベントの公開レビューキュー、ゲーム内実データの全件性はそれぞれ独立した状態として扱う。

## 固定全件の実測結果（2026-10-23）

[全件CI](https://github.com/Nimrodx0/Umasupport/actions/runs/39901794771) は **PASS**。対象固定GT559枚／2,488イベントのすべてについて、元位置、短見出しSHAとイベントSHAを一対一に結合した署名前レビュー行を生成できた。内訳は次のとおり。

| 未署名レビューの分類 | 件数 | 注記 |
| --- | ---: | --- |
| 固定GTの全イベント | **2,488** | 全行が公開審査待ち |
| 出典の分岐・効果の注意マーカーあり | **34** | 元の注意マーカーを個別保持 |
| 固定UmaSimスキル辞書での投影除外 | **110** | 他の分類と重複あり、スキルID以外の下流依存も含む |

| 正式公開承認 | **0** | 全件未署名 |
