# チュートリアル：初めてウマサルタントの開発版を確認する

**対象**：新しく参加する開発者。アプリと文書への入口を体験するための演習です。

## 1. 現行の仕様と状況を把握する

[要件](../requirements.md)、[開発状況](../status.md)、[工程](../roadmap.md)を読み、コードにある機能とP2の研究用指標を区別します。

## 2. ローカル起動する

リポジトリのルートで次を実行します。静的ファイルを直接ダブルクリックする方法は標準試験ではありません。

~~~sh
python -m http.server 8000
~~~

ブラウザで http://localhost:8000/poc/live.html を開きます。実際のゲームデータは外部公開元から読み込むため、通信や提供元の条件次第で読み込みに失敗することがあります。

## 3. 画面を観察する

デッキ・スキル比較・イベント設定・保存の基本操作を確認します。技術的に存在するイベントと公開承認済みイベントが別であることに注意します。

## 4. 検証コマンドを実行する

~~~sh
node --test poc/tests/core.test.js poc/tests/events.test.cjs
node poc/tools/check_project_tracking.cjs
~~~

これはローカルの機構／現行JSON確認であり、物理端末での利用者受入や全ゲームの網羅性を証明しません。詳しくは[PoC開発手順](../../poc/README.md)へ進みます。
