# Phase 2：GameWith裁定済み数値事実の独立編集台帳（2026-10-22）

## 目的・範囲

PR #167/#168で2,488件を本番実装の読込・集計経路に通せたが、これは**未承認の一時データ**であり公開イベントDBは依然として0件。これまでの例外裁定も主にコード内の監査定数で保持され、独立した「編集上採用した数値事実」の版管理データが存在しなかった。

今回、固定GameTora JSONに欠ける**SSR30318～30321の4枚・Checker由来20イベント位置**を、公開用とは完全に切り離した `poc/data/curation/adjudicated_event_facts.v1.json` に記録した。これはゲームの全20イベントが確認済みであることを意味せず、**「採用2・イベント経路の裁定待ち18」**の区別を保持する。

## 初回採用：SSR30321の連続位置2・3

元根拠：GameTora個別カードのサイト確認 `https://gametora.com/ja/umamusume/supports/30321-duramente` と、指定裁定元 `https://gamewith.jp/uma-musume/article/show/578817`（2026-10-22に確認済みのPR #164/#165監査記録）。固定GTコミット `6e38b54af4fad397ff4491e63007a90705a4fe67` に本カードの元ファイルはない。Checkerソースの位置と2026年スキル辞書IDは `phase2_four_ssr_editorial_review.cjs` の既存の固定監査と相互参照する。

| Checker掲載位置 | 編集上採用した操作選択数 | 数値効果（スキル計算対象外） | スキルヒント |
| --- | ---: | --- | --- |
| 30321／連続位置2 | 0 | やる気+1、パワー+10、絆+5 | なし |
| 30321／連続位置3 | 0 | パワー+15、絆+5 | スキル数値ID201463、Lv1 |

**「選択肢なし」から先行イベントの未検証な到達条件まで「無条件で到達できる」とは導けない。** 内部の先行選択依存は `priorStageDependenceVerified:false` のまま残す。公開アプリの `type:auto` イベントに変換して加算させない。

30318〜30321の残る**18イベント位置**については、編集上のイベント形状に一定の照合があっても、選択／結果によるスキル獲得条件の採用値が全て揃ったとは扱わないため、`PENDING_ROUTE_REVIEW` を明示する。元の12件のスキルヒント掲載位置のうち、GameWithで選択肢なしとして確定した位置3の1件だけがこの台帳の採用対象。他**11件**は元監査に残し、無条件のスキルヒントにはしない。

## 実装とゲート

- `poc/src/phase2_adjudicated_fact_intake.cjs`：元4SSR監査定数、固定参照URL、公開不可フラグ、イベント位置、採用事実5個の数値効果・1個のヒント、残り18件の保留状態を突合する。GameWithへの全面再クロールを行わず、既存の`evaluateException`へ採用済みの具体的数値だけ通す。本文・選択肢文章は台帳に含めない。
- `poc/tests/phase2_adjudicated_fact_intake.test.cjs`：結果分岐の創作、選択肢数の誤変更、スキルID/Lv改変、異なる出典URL、採用済みから保留への逆行、保留から勝手に獲得へ昇格、公開フラグの混入をfail-closedで拒否。
- `node poc/tools/verify_adjudicated_event_facts.cjs`：Nodeの純粋な数値件数だけ表示。新しい編集ファクトを実行するためのランタイムアダプターや公開用JSON生成器を用意せず、通常版の配信物を不変に保つ。通常CIの必須検証に接続。

## A/B/Cの区別と次の作業

- **A 機構**：Node単体・改変拒否と非公開台帳の検証。
- **B 出典**：2026-10-22時点の既存の個別GameWith例外裁定および元Checkerの12件の数値出典位置を**再利用**。新しく20イベント全件をゲームから採取したものではない。
- **C 実環境**：GitHub Actions上のNodeと既存Chromium CI。実ゲームでの経路、Windows/Android実機、公開素材の利用条件は今回の採用とは独立で未検証。

**正式公開イベント0件**、GT由来559枚／2,488イベントの一時統合実績、最優先差異65件、最優先網羅リスク7枚、元GT欠損SSR4枚の状態は不変。次は、同じ最小単位の「カード・イベント・選択位置・結果・数値ID・Lv」を**既存GT559枚にも適用**し、GameWithを全件取得せず疑義のみ補正する。編集台帳の存在だけで公開承認済みにせず、ユーザー指定の公開ゲートと独自表現レビューを通す。
