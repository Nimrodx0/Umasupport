## 現状の事実と注意

- **現行PoCはHTML/CSS/JavaScript/Python**。React + TypeScript + Viteは今後の候補であり、移行済みではない。
- 563枚はUmaSim `data/support_card.txt` の2026年9月30日時点のデータを取り込んだ実ID数。現行ゲームの全カードを網羅する保証ではない。
- 通常ヒントの対応は4,015件。イベント報酬・分岐は全カードを網羅していない。
- PoCの一部イベント（18定義）は選択肢と獲得候補を表すが、到達条件や成功失敗の仕様は未検証。
- 旧台帳の異表記を実IDに統合したが、変更後も古い保存デッキを壊さないIDマイグレーションが必要。
- Rタッカーブラインは台帳上残している。UmaSim登録漏れの可能性はあるが未確定。
- 以前のチャットで「ブラウザ検証済み」と報告された事項は当時の実行報告。移管後の環境で回帰テストする。

## 過去の失敗から維持すべき原則

1. ブラウザから外部サイトへ一括取得させるUIは設けない。ビルド時にデータを収集・検査する。
2. 未収録スキル名・イベント経路を推測で補完しない。
3. 「通常ヒント確認済みで0件」と「データ未収録」を区別する。
4. カードの名前だけで誤統合しない。実ID・レアリティ・人物とレビュー済みエイリアスを使う。
5. テストは実際に操作したスロットと状態を評価する。

## 検証コマンド（PoCソースを配置した場合）

```sh
node --test tests/core.test.js tests/stage.test.cjs
python -m unittest discover -s tests -p 'test_*.py'
python tools/build_v8.py --input inputs/full_support_hints.psv --full --output dist/uma_support_lab.html
```

最後のコマンドはビルド入力を別途用意し、第三者データの利用条件を確認してから実行する。
