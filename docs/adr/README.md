# Architecture Decision Records（ADR）

重要な技術・設計判断を、一件ごとに**背景、状態、選択、影響**とともに残します。既存の利用者判断履歴は[decisions.md](../decisions.md)が正本であり、勝手に現在有効と認定しません。

## 新しいADRの書式

1. タイトルと番号（ADR-000X）
2. 状態（提案、採用、却下、置換）・判断日・参照元
3. 背景と制約
4. 検討した選択肢と理由
5. 決定内容
6. 影響とリスク
7. 後続判断との置換関係

**決定済みADRの変更**：新しい決定を作成して旧記録から参照します。元の判断が存在しなかったかのように削除しません。
