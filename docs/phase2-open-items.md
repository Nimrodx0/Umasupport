## 開発再開の判定ゲート

1. **着手前**：本台帳の該当行 → 関連監査の**後続訂正まで** → 実コード・テスト・固定出典版を確認。古い監査の「次工程」だけを読んで作業を始めない。
2. **裁定**：固定GameTora由来データを基準に、カード／イベントに具体的な欠損・疑義があるときは[機械的GameTora→GameWith裁定契約](event-adjudication-enforcement.md)を守る。GameWithに事実が明示されれば編集採用する。未掲載・イベントID不明なら**その項目だけ**保留。ゲーム実測や他サイト一致を一律必須にしない。
3. **完了報告**：各行に「採用済み事実」「非公開実行候補へ反映済み」「同定未完」「出典未掲載のため保留」「公開／利用条件未承認」を区別し、再計測を伴う場合は日付・分母・固定ソース・CIを記す。閉じる場合は実際の試験／編集根拠をリンクする。
4. **公開工程への移行**：この台帳の**スキル経路・内部連続条件に直結する未解決点について、採用済み／明示保留の分類と、非公開2,512候補の整合を確認してから**、既存の[公開審査ゲート](checker-public-catalog.md)を使う。全部の非スキル項目の裏付けやゲーム全件直接実測を一律の先行条件としない。未確認情報を確定スキルとして公開しない。8イベントの[初回公開リハーサル](phase2-first-event-release-rehearsal-20261030.md)は下流の技術資産であり、Phase 2照合を代替しない。
5. **計画変更時**：[roadmap.md](roadmap.md)の依存・[decisions.md](decisions.md)の確定判断と比較し、既存残件を飛ばす場合は**省略する行・理由・検証影響**を明記する。既存計画の上に別の「最新計画」を無断で追加しない。
