# 実行時のデータ取得（2026-10-16 決定）

## 確定方針
- GitHubには独自アプリのコードのみを置き、第三者由来の実ゲームデータ自体は原則同梱・再ホストしない。
- 利用者のブラウザが起動時に外部の公開元から直接取得し、スキーマと内容を検証してからIndexedDBへ保存する。手動更新ボタンは設けない。
- HTTPエラー、通信切断、データ欠損・形式変更の場合、**最後の検証済みキャッシュ**へフォールバックする。キャッシュも無ければエラーを表示して起動を停止する。
- 出典、取得日時、キャッシュを利用しているかを明示する。取得日時は提供元の更新日ではない。
- CORSと提供元の利用条件を確認する。直接読めることはあらゆる利用が許諾されたことを意味しない。

## 現在の実装範囲
- `poc/live.html`：直接取得版の入口ページ。
- `poc/src/live_loader.js`：UmaSim `data/support_card.txt` のスキーマ検証、通常ヒント抽出、IndexedDBキャッシュ、障害時の旧版利用。
- `poc/src/live_app.js`：既存PoCのスキル集計・比較UIを実データモデルへ接続する。新規設定では空デッキ。
- `poc/tests/runtime.test.cjs`：人工テストデータによる正常読込、オフライン復帰、不正データ拒否の回帰テスト。
- 同梱版v8.1と異なり**通常ヒントのみ**。イベント、金／下位の関連、性能値、レビュー済みの表記エイリアスは未移植。旧版の全機能を網羅するものではない。

## 利用条件・検証待ち
- 初回取得にはネットワークが必要。キャッシュ禁止モードではオフライン利用不可。
- 取得先が `https://raw.githubusercontent.com/mee1080/umasim/main/data/support_card.txt` を変更・停止した場合はキャッシュ版を表示する。
- 公式のスキルIDが取得できていないので、スキル識別子は名前由来の暫定キー。後日ID移行時にユーザー設定の互換対応が必要。
- **2026-10-16 ユーザー報告：** GitHub Pages上で実ブラウザ動作を確認し、問題は見られなかった。少なくとも通常の起動・データ読込・表示については動作確認済みと扱う。ブラウザ種類、通信断の模擬、IndexedDBの保存内容、キャッシュによる再起動までの個別検証は未報告なので、オフライン復旧の実機確認は引き続き未完とする。
- 今回のNodeテストは人工データを使用。外部元データをレポジトリへコピーしていない。
