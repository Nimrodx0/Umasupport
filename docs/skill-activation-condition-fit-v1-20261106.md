# P2 発動条件適合性 v1：6区分の判定基準と既存53スキルへの試験適用（2026-11-06）

**採用した判定の意味：スキルの「発動条件が各脚質の走り方に合うか」という定性的な適合性の研究基準。実ゲームのスキル発動確率、スキル効果・獲得価値、サポカ全体の評価ではない。** 判定器と監査結果は研究用に追加したが、**既存53件の初期定性ラベルとアプリUI、カード集計・公開データは変更していない**。

## 1. 評価対象と6状態

出典のスキルごとに、**逃げ・先行・差し・追込を別々に評価**する。

| 状態（内部コード） | 採用基準 | 読み違えてはいけないこと |
| --- | --- | --- |
| **高適合** (high) | 当該脚質群が順位条件を満たす割合が、比較対象の脚質群より高いという**方向性**が、直接比較できた固定モデルの主要条件で揃った | 発動確率が何％以上、他脚質では発動不可、とは言えない |
| **低適合** (low) | 相手の脚質群より順位条件を満たす割合が低いという方向性が揃った | 発動しない、取得価値が低い、と断定しない |
| **条件依存** (dependent) | 同じ順位帯と局面でも脚質構成・コース等によって群間の逆転がモデルで観測された | どのコースで必ず逆転するかはまだ確定しない |
| **脚質差なし** (neutral) | 判定に必要な元のAND条件が、確認した範囲では距離・馬場等の**レース共通条件だけ**で、脚質・順位・未知の契機条件を持たない | スキルの強さ・発動のしやすさが全脚質で等しいという実測ではない |
| **評価保留** (held) | 追加のAND条件、未測定の区間、検証外の順位帯、異なるOR経路、出典不一致等でスキル全体を判定できない | 部分的に判定できた順位条件は、別属性として保持する |
| **発動不可** (ineligible) | 元の構造化された**明示running_style**条件が、すべての適用可能なAND／OR経路で当該脚質を除外する | 括弧タグやモデル上の0%だけを理由に発動不可としない |

高適合・低適合は、絶対的な成立割合の閾値ではなく、**同じ順位条件についての脚質間の相対的な方向性**を記述する。単一脚質の「発動しやすさ」の絶対値や確率に代用しない。

## 2. v1で実際に判定できる条件

検証済みの元順位条件は、厳密に \`order_rate<=50\` または \`order_rate>50\` の**相補的な2帯域**だけ。順位コードの大小演算子や出走人数との変換を拡大解釈せず、\`>=40\`・上位30％等は保留する。基準に使ったモデル実験と再現コードは以下のとおり。

- [GlobalSim 6コース・2,160レースの位置帯比較](skill-position-six-course-generality-20261105.md)：中盤と終盤前半の4窓で上位50％の前方／後方脚質群の優位方向が全576比較条件で維持。ただし9地点近似。
- [全記録時刻の順位別占有割合・1,080レース](skill-position-rank-phase-foundations-20261105.md)：序盤・中盤・終盤前半の順位条件方向を確認。**終盤後半**には逆転例。
- [固定脚質編成・1,440レース](skill-position-fixed-roster-paired-control-20261105.md)、[相手編成だけを変える5,760レース](skill-position-focal-opponent-roster-study-20261105.md)：モデルでの相手脚質構成への依存を確認。普遍的な数値の成立割合は設定しない。

**高／低が可能なランダム窓**：\`phase_random==0\`（序盤全体）、\`phase_random==1\`（中盤全体）、\`phase_random==2\`（終盤前半全体）、\`phase_firsthalf_random==2\`（終盤前半の前半）、\`phase_laterhalf_random==2\`（終盤前半の後半）。

**条件依存が可能な窓**：\`phase_random==3\`（終盤後半全体）について、モデルの順位群の逆転例が存在。終盤後半の一部分（\`phase_laterhalf_random==3\`等）は個別検証していないので保留。

**現時点で保留する窓**：\`phase_laterhalf_random==0\`（序盤の後半）、\`phase_firsthalf_random==1\`や\`phase_laterhalf_random==1\`（中盤の一部分）、\`phase==2\`（時点判定であってランダム窓ではない）、直線・コーナー等のコース形状依存窓。

距離カテゴリの明示条件（\`distance_type==1..4\`）は、6コースの実験対象のカテゴリとして照合できる。一方、**ダート・馬場状態・コース回り等は今回の位置モデルとの条件一致が未検証**なので、\`ground_type==2\`等が付いた発動経路の**スキル全体**は評価保留、**順位条件部分**の方向だけ別記録に残す。

### 元条件の論理構造

条件は **AND内を一つずつ評価し、OR経路は一経路ずつ評価してから統合**する。条件が一つでも未評価なら、順位部分が高／低であってもスキル全体は保留。複数OR経路の全てが同一方向の判定で合意する場合のみ、その方向をスキル全体へ適用する。

明示脚質によって発動できない経路はORから除外するが、**一つでも可能な経路が残れば「発動不可」にしない**。preConditionsのOR・複数のInvokeも保持し、解釈できないものを確率的に合成しない。未知の条件は条件不在ではない。タグ表記は\`running_style\`の厳密な制限に格上げしない。

## 4. 採用・未承認と次の条件

- **判定規則v1は合意した仕様として固定**。実装：[評価器](../poc/src/skill_activation_fit_v1.cjs)、[53件レビュー作成器](../poc/tools/skill_activation_fit_v1_report.cjs)、[判定とAND/OR・明示制限の単体テスト](../poc/tests/skill_activation_fit_v1.test.cjs)、[再現CI](../.github/workflows/skill-activation-fit-v1.yml)。
- **根拠のA／B境界**：A：人工データテストで未知AND・複数OR・明示脚質除外・補助条件保留を検証。B：固定UmaSim源から53件×4脚質を再計算し、元の53件の脚質ラベルとの一致を確認。
- **未承認**：他の828スキルへの正式判定、明示脚質・距離以外の様々な条件の実ゲーム照合、適合性をアプリで常時表示すること、数値による発動率計算、スキル効果の有用性、カード集約P3。
- **次の検証先**：保留27件のうち序盤後半・中盤前後半の実験区間が大きな未測定群。細かな区間に関する順位推定を慎重に再確認する。ダート条件は走行条件の一致を確認するまでは保留する。元スキルの\`order_rate>=40\`等の意味と正しい整数順位への変換は独立に検証する。

**何より、モデル上の順位占有走行距離割合は実ゲームのスキル発動確率ではない。**
