# 用語・定義の正本と参照索引

この文書は、開発・研究・図表・UI・利用者への説明で共通に使用する**優先用語・意味・表記**の正本です。[エージェント指示](../../AGENTS.md)と[文書運用規約](../governance/documentation-policy.md)に従って更新します。

## 正本の管理原則

- **一概念・一優先用語・一つの定義の正本**：複数工程にまたがる独自用語はここで定義する。個別分野の既存の仕様書・研究設計に正確な現行定義があるものは、**その箇所を正本としてリンクする**。同じ文言を別ファイルで独立管理しない。固定実験報告・判断履歴は書き換えない。
- **表記と意味を区別**：定義には比較対象、判定条件、分母、単位、適用範囲を必要に応じて添える。略称や旧表記は同義語として対応付けるが、**実際には違う量を同一語へまとめない**。
- **初出時に説明する**：この索引があっても、独立したユーザー向け説明や図表の見出しで意味を省略しない。リンク先を読まなければ「何と何の差か」が分からない表現を避ける。
- **採用状態を混同しない**：「研究用の計測指標」と「製品で採用したラベル」は別。利用者が承認していない研究上の閾値や仮称を正式な適性区分にしない。
- **新語の追加・変更**：使用前に既存用語を検索し、定義と類義語・異義語を照合する。名称・意味を変える場合は理由、旧用語、影響する文書・コード・表示を記録して同期する。単なる誤記なら発見した作業内で直し、正本の所在が複数領域にまたがる構造課題は[Dトラック D.3](../plans/documentation-maintenance.md)で扱う。

## P2の研究用指標（現行の優先用語）

ここでは**異なる量を誤って同一視しないための現行名称と定義**を管理します。詳細な元データ、母集団、固定計算例は[二軸研究](../evidence/skills/skill-specificity32-two-axis-20261109.md)と[P2.30の計算根拠](../evidence/skills/skill-p2-30-context-margin-sensitivity-20261111.md)で確認してください。

| 優先用語・記号 | 定義 | 単位と適用境界 |
| --- | --- | --- |
| **条件成立機会（W）** | 指定したモデル条件で、元スキルから取り出した**順位・時期の部分条件**が、対象判定窓（P2.9では10m）内に成立する機会を集計した割合。 | %。実ゲームの**スキル全体**の発動確率ではない。 |
| **点順位占有率（O）** | モデルの指定地点で、対象の順位帯にいる割合。10m区間内の「一度でも成立」とは別の事象。 | %。Wと直接同一視しない。 |
| **一様順位基準（U）** | 対象順位帯に入る順位の個数を、そのレースの出走頭数で割った理論的な基準割合。 | %。現実の脚質別順位分布を表すものではない。 |
| **脚質特異性（D＝O−U）** | 点順位占有率Oから、一様順位基準Uを引いた値。固定順位帯への占有の偏りを示す。 | ポイント。W−Uではない。 |
| **脚質間の条件成立機会差** | 同じ元部分条件・対象コース・モデル設定で比較した、**二つの脚質それぞれのWの差**。例：「差しW−先行W」。どちらを先に引いたかを必ず示す。 | ポイント。順位帯・モデル設定が異なる値を無条件に比較しない。 |
| **脚質間の条件成立機会差のシナリオ平均下限の最小値** | P2.30で、比較対象二脚質のW差の**保守的な下限**を、元条件に合うコース×能力設定についてシナリオ別に平均し、その平均下限の中で最も小さい値。優位と判定された方向に符号をそろえて比較する。 | ポイント。**各シナリオ平均**に対する下限の最小値であって、個別コース・シードの差の最小値ではない。研究専用。 |
| **脚質間の条件成立機会差の判定用閾値（仮）** | 前項の研究指標が「この差を上回るか」を調べるため、事前に選んだ比較の境界値。P2.30では0・1・3・5を試した。**観測データから算出した最小値そのものではない**。 | ポイント。意味のある差の正式基準や製品の高／中／低区分としては**未採用**。 |

### 非推奨の曖昧な言い方

- **「仮の最小差幅」**：*計測された最小値*と*仮の判定用閾値*のどちらを指すか不明なので使用しない。「脚質間の条件成立機会差の判定用閾値（仮）」等、実際に意味する概念を明示する。
- **「適性が高い」**：WやDの部分条件結果だけでスキル全体・サポカの適性が確定したかのように書かない。「検証条件下で、差しの部分条件Wが先行より高かった」など対象と根拠を明示する。
- **「発動率」**：モデルで観測した順位・時期の部分条件の成立機会Wを、実際のスキル発動率と呼ばない。
