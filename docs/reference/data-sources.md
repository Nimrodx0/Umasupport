# データソースと採用契約（現行）

**現在の取得・変換・公開の境界の正本**です。2026年10月の出典比較・当時の0件などの測定を含む原文は[当時の全文](../evidence/sources/data-sources-original-20261110.md)に保存しています。現行の配信・許諾は実コードと固定承認台帳でも確認してください。

## まず確認する現在のデータ経路

| 対象 | 現在の主経路 | 採用境界 |
| --- | --- | --- |
| カード実ID・通常ヒント・スキル数値辞書 | UmaSimの公開元からブラウザで取得し検証・キャッシュ | [実行時取得](runtime-data-loading.md) |
| 新カードのイベント候補 | GameTora由来の第三者GitHub構造化JSON（コミット・カードblob固定） | [増分取込手順](../how-to/curated-event-intake.md)。既存承認済みイベントを全件置換しない |
| 欠損・疑義がある個別候補 | 特定の出典と結果だけ、GameTora元サイト・GameWith記事を照合 | [裁定契約](event-adjudication-enforcement.md)。未確認を確定にしない |
| 公開イベント | ウマサルタント独自に編集し、対象ごとに承認されたJSON | [公開ゲート](../how-to/checker-public-catalog.md)、[承認台帳](../../poc/config/event-release-approvals.gt2487.v2.json) |

## データパイプラインの不変条件

- ソース別取得 → ID正規化 → スキル／イベント変換 → 妥当性検証 → ブラウザで検証済みキャッシュへ保存（旧PoCのみ同梱）。
- 通常ヒントとイベント由来報酬は**別の獲得経路**として保持し、同じカードで両方が存在しても提供枚数は1。
- カードの識別キーは可能な限りゲーム内IDを使い、旧仮IDからの移行エイリアスを保持。
- 名称が似たカードでも自動統合しない。対応表のレビューと回帰テストを必須とする。
- 検証済みのヒント0件と未収録を混同しない。
- 取得日時、元コミットや版、変換ログ、収録率を追跡する。

- **通常ヒントとイベント報酬は別の経路**。変換可能な候補、公開承認、実ゲーム全件の正確性はそれぞれ別の状態です。
- 元GameTora HTMLの全件直接取得、およびGameWithの大量巡回は現行の主データ入力ではありません。
- 新カードの未掲載を「イベントなし」へ確定させず、ID単位の欠損と出典の失敗を保留します。

## データの利用・公開条件

**Public GitHubへの公開は、データや画像の再配布が自由であることを意味しない。**

- UmaSimリポジトリにはAGPL系のライセンスがあるが、ゲームデータ自体や派生データへの影響を一律に断定しない。
- 攻略サイト由来のイベント文章、カード画像、ゲーム内名称・情報の扱いは別途確認。
- 公開リポジトリには、未承認の第三者原文・元データスナップショット・画像を含めない。
- バージョン管理には取得用アダプタとテストを入れ、実データは出典・権利確認後に公開する。

- 第三者の文章・画像と、照合に用いる個々の数値事実を区別します。取得方法、再配布、著作物性と利用規約も別の条件です。
- [イベントデータの利用条件の判断](../decisions/event-data-acquisition-rights-20261019.md)は時点付きの記録です。**今回の公開承認済み集合**は[実際の承認台帳](../../poc/config/event-release-approvals.gt2487.v2.json)の対象とハッシュを照合してください。
