## P2.29：単一の均衡基準と条件横断傾向を並行検討（2026-11-11）

[ユーザーの後続研究方針D-043](../decisions/log.md#decision-d-043) により、均衡編成をP3の唯一の標準基準にする方式を再検討。**均衡は再現可能な実験対照**として維持し、現実の典型的な脚質人数とみなさない。固定32元順位・時期部分条件×4脚質6ペア×9/12頭×4人工脚質編成の研究結果を再利用して、**比較できる対象条件すべてで同じ方向、観測可能な範囲だけの一致（走者不在あり）、方向逆転、同値・保留**を個別に監査する。コースとequal／人工±10%能力は元条件に適合する固定対象のみ。正式P3/P4表示、スキル全AND、実発動率の採用は保留。

[方法・未決定の基準条件](../evidence/skills/skill-p2-29-reference-context-and-consensus-20261111.md)。均衡内では384脚質ペア中337が厳密方向一致、4人工編成すべてなら143が方向一致（うち逃げ不在で比較できない192ペアは0と扱わない）。**脚質構成・9/12頭・コース・能力の代表性は未実証**。追加した[固定CI #42972103606](https://github.com/Nimrodx0/Umasupport/actions/runs/42972103606)で、192ペアを横断して**全8編成×頭数セルで同方向69組、比較可能な範囲で同方向66組、逆転29組、同値・保留28組**を確認。逃げ不在192比較セルを0や劣位にせず欠測を維持。これは元スキルの順位・時期の部分条件のみのW相対方向であり、スキル全体・サポカ・正式UIの適性評価には未採用。
