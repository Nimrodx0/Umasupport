## P2.33の芝／ダート共通条件機構の追加監査（2026-11-17）

[固定元P2.33の芝ダート比較と元スキル候補抽出](../evidence/skills/skill-p2-33-shared-surface-mechanism-20261117.md)をCIで検証。固定10条件の**順位・時期機構が同じ4組（ただし元スキルIDは異なる）**について、芝ダート同じ脚質・編成・頭数・能力・距離の**960文脈**でWを比較し、フル30で厳密な区間差469、**両15シード追認187**、仮5pt超の両分割追認5。東京芝／ダート1200mは**240文脈・厳密差189・追認95・仮5pt超追認2**。別途、元818スキル・970経路を原数値32静的文脈で照合し、両馬場を静的に許容する**88スキル**を抽出、うち**82スキル**は次のモデル実験に使いやすい単純な元Invoke／OR構造。**共通機構のモデルWは、同一元スキルの全AND発動機会やゲーム発動率ではない**。 **この研究は現状の製品適性の距離・芝ダート間接補正に採用せず、G5は簡易研究の実施・要否判断を終了。追加の元JVM全AND実走行は現行の必須工程ではない**。距離・競馬場を揃えた東京1200mでもコース形状の交絡は残る。さらに[同一元スキルIDの静的AND×部分W接続](../evidence/skills/skill-p2-33-same-id-static-model-projection-20261117.md)は**82技能全て**で可能で、同一IDの条件付き部分W参照5,624（実際の元モデル文脈は重複除去後960）を固定元CIで確認。ただし元スキル自体のJVM同一tick全AND・発動率ではない。元発動率・距離／馬場の因果効果は依然として未検証。
