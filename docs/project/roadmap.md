## 目的と判定

本育成・継承育成のサポートカードを、通常ヒント、公開承認済みイベントの獲得候補、上下位スキル、重複、目標カバーによって比較できるアプリの完成を目指します。獲得**候補**はゲーム中の確定入手とは異なります。

| ゲート | 完了に必要な確認 |
| --- | --- |
| A：機構 | 集計、分岐・打ち切り、検索、保存、復元、異常系 |
| B：データ | 出典の版・ID・結果・承認・保留理由 |
| C：実環境 | Pages、Windows・Android物理端末での操作と復帰 |

合格基準は[検証計画](../quality/verification-plan.md)が正本です。Aの成功をBやCの合格とみなしません。

## 2026-11-11時点の開発主軸：P2研究に復帰

ユーザーの指示により、W1・W5の検証強化とW3の保留カード表示・目標候補検索の改善は [PR #398](https://github.com/Nimrodx0/Umasupport/pull/398)・[PR #399](https://github.com/Nimrodx0/Umasupport/pull/399) を区切りとし、**主たる開発対象をP2（スキルの4脚質別発動条件研究）へ戻す**。W3の新カード自動監視は継続し、W2/W4の出典・権利・未解決個別差異は証拠が得られた範囲で管理する。Windows/Android実機検証は引き続き保留。

当面の順序は **P2.15：元AND/OR・preConditions・複数Invokeの構造と全条件評価の不足検証 → P2.32：未知条件を適性推定で省略できるかの影響監査／P2.33：距離・馬場の非明示的な差の簡易検証 → P2.18の研究用契約を保留付きでP3へ接続 → P3集約 → P4表示**。P2.32は仕様ベースの条件付き省略候補監査・元経路選別を実装済みで、既存P2.15判定機構をグループ別に再利用する工程を追加した。P2.33の追加実測は未着手であり、研究用のP3受入と正式なカード評価／公開を区別する。スキルの取得経路照合だけを理由に、P2の未完を飛ばしてP3を正式採点へ昇格させない。

[P2.15の固定元スキル全件監査](../evidence/skills/skill-p2-15-full-path-gate-audit-20261111.md)で、818照合スキル・954条件経路を分類し、859脚質セルの明示除外を独立一致確認。ただし**他のAND条件の同時成立・複数Invokeの意味・実スキル発動率は未評価**であり、P2全体の受入完了ではない。

**2026-11-13追加承認の研究優先原則**：[D-045の後続承認](../decisions/log.md#decision-d-045)に従い、最終的な判断対象を**脚質・距離・馬場の3軸の適用範囲と成立機会**と明確化する。非明示的な条件研究の重点は4脚質とし、未知条件のうち合理的に**適性への影響が無視可能と確認されたもの**は詳細研究と推定への反映を省略できる。元条件式・明示制限は保持し、**影響未測定は無影響とはしない**。距離・馬場は実用差・一般化可能性の**簡易研究で必要性を確認できた例外のみ**深掘りし、コース・コーナー形状の差を距離適性そのものへ読み替えない。既存P2.17/17bは脚質間差の距離依存という部分研究であり、距離・馬場別の同一スキル条件の成立機会を直接評価する追加研究は未実施。具体的な選定・終了条件は[P2.32/P2.33](../plans/skill-conditions/p2.md)を正本とする。正式な閾値、カードの採点・製品UIは変更しない。

**P2.29で代表条件の妥当性と条件横断の共通傾向を並行研究**し、実対戦の平均編成が分かるまでP2全体を停止する方式は採りません。ただし元スキルの全AND、15＋15シードの追加検証、数値差の実用的な意味は別の未完課題です。[P2.29研究](../evidence/skills/skill-p2-29-reference-context-and-consensus-20261111.md)。

**P2.32の機構再利用（2026-11-13）**：当初選んだ7スキルを全て別々に研究し直さず、[元の条件型・演算子・AND/OR構造を保持した共通グループ](../evidence/skills/skill-p2-32-mechanism-reuse-20261113.md)へ整理する。判定機構の既存実測は参照可能なモデル・コホート内でのみ再利用し、数値閾値、事前条件の履歴、別Invoke、コース、実ゲーム対応は各元スキルで確認する。グループの代表例から不足する機構を研究し、元全条件の発動確率を無条件に転写しない。

**元条件の各スキルへの展開（2026-11-13）**：P2.32での機構群の共通化を受け、元スキル固有の閾値と演算子を[3軸明示適用制限の固定元監査](../evidence/skills/skill-p2-15-parameterized-axis-gates-20261113.md)で一括再評価する工程を追加。馬場状態の不明を4候補として保持し、順位・時間・ランダム窓などの非明示動的成立機会は元の未知を維持する。適性採点やP2.33の非明示的差の判断には転用しない。

## 並行トラック：スキル発動条件とサポカ傾向

研究工程の**P0～P5**と製品工程の**W1～W5**を混同しません。[P0～P5詳細計画](../plans/skill-conditions/index.md)に独立した小工程と結果・未完ゲートを記載します。

| Phase | 内容 | 現在の扱い |
| --- | --- | --- |
| [P0](../plans/skill-conditions/p0.md) | 固定版のスキル条件・AND/OR全件監査 | 研究実施済み、出典更新時に再監査 |
| [P1](../plans/skill-conditions/p1.md) | 明示条件・状況条件を分離した内部モデル | 実装済み、回帰維持 |
| [P2](../plans/skill-conditions/p2.md) | 4脚質別の成立機会・脚質特異性を独立研究 | 固定モデル実験は進行。実対戦・閾値・全経路照合は未完 |
| [P3](../plans/skill-conditions/p3.md) | スキルの取得経路からカード単位への集約 | 未完 |
| [P4](../plans/skill-conditions/p4.md) | 検索フィルター・表示 | 未完 |
| [P5](../plans/skill-conditions/p5.md) | A/B/C統合受け入れ | 未完 |

**P2からP3への境界**：モデル上の順位占有割合は実ゲームのスキル発動率ではありません。逃げ・先行・差し・追込を独立比較し、①成立機会と②脚質特異性を別々に評価します。③発動後の効果の有用性は別の将来軸です。**2026-11-11後続指示により、P3で均衡編成のみを標準評価とする旧決定を再検討**し、複数編成・頭数・適用コース・能力設定でも一致する傾向、条件依存、欠測を区別するP2.29を先行させます。均衡編成は研究用の対照として保持するが現実の代表とは断定しません。単一基準か条件横断の関係か対象レース指定評価かは採用未決定であり、独自の重み付き平均・正式ラベルへ勝手に変換しません。従来2群の研究ラベルをP3/P4や公開UIに自動反映しません。

想定対戦相手の脚質人数を利用者が指定するイベント専用モードは**将来の未採用構想**であり、任意編成の根拠・保存方法を検討する前に実装確定としません。

## 実装の境界と変更規律

- **主入力はGameTora派生GitHub JSON**。GameWithは具体的な欠損・疑義の個別裁定用です。元GameTora HTMLの汎用直接取得は保留した旧計画です。
- 技術変換、現在のゲームとの一致、第三者データの利用条件、正式公開の承認は別物です。未承認の本文・画像・DBを公開しません。
- 優先順位変更はこのロードマップ、詳細な小工程と結果は[plans](../plans/index.md)、実測は[status](status.md)、確定した仕様判断は[requirements](../reference/requirements.md)と[decisions](../decisions/log.md)へ反映します。
