# P2：絶対順位・コーナー順位の15＋15シード方向安定性監査（2026-11-10）

**研究用・採用未決定。** 固定GlobalSim上の「元条件の順位部分」の調査であり、日本版実ゲームのスキル発動率、4脚質の最終適性ラベル、サポカ適性・スキル効果有用性を評価したものではない。

## 出典と手法

[元条件に一致する絶対順位・コーナー順位の1,440レース研究](p2-absolute-corner-source-model-20261110.md)で派生したレポートSHA256 **0ad669a4dca52ca652009a0702037281a2044bd7ba0c5d1a057a053b954df7bd** を固定入力とし、[監査プログラム](../poc/tools/skill_rank_corner_split_stability.cjs)で再計算する。

元の測定条件は均衡編成、12固定コース、9頭／12頭、equal／jitter10、各条件30シード。元条件のAND経路を識別するID・コース・頭数・能力モードを一致させたうえで、逃げ／先行／差し／追込の各2脚質ペアを検査する。両脚質が元の明示脚質制限で存在しない場合は比較から除外し、欠測をゼロとは扱わない。

- **W**：10m判定窓と順位部分条件が重なるモデル上の成立機会。
- **O**：1地点での順位部分条件の占有割合。
- **U**：該当順位の個数を頭数で割った理論的一様基準。
- **D = O−U**。W−Uではない。WとOの方向をそれぞれ独立に検査する。

脚質ペアの差は前半15シードと後半15シードで各々計算。両方で同じ脚質側が厳密に優位（数値丸めの誤差1e-6ポイントを除く）の場合のみ「**方向一致**」。それ以外は両方同値／片方同値／符号逆転に保留分類。**これは統計的有意差の検定ではなく、固定シード分割の記述的な感度検査**。

## 実測結果：Wに関する脚質ペア

| 判定区分 | 件数 |
| --- | ---: |
| 15＋15シードで厳密に同じ脚質の方向が優勢 | **2,006** |
| 両分割で数値上同値 | **239** |
| 一方の分割だけ同値 | **89** |
| 分割間で優位方向が逆転 | **18** |
| **合計** | **2,352** |

Oの独立比較は、方向一致2,006、両分割同値235、片側同値93、逆転18、合計2,352件。Wの方向一致2,006件の中でも**130件は全30シード平均の脚質差が5ポイント未満**（そのうち10件は1ポイント以下）。分割方向が一致しただけで、実務的に重要な差が確立したとはいえない。

4脚質すべての比較が揃った**392モデル条件**のうち、Wについて6ペアとも分割方向一致した条件は**87**。残る305は、少なくともどこかの脚質ペアが同値・片側同値・符号逆転となる。なお、明示脚質制限により4脚質すべてを観測していない条件はこの392の分母には含めない。

## 9頭／12頭の比較

元スキル経路・コース・能力設定・脚質ペアが一致する**1,176組**について、両頭数の各々が15＋15シード分割で方向一致したときだけ、頭数間で方向を比較する。

| 判定 | Wの件数 |
| --- | ---: |
| 9頭・12頭の両方で同じ厳密方向 | **958** |
| 少なくとも一方の頭数で方向を保留 | **218** |
| 両頭数で厳密方向が逆転 | **0** |

「両頭数で逆転が0」は、**保留218組を同じとみなした意味ではない**。比較対象は等しく設計した人工編成であり、頭数だけを変えた独立の因果実験ではない。Wの値自体には9頭と12頭で大きな差がある事例があるため、率や正式な評価を合算しない。

## 重複の扱い

**32本の元スキル経路は32の独立した研究ではない**。元条件と評価条件が同じ金・白系列などを含む。各経路の全コース・頭数・能力モード・脚質・W/Oおよび前半／後半の測定系列が完全一致するものを区別すると、**14種類の異なる測定プロフィール**に整理できる。さらにこの14種類も同じ1,440レースの人工モデル軌跡に基づくため、14件を独立した統計的な母集団と呼ばない。

[GitHub Actionsの実行結果](https://github.com/Nimrodx0/Umasupport/actions/runs/42739711288)は、元レポートのSHA256一致と上記の数値をすべて再検証し、派生監査JSONを別の成果物として14日間保持する。

## P2の次の判定ゲート

1. **脚質間の方向安定性を採用率・重要度へ変える基準は未確定**。小さな平均差、同値、逆転がある条件から一律の高／低ラベルを作らない。
2. **異なるコース・能力モード・人工的な相手編成への頑健性**を引き続き確認する。均衡編成を標準とする既定方針は維持し、他編成の変動を勝手に重み付き平均やペナルティにしない。
3. **順位以外の条件**は[観測可能性監査](p2-nonrank-condition-observability-20261110.md)を先行させる。追い抜き・ブロック・スパートの状態を順位軌跡から偽装して発動率へ変換しない。
4. 未計測の必須AND、ORの別経路、preConditions、複数Invoke、距離・脚質などの明示制限を省略せず、**元スキル全体の評価は保留**とする。スキル効果の有用性と公開UIは将来・未決定。
