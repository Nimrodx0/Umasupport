# 2026年版・2025年版の別サポカ資料による通常ヒント網羅の拡大監査

検証日：2026-10-17（JST）　関連：[Phase 1](roadmap.md) / [45枚の数値ヒント照合](independent-card-hint-audit.md) / [カードID母集団](card-population-independent-audit.md) / [PR #39](https://github.com/Nimrodx0/Umasupport/pull/39)

## 目的と証拠の限界

これまでの別系統資料では45カード・527通常ヒントIDを照合した。今回は**2026年10月の近い時点のカードカタログ**を探し、ゲーム内の最新状態やイベントスキルを推測せず、**UmaSimの4凸の通常ヒント名が別カタログのスキル欄に掲載されているか**を検査する。加えて2025年の別公開資料で一部の差分を三角照合する。

**最重要の限定**：[dareumaのカード資料](https://github.com/dareuma/umamusume-deck-build-tool/releases)は、作者がGameWithを参考にしていると明記している。[ktkhikr1228-labの2025年サポカ一覧](https://github.com/ktkhikr1228-lab/uma-tool/blob/4bfc708a558bc2ac02266860b42e61fec8a6ffe4/raw_data.txt)もGameWith系の編集済み情報を含む。**両資料が完全に別々のゲームマスターから生成されたとは保証できない**。資料間の一致は有用な誤記・欠落検出だが、ゲーム内の全件独立検証を意味しない。

## 2026-10の560カード照合

カードIDはリリース側にないため、`Title + CharacterName`を `[カード名]キャラクター`に構築してUmaSimの正式名称に照合。異なる表記7件は**別名・文字列・レアリティ・タイプ・一致先IDを固定登録**しており、あいまい一致で自動統合しない。

| 判定 | 件数 |
|---|---:|
| UmaSimカード総数 | **563** |
| 別カタログ収録 | **560**（SSR316、SR101、R143） |
| 明示的に検証して一意に対応したカード | **560 / 560**（厳密名称553、レビュー済み別名7） |
| UmaSimにあり別カタログにない | **3枚**（RのID `10146`、`10147`、`10148`） |
| 560枚の4凸通常ヒント延べ件数 | **3,986** |
| 別カタログの混合`Skills`にも名称がある | **3,965 / 3,986** |
| **通常ヒントが全件載っているカード** | **541 / 560** |
| 一部の通常ヒントが載っていないカード | **19枚・21件** |
| 別カタログの混合`Skills`にあり、UmaSimの通常ヒントにはない延べスキル | **1,480**（イベント等を含むため不一致と数えない） |

**別カタログに未収録の3枚**はUmaSimではそれぞれRの`[トレセン学園]エフフォーリア`、`[トレセン学園]ルーラーシップ`、`[トレセン学園]サムソンビッグ`で、4凸通常ヒント計**29件**。この3枚がゲーム内にないという意味ではない。実装日と取得版の差異などは別途検証。

**重要な解釈：** 混合`Skills`リストにはイベント由来のスキルが含まれるため、`Skills`の追加1,480件は「UmaSimの通常ヒント欠損」ではない。逆に、UmaSimの通常ヒントの21名称がリリース資料にないことも、UmaSimの誤りとは断定できない。版差、カード欄の編集抜け、イベント/通常ヒントの区別、名称変更を含め個別確認が必要。

## 2025年資料による追加照合

2025年資料は `_icon.jpg` と `_icon.png` が混在し、一部のレコードが不正に連結されている。長文カード資料の誤分割を隠して一致判定することを避け、不正な1行は検証対象から除外し理由を記録した。

| 項目 | 件数 |
|---|---:|
| 抽出カード区画 | **503** |
| 構造として読めたレコード | **502**（破損1） |
| UmaSim正式名への厳密一致 | **494** |
| そのうち、通常ヒント欄に情報がない | **82**（ゼロと決めつけず未記載扱い） |
| 4凸通常ヒントの名称比較が可能 | **412枚・2,891件** |
| UmaSimとの通常ヒント名称集合が完全一致 | **403 / 412枚** |
| 別資料で列挙されたうちUmaSimにもあるヒント名 | **2,877 / 2,891件** |
| 旧資料とのスキル情報不一致 | **9枚**（旧資料の版差・誤記・イベント混入の可能性） |

この旧資料を「現行2026の正解」として優先しない。例えば表記の`探究心／探求心`、`憧れを超えて／越えて`や、「中距離直線○／コーナー○」などは、資料間差分として追跡し、勝手に置換しない。

### 2026資料で欠けていた21件の三角照合

先の**19枚・21名称**を2025年資料とカードID単位で調べ直すと、**13枚・14名称は2025年の通常ヒント欄に存在**。残り**6枚・7名称**は2025年資料に使える通常ヒント記載がなく、判定不能だった。**2025年の明示的な通常ヒント欄がそれらの名前と矛盾する例は0件**。

- 2025年資料が該当ヒント名を載せていたカードID：`30042, 10025, 10080, 10105, 30191, 30199, 30108, 30039, 20084, 30146, 20025, 30025, 20059`
- 2025年資料では未確認：`30311, 30090, 20098, 30302, 30284, 30299`

このため、リリース資料に見当たらない21件のうち14件は別資料にもあり、**UmaSimの通常ヒント記録を補強する証拠が得られた**。ただし双方がGameWithに基づく可能性があり、独立した原マスターの裏付けを意味しない。**残る7件の独立確認は未完了**。

## ゲート、残件、実行手順

- **A（機構）：** カード同一性を厳格に判定し、7件のみ明示的名寄せ。無名カードや不正な旧ソースレコードを推測補完しない。混合スキル欄からイベントスキルを通常ヒントとして取り込まず、通常ヒントの掲載有無だけを機械集計。人工入力の同名重複、異なるレアリティ、読み込み不正の回帰テストを通常CIに追加する。
- **B（限定的）：** 2026リリース側560枚に対して3,965/3,986ヒント名を確認。さらに21件中14件を旧資料の通常ヒントから補強。2026リリースにないR3枚の29ヒントはこの比較では未確認。**全563枚・4,015件の公式現行マスターとの同時点独立確認は未完**。
- **C（実機）：** 今回はGitHub Actionsのソース比較のみ。ユーザーのAndroid/Windows物理端末での新たな実機操作は要求せず、未実施マトリクスに蓄積する。
- **表示順：** 外部カードの`Skills`の順序がゲーム内のスキル一覧順だと示す資料はない。2025年の`disp_order`問題も未解決につきアプリUIの五十音順＋金白階層を変更しない。
- **権利・ライセンス：** データを自動再配布しない。参照サイトの利用条件・共有元の真正性は正式公開の前に別途確認する。
