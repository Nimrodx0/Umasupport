# SSR・SRイベントの完全性監査（2026-10-16）

## 目的と現状

ユーザー方針に従い、Rカードは後回しにし、**SSR316枚・SR101枚の各イベントの完全性**を確認する。カードに何らかのイベントが登録されていることと、連続／ランダム／成功失敗／打ち切りを含む全イベントの収録とは区別する。

### 既知の基礎値

- UmaUmaChecker：SSR316枚、SR101枚の見出し。うちSSR5枚のイベント配列は空。SSR・SRで2,099イベント。
- UmaUmaCruise系：SSR311、SR101見出し。SSR・SRで両者は同じGameWith由来のため、**独立した一次検証ではない**。
- 今回、`poc/src/event_title_diff.js` と `poc/tests/event_title_diff.test.cjs` を追加。カード名＋レアリティの厳密な一意一致が確認できた **389枚** の内部イベント名を突合した。残る表記差のカードは別途正式IDで確認するまで自動参加させない。
- 389枚のイベントタイトル集合：両ソースで共通1,211件、UmaUmaCheckerにだけ存在769件、UmaUmaCruise系にだけ存在11件（11枚）。**名称集合の差分であって、11件のイベントがゲーム内で実在しUmaUmaCheckerで欠落しているという証明ではない。**
- 11件の個別確認対象カードID：`20021`、`30021`、`30036`、`30052`、`30067`、`30080`、`30081`、`30137`、`30173`、`30198`、`30207`。イベント名と文章はリポジトリに転載せず、監査ツールの出力はカードIDと**件数のみ**。
- 389枚中、31枚は両ソースのイベントタイトル集合が一致。残りには片側だけにタイトルがある。名前の別表記、同名イベント、イベントの分類方法、古いソースなどが混ざる可能性がある。**実際の網羅率は未計測**。

### 重要な発見

[U-tools](https://xn--gck1f423k.xn--1bvt37a.tools/supports/30240/event) のイベントURLにはUmaSimにあるものと同じ形式の5桁サポカIDが直接含まれ、**連続イベントとランダムイベントがセクション分け**されている。4枚でイベント専用ページを表示確認、30320もカード詳細の掲載を確認。ただし、このURL形式で全417枚のイベント専用ページが利用可能かは**未検証**。GameToraのカードページにも同形式の5桁IDが含まれる。表示URLが同じであることと、ゲームマスター由来のID対応が全面的に確定したことは同義ではない。

U-toolsのページではスキルのヒントレベル等の一部報酬も構造化して表示される。ただしU-toolsの表記は「All Rights Reserved」で、**大量自動取得・データ複製・アプリへの転載に必要な利用許可は未確認**。本工程では個別ページの閲覧・URL確認と比較の方針策定に止め、イベント文章の自動抽出やリポジトリへの転載を行っていない。

## 次の工程

1. **11枚のイベント名差分を個別精査**。正式なカードIDが分かるU-toolsやGameToraのイベント一覧と照合し、単なるタイトル別表記か実際の欠損かを区別する。
2. **欠損5枚の補完元を確定**。U-tools／Game8等にイベントの掲載があっても、転載・自動取込みの許諾とイベント分岐の精度が確認できるまで本番データには加えない。
3. **412枚の完全性を独立系統で検証**。同じGameWith抽出元同士の一致だけでは完全性を証明できない。連続・ランダム件数や報酬、成功・失敗・打ち切りをマスターデータ由来のイベント関係と照合する。
4. **イベントID・スキルIDの正式な対応付け**。イベント一覧画面のスキル名を同名だけで機械結合せず、レビュー済みの写像を使用する。
5. 公開アプリは今後も現行の`events:[]`とし、収録範囲・権利関係・到達条件が確認できた分だけ段階導入する。

## 監査ツール

```sh
node poc/tools/compare_event_sources.cjs
```

`eventTitleComparison` フィールドに厳密一致した389枚のイベント名差分の統計およびカードIDが含まれる（上流のデータが更新された場合は値が変動）。毎回のCIでリモートJSONを取得せず、GitHub Actionsの手動 **Event Source Coverage Audit** に組み込む。第三者イベント本文はソースコード・リポジトリ・CIログへ出力しない。
