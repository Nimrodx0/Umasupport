# Phase 2：旧マスターの未一致ストーリーIDとイベント種別の監査

更新：2026-10-17。事前計画（実ソース計測前）。関連：[既存イベント名照合](event-title-fingerprint-audit.md)、[旧ゲームマスター](historical-event-story-audit.md)。

## 目的と入力境界

固定2025年マスターのカード直結ストーリー1,028件のうち、2026年固定UmaUmaChecker（SSR・SR417枚、イベント候補2,099件）と**記号差除去後も名称が一致しないカード固有ストーリー**を、数値 `story_id` と関連メタデータまで絞り込む。対象となる30241の旧18対Checker17（名称補助一致17、旧側残1）を最優先する。

- 元マスターの `single_mode_story_data.story_id` を `text_data.category=181` のイベント名へ連結し、名称の一時的な指紋を算出。
- 差分をカード内で多重集合比較し、未一致の**旧masterの数値story_idと数値メタ情報のみ**を記録。名称・選択肢・効果文・ハッシュは保存も標準出力もしない。
- `event_category`、`show_progress_1/2/3`、`ending_type`、`gallery_main_scenario`、`gallery_condition`は元DBの**生の数値**。その意味を推測して「連続／真エンディング／不要イベント」と分類しない。
- 同じ名称が旧masterに複数ID存在するとき、Checkerで少ない場合には**どちらの旧IDが欠けたか確定しない**。「残数」と「候補story_id全件」を列挙して曖昧性を保持する。

## 合格基準

**A 機構：** 人工SQLiteで、2つの同名IDが候補1つに対応する曖昧ケース、単独残差、メタデータ列欠損、タイトル欠落、重複テキスト索引、不明カードを検出。通常CIへ組み込む。

**B 限定実データ：** 既存厳密タイトル照合と同一の固定入力で、旧SSR/SR計1,017とChecker計2,099について、残差総数・カード数・数値`event_category`別分布・30241の未一致IDおよびメタデータを検証。元の暫定名称一致985件が変わらないことをチェック。2025年版であり2026年のイベント構成や実際のゲーム内発生を証明しない。

**C 実機：** アプリUI・公開DBに変更なしのため今回対象外。利用者に端末操作は求めない。

## 次の判断

30241の未一致1件を数値イベントID・元マスターメタ情報・追加の公開ゲーム資料で比較し、**候補欠損／イベント体系の違い／改題や版差のいずれかに確定できない場合は未確認とする**。グループSSRのキャラクター構成員と連続発生、終了条件、報酬・利用許諾は依然として未承認。アプリの公開イベントDBの実イベント数は0のまま。
