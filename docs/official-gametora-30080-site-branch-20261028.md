# SSR30080の元GameToraサイトにおける3選択肢・4結果候補・打ち切り構造（2026-10-28）

## 検証の位置づけ

[旧固定3カードの構造選定](official-gametora-existing-structural-cohorts-20261028.md)のSSR30080について、GameTora本体の[カードページ](https://gametora.com/ja/umamusume/supports/30080-sasami-anshinzawa)の1イベントだけを実Chromeで開き、既存の旧固定参照と**画面構造を別々に**比較した。[PR #254](https://github.com/Nimrodx0/Umasupport/pull/254)／[専用Actions #40657924719](https://github.com/Nimrodx0/Umasupport/actions/runs/40657924719)で実測。

旧出典の版は systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67、対象のGit blob SHAは 8ce27e74dd18de7a08efa6a0bcf53d5be7a59a86。ブラウザ実行前に固定検査を行い、第三者の原文、選択肢文言、HTML、画像やJSONはリポジトリへ保存していない。

最初の実Chrome試験では、ORを直下の子要素だけで探したため表示上の3経路と誤診し、専用CIは失敗した。**元出典の4経路を画面へ補完してはいけない**ため失敗のまま検出。次の修正でDOMの子孫要素から実際に見えているORマーカーを独立に1件発見し、実サイトで2・1・1経路に分類できた。両側に兄弟要素がないOR文字列は新規の結果経路として扱わない。

## 実装とA/B/C

- 汎用的な構造比較関数：poc/src/official_gametora_rendered_branch_topology.cjs。任意のイベントについて元出典の選択肢と結果数を数え、**元サイトから独立に観測したグループ構造**と照合する。選択肢ラベルの一意照合、打ち切り表示の位置、内部ORの存在を異なる証拠として報告する。
- 限定サイト実行：poc/tools/probe_official_gametora_30080_branch.cjs。カード1枚・対象イベント1件・固定Git blobを限定読取。robots確認、403・429中止、本文・画像・HTMLのログ出力なし。画面からは構造・件数と匿名の数値だけ出力。
- **A＝Pass**：合成6試験。4外側グループを4結果として誤認しない、サイトにないORを捏造しない、ラベル欠損、打ち切り不在や誤位置を独立に判定。
- **B＝限定Pass**：旧固定SSR30080の既存構造は11イベント・22経路、今回の実証対象は**そのうち1イベント・4経路だけ**。
- **C＝限定Pass**：Ubuntu 24.04 GitHub Actions実Chromeで対象イベントの上記構造を確認。**ウマサルタントの実画面／Windows・Android実機**は今回新たに検証していない。

## 未確定の境界

**画面上の3グループ・ORによる4候補**は事実だが、出典に書かれたユーザーの3選択肢の日本語ラベルは元サイトで一意照合できない。選択肢の結果報酬とスキルID、ゲーム上の抽選条件・確率、他イベントとの内部の依存関係、外部発生条件、お出かけ解放は証明していない。したがって新たな正式公開イベントは追加せず、公開承認0件は継続。次は報酬の種類・値で各経路を一意に結びつけられるか、また他のカードに共通するDOMのOR解析器を整備する。
