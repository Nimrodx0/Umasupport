# Phase 2：2,511件統合後の固定GT／Checker差異65位置の残件照合（2026-10-23）

## 何を解消する監査か

従来の[固定出典差異65位置](phase2-source-exception-overlay-20261023.md)を、「未収録イベント65件」と読んではいけない。固定GameToraとCheckerのイベント同定差、GameTora側ですでに収録されている位置、補完済み位置が混在している。さらに固定両元にないSSR30240の連続3段階は**65の外側**。2026-10-23時点の本番互換**非公開563枚・2,511イベント**と、独立の出典差異台帳を直接突き合わせ、補修済みと調査対象を分離した。

## 監査する対象と正しい数え方

| 固定出典差異の種類 | 元の位置数 | 2,511候補との現在の関係 |
| --- | ---: | --- |
| Checker-only、GTに4SSRカード自体がない | 20 | 4SSR（30318〜30321）それぞれ**通常2＋連続3**を追加済み。カード・5イベント単位で充足。Checker側の各sourceKeyとのイベントID単位の完全同定ではない |
| Checker-only、GTにカードはある | 20 | SSR30221の欠損連続3段階を追加済み。**残り17は資料間のイベント同定が未完**。実イベント17件の欠落と断定しない |
| GT-onlyの非Rイベント | 24 | **元GTイベントがすでに2,511候補内に存在することをID＋出典元位置で確認**。Checkerに存在しないことをGT側のイベント漏れと誤解しない |
| GTの操作分岐が1行に圧縮されたSSR30080/6 | 1 | GameWithで裁定済みの**3択**が本番互換候補内に入っていることを確認 |
| **65位置の外：両固定元にないSSR30240連続3段階** | **3** | GameWith同一カード記事は2026-10-23にも「発生イベントと選択肢一覧：検証中」。U-toolsは最終段階で「迅速果断」Lv1を報告するが、選択／結果別の完全性は未確定。候補へ自動加算しない |

従って、**調査対象として残るのはChecker側のイベント同定17位置＋両固定元欠損のSSR30240連続3段階＝20位置**。これは「新たに追加すべきイベント20件」という意味ではない。Checker-onlyの17件には、イベントの改題／同定の違いが含まれ得る。SSR30240の3段階にも、元資料に明示されていない選択・結果を創作しない。

SSR20075（SRタップダンスシチー）の連続初段階はこの17件に含まれる。GameWithから操作なし・根性+15・絆+15は採用済みだが、U-tools／他資料の別数値+5/+5との**結果条件が未分類**であり、無条件報酬にするべきでない。これはスキル報酬を含まない位置なので、スキル経路の欠落調査より優先しない。

## 自動監査をどう実施するか

`poc/src/phase2_2511_gap_reconciliation.cjs` は、固定版で監査された出典差異 `phase2_release_triage` と、実際に[全件2,511へ組み立てたカタログ](phase2-private-2511-chain-loader-20261023.md)のSHA付き未承認オブジェクトだけを入力とする。

- 固定GTなしの4SSRについて、各カードに通常2件（安定ID `usl:<card>:random:4/5`）と連続3件（`usl:<card>:chain:1/2/3`）が存在するか直接確認
- SSR30221について、連続3件の安定IDを確認。元Checker sourceKeyとの完全な同一イベントIDの突き合わせを行ったと偽らず、**カード範囲内の補完**として記録
- GT-onlyの非R24件を、GT元の`sourceOrdinal`・同カード内`gt-<id>-event-NNN`と正確に接続し、実際に非公開2,511件に残っているか全位置確認
- SSR30080の例外1件が操作3択・特殊トリガーを保っているか確認
- SSR30240の2通常イベントだけはGT元から引き継ぎ、連続3件を未承認で自動追加していないことを確認。GameWithの未掲載判定台帳を使い、勝手な利用許可・報酬採用に変えていないか検査
- 専用Nodeの改変拒否テスト、固定GT全件CIの**実データ**からサポカID・Checker側ordinalのみに限定した残件メタデータを出力。第三者のイベント名・文章、非公開イベントカタログや選択肢文言はログにもPublicにも出さない

## 次の修復順位

1. **SSR30240**：カード版を限定し、「迅速果断」の取得元であることと、その3段階のどの結果・Lvで得られるかを区別する。GameWithには育成イベント由来のスキル名はあるが、個別のイベント表は未掲載。GameWithにない事実をGameWith採用済みと偽らない。U-tools単独の報酬候補は内部保留。
2. **Checker-only未対17位置**：カードID・Checker位置・GTイベントタイトル正規化・数値スキルヒントの一致を個別に見て、実際の追加スキル経路がある位置を優先。同じゲームイベントを別IDで二重登録しない。
3. **SR20075**：スキル報酬ではない+15/+15対+5/+5の結果を分類。スキル経路と内部連続フラグに影響する新しい条件が判明した場合だけ優先度を上げる。
4. **公開移行**：本監査は公開承認の代用にならない。独自イベント表示、出典／利用根拠、イベントSHAと人手承認台帳、Pagesでの操作検証を別途進める。

### A/B/C境界

A＝人工の65位置監査を改変して、別カード割当・3択補正欠落・GT-only元位置消失・未承認昇格を必ず失敗させる。B＝固定GT2,488／Checker全件例外65と実統合2,511を**1回のCI処理内で突き合わせたときのみ確定**。C＝試用UIは今回変更せず、通常版Webアプリへのイベント公開と物理端末の操作は別工程。

**公開承認済みイベント0件**は変えない。
