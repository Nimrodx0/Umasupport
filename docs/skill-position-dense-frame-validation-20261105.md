# P2：密フレームからの順位帯区間積分で9地点近似を検証（2026-11-05）

**状態：検証用コード・再現CI。数値結果はActionsの実エンジン実行で確定させる。公開アプリとスキルの脚質分類は変更しない。**

## なぜ必要か

[2,160レースの感度監査](skill-position-window-sensitivity-audit-20261105.md)では9つの走行位置で測った順位割合を台形補間し、区間平均の推計とした。しかし、9地点の間に追い抜きや順位の入れ替わりが集中すれば、疎な観測からの平均値は誤差を持ちうる。この誤差を数値化せずに、P2の新しい脚質閾値を定めない。

## 密フレーム積分の定義

各ウマ娘が「自分の走行距離の対象区間」を通る間、相手の位置は**同時刻**のフレーム内補間で評価する。フレーム間で全頭の位置を線形補間し、その区間で走者同士が追い抜く時刻を相対位置のゼロ交点から求め、**交点ごとに区間を分割**する。順位が一定の小区間の走行距離を足し、上位半数・後方半数にいた距離の割合を計算する。

これは9地点の台形補間とは異なり、**保存された各フレーム間の追い抜きを考慮**できる。一方、各フレームの間は線形運動を仮定するので、ゲームエンジンの真の連続位置の厳密解ではない。

- 9頭：モデル上の上位半数＝1～5位、12頭＝1～6位。
- 第三者の元条件に基づくランダム発動区間の4種類（中盤全体、終盤前半の前半／全体／後半）に限定。
- 走者の全区間分のフレームが得られない、または他走者と有長区間にわたって同位置で判定できない場合は、未知として除外。**0%と見なさない**。
- 密フレーム集計と9地点の集計は、同じレース、コース、脚質、種子、頭数、脚質構成、人工能力条件で実行。比較対象の走者数が異なるセルは**比較不可**として保留。

## 研究用の限定した試験母集団

固定版GlobalSim v77（コミット80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1）を一時領域でビルドし、以下の条件を組み合わせる。

- コースID：10501（1,200m）、10504（2,000m）、10506（2,500m）。
- 9頭／12頭。
- 脚質構成：均衡型、2026年1月観測の長距離チャンミA予選の4脚質割合を使用したモデル抽選型。
- 同能力／各馬の5種類の能力値を人工的に±10%変化。
- 原則は各セル3シード、手動CIは1～20シード。計3×2×2×2×3＝**72シミュレーションレース**（標準設定）。前回の2,160レースを全件再計算するのではなく、誤差検証のための固定代表パイロット。
- すべての走者はスキルなし。出走者の脚質構成は、イベントごとの周辺分布から抽選したものであり、全国的な平均レースでも本物の各マッチでもない。

解析器：[globalsim_dense_window_validation.cjs](../poc/tools/globalsim_dense_window_validation.cjs)、単体試験：[globalsim_dense_window_validation.test.cjs](../poc/tests/globalsim_dense_window_validation.test.cjs)、固定ソース実CI：[GlobalSim dense-frame window crosscheck](../.github/workflows/globalsim-dense-window-validation.yml)。

## 合否と採用判断

- **A**：人工フレームで1回の追い抜きが50%／50%の区間に分かれること、複数追い抜き、長時間の同順位、未完フレーム、走行距離の後退、9/12頭の再現をNodeテストで確認。
- **B**：実GlobalSimソースを固定ビルドし、同じ走者群の密フレーム積分値と疎な9地点補間値を、比較可能なセルに限定して比較。結果には比較可能なセル数・保留セル数・絶対差の最大・中央値・平均を記録する。ログや生のレースフレームは保存せず**派生した差分だけ**をCI artifactに保持する。
- **C**：実際の日本版ゲーム、発動抽選・他の条件、他人の対戦メタ・実機端末の検証はこの工程に含まれない。

**採用ゲート**：同一条件で疎な9地点積分と密フレーム積分がどれほど離れるかを確認し、前者を暫定推計として使用する範囲を判断する。誤差が小さくても、その時点で順位条件成立割合をスキルの実発動率へ読み替えたり、全53スキルのP2分類を自動変更したりしない。
