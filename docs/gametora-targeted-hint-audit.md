# GameTora個別カードの通常ヒント22枚・180件の照合

検証日：2026-10-17（JST）　関連：[Phase 1](roadmap.md) / [通常ヒントの拡大監査](expanded-card-hint-crosscheck.md) / [カードID母集団監査](card-population-independent-audit.md) / [PR #40](https://github.com/Nimrodx0/Umasupport/pull/40)

## 目的・調査対象

2026-10-02更新の別カタログ（dareuma）で、UmaSimの通常ヒントが**19枚・21件**掲載されていなかった。加えて別カタログにカード自体がないR **3枚**（ID `10146` エフフォーリア、`10147` ルーラーシップ、`10148` サムソンビッグ）は4凸通常ヒント合計29件を個別確認できていなかった。

別の公開サイト[GameTora日本語版サポカ一覧](https://gametora.com/ja/umamusume/supports)から**対象22枚だけ**の詳細ページへ辿り、「サポートヒント」セクションだけを抽出してUmaSimの4凸通常ヒント名称集合と照合した。GameToraは「イベントで貰えるスキル」を別セクションに分けているので、イベント報酬を通常ヒントに混入しない。

使用データ：
- UmaSim [`support_card.txt`](https://github.com/mee1080/umasim/blob/cf9366f6a487bd8f197b53d8a11981207beb9f6c/data/support_card.txt)（固定版2026-10-13、SHA-256 `153213019b5232df6c211427b862978218b60df6baee03c2a5fee75e0966d424`）。
- [GameToraのサポカ一覧](https://gametora.com/ja/umamusume/supports)とそこからリンクされた22枚の公開詳細ページ。**2026-10-17時点**でサイトに掲示された更新日時は2026-10-15。動的ページであり固定版コミット/SHAは取得できない。
- 拡大監査の補助資料：[dareumaの2026-10-02更新カタログ](expanded-card-hint-crosscheck.md)。このカタログは通常ヒント・イベント由来のスキルが混合しており、GameToraの「サポートヒント」と同じ意味ではない。

## 実測（2026-10-17）

[GitHub Actions #39010407751](https://github.com/Nimrodx0/Umasupport/actions/runs/39010407751)（成功、実Chromium）、先行[Actions #39010350454](https://github.com/Nimrodx0/Umasupport/actions/runs/39010350454)（同じ22件・180件の一致）。

| 確認項目 | 結果 |
|---|---:|
| 対象カードID | **22** |
| 詳細ページ正常取得・「サポートヒント」構造を解析 | **22 / 22** |
| 4凸の通常ヒント名称集合が一致 | **22 / 22** |
| 対象カードのUmaSim通常ヒント延べ件数 | **180** |
| GameTora「サポートヒント」欄で同名を確認 | **180 / 180** |
| 両方向の名称差分 | **0** |
| dareumaにカード自体がないRカード | **3枚・29ヒント、GameToraですべて一致** |
| dareumaにヒントの掲載が欠けていた対象 | **19枚・21件、GameToraで各カードの全ヒント一致** |

対象IDは、19枚が `30311,30090,20098,30302,30284,30299,30042,10025,10080,10105,30191,30199,30108,30039,20084,30146,20025,30025,20059`、3枚が `10146,10147,10148`。

前段の2026年カタログに名前が存在した通常ヒント **3,965件**と、前段で掲載されていなかったヒント **21件**と、カードごと別カタログに未掲載のRカード3枚の **29件**の和は **4,015件**。したがって、**UmaSimの4凸通常ヒント4,015件は、全件について最低1つの別途公開されたカード資料にも同じ名称が見つかった**。

**この結論の限界**：2026年カタログはヒントとイベント由来のスキルの混合集計であり、3,965件について「通常ヒントとして掲載されている」ことまで確認したわけではない。**そのうち22枚についてはGameToraの「サポートヒント」欄だけで180件を確認した**。全563枚の4凸通常ヒントをGameToraの専用欄で独立照合したと表現しない。2026年カタログ・GameTora・UmaSimの元マスターデータの真正の独立性も未確認であり、「公式ゲームデータで全件照合済み」ではない。

## 再現とセーフガード

- [固定IDを対象にした監査コード](../poc/tools/probe_gametora_hint_page.cjs)はPlaywright Chromiumを起動し、サイトのサポカ一覧を開き、**実際のリンク先のスラッグ付きURL**を特定する（例：[30311 エフフォーリア](https://gametora.com/ja/umamusume/supports/30311-efforia)）。数値IDだけの `/supports/30311` は404のため使わない。
- 対象22枚のみ順番に開き、画像・フォントをブロックし、通常ヒントの「サポートヒント」から次の「イベントで貰えるスキル」または「育成イベント」までの範囲にあるスキル名称だけ取得する。
- **22枚・180件の両方向完全一致を期待するfail-closedゲート**。DOMの変更、404、重複、取得失敗、ヒントの改訂で一致しなくなれば失敗として再審査する。異常を自動補完せず公開データの採用に転用しない。
- [独立パーサーの人工DOMテスト](../poc/tests/gametora_hint_parser.test.cjs)と[限定的GitHub Actions](../.github/workflows/gametora-hint-structure.yml)で再実行。通常CI/Pages配信の立ち上げでは外部サイトへ問い合わせない。原文／カード画像／HTMLをレポジトリやActionsアーティファクトに保存しない。
- 調査初期にはスラッグのないURL404、一覧の描画待ち不足、カードによりイベント獲得スキル節がないこと、人工テストファイルの取り違えという**監査コード由来の失敗**があった。これらを個別に修正し、**最終版の実データ監査・通常CIの両方が成功したこと**をもって検証結果とする。過去の失敗を元データの不一致としない。

## Phase 1 の判定

- A：対象22枚に対し、元データの不一致、DOMパース失敗、同名重複、対象外イベントスキル混入を防ぎつつ検査成功（人工DOM回帰は通常CI）。
- B：**4凸通常ヒント名称の別公開資料との掲載照合は、対象全4,015件について達成**。22枚180件についてはGameTora専用通常ヒント欄と完全一致。原マスター全件・0〜3凸全件・正規数値スキルIDの完全性・ヒント性能値の同時点独立照合は未完であり、**Phase 1全体のBゲート完了ではない**。
- C：PlaywrightのLinux Chromium実ブラウザで**外部サイト**を見た監査であり、利用者の物理Android/Windows端末でのウマサルタントの受け入れ試験ではない。実機確認はまとめて管理。

次の作業候補：0〜3凸通常ヒント段階差、ヒント性能の別マスター照合、`201012`数値スキル辞書ギャップ、2026年実装スキルの`disp_order`入手とゲームUI順序照合、イベント経路承認のためのPhase 2の権利・元データ品質確認。
