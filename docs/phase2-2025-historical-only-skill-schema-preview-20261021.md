# Phase 2：2025年版マスターのみで裏付けた28スキルIDを使用した非公開試験変換（2026-10-21）

## 要旨

GameTora由来の固定イベント全2,488件を既存アプリのスキーマへ変換する際、**2026年UmaSim固定辞書にない79件の数値ヒント（28種類）**について、[旧2025年ゲームマスターによる独立照合](phase2-2025-master-missing-skill-overlap-20261021.md)により、全28IDの旧名称・通常/レア区分が存在することを確認した。

これを公開するゲーム情報には採用せず、**2025年限定の歴史的根拠**として隔離して、一時的なスキル辞書から技術的なスキーマ試験変換を行った。GameToraをイベントデータの正本として使用する基本方針は維持。GameWithは異常・矛盾箇所の裁定だけに使い、全件を再構築することはない。

## 固定ソース全件実測

## 実装と安全条件

- `poc/tools/crosscheck_missing_event_skills_2025.py`に、Runner内部の**指定された`RUNNER_TEMP/historical-master/`内だけ**に一時日本語スキル名を保存する機能を追加。GitHub Actionsによるアップロード対象`whole-event-output/*.json`に生文字列を置かない。公開の監査結果には、ID・レア度・件数・名称SHA-256のみを書き出す。
- `poc/src/historical_skill_dry_run.cjs`：2025年版マスター固定SHA・GameTora固定版・UmaSim固定版・元クロスウォーク79件の位置・数値ID・旧レア度・名称SHA-256を検証。全件一致時のみ一時実行辞書を生成。旧マスター由来スキルの`group`は実マスターの階層値とは独立の負数へ隔離し、金白の親子関係を勝手に生成しない。
- `poc/src/gametora_app_schema_dry_run.cjs`：従来の根拠付き補完ID2種11記載と**旧2025年限定の28スキルID**を別々に把握して試験変換。 `historical2025OnlyIdsAreNot2026Verified:true`を必須メタ情報として保持する。
- `poc/tools/probe_gametora_app_schema_dry_run.cjs`：旧マスターの補助資料を渡した場合だけ、2,449件など歴史的スナップショット限定の数値を再計算・固定検査。補助資料なしなら従来の2,347件を基準とする。
- 合成SQLiteとNodeテストで、証拠の偽ハッシュ・数値ID差し替え・欠落・版不一致・2025限定で後続が復帰することを検証。
- **本番イベントDBへは書き込まない。メモリ内だけの技術的変換**で、イベント・スキル名の元文も公開しない。

## 明確な限界と次工程

**2025年にIDと名前が存在したからといって、2026年のゲームに現在も同じ効果・名称で存在するとは断定できない。** 2026年版マスターの確認、GameToraやGameWithの現在記事と比べた版差の再検証、合法な表示文言、公開承認は未了。特に旧版だけの77件はそのまま「現行ゲーム確認済み」として本番採用しない。

次は**残る特殊分岐34件・連続前段4件・報酬重複1件**をより細かく調査し、GameToraの元構造で条件が表現できるものを優先して処理する。GameWithは疑義のある個所だけで参照し、確定できない項目は保留のまま。加えて旧2025年版でしか確認できない28IDを2026年資料で再確認する必要がある。

**今回時点の正式公開イベントは0件、現行ゲーム実測済みの連続経路も0組。**
