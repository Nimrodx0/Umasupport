# P2基礎研究：注目馬を固定して対戦相手の脚質構成のみ変更する実験（2026-11-05）

**結果：GlobalSimの順位条件成立割合は、相手脚質構成の変更だけで顕著に変化する。全局面・全順位帯・全コースで数値を共通化する根拠はない。実ゲームへの適性規則の採用、53スキルの脚質ラベル変更、P3/P4 UIへの反映は行わない。**

## 1. 何を固定して、何を変えるか

従来の[固定編成・同一シード比較](skill-position-fixed-roster-paired-control-20261105.md)は、編成間で同じ脚質に属する走者が異なったり、人数自体が変わったりしていた。今回の主目的は、この交絡を抑えて**同じ注目馬1頭**の順位を比較すること。

- **固定**：注目馬の脚質、枠番0、初期能力値、スキルなし、コース、頭数、モデル内部に与える乱数初期値。他の馬についても枠番・初期能力値は編成間で固定。
- **操作する変数**：注目馬以外の8頭／11頭の**脚質ラベルだけ**。3種類の人工編成を用意。
- **同一シードで対照**：同じコース・頭数・注目脚質・能力設定・シード番号を共有する3レースをペアとして比較。内部で脚質ごとに乱数の消費順序が異なる可能性は残るため、**内部の確率事象が同一だったとはみなさない**。
- **注目馬の枠番は常に0**。枠番全体に対する一般平均ではなく、統制実験である。

| 対戦相手の編成 | 9頭レースの相手8頭（逃/先/差/追） | 12頭レースの相手11頭（逃/先/差/追） |
| --- | --- | --- |
| 均衡型（基準） | 2 / 2 / 2 / 2 | 3 / 3 / 3 / 2 |
| 前方脚質多め | 3 / 3 / 1 / 1 | 4 / 4 / 2 / 1 |
| 後方脚質多め | 1 / 1 / 3 / 3 | 1 / 2 / 4 / 4 |

注目馬の脚質（逃・先・差・追の4通り）は表の相手8頭／11頭に**追加している**。対戦馬の具体的な枠番への割り当ては試行番号で共通規則に従って回転させ、3編成間で注目馬の属性は変えない。

GlobalSim固定エンジン v77（コミット \`80b54cacf174b54ff6f7ca27ee7f88b5856c0bd1\`）で、6コース×9/12頭×注目馬の4脚質×相手3編成×同能力/人工±10%能力差×20シード＝**5,760レース**。注目馬の序盤・中盤・終盤前半・終盤後半の4局面で、全記録時刻から線形補間し、追い抜き位置で分割した**1位から最下位までの走行距離割合**を算出。上位20/30/40/50/60/70/80%の7帯を評価。

- **評価値**：相手を変更した場合の注目馬の順位条件成立割合 **－** 均衡型の場合の同じ注目馬の成立割合。単位はパーセンテージポイント。
- 比較母数：6コース×2頭数×4注目脚質×2能力設定＝**96比較条件**／局面／順位帯／相手編成。各比較条件は20シードの対応差の平均。統合しても現実のゲーム対戦分布の平均とはならない。
- **欠測**：位置の曖昧さ・記録不足があれば同一シードの対照ペアを保留し、0%にしない。今回の固定実験は合計5,376比較条件すべて20ペアを取得、**保留0**。
- **統計上の制限**：同じ20シードを7順位帯×4局面でも使うため、比較条件は独立のレース数ではない。推定誤差は残る。

## 2. 終盤後半の上位50%では、相手構成が大きく効く

同じ注目馬で相手の脚質だけ変更したとき、上位50%以内にいた距離割合が、均衡型より増加／減少した比較条件数：

| 対戦相手の変更 | 増加 | 減少 | 同値 | 変化の絶対値の中央値 | 最大値 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 前方脚質多め | 28 | **67** | 1 | **10.98ポイント** | 54.50ポイント |
| 後方脚質多め | **78** | 18 | 0 | **12.41ポイント** | 46.90ポイント |

どちらも96条件（6コース×2頭数×4脚質×2能力設定）、各20シード。前方脚質の対戦相手を増やすと**同じ注目馬が上位にいる時間・距離は減りやすく**、後方脚質を増やすと**増えやすい**。ただし、符号が逆の条件もあるので単調な絶対法則ではない。

### 注目馬の脚質による違い

終盤後半・上位50%の、96条件を注目馬の脚質ごとに分けた**24条件の平均差**。この平均は実験セル同士を同等に扱う記述統計であり、実際の対人レースでの推定効果ではない。

| 注目馬の脚質 | 前方脚質多め－均衡型 | 後方脚質多め－均衡型 |
| --- | ---: | ---: |
| 逃げ | -8.39ポイント | +11.69ポイント |
| 先行 | -9.28ポイント | +7.18ポイント |
| 差し | -11.45ポイント | **+22.08ポイント** |
| 追込 | -0.79ポイント | +10.04ポイント |

**差し**はこの標本で後方脚質が増えると大きく上位50%条件に入りやすくなったが、これを実ゲームの一般効果量と呼ばない。注目馬は常に0番ゲート、全員スキルなしであり、対戦馬の脚質分布は特定の人工設定でしかない。

### 前半10シードと後半10シードの傾向

終盤後半・上位50%では、前方脚質多めの96比較条件中**58件**、後方脚質多めでは**70件**が、前半10試行と後半10試行で**ともに同じ非ゼロ符号**になった。残りの符号の不安定な条件に細かな補正値を採用する根拠はない。

## 3. レース局面によって影響の強さも違う

上位50%条件について、編成の変更による絶対差の中央値・増減方向を局面別に示す。

| 局面 | 前方多め：減少 / 96 | 絶対差の中央値 | 後方多め：増加 / 96 | 絶対差の中央値 |
| --- | ---: | ---: | ---: | ---: |
| 序盤 | **96** | 5.32ポイント | **88** | 13.75ポイント |
| 中盤 | **81** | 4.00ポイント | **69** | 10.00ポイント |
| 終盤前半 | **85** | 13.58ポイント | **86** | 12.34ポイント |
| 終盤後半 | **67** | 10.98ポイント | **78** | 12.41ポイント |

序盤の「前方多め」に対する減少96/96など、方向性が揃う条件もあるが、他の順位帯では同値が増える。順位閾値・局面・頭数により「50%」という同じ数値でも具体的な順位が異なるので、条件を跨いだ絶対率にはしない。

## 4. 規則の適用方針と限界

- **強く支持されること**：同じ馬・枠番・能力値・コース・入力シードでも、対戦相手の脚質構成だけの変更で、順位条件成立割合の数値が**数～数十ポイント単位**で変わり得る。従って**脚質×順位帯×局面ごとに固定の一般的「発動率」や占有率を置く単純化は不適切**。
- **まだ共通化できる可能性があること**：モデルの**前方群が前方順位に入りやすいという定性的な方向性**。ただし今回の実験は1頭をゲート0に固定し、対戦相手の構成を操作したので、群間の普遍的優劣を直接検証する設計ではない。前回の[1,440レース結果](skill-position-fixed-roster-paired-control-20261105.md)をあわせて扱う。
- **例外・不確かさ**：相手編成の変更によって内部乱数の使用順序も変わり得る。各条件20シードの前後半でも符号が一致しない場合がある。ゲームの標準的な脚質構成・能力分布・プレイヤーの行動・実スキル・LoHのNPCなどを再現していない。
- **現時点の実装候補**：スキルの順位条件／発動局面を解釈する**共通の基本規則**と、対戦相手構成やコースなどに関する**必要な場合だけの条件依存評価**を分ける。数値補正の採用基準は未決定。
- **実ゲームの発動率ではない**：測っているのは、固定GlobalSimモデルの**順位条件が成立していた走行距離の割合**。発動区間内の位置抽選、AND/OR、他者の行動、発動抽選、効果量の評価は含まれない。

## 5. 次に必要なこと

個別スキルへの数値割り当てを拡大するのではなく、**何を共通規則として採用できるかという判定基準**を設計する。今回の結果を踏まえると、**定性的な方向と定量的な成立割合を分けたモデル**が妥当な候補となる。数値側の採用には、対戦相手構成の代表性とモデルの不確かさの評価を明示する。

必要なら他のゲートでも注目馬の比較を再実行し、ゲート0固定の影響を評価する。さらに実ゲームのレース観測との照合なしに、モデル上の方向性を日本版の確定したスキル適性として採用しない。

**製品変更なし**：既存53スキルの定性的ラベル、サポカ集約、表示UI、公開イベントデータに今回の実験値を流し込んでいない。
