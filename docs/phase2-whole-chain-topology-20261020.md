# Phase 2③：全連続イベント到達構造の一次監査（2026-10-20）

## 検証したい仕様

[承認された5工程](phase2-whole-event-intake-plan-20261020.md)の第3工程は、サポカの連続イベントについて、前の**どの選択・結果が後のイベント／報酬の可否を左右するか**を全件で復元すること。**単に次の段階が掲載されていること、`chain_end` の記載がないことは継続の実ゲーム確認ではない**。イベント外部の発生率・絆・ターンは対象外。

今回の実装 `poc/tools/audit_whole_chain_topology.cjs` は第3工程の**全件の棚卸しと検証優先順位付け**であり、経路の確定やイベントDBの本番収録ではない。

## 入力と出典の境界

- GameTora由来固定JSON：`systemless10/UmamusumePS` の `6e38b54af4fad397ff4491e63007a90705a4fe67`。
- Checker結果・停止の観測：固定 `checker_explicit_result_facts.v1.json`。
- 旧2025年マスターの段階番号：固定 `checker_chain_stage_audit.v1.json`（独立マスター由来だが旧年度）。
- [第1工程の一意タイトル仮リンク](phase2-whole-event-intake-plan-20261020.md)、[第2工程の選択肢ラベル・結果別ヒント対照](phase2-whole-event-reward-audit-20261020.md)。
- `.github/workflows/whole-event-inventory.yml` はこの3段階を順に実行。元データはGitHub Actionsランナー上で一時参照し、第三者のイベント名・選択肢名・文章・元JSONを出力またはコミットしない。出力はID、位置、条件マーカー種別、数値件数とレビュー理由のみ。

## 監査する単位・不確実性

- **イベント／段階：** `section:"arrows"` のサポカイベントを全件列挙し、同一カードの掲載順から隣接段階ペアを作る。ただしこれは `UNVERIFIED_SOURCE_ORDER_ADJACENCY` であり、**実ゲームの接続や段階の存在条件を証明しない**。
- **選択肢：** 選択肢別に `outcomes`／`segments` の各経路の `chain_end` を検出。「全結果終了」「一部結果だけ終了」「終了マーカーなし」を区別する。ある結果だけ終了するケースでは選択肢全体を打ち切りにしない。
- **前段依存：** `both_previous_chain_good` 等のマーカー、`when` の成功・失敗条件を区別して保持。**前段結果による最終報酬差**と、**後続イベントの出現可否**は別の構造であり、混同しない。
- **Checker照合：** 同名イベント仮対応があり、選択肢の文言も一致または表記差だけのものに限り、両資料の終了マーカーの「存在」を比較。結果別の停止位置は無条件には合わせず、選択肢数・文言が不一致ならレビュー保留。
- **各カード：** 全体母集団563枚、GameTora JSON未収録4枚、サポカ連続イベントがないカードも明示。「未収録」「通常イベントのみ」「連続イベントあり」を混同しない。
- **ゲート：** `chainEdgesVerified:false`、`gameVerified:false`、`releaseApproved:false`、`forSkillGrant:false` を固定し、**隣接ペアの検証済み件数は0**のまま。実ゲーム内経路・別系統ゲームマスター等の追加根拠なしに自動接続しない。

## 2026-10-21：未裏付け152組の再分類

[PR #118の全件再実行](https://github.com/Nimrodx0/Umasupport/actions/runs/39513938717)で、従来「2025年マスターの段階番号の根拠不足152組」とだけ報告していた範囲を原因別に切り分けた。

| 原因 | 隣接候補 |
| --- | ---: |
| 2025年の完全な段階系列に一致（従来から） | 523 |
| **全体の系列は不完全だが、局所の2段階は連続・一意** | **15** |
| 両端とも2025年の厳密名寄せ段階が見つからない | 96 |
| 前段だけ旧段階照合ができない | 15 |
| 後段だけ旧段階照合ができない | 26 |
| **全件** | **675** |

順序証拠があるペアは、完全な旧系列からの523組に部分的な旧系列の15組を加えた**538組**。まだ旧マスターで段階順の裏付けがないペアは**137組**（96+15+26）まで細分化できた。137のうちRカード・新設カード・イベント改題がそれぞれどの程度寄与するかは、独立した直接名寄せで改めて調べる。

**15組は2025年の局所構造が互いに連続する証拠であり、2026年のイベントの出現・経路継続を検証した15組ではない**。経路正式認証は引き続き0組、公開DBの実イベントは0件。全152件のカードID、前後イベント位置、Checker候補ID、原因コードは数値のみの監査artifact `historicalGaps` として取得可能。

## 2026-10-21：GameTora対旧マスターの直接照合で47組追加

[最新の直接照合実測・詳細](phase2-direct-2025-master-chain-20261021.md)では、Checkerを介さずGameTora日本語イベント名と旧2025年の`story_id`見出しを突き合わせた。この方法で930連続イベントの名称が厳密に対応し、旧段階順の裏付けを持つ候補は**538→585組**へ増加。従来裏付けのなかった137組のうち47組を補完した。残る90組のうち**86組は該当カードに旧マスターの直結ストーリー行がなく、4組は行が存在するがイベントの名寄せが未解決**。段階順の矛盾例は0組。

これは過去の段階メタデータとの整合性であり、実ゲーム2026版の経路確定にはならない。**実際に到達できる検証済み隣接経路は引き続き0**。残る調査は2026年版の参照可能な数値マスター／第三者資料の範囲と利用条件を見極めた上で進める。

## 2026-10-21：明示終了の一致と「双方とも無記載」を厳密に区別

[第3工程の個別再調査](phase2-special-branch-review-20261021.md)で、従来「終了マーカーの存在が一致810位置」という数字の内訳を改めて計算した。

- **79位置**：両資料が明示的に終了マーカーを記載する（積極的な相互支持）。
- **731位置**：両資料とも終了マーカーなし（「終了しない」が検証された証拠ではない）。
- **1位置（`20023`）**：GameTora系データにだけ終了が明示され、Checkerに記載なし。片側の記載不足は論理的な矛盾ではない。
- **0位置**：Checkerにだけ明示終了。

これら811位置は日本語選択肢の文言が仮一致した位置だけであり、残る658位置の選択肢の同一性は未確認。今回のデータ/テスト変更は`chain_end`をゲーム内の実際の経路の確証へ昇格せず、矛盾の判定が過剰だった部分を修正した。

また、[2025年マスターの残差4組診断](phase2-special-branch-review-20261021.md)で、実際には2つのイベント段階が**旧2025年の完全同名・同一段階で複数story_idを持つ**ため一意対応ができず、残る1段階だけが名称94.1%類似の別表記であることを特定した。旧2025年の段階が記載されていない欠落ではなかった。直近の旧マスター段階順585組と実ゲームで検証した接続0組は変更なし。

## 次の完了条件

- 未確定の隣接ペアを、別資料の連続段階・打ち切り・継続条件・ゲーム版に照らして照合し、「継続確定・条件付き・終了・不明」に分類する。
- 実ゲームマスターあるいは独立したイベント順序データの**ストーリーID**と接続し、掲載順からの恣意的な後続ID採番をやめる。
- 条件付き報酬と条件付きイベントアクセスを区別し、元選択・結果を変更した場合の到達可否と報酬の回帰テストを全件DBに適用する。
- 出典・大規模採録の利用条件を検討。独自DB収録と本番公開は後続の独立ゲートとする。
