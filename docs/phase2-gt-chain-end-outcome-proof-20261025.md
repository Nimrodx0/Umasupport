# Phase 2：固定GTの結果別 `chain_end` とスキル側 `terminal` の一致照合（2026-10-25）

## 目的と事実の出典

従来の[固定GT非スキル全件監査](phase2-grand-live-lowest-and-full-energy-20261025.md)では、連続イベント内部の打ち切りを表す制御効果があるだけで結果全体を保留していた。元の効果`chain_end`は固定GameTora由来版`systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`の[パーサで`ee`として定義](https://github.com/systemless10/UmamusumePS/blob/6e38b54af4fad397ff4491e63007a90705a4fe67/server/app/gametora.py#L98-L116)され、[実行処理](https://github.com/systemless10/UmamusumePS/blob/6e38b54af4fad397ff4491e63007a90705a4fe67/server/app/event_engine.py#L1469-L1475)では当該チェーンの残りを終了させる。個別**結果ごと**に記載され、同じ選択肢の別結果に打ち切りがないこともある。

そこで`poc/src/phase2_gt_whole_nonskill_effect_inventory.cjs`で、元が`section:'arrows'`かつ効果が`{type:'chain_end'}`だけのパラメータなしレコードである場合、その**結果の末端**へ`terminal:true`を記載する。元からスキル系に`terminal`が存在したという意味ではなく、独立の非スキル元の同じ結果にのみ停止があることを表す。数値報酬が同じ結果にある場合も位置を移さない。

### 二重の安全ゲート

1. 非スキル元側の`chain_end`の由来・個数・パラメータ形状・`arrows`セクションを検査。連続以外の文脈・追加キー・重複マーカー・他種の制御フラグがある結果は隔離を維持する。`branch_flag`や先行分岐ガードを`chain_end`とみなさない。
2. 非公開の元スキル2,512イベントとの結合時に、カードID・元GTイベント番号・選択肢・結果／排他的OR親番号を照合した後、**対応するスキル報酬結果の`terminal`とGT非スキル結果の`terminal`がともに真またはともに偽か**を追加照合。一方だけ打ち切りならそのイベント全体を拒否する。`requires`・`terminal`・スキル報酬のSHA不変検証は継続。新規に連続イベントの前後接続は作成しない。

実装は`poc/src/phase2_gt_whole_nonskill_effect_inventory.cjs`、`poc/src/phase2_2512_private_effect_join.cjs`。合成A試験は`poc/tests/phase2_gt_chain_end_effect_join.test.cjs`で分岐別の停止、継続、OR分割での終了条件一致・不一致、異常形状の拒否を確認する。

### スキル側との結果ごとの照合

固定GT由来2,395イベントのうち**2,394イベント**で既存2,512件のスキル結果と同一位置・同一停止条件を維持したまま非スキル報酬を結合できた。統合した成分は確定数値**10,919**、状態操作**92**、動的報酬**22**。既存のスキルエンジンで563カードの`directRoutes`結果をSHA照合、公開版と同じ`preflight`／使い捨てモデル`attach`は全2,512イベントで合格。変更のないイベントは118件。例外は既知の**SSR30080イベント#6**で、元GTはauto／GameWithで個別裁定した本来の3択はchoiceであり、元GTの一括報酬を勝手に選択肢へ配らない。別の`SOURCE_TERMINAL_MISMATCH`は**0件**。

この「2,394件」は**固定データ由来のイベントのスキル＋非スキル結果を構造的に結合できた数**であって、ゲーム内のすべての連続分岐の独立照合済み数でも、正式公開データ数でもない。外部的なイベント発生確率は本プロジェクトの対象外であり、元の出典にない前段選択や新しいチェーン状態を捏造しない。
