# Phase 2：563カード／2,496イベントの非公開統合候補（2026-10-23）

## 概要

開発用の固定GameTora 559枚・2,488イベントは、本番集計エンジンに完全投影でき、出典短見出しも元位置・個別SHAと結合されている。一方、固定GTが持たないSSR30318〜30321の通常8件はGameWithから位置・数値を編集採用済みで、独立した[オンライン試用](phase2-eight-pages-browser-preview-20261023.md)は動くが、これまで**単一の全カードイベント候補**としては動作検証されていなかった。

本工程では、既存の2,488件の個別未署名台帳と[GameTora／Checker例外](phase2-source-exception-overlay-20261023.md)を根拠として、GameToraの元イベントIDを保ちつつ、確定済みの**SSR30080/6の操作3択補正**を1件適用する。その後、固定GTで欠ける4SSRへ通常8件を追加する。結果は **563枚・2,496イベント**の一時的な独自スキーマ形式となる。

## 実装の契約

`poc/src/phase2_integrated_private_catalog.cjs` は、すべて**未承認**の4入力（GT数値正規化、GTタイトル結合済みスキーマ、GTイベント個別SHA/未署名台帳、GT/Checker出典差異トリアージ）から組み立てる。

- 元GT2,488イベントのすべてについてカードID・イベントID・SHAを再計算して未署名台帳と突き合わせる。例外と診断されたSSR30080/6に限り、個別GameWith裁定済みの1→3択補正を適用。元の特殊発生条件を維持する。補正前と補正後のイベントSHAを別々に保持する。
- 4SSRを `sourceMissing:true` として元GTに収録していないことを確認。既存の`phase2_eight_release_candidate.cjs`が厳格に裁定・検証している通常2択×8件、ヒント4件だけを追加する。GTにはない連続12段階やSSR30240の未裁定3段階は混ぜない。
- 全サポカIDが重複せず、既存GTイベントはSSR30080/6以外の**2,487件がSHA不変**であることを検査。新たな全イベントの`event_schema.validateCatalog`と、4SSR通常8件の上／下選択・未選択に対する**実`UmaCore.directRoutes`**での個別ID/Lv照合を行う。
- CI実行中はJSON形式のイベント本文全体を**メモリ内にしか保持しない**。出力は件数、公開未承認状態、統合全体SHA、SSR30080の前後SHAに限定。元イベント・選択肢の原文は出さない。
