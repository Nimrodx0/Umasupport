# Phase 2：5SSRの連続15段階を本番イベント型へ加えた2,511件の非公開統合（2026-10-23）

## 目的

[2,496イベントの本番ローダー検証](phase2-integrated-private-loader-acceptance-20261023.md)まで進んだが、4枚の固定GT欠損SSR30318〜30321の連続12段階、SSR30221の連続3段階は、別の試用ページにしか存在しなかった。ユーザーは**明示的に打ち切りがなければ次段階のイベント解放フラグON**、出現のランダム性はアプリの評価対象外、と再確認している。[直近の決定](phase2-chain-ordinary-continuation-planner-20261023.md)。

これら5SSRの編集採用済み **15段階／22結果行／スキルヒント9件／フラグON17経路**を、既存の非公開2,496イベントカタログと統合する。もとの2,496件は内容SHAを変更せず、追加だけを行う。**563サポカ・2,511イベント**の開発用スキル経路がひとつの本番イベント型で動作可能になる。

## 技術的な契約

- `poc/src/phase2_2511_chain_runtime.cjs` は、元の未承認カタログSHA、公開許可フラグ、カードID、GameWith採用済みの15段階・22結果行・9スキル名とLv・17通常フラグの全件一致がなければ失敗する。元カタログを変更せず複製し、5カードに段階を追加する。
- 連続1段階は追加条件なし。2・3段階にはそれぞれ**直前のイベントIDを `requires.all` に登録**。選択肢なしの段階は `type:'auto'`、実際の2択がある段階は `type:'choice'`。通常ルートは `terminal:false` で扱うが、データに明示的な打ち切りが加われば本番コアはその選択肢／結果だけ次段階を遮断する。
- 数値IDをユーザー向けに表示せず、追加のヒント9件には固定UmaSim名と個別GameWith裁定済み「食いしん坊」を `verifiedSkillName` に対応させる。独自本文・GameWithの選択肢原文・画像は複製しない。
- 7選択式＋8自動＝15イベント。22結果行、9ヒント。元GT2,488／SSR30080の3択補正／GameWith通常8イベントという従来の構成と範囲はそのまま。
- `poc/src/phase2_2511_chain_loader.cjs` は `public_event_catalog.preflight`と`attach`を**一時複製モデル上だけ**で実行する。全ID・日本語名を固定スキル辞書で再照合し、全イベントの読込内容SHAを比較する。
- `UmaCore.reachability` と `UmaCore.directRoutes` は、各選択位置から次段階を開くか、前段未選択・明示終端でブロックするかを実計算する。SSR30221のように選択肢のない3段階は手動到達チェックなしで「食いしん坊」獲得可能経路につながる。

## 固定GT全件の実測結果（2026-10-23）

[全件GameTora監査Action](https://github.com/Nimrodx0/Umasupport/actions/runs/39924522343) **PASS**。実固定GT・独立2026名称補完・5SSR編集済みソースを組み合わせ、非公開 **563カード・2,511イベント**を `public_event_catalog.preflight`／`attach`へ投入して検証した。追加15段階・22結果行・9件のスキルヒント・17件の後続フラグは、実本番`UmaCore`で選択ごとに照合成功。

固定スキル辞書の既存ヒント名との統合1,155件、追加の数値スキルレコード270件。元イベントすべてのSHAは保持。変更前の元独自カタログSHA-256：`9a2521fc132428ca386680e3bbcf193d8c6ca3d5d1993ffb7bdea9dacd4bbf06`、本番の辞書照合後カタログSHA-256：`75ab7e4c99562ab2f2ddde64499764306438d086a0b598d09d7943e4262e860f`。2つは変換前／後なので異なる値が正常。

**修正履歴**：初回の合成テストでは、実スキル「解き放つ情念」のレビュー済みレア／通常グループを合成辞書が誤記したため拒否された。元辞書のレビュー済み上下関係 `203801/203802` を合成テストにも反映。全件試験では、ID201651「スリップストリーム」が既存モデルの`hint:スリップストリーム`へ正常に統合されることを、新監査が元数値IDと直接比較して誤検知した。**読込後のイベント報酬と実コア経路を比較**するよう修正し、本番前の数値ID／照合済み名は従来どおりローダーの`preflight`で検査。実数値の報酬は変更していない。

**正式公開イベント数0。** 2,511イベントを一般公開用DBに複写したわけではない。一般ユーザー向けの実機表示は、現行の5SSR連続試用ページのみ。公開条件・個別欠損等の編集は残る。
