## 正確に区別すべき4つの層

1. **出典から抽出できた事実**：固定GameTora由来ファイルに何件あるか。現行ゲームの全件網羅を証明しない。
2. **技術的にスキーマへ変換できた事実**：アプリのJSON・機構へ載せられるか。先行イベントの継続や報酬の実ゲーム上の正しさまで保証しない。
3. **ゲームで確認できた・別資料で裏付けた事実**：現行版への適用を別途検証したか。2025年の旧マスター名での試験は現行ゲーム裏付けではない。
4. **正式に配信してよい事実**：独自表現、承認台帳、出典・利用条件、公開ゲートを通過したか。技術的変換だけで公開に昇格させない。
