# イベント出典優先順位の実装契約と再発防止（2026-10-22）

## なぜ必要か

`AGENTS.md`・`docs/decisions.md`・[GameTora基準／GameWith裁定方針](gametora-baseline-event-policy-20261021.md) に、2026-10-21時点で方針は既に明記されていた。にもかかわらず、30321ドゥラメンテの連続2・3を「GameWith記事には明記されるが、第二の独立サイトや実ゲームで実証できない」として保留した。**これは文書の欠落ではなく、方針を参照・適用できなかった作業上の失敗**。PR #164で2件だけ訂正しても、新しいカードで同じ判断を繰り返す危険はなくならない。

既存の汎用数値裁定関数`poc/src/event_source_precedence.cjs`にも、**GameToraのベース数値が欠落している場合にGameWithの値が存在しても`unresolved-baseline-missing`を返す**挙動があり、欠損ならGameWithで裁定する規則と矛盾していた。この点も修正し、GT元サイトをカード単位で確認してから、GameWithの明示的な事実を選択できるようにした。

## 例外裁定の決定表

| GT固定元 | 対象カードのGT元サイト | GameWithの該当事実 | 編集上の決定 |
| --- | --- | --- | --- |
| 通常の値があり疑義なし | 必須ではない | 必須ではない | **GT値を採用**。GameWith全件照合は禁止 |
| 欠損／疑義あり | 確認した | 明示・矛盾なし | **GameWithを採用値として確定**。第二の独立サイトやゲーム実機確認を要求しない |
| 欠損／疑義あり | **未確認** | 明示 | **GT元サイト確認だけ未完了**。他社サイトの追加証拠は要求しない |
| 欠損／疑義あり | 確認した | **該当の事実が未掲載** | どの事実が未掲載か記録して保留 |
| 欠損／疑義あり | 確認した | **GameWith内部の明示的な矛盾** | 相反する具体的な記載を記録して保留。別のGameWithイベント個別記事が解決するならそれを調べる |
| 欠損／疑義あり | 確認した | **カード／イベント同定やスキルID不明** | 具体的なID・数値対応だけ保留 |

**「第二の独立サイト未確認」「ゲーム実機未検証」「再配布許可未取得」は、GameWithの数値・選択肢を編集上の採用値にする作業の保留理由として不許可**。ゲーム版の正確性が科学的に証明されたという意味ではない。外部イベントの発生時期・発生確率は再現対象外。イベント内部の選択／成功失敗や先行分岐は、掲載されている情報だけを採用し、不明な後続の打ち切り・依存は捏造しない。

## 実装した強制点

- **恒久的作業規則**：`AGENTS.md`に作業開始時の必須照合と、GameWith掲載事実に余計な第二証拠を要求しない原則を追加。
- **構造化設定**：`poc/config/event-source-priority.v1.json`の`exceptionAdjudicationContract`へ「明示的GameWith事実の採用」「第二編集サイト・ゲーム実機は一律の裁定必須条件でない」「GT元サイトのカード別確認」「正式公開と裁定は独立」を明示。検証器が契約値の変造を拒否。
- **共通判定器**：`poc/src/event_exception_adjudication.cjs`の`evaluateException`。カードID、GT元サイトURL・参照日・取得範囲、GameWith記事URL・参照日、報酬・選択肢の明示状況で裁定。**明示的な事実があるのに`PENDING`とすることを拒否**。GameWith未掲載・記事内矛盾など実在する保留理由のみ許可。返り値に`game2026Verified:false`・`publicationApproved:false`を別々に保持。
- **汎用数値優先判定の欠損修正**：`decideNumericEffect` はGT基準値がなくGameWith候補だけあるとき、GT元サイトの個別確認がなければ`pending-gametora-live-site-check`、確認済みなら`adjudicated-missing-baseline-by-gamewith`。GT値が正常なら引き続きGT採用。Game8だけでGTを置換しない。
- **既存30321の後戻り防止**：`poc/src/phase2_four_ssr_editorial_review.cjs`で、PR #164のGameWith裁定2件に共通判定器を適用。Checkerの元行・ヒントID・GameWith値の個別検査も維持。
- **必須CI**：`.github/workflows/ci.yml`に共通判定器、汎用数値裁定、30321の回帰テストを追加。新規判定器や方針の変更は`.github/workflows/whole-event-inventory.yml`の全件GT照合も起動させる。
- **PRチェックリスト**：`.github/PULL_REQUEST_TEMPLATE.md`に元サイト確認、GameWithの個別事実の明記／未掲載、裁定・後続条件・公開ゲートの分離を入れる。

## できることと限界

**CIで検出可能**：汎用数値判定器がGT欠損を一律未解決とする退行、GameWithの具体的な事実があるのに二つ目のサイトや実機を理由に保留する退行（共通判定器を使う経路）、カードIDに合わないGameTora元サイトの参照、未掲載を勝手に確定、30321の2イベントを未決に戻す改変、公開済みとして扱うフラグの取り違え。

**CIだけでは検出不可能**：今後のAIが共通判定器を意図的に呼ばず、調査結果を監査記録へ入力しない場合、GameWith記事の記載を人間／モデルが読み違える場合、実ゲームが記事から変化した場合、独立する記事が本当に独立した編集元かどうか。従って**チェックリストをPR作成時に確認し、既存の出典方針を作業開始時に読む運用**も必要。現時点でGitHubのブランチ保護ルールを追加し、これらのCIを管理者にも不可避の必須チェックに設定したとは主張しない。

## 再現できる負の試験

- GT欠損＋対象カードGT元サイト確認済み＋GameWithに数値明示：**採用**。
- 同じ記録なのに保留理由を「他社サイトの独立照合待ち」「実ゲーム再現待ち」「素材許諾待ち」に変更：**テスト失敗**。
- GameWithに値がなく、GT元サイトだけにイベント一覧がある：**該当事実を採用せず、本当に未掲載であれば保留**。
- GT元サイトURLが異なるカードIDを指す：**テスト失敗**。
- 元GTの正常値とGameWithの個別値があり、疑義なし：**GT値を保持**。
- 裁定済みでも`game2026Verified`と`publicationApproved`がfalseのまま：**通過**。

※ 追加のサイトは欠落発見のために参照できるが、既にGameWithで裁定できる項目の採用を妨げる理由とはしない。
