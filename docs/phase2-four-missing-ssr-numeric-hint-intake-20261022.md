# Phase 2：固定GameToraにないSSR4枚、20イベント・12ヒント数値候補を取り込む（2026-10-22）

## 何を取り込んだか

[GameTora固定データで欠落した4SSR](phase2-missing-gametora-cards-20261022.md)（カードID`30318`〜`30321`）について、固定Checker由来の**未承認イベント候補各5件**を、元の候補IDと選択肢行順序を維持したまま、**非公開の数値スキルヒント候補**に変換した。これまで4枚が「イベント候補が各5件ある」だけだったところから、実際の**どの候補イベント・どの選択肢に、どのスキル数値IDのヒントLvが記録されているか**まで位置を追跡できるようになった。

| 項目 | 固定CIの実測 | 制限 |
| --- | ---: | --- |
| GT固定元にサポカのイベントファイルがない | **SSR4枚** | ゲーム内にイベントがない意味ではない |
| Checkerが持つ候補イベント | **20件**（各5件） | 現行ゲームの全イベントを立証しない |
| Checkerで区切られた効果・選択肢の行 | **35行** | **実際に選択できる35通りと解釈しない**。条件分岐も含みうる |
| 連続イベントと思われる段階 | **12候補** | 各カード先頭3件という出典の掲載順に基づく**暫定分類** |
| 通常イベントと思われる項目 | **8候補** | 同じく暫定分類 |
| 2026年の独立スキル辞書へ一意に対応したヒント | **12記載** | **取得可否・分岐の正しさは未確認** |
| 日本語名の正規化で直接一致 | **11記載** | スキル名が同じこと以外の証拠は別 |
| 一点限定の`○／◯`表記差を確認した一致 | **1記載** | `良バ場○`のID`200152`へのみ対応し、`良バ場◎`と混同しない |
| 結果・選択操作の独立検証が不足 | **20候補** | 正式公開へ一件も昇格させていない |

## 元イベントの位置に結びついた数値事実候補

ここでの位置は**Checker内の1始まりイベント番号と、その内側の効果・選択肢の行番号**。GameToraで存在しないイベントの番号を捏造していない。各スキル数値IDは`Tsuyuchan-jp/umamusume-data@0cacbb1aaf9dca10283d5b9ea20b205b9d204535`の2026年10月版スキル名データへ照合した（固定名IDへの1対1対応）。**ヒントLvもCheckerの文字列を数値化した技術候補**で、別途攻略資料との報酬・条件照合が必要。

| カード | Checkerイベント位置／行 | 記録されたスキル数値ID：ヒントLv |
| --- | --- | --- |
| **30318** ライスシャワー | 3／1、5／2 | `201323`:Lv1、`200152`:Lv1 |
| **30319** ナリタブライアン | 2／1、3／1、5／2 | `204412`:Lv1、`202371`:Lv1 ＋ `204151`:Lv2、`201641`:Lv1 |
| **30320** アドマイヤグルーヴ | 2／1、3／1、5／1 | `201651`:Lv1、`203801`:Lv2 ＋ `204721`:Lv1、`202082`:Lv1 |
| **30321** ドゥラメンテ | 3／1、5／2 | `201463`:Lv1、`202602`:Lv1 |

**重要な留保**：同じ行に2ヒントの記載があっても、そのイベントで両方とも実際に取得できるか、前段の選択・成功失敗が影響するかはこの台帳では確定していない。**12ヒント獲得可能と計上しない**。標準ヒントでの保有カード数や公開アプリの提供枚数には追加しない。

## 技術的に確認した厳格な保存則

- 元出典：`Cilda/UmaUmaChecker@8cf9fcb3cc7239041161be75c84daf9f8f22d29f` の`Events.json`と、UmaSim固定サポカID／属性。4枚のカードがGameTora固定元にないことを**別の563枚台帳**で確認。
- スキル名／ID対応：2026年10月4日版 `Tsuyuchan-jp/umamusume-data@0cacbb1aaf9dca10283d5b9ea20b205b9d204535` の`skills.json`。元ファイルのGit blob SHA・SHA-256とChecker・UmaSimのハッシュを検証する。
- `poc/src/missing_four_ssr_skill_fact_candidates.cjs`：20イベントの元`sourceKey`、元イベント内容の`sourceDigest`、元タイトルハッシュを一対一で照合。効果テキストから`ヒントLv`が見つかったのに一意のID／Lvにできなければ**fail-closed**。対応できる1件だけ`○／◯`を個別変換、名前が重複・変化したら拒否。
- `poc/tools/build_missing_four_ssr_skill_fact_candidates.cjs`：元テキストは**CIの一時メモリ上で読むだけ**。元イベント名・選択肢の文章・効果文章・スキル名の一覧は結果JSONやログへ転載しない。出力は`whole-event-output/missing_four_ssr_numeric_skill_candidates.v1.json`だけで、GitHub Actionsの一時監査成果物。公開用`poc/data/reviewed_events.v1.json`へ書く経路はない。
- `poc/tests/missing_four_ssr_skill_fact_candidates.test.cjs`：IDや出典・候補件数の改変、未解読のヒント記載、名前の不一致、レアリティの混同・出力文章混入を拒否。

## 独立した確認が必要な次の工程

カードの登場自体は公式情報でも確認できる。2026年9月30日ガチャ： [Cygames公式お知らせ](https://dmg.umamusume.jp/news/detail/?id=3467)（30319／30320）、イベント限定配布：[Cygames公式お知らせ](https://umamusume.jp/news/detail?id=3481)（30321）。それぞれの**イベント内報酬・分岐の現在性**は別途確認する。

個別の疑義裁定に利用するカード別攻略資料：[30318](https://gamewith.jp/uma-musume/article/show/578814)、[30319](https://gamewith.jp/uma-musume/article/show/578819)、[30320](https://gamewith.jp/uma-musume/article/show/578818)、[30321](https://gamewith.jp/uma-musume/article/show/578817)。これらのページが存在するというだけで、12件を独立検証済みへ昇格しない。CheckerはGameWith派生である点にも注意する。

この後は**20イベントそれぞれの連続内部の順序・選択できる枝と成功失敗・ヒント報酬、特に前段結果の依存・途中終了を個別に検証**する。次いで第三者の表現転載を避けた独自の名称・出典・権利判断・レビュー承認へ進む。A＝人工単体、B＝固定Checker・2026スキルIDの20件全件照合、C＝2026現行ゲームとWindows/Android実機（未実施）。技術候補とゲーム確認済み、正式公開とを混同しない。
