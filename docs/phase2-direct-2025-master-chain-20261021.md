# Phase 2③ 追補：GameTora系イベントと2025年旧マスターの直接名寄せ（2026-10-21）

## 背景と成果

従来の連続イベント675組の掲載順照合は「GameTora系 → Checker候補 → 2025年の固定master.mdb」という三者連結だった。2025年マスターの段階構造で裏付けられたのは**538組（完全な旧系列523、局所的に段階が連続する不完全旧系列15）**で、**137組**が2025年名寄せ段階データの片端または両端で未照合だった。

今回、この不一致137組を対象としつつ**全675組**について、**GameTora系の日本語イベント名から2025年master.mdbのcategory=181イベント見出しを直接照合**。従来のCheckerイベント名の存在や照合キーに依存しない別経路の検査を実装した。

[PR #119の固定2025年マスター直接照合・実測](https://github.com/Nimrodx0/Umasupport/actions/runs/39514591150)の結果：

| 検査項目 | 件数 |
| --- | ---: |
| 全カードと固定GameTora系の連続イベント | 563枚、1,069イベント |
| 2025年旧マスターとの日本語名称厳密一致（連続イベント） | **930イベント** |
| 掲載上隣接する連続イベントの候補 | 675組 |
| 従来のChecker経由で旧段階順を支持できた候補 | 538組 |
| **Checkerを介さない直接照合で新たに旧段階順を支持した候補** | **47組** |
| **直接照合でも旧段階順が一致した候補** | **585組（86.7%）** |
| 2025年マスター上で段階順が矛盾する候補 | 0組 |
| 直接照合でなお旧段階順を付与できない候補 | **90組** |
| 上記90組のうち2025年マスターに該当カード直結ストーリーがない | **86組** |
| 上記90組のうち直結ストーリーはあるが一部イベントの直接名寄せができない | **4組** |

2025年マスターの `single_mode_story_data.story_id` から `text_data(category=181, index=story_id)` を照合。**master内部行IDとstory_idを区別**。次に同じカードIDのGameTora日本語イベント見出しと正規化して厳密に一意一致するものだけ仮リンク。重複イベント名、マスター側の重複段階（同一カード、同じchainMax/groupFlag/stage）、旧マスターの段階の不一致は証拠として採用しない。原名・元テキスト・第三者JSONや元master.mdbは出力せず、カードID、ソース内位置、2025年の数値story_id、該当理由のみを一時アーティファクトへ保存。

**585組の意味：** 2025年旧データに掲載された段階番号とGameTora系ソースのイベント名・順番が整合した、という**歴史的な構造の裏付け**だけ。2026年のゲーム内でイベントが必ず順次発生すること、特定の選択肢で打ち切り／継続すること、実ゲームの獲得スキルが一致すること、権利上アプリに原文を含められることは証明されていない。**実ゲーム経路の認証済み件数は0組**。

## 次の優先作業

今回の90組は**86組で2025年の該当カード直結ストーリー行がなく、4組は直結行が存在するが一部のイベント名が直接名寄せできなかった**。前者は旧マスターがそもそも対象カードを含まない可能性と直結イベント未収録を区別する必要があり、後者はカードIDとイベント位置を特定して表記差・改題・候補名の重複を重点調査できる。旧2025年マスターにない新設カードの場合は、2026年版の新しいマスター、または同時期の独立したゲームイベント資料を探す必要がある。古い版から2026年現在のイベントが削除・追加・改題されたと推測する前に、版情報を確認する。

第3工程の本当の完了には、**675候補の現行イベント到達可否、全分岐での打ち切り、前段成功／失敗による条件の意味**を実ゲームまたは適切な独立証拠と照合する必要がある。今は旧マスターの段階順を極力回収した段階であり、実ゲーム確認や公開ゲートの代わりにはならない。
