# 旧ゲームマスターと現行UmaSimの限定的クロスチェック

更新：2026-10-17　関連：[検証計画](verification-plan.md) / [スキル監査](skill-hierarchy-coverage.md)

## 目的

2026年のスキル分類と独立に収集されたゲームマスターの対応を、利用可能な過去の実データで実測する。ただし**古いマスターで2026年の322組全件を確認できたとは解釈しない**。

## 実行方法と安全性

[限定的GitHub Actions](../.github/workflows/historical-skill-master-audit.yml) は、ワークフローファイル自身のPR変更時または手動のときだけ実行する。**通常CIとPages起動に外部取得は増やさない**。固定版の公開データを一時的なランナーディレクトリへ1回ずつダウンロードし、終了時に破棄する。第三者生データをこのリポジトリ、公開JSON、Actionsアーティファクトに保存しない。ログには件数、判定分類、SHA-256のみを出す。

`poc/tools/verify_skill_master.py` をあえて `--strict` なしで呼び出す。古いマスターに存在しないIDが大量にあるのは予測可能であり、同時期の完全一致と偽って失敗させない。

## 判定の意味

- `independent_master_order_agrees`：両版に同じIDがあり、グループ・金白レアリティ・昇格順序も一致した。
- `master_missing`：2025年版に2026年のIDがない。2026年データの誤りとはいえない。
- `master_extra_group_members`：同じグループの構成員が2025年版と異なる。版差・解析の問題を追加調査。
- `master_rank_order_conflict`：共有IDの昇格順に不一致。データソースまたはロジックを調査。
- `master_supports_no_lower_in_snapshot`：2025年版にも白下位がない。2026年版の不在を保証しない。

## 実測結果（2026-10-17、固定コミット）

初回実行：[Actions #38937045493](https://github.com/Nimrodx0/Umasupport/actions/runs/38937045493) / **成功**。2025年マスターのスキル行は1,847、2026年UmaSimは2,139。以下は**2026年UmaSimでの金325群**を全入力として判定した内訳。

| 分類 | 金スキル系列の件数 | 解釈 |
|---|---:|---|
| ID・グループ・レアリティ・昇格順が旧マスターと一致 | **269**（修正監査器で再確認待ち） | 旧版とのクロスチェックを通過 |
| 旧マスターに構成IDが足りない | **53** | 新規追加・版差の可能性。現在の誤りとは断定しない |
| 旧マスターの同グループ内に追加の**非昇格（group_rate=-1）**IDがある | **18**（269に含まれる） | 全18件の負値を実測。昇格系列から除外し、差分ではなく補足情報とする |
| 白なし候補で旧マスターでも同グループに白がない | **3** | **旧版時点の**不在を再確認 |
| グループ・レアリティが食い違う／昇格順が逆転 | **0** | 同じIDが揃った比較では直接矛盾を検出せず |
| **合計** | **325** | 269 + 53 + 3（負値IDの18組は269に含む） |

初回の素朴な照合器では**251組**を一致と数えていたが、構成差とした18件を [追加実測](https://github.com/Nimrodx0/Umasupport/actions/runs/38937531528) で調べると**全件 `group_rate = -1`** だった。これは昇格系列とは別の補助レコードであり、[Wikiのグループ抽出処理](https://umamusu.wiki/Module:Game/Skills/Data/Groups) も負値レコードの除外に対応する。この仕様を反映した結果、**269/322組（83.5%）が歴史的な独立マスターでの一致候補**となり、**残る53組**は2025年版への収録がない。修正後のActions実行で再計算してから確定とする。

- UmaSimデータ SHA-256：`b7ba1d6c5dd2af9ed1f4e649f16ec1d319198e2f1ac9db07c54e14d29f0b25ec`
- 2025年マスター SHA-256：`46363929ab097edf164d78a1e8f8d212dbf8c440a7c44431079198ca167002cb`
- 厳格全件ゲート：**未通過**（`passed=false`）。元データに約1年の版差があるので想定内。

この結果から2026年の全322組が完全に確定したとは扱わない。負のグループレートを持つ18件は階層から除外すべき非昇格レコード。2025年版にない53件のため、現行全件照合ゲートは未通過である。

**Phase 1のB（現行322組の独立全件確認）とC（Pages/スマホ実機）は引き続き未完了。**
