# Phase 2：SSR30180「あなたを想って」数値スキルヒントを非公開全件へ補完（2026-10-23）

## 発見した実際のスキル経路差

[16位置の全件Checker数値ヒント比較](phase2-remaining-checker-skill-impact-20261023.md)で、Checker側の唯一の未収録数値ヒント候補が**SSR30180「刻み続ける者たち［この先も！］」のイベント位置7**、数値ID `200332` であると判明した。ID200332は「コーナー巧者○」で、同カードの従来の固定GameToraイベント報酬には存在しない。

現行[GameToraの当該カードページ](https://gametora.com/ja/umamusume/supports/30180-group)を確認後、[GameWithの対象カード記事](https://gamewith.jp/uma-musume/article/show/431692)に記載された次の明示事実を編集採用する。

- イベント短見出し：「あなたを想って」
- プレイヤー選択：**なし（0択）**
- スキル：「コーナー巧者○」、ヒント**Lv1**
- 固有の発生タイミング：**クラシック級1月前半**。これは外部のイベント発生条件であり本アプリではタイミング／発生抽選を計算しない。
- 同じGameWith記事にはステータスや絆の増減も載るが、現行アプリはスキル経路が目的であるためイベント型へスキルヒント1件のみを投影する。ステータス報酬を表示・集計する機能は別工程。

GameTora由来固定モデルにこのIDのイベント報酬がない事実は、**GameWithの明示的な欠損裁定として十分**。二つ目の攻略サイト、実ゲーム内での直接観測、内部story IDの推定を必須とはしない。[GameTora優先→GameWith疑義裁定契約](event-adjudication-enforcement.md)に従う。

## 実装境界

`poc/data/curation/adjudicated/30180_missing_special_hint.v1.json`に、カード版／元GT固定版と記事URL／選択数0／ヒント数値ID200332／Lv1／外部タイミング／出典編集採用と公開承認の別を固定した。

`poc/src/phase2_30180_special_event_overlay.cjs`は、次の条件を確認した場合だけ、すでに検証済みの非公開**全2,511件**へ**1件**を追加する。

1. 数値IDを優先順位検査する既存の16位置監査が、SSR30180・Checker位置7だけを唯一のP0、ID200332未収録候補と認めている。
2. GT元カタログのSHAが一致し、同じIDのイベントまたはスキル報酬がSSR30180のイベント内にまだない。
3. `usl:30180:special:checker-007` という独自IDで `type:auto`、`availabilityKind:special-trigger`、`rewards:[{skillId:"skill:200332",level:1,verifiedSkillName:"コーナー巧者○"}]` とし、選択肢が存在するという誤解を与えない。
4. `UmaCore.directRoutes` のヒントID/Lvが一致し、既存2,511件の元SHAは変更しない。
5. GitHub Actionsの固定563カード・2,511元候補と合わせて、**非公開2,512候補**を実`public_event_catalog.preflight/attach`へ渡す。実本番辞書に解決されたスキルIDとイベント経路を再照合する。カタログ本体はログにもリポジトリにも配布しない。

## 注意点

これは**実際にイベントでスキルが獲得可能になるというGameWithの明示事実**を、スキル獲得経路の技術候補へ移す修正である。外部トリガー「クラシック級1月前半」が必ず発生するかどうか／いつ発生するかはモデル化しない（ユーザー確定仕様）。独自の表示名を使い、第三者の文章・画像を無断転載しない。

**正式公開イベント0件は不変**。数値編集採用は公開承認の代用ではない。既存Checker差異65位置やSSR30240連続3段階の保留状態も変更しない。カード単位で数値ヒントの未収録候補が一つ解消したことと、Checker全体のイベントID同定が全件済んだことを区別する。
