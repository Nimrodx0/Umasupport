# 詳細計画の入口

[上位ロードマップ](../roadmap.md)は工程の**順番と依存関係**を示します。この場所では、各工程を独立して進捗判定できる小工程へ分割します。最新の実測値・公開件数は[status](../status.md)、研究根拠は[evidence](../evidence/README.md)を参照します。

| トラック | 詳細計画 | 管理対象 |
| --- | --- | --- |
| 製品完成 W1～W5 | [製品の詳細計画](product.md) | 公開イベント受け入れ、例外、新カード増分、差異、運用 |
| スキル研究 P0～P5 | [発動条件とカード傾向](skill-conditions/index.md) | 構造、モデル、研究、集約、UI、検証 |

上位工程の成果物・依存関係・受入条件は[WBS Dictionary](wbs-dictionary.md)で管理しています。

## 小工程の管理単位

各小工程に **ID・実施内容・状態・結果・根拠・終了条件** を記載します。状態は「完了（記載した範囲）」「部分完了」「未完」「未着手」「保留」を区別します。

研究器が完成したことをアプリへの実装・公開完了とは呼びません。A（機構）・B（データ）・C（実環境）も別々です。調査結果や反例は[evidence](../evidence/README.md)へ保存し、ここにはそれを追うためのリンクと判定だけを記載します。

進捗が増えた場合は**該当IDの行を更新**し、新しい検証課題は下位IDを追加します。既済結果を同じ段落へ連結し続けません。
