# P2：4脚質別・二軸の発動条件適合性研究

[工程一覧](index.md) ／ [P1](p1.md) ／ [P3](p3.md) ／ [現在の実測](../../project/status.md)

## 確定した考え方

逃げ・先行・差し・追込は**4脚質独立**で比較します。①**条件成立機会**、②**脚質特異性**は別々の研究指標です。③**発動後の効果の有用性**は別軸で将来検討。従来の前方／後方2群は参考にとどめます。

**目的と研究継続の判断**：最終的に、スキルの**脚質・距離・馬場の3軸**について①明示的適用範囲と②発動条件の満たしやすさを区別し、P3のサポカ単位集約へ渡す。③発動後の効果の有用性は将来保留。**展開由来の非明示的な成立傾向の研究主軸は4脚質**とし、距離・馬場は明示条件を基本に必要な場合だけ条件相互作用を調査する。スキルごとの大まかな4脚質適性を説明することが現在の主要研究目標。細部の完全再現は不要だが、十分な根拠がないまま研究を終了することも目的ではない。研究の追加は「説明できないスキル数・未解釈条件・想定反例」と、追加調査で推定が改善する見込みを根拠に判断する。

**2026-11-11の利用者承認方針（[D-045](../../decisions/log.md#decision-d-045)）**：`track_id`・`distance_type`・`ground_type`などの明示的なレース条件は、まず**スキルの適用範囲を決める条件**として保持する。**対象外のレースを脚質適性の「低さ」や0点として集計しない**。ただし距離・競馬場・馬場が、別の順位・追い抜き・局面条件の脚質別成立傾向を変化させ得るため、「適用範囲」と「文脈との相互作用」は排他的でない。**未検証の相互作用を「影響なし」と見なさず、元の条件と比較設定を揃えて調べる**。詳細な方法・数値は[P2.17](../../evidence/skills/skill-p2-17-distance-context-style-gap-20261112.md)。正式な脚質適性とP3の集約はなお未決定。

GlobalSimにおける順位帯占有率や10m条件成立割合は**実ゲームのスキル発動率ではありません**。従来の「均衡編成のみをP3標準に渡す」方針は**いったん暫定比較基準の位置付けに戻して再検討**します（2026-11-11利用者指示）。まず複数の脚質構成・9/12頭・コース・能力条件で**共通して認められる脚質ペアの成立機会の傾向**と、逆転・同値・欠測を分離する。これにより、代表条件を一つ選べなくても、対象範囲が明確な頑健性を研究できる。**P3/P4への正式な採否・表示規則は未決定**。AND/OR・複数Invoke・欠測がある場合、部分条件からスキル全体の高／低を決めません。


## 研究継続・保留・P3試作へ進む判断（2026-11-13引継レビュー）

この節は**次の研究の選び方と研究用引渡しの確認項目**を整理するものであり、既存の[D-045](../../decisions/log.md#decision-d-045)、正式な脚質適性閾値、カード評価、公開判断を変更しない。P2全体の終了認定やP3/P4製品実装の承認でもない。研究の目的はゲーム実装を全条件について再現すること自体ではなく、**元スキルごとの脚質・距離・馬場の3軸について、明示的な適用範囲と成立機会の違いを不確実性込みで説明できるようにすること**である。非明示的な成立傾向は脚質を主な研究対象とし、距離・馬場は簡易検証で重要性と一般化可能性を判断する。

### 利用者承認の省略基準と3軸の研究資源配分（2026-11-13）

**条件を「元データに存在しない」とするのではなく、「適性推定では影響を無視してよい」と根拠付きで判定する。** 研究追加を決める前に、元のAND/OR・複数Invoke・preConditionsの経路と明示制限を確認し、対象スキル・対象レース群・3評価軸ごとに、追加条件の省略でどの判断が変わり得るかを簡易に監査する。

| 区分 | 研究・評価上の扱い |
| --- | --- |
| 明示的な脚質・距離・馬場・競馬場等の適用制限 | 常に保持・適用する。対象外は発動機会0点や低適性とは別の「対象外」とする |
| **ゲーム仕様上**3軸の固有差と独立、元論理構造上判断へ影響しない、または同一比較条件の感度試験で無視できると示された条件 | **詳細研究を省略可**。推定時のみその条件の影響を省略し、出典式と省略した理由・根拠・比較時の固定前提を残す |
| 相対的優劣は変えないが、発動機会の絶対的大きさを強く制限する条件 | **一律省略不可**。二軸を別々に検証する |
| 未測定、影響を否定できない、反例がありそうな条件 | 条件付き／未判定として保持。調査を後回しにしても「無影響確認済み」にしない |
| 一部のコース・編成のみ結果が異なる条件 | コース・編成依存として記録し、その一例から全条件の適性を推定しない |

**根拠の優先順**：まずゲーム仕様と元条件の論理構造による定性的な判定を行う。例えば「コンディションが絶好調」という状態条件は脚質・距離・馬場を直接選別しないため、各軸を比較するときコンディションを同じ状態に固定するなら、3軸の相対的な違いを調べる目的でその状態条件のシミュレーションは不要。ただし絶好調がスキル自体の発動を制限する事実は残す。状態が固定されない実レース全体の成立機会を推定するときは、状態の分布や他条件との関係が必要となり、ゲーム仕様がそれを保証しないなら未知として区別する。**仕様・論理だけで判断できない条件に限り**簡易的な対照・感度検証を行う。条件の種類だけでなく、どの評価軸・前提で省略可としたかを記録する。

**検証の最小単位**：原スキル・適用レース・脚質／距離／馬場の比較単位を一致させ、可能なら同一モデル走者・同一時刻の条件を含む／除く対照比較を用いる。省略により、条件成立機会の大きさ・4脚質間の相対比較・距離や馬場間の傾向・未判定がどう変化するかを見る。影響の上限が未確定なら、推定可能な範囲と保留を分け、試験したごく一部のスキル・条件から全件の省略可否を推測しない。**正式な「無視できる差」の数値閾値は未決定**であり、既存研究の仮5ptなどを自動採用しない。

**3軸の研究優先順位**：脚質は順位・位置・追い抜きなどの非明示的な条件を重点調査する。距離・馬場は明示的な条件を全件扱い、非明示的な差について[既存P2.17](../../evidence/skills/skill-p2-17-distance-context-style-gap-20261112.md)・[P2.17b](../../evidence/skills/skill-p2-17b-distance-split15-20261112.md)を出発点に、**同一元スキル条件に対する距離別／芝ダート別のWの大きさ**を直接比較する。P2.17で研究した**距離を変えた際の「脚質ペアのW差」の変動**だけでは、同一スキルの距離適性自体は決まらない。芝ダートと馬場状態を分ける。

**距離・馬場の簡易調査の終了条件**：比較可能な元条件・コースとモデルの制約を明示し、(a)判断を変えるほどの実用差があるか、(b)複数コース／編成等で方向や規模が一貫するか、(c)距離の長さとコース形状・コーナー配置・直線・芝ダートの交絡がどこまで分離できるか、(d)明示制限と未知の全ANDを維持しているか、を検査する。**実用差が小さい／一般化できないという根拠が得られた範囲は深掘りを終了**し、明示制限を基本にする。重要な反例は限定的な追試の対象とし、特定コースの特徴を「短距離に有利」等へ一般化しない。**根拠不足による打切り**は「影響なし」とは別の研究保留として記録する。

関連する確定判断：[D-045の2026-11-13追加承認](../../decisions/log.md#decision-d-045)。正式なP3採点・P4ラベルの採否は引き続き独立ゲートとする。

### 追加研究の事前判断

| 確認事項 | 継続の判断材料 | 満たさない場合 |
| --- | --- | --- |
| 製品目標への影響 | どの元スキル・脚質・適用レース文脈の判断が、現在の未観測条件によって変わり得るかを示す | 未判定件数の多さだけを理由に、元述語を順番に実装し続けない |
| 出典と観測可能性 | 元条件の演算子・AND/OR・Invoke・事前条件履歴を保ち、別モデルの観測値で検証できるかを明示する | 原UmaSimで未実装・無視される述語を、別モデルの値だけでゲーム上の事実へ昇格しない |
| 比較の妥当性 | 同じ元条件と対象コース・距離・馬場・頭数・編成・能力・シード範囲のうち、比較可能な母数と欠測を脚質別に示す | 異なる母数の成立**件数**や単純合算から、4脚質の優劣を決めない |
| 検証の増分 | 既知の真／偽と未判定の変化だけでなく、脚質間の**比較判断**・逆転・保留がどう変わったかを報告する | 未判定だけが減り、判断改善が説明できない研究は優先度を見直す |
| 外挿の根拠 | 固定モデル・元UmaSimランタイム・実ゲーム観測を分け、モデル間の差・技能装備の有無・独立検証を記載する | 固定モデルの多数のtickやseedを、実ゲームの発動確率・統計的な独立試行に読み替えない |

対象を選ぶ際は、既存の[P2.26～P2.28](../../evidence/skills/skill-coarse-four-style-review-20261111.md)の広い母集団と、[P2.15](../../evidence/skills/skill-p2-15-source-corner-full-join-20261113.md)の限定された全条件研究を区別する。P2.15の固定253元スキル×8無スキル人工モデルレース（21,252元スキル×走者×レース単位）の成立件数は、異なる脚質の出走・対象母数を補正した比較でも、元UmaSimの実スキル装備時や実ゲームの発動率でもない。特に固定UmaSimで無視される`order`／`order_rate`を外部の順位値へ対応させた結果は、仮定付きのモデル条件解釈として残す。

### 研究用P3への限定引渡し

1. P2で元スキルID・対象レースの適用範囲・元条件の経路・モデルと出典の版・確認できた条件・未判定を独立に記録する。
2. 比較対象の脚質がいない、対象外レース、未観測、固定モデルでは成立しなかった、元データ未収録を区別し、いずれも根拠なく「低適性」や0点にしない。
3. 一部の元条件についてだけ根拠がある場合も、[P2.18](../../evidence/skills/skill-p2-18-research-evidence-contract-20261112.md)のような**研究専用・正式採点不可**の契約でP3の同定・取得経路・仮の表示方式の検証を並行してよい。元全条件の成立やモデルから実ゲームへの外挿は未検証と明記する。
4. 正式なスキル適性・サポカ採点とP4公開に進むには、出典ID・対象範囲・十分な検証結果・未判定の扱い・評価基準を独立に審査し、利用者の未決定事項を先回りして確定しない。

**次のP2作業**：未マージの[PR #434](https://github.com/Nimrodx0/Umasupport/pull/434)の仮定と検証範囲をレビューする。次に**P2.32**の省略可否の最小影響監査と**P2.33**の距離・馬場の簡易一般化検証を、既存のP2.15～P2.31研究成果を再利用して設計する。元モデルの事前条件履歴・追い抜き状態・他スキル発動依存は候補だが、未知件数の多さよりも3軸の適性判断への影響を優先する。
