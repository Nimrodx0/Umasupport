# P2：4脚質別・二軸の発動条件適合性研究

[工程一覧](index.md) ／ [P1](p1.md) ／ [P3](p3.md) ／ [現在の実測](../../project/status.md)

## 確定した考え方

逃げ・先行・差し・追込は**4脚質独立**で比較します。①**条件成立機会**、②**脚質特異性**は別々の研究指標です。③**発動後の効果の有用性**は別軸で将来検討。従来の前方／後方2群は参考にとどめます。

GlobalSimにおける順位帯占有率や10m条件成立割合は**実ゲームのスキル発動率ではありません**。標準P3へ渡す基準は**均衡編成のみ**で、他の編成は感度研究として保持します。AND/OR・複数Invoke・欠測がある場合、部分条件からスキル全体の高／低を決めません。
