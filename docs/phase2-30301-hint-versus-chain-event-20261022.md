# Phase 2：30301のヒント行と連続イベント段階を誤統合しない（2026-10-22）

## 固定出典と正確な差分

カードID **30301**（SSRグランアレグリア）の固定Checker（`Cilda/UmaUmaChecker@8cf9fcb3cc7239041161be75c84daf9f8f22d29f`）には5つの候補行があり、固定GameTora（`systemless10/UmamusumePS@6e38b54af4fad397ff4491e63007a90705a4fe67`）にも5つの元イベントがある。**数が同じでも、全5イベントの同一性が保証されたわけではない。**

- 両出典で確かに同じ名称として1対1に対応するのはCheckerの位置2→GT位置3、3→5、4→1、5→2の**4イベント**。
- **Checker位置1**：GameWithと共通の表題「成長のヒント」。`選択肢なし`の1行に通常スキル「足任せ」のヒントLv4と絆増分が記載される。固定Checkerでの数値的識別子は`checker:30301:3b1cb9d61ef50cb538c9`。Checkerの資料には連続イベントの欄に置かれているものの、これが本当に固有の連続イベント段階であるかは未確認。
- **GT位置4／ローカルイベントID1294／連続第2段階**：**実選択肢が上下2つ**。上は体力等、下は数値スキルID**203352**のヒントLv**1**等（それぞれ効果配列を別々に保持）。[ゲームエイトの同カード記事](https://game8.jp/umamusume/785657)はこの二択を掲載し、[現在のGameToraのカード記事](https://gametora.com/ja/umamusume/supports/30301-gran-alegria)も連続3段階の第2イベントを同じ見出しで収録する。
- [GameWithカード別記事](https://gamewith.jp/uma-musume/article/show/561921)は、Checkerと同じ1行を連続の欄に載せる一方、[GameWithの足任せスキル別記事](https://gamewith.jp/uma-musume/article/show/489524)では**同カードは練習ヒントの提供元であり、該当スキルのイベントヒント提供カードではない**と区別する。これは「練習ヒントを連続イベントと取り違えた疑い」を強めるが、内部データの作成過程・実ゲームの直接確認ではない。

以上よりChecker位置1とGT位置4を**同一イベントとしてペア化しない**。両出典の全件インデックス上のChecker-only1とGT-only1を個別に残す。データが衝突するこの位置について、`CROSS_SOURCE_EVENT_IDENTITY_CONFLICT`、疑義`CHECKER_CHAIN_ROW_MAY_BE_TRAINING_HINT`、`mustNotPair:true`を監査行に記録する。**「練習ヒント起源」という説明も確定済みゲーム事実に昇格させない。**
