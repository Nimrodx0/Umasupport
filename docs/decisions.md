# 要件意思決定ログ

更新日：2026-10-16

要件の詳細は [requirements.md](requirements.md) を正本とする。本書には対話で確定した判断と理由を記録する。

| No. | 確定事項 |
|---:|---|
| 1 | 自動最適化はせず、デッキは利用者が手動構築する |
| 2 | 成否依存など条件付きのイベント報酬も区別して扱う |
| 3 | 統合表とデッキ左右比較の両表示 |
| 4 | 選択式イベントは未設定を初期値とし、未選択ルートの報酬を数えない |
| 5 | 選択肢のない到達可能イベントは自動集計 |
| 6 | 金・下位白スキルを別々に集計し関連表示 |
| 7 | 継承デッキにも金・白両方を表示し、因子化対象フィルターを追加 |
| 8 | 目標スキルの登録とカバー確認 |
| 9 | 目標ごとに本育成／継承育成／どちらか／両方を指定 |
| 10 | サポカ以外からの獲得経路は集計対象外 |
| 11 | 本育成・継承育成デッキは独立して複数保存・複製 |
| 12 | デッキ外を含む全カードからのスキル逆引き |
| 13 | 所持・未所持・未登録と性能解放0〜4段階を管理 |
| 14 | ゲーム内の標準スキル表示順を優先。難しければ五十音順 |
| 15 | ヒントLv・ヒント発生率などの性能を表示 |
| 16 | 6枠は対等でレンタル専用枠なし |
| 17 | デッキごとの性能解放段階を設定。サポカレベル設定なし |
| 18 | 不完全なカードデータも利用可能にして欠損を明示 |
| 19 | 検証済みデータをアプリに同梱。ブラウザによる都度取得なし |
| 20 | キャッシュとオフライン時の既存データへのフォールバック |
| 21 | 設定のJSONエクスポート／インポート |
| 22 | 名前付き目標スキルセットを複数保存・切り替え |
| 23 | カード入替・編成差分の履歴表示は不要 |
| 24 | イベント選択はカード詳細とデッキ一括設定の両方から操作 |
| 25 | 提供枚数中心／サポカ画像付きの表示密度切替 |
| 26 | 未カバーの目標スキルもメイン一覧に表示 |
| 27 | 上位スキル経由の間接カバーを直接カバーと区別 |
| 28 | 画像グリッドによる所持サポカの一括登録画面 |

## 後続の追加決定

- 金スキルの直下に下位白スキルをインデントと枝線で表示する（v2）。
- ユーザー向け「カード台帳を取得」ボタンは廃止。データ更新は開発・配信側で行う（v5）。
- **全サポートカード対応**を完成時の必須目標とする。カードが選べるだけでは不十分で、通常ヒント・イベント経路まで整備する。
- 表記ゆれによる重複はレビュー済みエイリアスで統合し、別カードを誤統合しない。ID移行も維持する（v8.1）。
- 未照合のR「タッカーブライン」は一旦保留する（2026-10-16）。
- このGitHubレポジトリを今後の仕様・実装・開発履歴の正本とする（2026-10-16）。

**運用原則：** 決定事項と実装済み事項は別であり、各機能について未実装・部分実装・検証済みを区別する。仕様変更したら日時・理由・影響範囲を追記する。
