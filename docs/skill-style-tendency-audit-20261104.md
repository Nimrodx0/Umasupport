## 1. ユーザーと合意した判断

- 「他の脚質でも発動しうる」は、**どの脚質に向く傾向があるか**を示すうえで保留の理由にしない。一般的なレース中の脚質ごとの位置取りを根拠に、合理的な傾向なら積極的に推定する。
- 明示条件 → AND/ORを保全した発動状況 → ゲームシステムに基づく脚質傾向、の順に推定する。
- **上昇気流**の「終盤前半・後方50%」は、差し・追込寄りの定性的推定を付ける。**ギアシフト**の「中盤・上位50%以内」は逃げ・先行寄りとする。
- この推定は「逃げ専用／差し専用」等の厳格なゲーム内作戦制限ではなく、発動機会についての**定性的な傾向**。数値の発動率は計算しない。
- `order_rate>=40`、`30～80`のように前方から後方まで広く含む条件は、これだけで後方脚質向きとは決めず、別の要因を併せて調べる。
- 発動後の効果の実用性も重要な別軸だが、データを確認し、判断方式が簡潔に成り立つまでユーザーの判断に委ねる。

## 2. 実装したP2第一版

入力はP1 `skill.activationProfile`（厳格なID・名称照合済み）の構造化条件とP2 `skill_rank_timing.js`。元の `conditions`（ORの各AND経路）と `preConditions`・`Invoke` を保持したまま推定する `poc/src/skill_style_tendency.js` を新設。

| 元条件（同じANDの順位帯と局面） | 推定 | 規則ID |
| --- | --- | --- |
| `order_rate<=50`（または明確にその内側の範囲） | 逃げ・先行寄り | `P2-RANK-AT-MOST-50-v1` |
| `order_rate>50`（または明確にその内側の範囲） | 差し・追込寄り | `P2-RANK-OVER-50-v1` |
| `order_rate>=40`など両帯域にまたがる範囲 | 要追加解析 | なし |
| 順位条件だけ／局面条件だけ／未照合 | 推定不能・未収録等を区別 | なし |

上記は条件を満たす**傾向の分類**であり、脚質別の順位確率を実測したものではない。序盤・中盤・終盤という発動局面の値と、`phase_random`の抽選／局面内前後半の意味は保持する。

**全体推定の許可条件**：1つの`Invoke`内に発動用の複数OR経路がある場合、**各経路を個別解析**し、**全経路が同じ方向**の傾向で、他馬依存など未評価の追加条件がなければ全体へ付ける。異なる方向が混在、別のOR経路が解析不能、追加の追い抜き／ブロック条件、`preConditions`に未解釈の条件、複数`Invoke`等は全体推定を保留する。**単純な例外があり得ること**と、**条件式の解釈がまだできていないこと**を別扱いする。

- 明示 `running_style` 条件か、ゲーム説明の認識済み作戦タグがある場合は`explicit-only`に分類し、推定と混同しない。
- 固定版ソースに未収録のスキルは`unavailable`。順位と局面が揃わないものは`not-inferable`、他条件との組合せ等の検討を要するものは`needs-review`。
- 論理枝の根拠 `sourceConditions`、`invokeIndex`、`orIndex`、局面ウィンドウ、規則ID、推定の脚質名をメタデータとして保持。
- ブラウザ起動時に`UmaSkillStyleTendency.attach(model)`を独立に実行。既存の通常ヒント、イベント、獲得候補、所持・検索・保存設定等は変更しない。**新しい検索フィルター・サポカ上のラベル表示はP4の対象**。

## 4. 監査・出典の限界

- [UmaSim固定`RaceState.kt`](https://github.com/mee1080/umasim/blob/f6e4501ee6c6c2d4ac8698e7796e309d31575bde/race/src/commonMain/kotlin/io/github/mee1080/umasim/race/calc2/RaceState.kt)と[SkillChecker.kt](https://github.com/mee1080/umasim/blob/f6e4501ee6c6c2d4ac8698e7796e309d31575bde/race/src/commonMain/kotlin/io/github/mee1080/umasim/race/calc2/SkillChecker.kt)：局面0～3の判定と抽選コードの意味。元条件`order_rate`は[SkillData.kt](https://github.com/mee1080/umasim/blob/f6e4501ee6c6c2d4ac8698e7796e309d31575bde/race/src/commonMain/kotlin/io/github/mee1080/umasim/race/data2/SkillData.kt)に記録されるが、シミュレーターでは順位判定が省略される場合があるため、出典データを元条件として読む。
- [ゲームエイト作戦の脚質・速度差（2026-09-24更新）](https://game8.jp/umamusume/459899)：序盤は逃げ・先行が前方を取りやすく、後方脚質は終盤に向けて追い上げる、という一般的な解釈の根拠。[ウマ娘スクールのポジションキープ解説](https://umamusumeschool.com/position_keep/)は、脚質人数・先頭脚質が不在の場合などの例外を確認する参照。ただし古い解析内容が含まれるため、実際の順位割合ごとの発動率の直接根拠にはならない。
- **定性的傾向の根拠**と、**厳格に正しい発動確率／ゲーム現行仕様の保証**を混同しない。現行ゲーム実機による発動率検証・順位分布シミュレーションは実施していない。
- **A**：人工的なAND/OR、前提条件、複数Invoke、明示作戦、情報欠損と、元の順位帯からの判定をテスト。
- **B**：固定2,162件全件・アプリ881件の状態が合計一致。実在4スキルの判定結果を確認。
- **C**：GitHub ActionsのChromium自動操作で新たな内部メタデータを検証。新規UI表示もWindows/Android物理端末確認も今回未実施。
