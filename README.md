# Uma Support Lab

ウマ娘 プリティーダービーの**本育成／継承育成**で使う2つのサポートカード編成を、スキル獲得経路・重複・イベント選択・目標スキルの観点から可視化・比較するブラウザアプリを開発するプロジェクトです。

> 開発段階：PoC v8.1（2026-10-16）。通常ヒントのデータ取り込みは進展しましたが、イベント分岐・現行全カードの網羅・配布条件は未検証の部分があります。実用上の判断を保証する完成品ではありません。

## ソースコードの取り扱い

以前の検証版v8.1は単一HTML＋JavaScript＋Python変換スクリプトで動作します。React/TypeScript/Viteは**将来の本実装案**であって、現行のPoCで採用済みではありません。

要件・開発記録に加え、[PoCのプログラム／テスト／架空デモ](poc/README.md)も登録済みです。架空データだけの[demo.html](poc/demo.html)を使えば、実ゲーム由来のデータを配布せずに画面や集計ロジックを確認できます。完全なv8.1データ版の再ビルドには、まだ非公開の入力データが必要です。詳細は[poc/README.md](poc/README.md)を参照してください。第三者データ・イベント文章・画像の再配布条件は確認が必要です。

本プロジェクトは非公式のファン制作ツールです。Cygamesの公式プロジェクトではありません。

## GitHub Pagesで公開する

GitHubの **Settings → Pages → Build and deployment** で、**Source: Deploy from a branch**、**Branch: main**、**Folder: /(root)** を指定して **Save**。

公開URL: https://nimrodx0.github.io/Umasupport/

ルートの `index.html` は `poc/live.html` への入口です。現行のアプリ本体は `poc/live.html` と `poc/src/` にあり、`poc/demo.html` は架空データのテスト画面です。ゲームデータはアプリ起動時に外部公開元からブラウザが直接取得するため、初回はネット接続が必要です。2026-10-16にGitHub Pages上での通常起動・公開元データ読込・表示をユーザーが実ブラウザで確認済みです。GitHub ActionsのPoCテストとPagesデプロイも最新mainで成功。**IndexedDBの保存内容・オフライン再読込は未検証**で、[Issue #1](https://github.com/Nimrodx0/Umasupport/issues/1)で追跡します。

## 保存設定の互換性

- 現行データにないカード・目標スキルIDは削除せず「未収録」と表示し、集計には加えない。
- レビュー済みのIDエイリアスだけを変換する。旧v8.1の全エイリアス表は未移植で、全面互換ではない。
- 不正な保存設定は上書き前に退避を試み、JSONダウンロードを案内する。
- ユーザー設定はlocalStorage、取得したゲームデータはIndexedDBに別々に保存する。
