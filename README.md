# Uma Support Lab

ウマ娘 プリティーダービーの**本育成／継承育成**で使う2つのサポートカード編成を、スキル獲得経路・重複・イベント選択・目標スキルの観点から可視化・比較するブラウザアプリを開発するプロジェクトです。

> 開発段階：PoC v8.1（2026-10-16）。通常ヒントのデータ取り込みは進展しましたが、イベント分岐・現行全カードの網羅・配布条件は未検証の部分があります。実用上の判断を保証する完成品ではありません。

## ソースコードの取り扱い

以前の検証版v8.1は単一HTML＋JavaScript＋Python変換スクリプトで動作します。React/TypeScript/Viteは**将来の本実装案**であって、現行のPoCで採用済みではありません。

要件・開発記録に加え、[PoCのプログラム／テスト／架空デモ](poc/README.md)も登録済みです。架空データだけの[demo.html](poc/demo.html)を使えば、実ゲーム由来のデータを配布せずに画面や集計ロジックを確認できます。完全なv8.1データ版の再ビルドには、まだ非公開の入力データが必要です。詳細は[poc/README.md](poc/README.md)を参照してください。第三者データ・イベント文章・画像の再配布条件は確認が必要です。

本プロジェクトは非公式のファン制作ツールです。Cygamesの公式プロジェクトではありません。

## 開発版の保存設定

- 一般公開前の開発段階では、旧カードID・旧スキルIDの保存設定移行や後方互換処理を行わない。
- 設定の形式と現在のデータに存在するカード・スキルIDを検証する。不正な場合はエラーを表示し、確認付きで初期化できる。確認前に保存値は上書きしない。
- 手動の設定JSON保存・読込は維持するが、復旧用の自動バックアップやダウンロードUIは設けない。
- ゲームデータのIndexedDBキャッシュと、通信障害時の検証済みデータへの復帰は今までどおり必要。

## 実イベントソースの照合監査

[実イベントデータの照合記録](docs/event-source-audit.md) に、候補45枚のIDと名称がUmaSimと一致し、126イベント中124件でカードIDを特定できた結果を記載しています。元データに連続イベントの依存・打ち切り情報が不足し、正式スキルIDや利用条件も未確認です。`node poc/tools/audit_events.cjs` は開発者向けに元データを直接読み取って再監査します。公開アプリには実イベントを導入していません。

**イベントデータの今後の優先課題：** まず [網羅的な供給元の選定](docs/event-source-selection.md) とカード別収録率を調査し、それが済んでから実イベントを段階的に導入します。現時点で主ソースは未決定です。

## 全サポカ向けイベントソースの調査

[供給元の全件測定](docs/event-source-selection.md) で `umaumacruise_customjson` の466カード見出し・1,403イベントを実測し、UmaSimの563枚に対する名前＋レアリティ一致442枚を確認しました。現時点では**ゲーム内ID・連続イベントの構造化・利用条件が不十分なため主データ元は未決定**。開発者は `node poc/tools/audit_cruise_source.cjs` でデータを公開元から直接取得して再監査できます（ゲームデータをリポジトリに含めません）。

追加調査によりUmaUmaCheckerの日本語イベントJSONはSSR・SRのカード見出し417/417枚と一致。ただしSSR5枚のイベント記録が空で、イベントありは412/417。詳しくは[イベントデータソース比較](docs/event-source-selection.md)。

**イベント収録の追加検証：** 5枚の空レコードはGame8／U-toolsで参照ページを確認でき、既存412枚ではイベントタイトルの差分検査を追加しました。結果と未照合の11枚は[供給元の調査記録](docs/event-source-selection.md)にあります。実ゲームイベントは公開版にまだ取り込んでいません。

## ウマサルタント独自イベントDB（初期基盤）

[公開イベントDBの構築・レビュー手順](docs/checker-public-catalog.md) を追加しました。UmaUmaCheckerのSSR・SRイベントを候補として取り込み、個別に承認した事実データのみを poc/data/reviewed_events.v1.json に公開する構成です。通常ヒントは引き続きUmaSimから起動時取得。実イベントの公開収録は**まだ0件**で、欠損・新規カードはGameWithの個別記事を使って補完する予定です。U-toolsは当面利用しません。

SSR・SRの表記差24件を[明示的な対応表](docs/checker-aliases-and-gaps.md)として整理し、UmaUmaCheckerの417枚全件をUmaSimのカードIDに対応付けました。候補イベント2,099件を検出しましたが、SSR5枚はイベント0件で、GameWithにも詳細「検証中」のカードがあります。実イベント公開DBはまだ0件です。

欠損SSR5枚のうち4枚でGame8のイベント段階・スキル報酬位置を確認し、[文章を含まない事実候補](docs/game8-missing-ssr-review.md)として構造化しました。残るジャングルポケットは報酬未確認。**公開イベントDBはまだ実イベント0件**です。


**スキルID照合の進捗（2026-10-16）：** Game8による欠損SSR4枚のスキル報酬とジャングルポケットの獲得スキルを、[UmaSim数値IDと照合](docs/skill-id-candidate-audit.md)しました。14種類中13種類はUmaSimで厳密一致、残る「逃げためらい」は別資料からの暫定IDです。通常ヒントの名前IDとの統合・分岐検証は未着手のため、公開DBへの実イベント登録は引き続き0件です。
